# 1. 背景意图 (Background)

`ExchangeRateAdminAppService` 的列表接口 `GetPagedListAsync` 此前只返回 `CurrencyId`（币别id），前端展示时需要再额外请求币别接口才能拿到币别代码。本次让列表接口**额外返回每行 `CurrencyId` 对应 `App_Currencys` 表的 `Code`（币别代码）**，方便前端直接展示，无对应币别时为 `null`。

# 2. 核心逻辑变更 (Core Logic)

涉及文件：

- `src/CsprojBuilder.Application/App/ExchangeRate/ExchangeRateAdminAppService.cs`
- `src/CsprojBuilder.Application/App/ExchangeRate/Dto/ExchangeRateDto.cs`

## 2.1 DTO 变更

`ExchangeRateDto` 在“额外字段”区域新增：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `CurrencyCode` | `string` | `CurrencyId` 对应 `Currency` 表的 `Code`（币别代码），无则 `null` |

## 2.2 解析逻辑

1. 构造函数新增注入 `IRepository<Entites.Currency, long> _currencyRepository`。
2. `GetPagedListAsync` 分页取出 `items` 后，提取本页 `CurrencyId` 去重，一次性 `_currencyRepository.GetAll().Where(c => currencyIds.Contains(c.Id)).Select(c => new { c.Id, c.Code })` 批量查询币别代码。
3. 映射 `ExchangeRateDto` 后按 `CurrencyId` 回填 `CurrencyCode`。

> 采用“当前页批量查询 + 内存匹配”的方式，避免在循环内逐条查库（N+1），与发票申请等模块返回 `CurrencyCode` 的写法保持一致。

# 3. 避坑指南 (Pitfalls)

- **命名冲突**：`Currency` 实体与 `CsprojBuilder.App.Currency` 命名空间撞名，注入与查询时须使用全限定 `Entites.Currency`。
- **仅列表接口改动**：本次只调整列表 `GetPagedListAsync`；如详情 `DetailAsync` 也需返回币别代码可按同样方式补充。
- **无数据返回 `null`**：当 `CurrencyId` 在币别表中查不到时，`CurrencyCode` 为 `null`。
