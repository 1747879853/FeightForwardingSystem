# 客户对账-选费用支持多销售多操作多客服-前端对接文档-2026-08-14

## 1. 接口概览

| 项   | 值                                                       |
| :--- | :------------------------------------------------------- |
| 名称 | 可对账费用按业务分组列表（对账单加费用时的「选择费用」） |
| 方法 | `GET`                                                    |
| 地址 | `/api/services/app/StatementAdmin/GetOrderFeeGroupAsync` |
| 权限 | `Admin.Statement.Get` + `Admin.OrderFee.Get`             |
| 返回 | `PagedList<TransportOrderDto>`                           |

## 2. 破坏性变更（必改）

关联人员筛选由单选改为多选，**原单选字段已删除**：

| 原参数 | 原类型 | 新参数 | 新类型 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `saleId` | long? | `saleIds` | long[] | 销售，多选，命中任一即返回 |
| `operatorId` | long? | `operatorIds` | long[] | 操作，多选，命中任一即返回 |
| `customerServiceId` | long? | `customerServiceIds` | long[] | 客服，多选，命中任一即返回 |

> [!IMPORTANT] 旧参数继续传**不会报错**，会被静默忽略，表现为「选了筛选条件但结果没过滤」。请全局搜索这三个旧参数名并全部替换。

**传参格式**：GET 查询串必须重复键名，不能用逗号拼接。

```text
正确：?settlementId=xxx&saleIds=101&saleIds=102&operatorIds=205
错误：?settlementId=xxx&saleIds=101,102
```

**筛选组合语义**：不同字段之间是「且」，同一字段内的多个 id 之间是「或」。例如 `saleIds=[101,102]&operatorIds=[205]` 表示「销售是 101 或 102」**且**「操作是 205」的业务。

**顺带修复**：这三个筛选此前后端比对的是关联人员子表的行主键而不是用户id，实际筛不出正确数据。本次已修正为按用户id筛选，前端传的仍然是**用户id**（`User.Id`，即业务详情里 `orderUsers[].userId` 的值），传参口径不变。

## 3. 完整入参（`GetOrderFeeGroupInputDto`）

### 3.1 分页与排序

| JSON | 类型 | 必填 | 默认 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `pageIndex` | int | 否 | `1` | 当前页码，从 1 开始 |
| `pageSize` | int | 否 | `10` | 每页记录数，范围 1~100000 |
| `sorting` | string | 否 | `CreationTime DESC` | 排序表达式，作用于业务（`TransportOrder`） |

### 3.2 费用条件

| JSON | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `settlementId` | Guid | **是** | 结算对象（客户id），只返回该结算对象的费用 |
| `includeStatemented` | bool? | 否 | 不传/`false`：只返回从未对账过的费用；`true`：把已在其他对账单里的费用也返回（多次对账） |
| `statementId` | Guid? | 否 | 给已有对账单加费用时传，排除本对账单已包含的费用；新建对账单不传 |
| `feeCodeIds` | long[] | 否 | 费用名称id集合，只返回这些费用名称 |
| `exceptFeeCodeIds` | long[] | 否 | 要排除的费用名称id集合 |
| `paySide` | enum? | 否 | 收付类型 |
| `feeStatus` | enum? | 否 | 费用状态 |
| `settlementStatus` | enum? | 否 | 结算状态 |
| `invoiceStatus` | enum? | 否 | 开票状态 |
| `currencyId` | long? | 否 | 币别id |
| `accountDateStart` | DateTime? | 否 | 会计期间起（含），只比较到月 |
| `accountDateEnd` | DateTime? | 否 | 会计期间止（含），只比较到月 |

### 3.3 业务条件

| JSON | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `clientId` | Guid? | 否 | 委托单位id |
| `keyword` | string | 否 | 编号模糊匹配，覆盖委托编号 `commissionNum`、主提单号 `mblNum`、订舱号 `bookingNum` |
| `bizType` | enum? | 否 | 业务类型（海运出口/海运进口/空运出口等） |
| `etdStart` | DateTime? | 否 | 开船日期起（含） |
| `etdEnd` | DateTime? | 否 | 开船日期止（含） |
| `polId` | long? | 否 | 起运港id，**仅对海运出口业务生效** |
| `podId` | long? | 否 | 目的港id，**仅对海运出口业务生效** |
| `orgId` | long? | 否 | 组织id，自动包含该组织的全部下级组织 |
| `saleIds` | long[] | 否 | **本次新增**，销售用户id集合，多选 |
| `operatorIds` | long[] | 否 | **本次新增**，操作用户id集合，多选 |
| `customerServiceIds` | long[] | 否 | **本次新增**，客服用户id集合，多选 |
