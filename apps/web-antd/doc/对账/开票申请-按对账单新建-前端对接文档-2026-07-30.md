# 开票申请 — 按对账单新建（前端对接）

**变更日期**：2026-07-30

## 接口

| 项 | 内容 |
|------|------|
| 方法 | `AddByStatementAsync` |
| 路由 | `POST /api/services/app/InvoiceApplicationAdmin/AddByStatementAsync` |
| 权限 | `Admin.InvoiceApplication.Add` + `Admin.Statement.Edit`（须同时具备） |

## 入参

```json
{
  "statementId": "对账单Guid"
}
```

## 返回

```json
[
  "开票申请Id1",
  "开票申请Id2"
]
```

说明：后端会按**费用币别自动拆分**，所以可能返回 1 个或多个开票申请 Id。

## 后端固定行为

1. 只接受对账单下**应收**费用；若存在应付，报：`存在应付费用 不可提交开票申请`。
2. `OrgId` 取当前登录用户默认组织；未配置时报：`对账单未设置所属组织`。
3. 银行不填、商品明细为空、发票类型固定 `p`，所属人/组织沿用对账单。
4. 每条费用申请额直接取最大可开票额度 `remaining`。

## 前端注意

1. 成功后应逐条进入开票申请详情补商品明细、银行等提交所需信息。
2. 不要假设只返回一个 Id；多币别对账单会拆成多张申请。
