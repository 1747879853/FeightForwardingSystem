# 客户对账-详情返回PaySide-前端对接文档-2026-07-30

路由前缀：`/api/services/app/StatementAdmin`  
权限：`Admin.Statement.Get`

---

## 1. 详情 — `GET /api/services/app/StatementAdmin/DetailAsync`

### 入参

| 字段 | JSON | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 对账单id | `id` | Guid | 是 | 对账单主键 |
| 是否打印 | `isPrint` | bool? | 否 | 打印场景扩展字段 |

### 出参新增/补齐（`StatementDto` 头）

| 字段 | JSON | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 收付类型 | `paySide` | int | 按对账单下全部费用汇总，规则见下表 |

> 费用行上的 `orderFeeGroups[].orderFees[].paySide` 仍是单条费用收付枚举（收/付），勿与对账单头汇总 `paySide`（0/1/2）混用。

---

## 2. 汇总规则

| 值 | 含义 |
| :--- | :--- |
| `0` | 全部为收 |
| `1` | 全部为付 |
| `2` | 收付都有 |

判定：对账单下费用是否包含收、是否包含付；两者都有则为 `2`，仅付为 `1`，否则为 `0`。

---

## 3. 前端适配清单

- [ ] 详情页对账单头展示收付类型汇总 `paySide`
- [ ] 文案：`0`全部为收 / `1`全部为付 / `2`收付都有
- [ ] 勿与费用行 `paySide`（收/付枚举）混用
