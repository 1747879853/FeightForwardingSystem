# 集装箱信息-柜型字段-前端接口文档-2026-08-14

**变更日期**：2026-08-14 **受众**：前端 **性质**：新增字段（新建/编辑入参新增必填枚举，列表/详情/箱型简易对象出参新增字段）

路由前缀：`/api/services/app/CtnCodeAdmin`

---

## 1. 新增字段

| 字段        | JSON          | 类型                      | 含义 |
| :---------- | :------------ | :------------------------ | :--- |
| CabinetType | `cabinetType` | int 枚举 `CtnCabinetType` | 柜型 |

枚举取值：

| 值  | 含义   |
| :-- | :----- |
| 0   | 普柜   |
| 1   | 特种柜 |

说明：

- 不可为空。新建/编辑必传，传 0/1 以外的值报「柜型输入错误」。
- 不传时后端按 0（普柜）处理，若业务要求强制选择请在前端表单做必填校验。
- 存量数据默认全部为 0（普柜），需业务侧人工调整特种柜。

## 3. 新建 — `AddAsync`

**POST** `/api/services/app/CtnCodeAdmin/AddAsync`

入参（`CtnCodeAddDto`，Body）：

| 字段 | JSON | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| 集装箱类型 | `ctnSize` | string | 否 | 最长 1024 |
| 集装箱尺寸 | `ctnType` | string | 否 | 最长 1024 |
| 表现形式 | `ctnName` | string | 是 | 如 20GP/40GP/40HQ，为空报「集装箱信息名称不能为空」 |
| **柜型** | **`cabinetType`** | **int 枚举** | **是** | **新增。0普柜 1特种柜** |
| EDI代码 | `ediCode` | string | 否 | 最长 1024 |
| 箱皮重 | `ctnWeight` | decimal | 否 | 2 位小数 |
| 中文说明 | `cnExplain` | string | 否 | 最长 1024 |
| 英文说明 | `enExplain` | string | 否 | 最长 1024 |
| AFR代码 | `afrCode` | string | 否 | 最长 1024 |
| 默认限重 | `limitWeight` | decimal | 否 | 2 位小数 |
| TEU | `teu` | int | 否 | 箱量折算系数 |
| 排序号 | `orderNo` | int? | 否 |  |
| 状态 | `status` | int | 否 | 0启用 1禁用 |
| 是否默认展示列 | `isDefault` | bool | 否 |  |
| 备注 | `remark` | string | 否 | 最长 1024 |

出参：`long`，新建记录的主键 id。

## 7. 箱型简易对象 `CtnCodeSimpleDto` 同步新增

| 字段       | JSON              | 类型         | 说明                    |
| :--------- | :---------------- | :----------- | :---------------------- |
| 主键id     | `id`              | long         | 箱型id                  |
| 表现形式   | `ctnName`         | string       | 如 20GP/40GP            |
| **柜型**   | **`cabinetType`** | **int 枚举** | **新增。0普柜 1特种柜** |

| 集装箱尺寸 | `ctnType`         | string       |                         |
| TEU        | `teu`             | int          |                         |

```json
{
  "ctnCodeId": 12,
  "ctnCode": {
    "id": 12,
    "ctnName": "40RF",
    "cabinetType": 1,
    "ctnSize": "40",
    "ctnType": "RF",

  }
}
```
