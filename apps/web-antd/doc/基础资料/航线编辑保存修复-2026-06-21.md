# 1. 背景意图 (Background)

选择一条航线数据，修改其航线代码(Code)等字段后点击保存，接口返回成功但实际内容未保存。原因是 `LaneCodeAdminAppService.EditAsync` 只回写了 `Status` 一个字段，`Code/LaneName/LaneEnName/EdiCode` 均未从入参赋值到实体，导致除状态外的修改全部丢失。

# 2. 核心逻辑变更 (Core Changes)

`src/CsprojBuilder.Application/App/LaneCode/LaneCodeAdminAppService.cs` 的 `EditAsync`：

- 在保存前补齐字段赋值：`Code`、`LaneName`、`LaneEnName`、`EdiCode`、`Status` 全部从 `LaneCodeEditDto` 写入实体后再 `UpdateAsync`。

# 3. 避坑指南 (Pitfalls)

- 该编辑方法采用手动逐字段赋值（非 `ObjectMapper.Map` 覆盖实体），新增可编辑字段时需同步在 `EditAsync` 中追加赋值，否则会再次出现“保存成功但不生效”。
- `LaneCodeEditDto` 已定义全部可编辑字段，但 DTO 有字段不代表服务端会保存，需以服务端赋值为准。
