# 1. 背景意图 (Background)

`CodeGoods` 表新增了 `CargoId` 字段(货物类型)。为保证前后端一致，需要同步调整商品信息(品名)模块接口：新增/编辑支持写入该字段，列表/详情支持返回该字段，且列表支持按该字段筛选。

# 2. 核心逻辑变更 (Core Changes)

## 2.1 数据结构变更

| 位置                | 变更内容                                         |
| :------------------ | :----------------------------------------------- |
| `CodeGoodsAddDto`   | 新增字段 `CargoId: CargoType`，用于新增接口写入  |
| `CodeGoodsEditDto`  | 新增字段 `CargoId: CargoType`，用于编辑接口写入  |
| `CodeGoodsDto`      | 新增字段 `CargoId: CargoType`，用于列表/详情返回 |
| `CodeGoodsQueryDto` | 新增字段 `CargoId: CargoType?`，用于列表查询条件 |

## 2.2 查询与持久化逻辑变更

| 位置 | 变更内容 |
| :-- | :-- |
| `CodeGoodsAdminAppService.EditAsync` | 新增赋值 `codeGoods.CargoId = input.CargoId;` |
| `CodeGoodsAdminAppService.GetPagedListAsync` | 新增筛选 `.WhereIf(input.CargoId.HasValue, m => m.CargoId == input.CargoId.Value)` |

# 4. 字段说明 (Field Definitions)

| 字段名 | 类型 | 方向 | 说明 |
| :-- | :-- | :-- | :-- |
| `cargoId` | `CargoType` / `CargoType?` | 请求+响应 | 货物类型。新增/编辑必传；列表查询可选；列表/详情返回 |

> `CargoType` 枚举定义：`S=普通货`、`R=冻柜`、`D=危险品`、`O=超限箱`。

# 5. 前端联调说明

- 新增与编辑页面提交参数时补充 `cargoId`。
- 列表页查询区可新增“货物类型”筛选，传 `cargoId` 即可精确过滤。
- 详情页和列表列可直接读取返回的 `cargoId` 做枚举显示。

# 6. 避坑指南 (Pitfalls)

- `CargoId` 在实体中为非空枚举，新增/编辑接口需保证前端传值合法，避免使用未定义枚举值。
- 列表筛选为可选条件，不传 `cargoId` 时保持原有查询行为不变。
