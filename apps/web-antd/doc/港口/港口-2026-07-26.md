# 背景意图

前端选港场景需要一份**登录即可访问、不分页**的港口全量列表，并带出关联国家英文名，避免走带权限的 `PortCodeAdmin` 分页接口。

# 核心逻辑变更

1. 新增 `PortCodeAppService` / `IPortCodeAppService`，仅 `GetListAsync`。
2. 权限：`[AbpAuthorize]`，无业务权限点。
3. 出参新建 `PortCodeListItemDto`；JSON 字段精简为单字母：`i`/`p`/`c`/`e`（id/portName/cnName/countryEnName）。
4. 查询：`AsNoTracking`，按 `PortName`、`Id` 排序，不按 `Status` 过滤。

# 避坑指南

- 接口地址是 **`/api/services/app/PortCode/GetListAsync`**，不是 `PortCodeAdmin`。
- 前端须按单字母字段取值（`i`/`p`/`c`/`e`），不是 `id`/`portName` 等全名。
- 不改动既有 `PortCodeSimpleDto`，避免影响外键组装场景。
- 若业务只要启用港（`Status=0`），当前接口不会过滤，需前端处理或再改服务端。
