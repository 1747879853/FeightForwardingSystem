# 1. 背景意图 (Background)

**业务需求：** 客户列表 `GetPagedListAsync` 此前只能按关键字、行业类别筛选。本次新增按「客户合作状态」（`ClientCoopStatus`）和「供应商合作状态」（`SupplierCoopStatus`）筛选，且两个条件均支持**多选**（例如同时筛选「正式」+「暂停合作」）。

**涉及改动：**

- 列表查询 DTO 新增两个多选参数。
- 列表接口按多选集合过滤。

# 2. 核心逻辑变更 (Core Logic Changes)

## 2.1 DTO

文件：`src/CsprojBuilder.Application/App/Client/Dto/ClientDto.cs`

`ClientQueryDto` 新增两个字段：

- `List<CoopStatus> ClientCoopStatus`：客户合作状态多选，为空不筛选。
- `List<CoopStatus> SupplierCoopStatus`：供应商合作状态多选，为空不筛选。

## 2.2 客户接口 (ClientAdminAppService)

文件：`src/CsprojBuilder.Application/App/Client/ClientAdminAppService.cs`

`GetPagedListAsync` 查询新增两个 `WhereIf`：

- 当 `ClientCoopStatus` 非空时：`input.ClientCoopStatus.Contains(m.ClientCoopStatus)`。
- 当 `SupplierCoopStatus` 非空时：`input.SupplierCoopStatus.Contains(m.SupplierCoopStatus)`。

# 3. 接口参数说明 (API)

**GET** `/api/services/app/ClientAdmin/GetPagedListAsync`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 关键字，模糊匹配 简称/代码/全称/英文名/备注 |
| industryCategory | string | 否 | 行业类别 |
| clientCoopStatus | CoopStatus[] | 否 | 客户合作状态多选，为空不筛选 |
| supplierCoopStatus | CoopStatus[] | 否 | 供应商合作状态多选，为空不筛选 |
| pageIndex / pageSize / sorting | - | 否 | 分页与排序 |

**CoopStatus 枚举：** `0=潜在, 1=正式, 2=暂停合作, 3=黑名单`

**多选传参示例：**

```
GET /api/services/app/ClientAdmin/GetPagedListAsync?clientCoopStatus=1&clientCoopStatus=2&supplierCoopStatus=1
```

（筛选：客户合作状态为「正式」或「暂停合作」，且供应商合作状态为「正式」）

# 4. 避坑指南 (Pitfalls)

- **多选为空即不筛选**：传空数组或不传该参数时，该维度不参与过滤。
- **两个条件为「与」关系**：`clientCoopStatus` 与 `supplierCoopStatus` 同时传入时取交集（同时满足）；各自内部为「或」关系（多选）。
- **枚举值传数字**：GET 请求传枚举的整数值，重复同名参数即为多选数组。
