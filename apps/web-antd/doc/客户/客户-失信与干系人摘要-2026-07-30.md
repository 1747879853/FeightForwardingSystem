# 1. 背景意图 (Background)

**白话解释：** 业务侧（登录即可）需要按客户 Id 快速拿到失信状态、业务来源，以及干系人（销售/客服/操作/单证四组），不必调用需 Admin 权限的完整详情接口。

# 2. 核心逻辑变更 (Core Changes)

- 新增 DTO：`ClientDishonestStakeholderDto`
- 新增接口：`ClientAppService.GetDishonestStakeholdersAsync`
- 干系人四组划分与 `ClientAdminAppService.DetailAsync` 一致（按 `UserAttribute`）
- 查询走 `AsNoTracking`，并复用 `ClientListDataPermissionFilterAsync`

| 接口 | 方法 | 地址 |
| :-- | :-- | :-- |
| `GetDishonestStakeholdersAsync` | `GET` | `/api/services/app/Client/GetDishonestStakeholders` |

# 3. 避坑指南 (Pitfalls)

> [!IMPORTANT]
>
> 1. 无权限或不存在时统一提示「客户不存在或无权限」。
> 2. 干系人昵称取 `NickName`，不是 `Name`/`UserName`。
> 3. `codeSource` 可空（客户未维护业务来源时为 null）。
