# 客户失信与干系人摘要 — 前端对接

**日期：** 2026-07-30  
**服务：** `Client`（登录即可，非 ClientAdmin）  
**接口：** `GET` `/api/services/app/Client/GetDishonestStakeholdersAsync`

## 入参

| 字段名 | JSON Key | 类型   | 必填 | 说明            |
| :----- | :------- | :----- | :--- | :-------------- |
| Id     | `id`     | `Guid` | 是   | 客户id（Query） |

## 出参 `ClientDishonestStakeholderDto`

| 字段名 | JSON Key | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| Id | `id` | `Guid` | 客户id |
| IsDishonest | `isDishonest` | `bool` | 是否失信 |
| CodeSource | `codeSource` | `CodeSourceSimpleDto` / null | 业务来源 |
| Sales | `sales` | `ClientStakeholderDto[]` | 干系人-销售 |
| CustomerServices | `customerServices` | `ClientStakeholderDto[]` | 干系人-客服 |
| Operations | `operations` | `ClientStakeholderDto[]` | 干系人-操作 |
| Documentations | `documentations` | `ClientStakeholderDto[]` | 干系人-单证 |

`ClientStakeholderDto` 常用字段：`id` / `clientId` / `userId` / `isDefault` / `userAttribute` / `userNickName`。
