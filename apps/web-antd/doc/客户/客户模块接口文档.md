# 0. 公共类型

## 0.1 `country`（`CountryCodeSimpleDto`）

列表、详情、结算银行在 `countryId` 有值且国家还在时返回。没选国家，或国家已被删，`country` 为 `null`。

| 字段            | 类型   | 说明                            |
| :-------------- | :----- | :------------------------------ |
| `id`            | long   | 国家id，与外层 `countryId` 相同 |
| `code`          | string | 国家唯一代码                    |
| `countryName`   | string | 国家中文名称                    |
| `countryEnName` | string | 国家英文名称                    |

```json
"country": {
  "id": 86,
  "code": "CN",
  "countryName": "中国",
  "countryEnName": "China"
}
```

# 1. 重复校验

**POST** `/api/services/app/ClientAdmin/CheckDuplicateAsync`

入参在请求体。有重复返回 `true`，没有返回 `false`。四个文本都为空（trim 之后）直接返回 `false`，不查库。

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `id` | Guid? | 否 | 编辑时传当前客户id，用来把自己排除掉。新建不传 |
| `name` | string | 否 | 简称。非空时全局判重 |
| `fullName` | string | 否 | 全称。非空时全局判重 |
| `enFullName` | string | 否 | 英文全称。非空时全局判重 |
| `taxNo` | string | 否 | 纳税人识别号。非空时只在同一 `countryId` 下判重 |
| `countryId` | long? | 否 | **2026-09-28 新增。** 税号判重用的国家。不传只和同样没填国家的客户比 |

税号判重要把当前表单上的 `countryId` 一起传。不传时，两个都选了中国、税号相同的客户，这个接口会返回 `false`，保存时仍会被拦住。

# 2. 新增

**POST** `/api/services/app/ClientAdmin/AddAsync`

权限 `Admin.Client.Add`。成功返回新客户 `Guid`。

## 2.2 与本次相关的报错

| 提示 | 触发 |
| :-- | :-- |
| 相同国家下纳税人识别号不能重复 | 同一 `countryId` 下已有相同 `taxNo`（都没填国家也算） |
| 国家不存在 | `countryId` 有值但查不到 |
| 合作客户简称不能重复 / 合作客户全称不能重复 / 合作客户英文全称不能重复 | 对应字段全局重复 |
| 合作客户简称不能为空 / 合作客户全称不能为空 | 必填为空 |
| 行业类别不能为空 | 没传行业类别 |

# 3. 编辑

**PUT** `/api/services/app/ClientAdmin/EditAsync`

权限 `Admin.Client.Edit`。成功返回 `true`。

入参与新增相同，另加必填 `id`（客户id）。`taxNo` 与 `countryId` 的判重规则与新增相同，排除自己。只有未提交、已驳回能直接编辑，其余状态要走申请修改。

申请修改、申请修改审核通过用的是同一套校验，税号同样按国家判重。申请修改的地址和入参见《客户审核接口文档.md》，本文不重复。

# 4. 列表

**GET** `/api/services/app/ClientAdmin/GetPagedListAsync`

权限 `Admin.Client.Get`。分页参数是 `pageIndex`、`pageSize`。

筛选没有新增国家条件。出参每条是客户对象，在原有 `countryId` 之外多了 `country`（见 0.1）。`countryId` 为空时 `country` 为 `null`。

列表不返回地址、附件、最后一次审核任务，也不实时计算合作统计。

# 5. 详情

**GET** `/api/services/app/ClientAdmin/DetailAsync?id={guid}`

权限 `Admin.Client.Get`。出参同样带 `countryId` 和 `country`（见 0.1）。另外还有地址、附件、合作统计、`lastAuditTask`。

# 6. 结算银行

**GET** `/api/services/app/ClientAdmin/GetSettlementBanksAsync?id={guid}`

权限 `Admin.Client.Get`。出参同样带 `countryId` 和 `country`（见 0.1），以及开票信息和银行。
