# 1. 背景意图 (Background)

**业务需求：** 合作客户（`Client`）此前仅有「公司电话」（`Phone`）字段，缺少独立的「手机号」字段。本次为客户主表新增「手机号」（`Mobile`）字段，最大长度 64，并同步到客户的增删改查接口，供前端录入与展示。

**涉及改动：**

- 客户主表实体新增 `Mobile` 字段。
- 客户新建 / 编辑 / 列表 / 详情等接口的输入输出 DTO 均携带 `Mobile`。
- 编辑接口显式回写 `Mobile`。

# 2. 核心逻辑变更 (Core Logic Changes)

## 2.1 实体与数据结构

文件：`src/CsprojBuilder.Core/Entites/Client.cs`

- `Client` 新增属性 `Mobile`（`string`，`[StringLength(64)]`），位于原「公司电话」`Phone` 之后。

> 注：按要求未生成 migration，由维护人自行生成。

## 2.2 客户接口 (ClientAdminAppService)

文件：`src/CsprojBuilder.Application/App/Client/ClientAdminAppService.cs`

- **新增 `AddAsync`**：入参 `ClientAddDto` 携带 `Mobile`，经 `ObjectMapper.Map<Entites.Client>(input)` 自动映射写入主表，无需额外处理。
- **编辑 `EditAsync`**：在字段回写处新增 `client.Mobile = input.Mobile;`。
- **列表 `GetPagedListAsync` / 详情 `DetailAsync`**：通过 `ObjectMapper.Map<ClientDto>` 自动带出 `Mobile`，无需额外处理。

## 2.3 DTO

文件：`src/CsprojBuilder.Application/App/Client/Dto/ClientDto.cs`

- `ClientAddDto`（新建输入）：新增 `string Mobile`。
- `ClientEditDto`（编辑输入）：新增 `string Mobile`。
- `ClientDto`（列表与详情输出）：新增 `string Mobile`。

# 3. 避坑指南 (Pitfalls)

- **`Phone` 与 `Mobile` 区分**：`Phone` 为「公司电话」，`Mobile` 为「手机号」，二者均为 64 长度、可空，前端注意区分录入。
- **新增靠 AutoMapper，编辑靠手动**：`AddAsync` 依赖 `[AutoMap]` 自动映射；`EditAsync` 为逐字段回写模式，新增字段必须手动补充赋值，否则编辑不生效。
- **无 migration**：主表结构有变更（新增列），需自行生成并执行 migration 后接口方可正常读写。
