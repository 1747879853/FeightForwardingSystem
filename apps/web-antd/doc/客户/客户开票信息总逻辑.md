# 1. 业务背景说明 (Background)

**白话解释：**  
记录合作客户可用于开票的抬头、税号、地址电话及银行账户。一个客户可有多条开票信息，每条下可挂多个币别银行账户。

# 2. 功能与操作说明 (Features & Operations)

- **新增：** `AddAsync`，写主表并可同时写入银行子表。
- **编辑：** `EditAsync`，局部赋值主表字段；银行子表按「有则改、缺则删、多则增」。
- **批量保存：** `BatchEditAsync`，按客户全量同步开票信息（缺的删、有的改、新的增）。
- **删除：** `DeleteAsync`，先删银行子表再软删主表。
- **列表/详情：** 按客户查列表、按 id 查详情（含银行与币别代码）。
- **AI 识别预填（不属于本模块接口）：** 上传客户发来的开票资料或粘贴开票资料文字，由 `GeminiAdmin/ExtractClientInvoiceInfoAsync` 识别出本页全部字段与银行列表，前端填回表单后仍走上面的 `AddAsync` / `EditAsync` / `BatchEditAsync` 保存。出参字段名与本表列名一致，且已按列长截断、按币别置好默认银行，可直接提交。接口说明见 `文档/外部Api对接/Gemini/Gemini对接-前端对接.md` 第 10 节。

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：同一客户抬头唯一]** 新增/编辑/批量保存时，同 `clientId` 已存在相同 `header`（编辑排除自身）→ 提示「同一客户下抬头不能重复」。
>
> **[卡点 2：同一客户税号唯一]** 税号非空且同 `clientId` 已存在相同 `taxNum` → 提示「同一客户下纳税人识别号不能重复」。
>
> **[卡点 3：币别默认银行]** 若提交了银行列表，每个币别必须且只能有一个 `isDefault=true`。
