# 客户失信备注接口-前端-2026-07-23

## 1. 加入失信 — `PUT /api/services/app/ClientAdmin/AddDishonestAsync`

权限：`Admin.Client.AddDishonest`

### 入参

| 字段     | JSON              | 类型   | 必填 | 说明                   |
| :------- | :---------------- | :----- | :--- | :--------------------- |
| 客户id   | `id`              | Guid   | 是   | 单个客户               |
| 失信备注 | `dishonestRemark` | string | 是   | trim 后非空，最长 1024 |

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "dishonestRemark": "长期拖欠运费"
}
```

### 出参

无返回体。成功后该客户 `isDishonest=true`，`dishonestRemark` 为入参值。

### 错误提示

- `失信备注不能为空`
- `失信备注长度不能超过1024`
- `请选择需要加入失信的合作客户`
- `合作客户不存在`

---

## 2. 取消失信 — `PUT /api/services/app/ClientAdmin/CancelDishonestAsync`

权限：`Admin.Client.CancelDishonest`

### 入参

| 字段   | JSON | 类型 | 必填 | 说明     |
| :----- | :--- | :--- | :--- | :------- |
| 客户id | `id` | Guid | 是   | 单个客户 |

```json
{ "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }
```

### 出参

无返回体。成功后 `isDishonest=false`，`dishonestRemark=null`。

---
