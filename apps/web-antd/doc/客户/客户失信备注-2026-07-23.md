# 客户失信备注-2026-07-23

## 背景意图

合作客户需记录失信原因。实体已增加 `DishonestRemark`（失信备注），仅在「加入失信」时赋值、「取消失信」时清空；列表可按备注模糊筛选；新增/编辑不可改。

## 核心逻辑变更

1. **加入失信** `AddDishonestAsync`：入参改为 `{ id, dishonestRemark }`；`dishonestRemark` **必填**，最长 1024；置 `isDishonest=true` 并写入备注。
2. **取消失信** `CancelDishonestAsync`：置 `isDishonest=false`，`dishonestRemark=null`。
3. **列表筛选**：`ClientQueryDto.dishonestRemark` 模糊匹配（Admin / 通用 Client 列表均支持）。
4. **出参**：`ClientDto` / `ClientSimpleDto` 返回 `dishonestRemark`（只读）。
5. **新增**：强制 `dishonestRemark=null`；编辑不触碰该字段。

## 避坑指南

- 加入失信未传备注会报「失信备注不能为空」。
- 前端勿在 Add/Edit 提交 `dishonestRemark`，改了也不会生效。
