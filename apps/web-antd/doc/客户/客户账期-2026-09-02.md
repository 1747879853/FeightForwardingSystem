# 一、背景意图

`GetSettlementDateAsync` 筛「当前生效」账期时，生效时间和失效时间只要有一端没填，就应该不限制那一端。旧条件把 `EffectiveTime` 写了两遍，失效时间根本没参与比较。

完整口径见《客户账期总逻辑》第 7 节。

# 二、核心逻辑变更

当前生效（`now` 为当前时间）：

- `permanent=true`：直接算生效
- 否则：`(生效时间为空 或 生效时间 <= now) 且 (失效时间为空 或 now <= 失效时间)`

两端都空也算生效。

# 三、避坑指南

> [!IMPORTANT] **新增/编辑账期仍要求：非长期有效必须填生效时间。** 这条只改应结日期匹配，没放开录入校验。不填生效时间仍然只能勾长期有效后保存。
