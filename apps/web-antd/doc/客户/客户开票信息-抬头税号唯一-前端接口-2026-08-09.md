# 说明

本次无新增接口，仅在既有保存接口增加校验。前端需按错误文案提示用户。

## 受影响接口

### `POST /api/services/app/ClientInvoiceInfoAdmin/AddAsync`

保存前校验同一 `clientId` 下 `header`、`taxNum` 唯一。

### `PUT /api/services/app/ClientInvoiceInfoAdmin/EditAsync`

同上，排除当前 `id`。

### `POST /api/services/app/ClientInvoiceInfoAdmin/BatchEditAsync`

1. 入参 `clientInvoiceInfos` 内 `header`/`taxNum` 不可自相重复
2. 逐条新增/编辑时再与库内数据判重

## 关键错误提示

| 场景             | 提示                           |
| :--------------- | :----------------------------- |
| 同一客户抬头重复 | 同一客户下抬头不能重复         |
| 同一客户税号重复 | 同一客户下纳税人识别号不能重复 |

## 前端建议

- 提交前可对当前客户开票信息列表做本地去重提示（抬头必填；税号非空才判重）。
- 仍以服务端校验为准。
