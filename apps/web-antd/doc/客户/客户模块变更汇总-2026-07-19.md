# 一、合作客户 Client

## A. 字段变更（改了哪些字段）

### 新增字段
| 字段 | 类型 | 出现位置 | 说明 |
| :--- | :--- | :--- | :--- |
| `isDishonest` | bool | 列表/详情/简易输出、Query 筛选 | 是否失信。**Add/Edit 不接收**，只能由失信接口修改 |
| `enterpriseType` | int? | Add/Edit/Query/输出 | 企业类型，**前端自定义枚举**（后端仅存 int，不维护枚举） |
| `isShared` | bool | Add/Edit/Query/输出 | 是否共享，不可空，默认 false |
| `showCompanyId` | long? | Add/Edit/Query/输出 | 展示归属公司 id；**不参与权限**；须为公司组织(`isCompany=true`) |
| `showCompany` | OrganizationUnitSimpleDto | 列表/详情/简易输出 | 展示归属公司对象：`{ id, displayName, shortName, enName }` |

### 删除字段（前端需下线，入参/出参/筛选全移除）
`clientType`（客户性质）、`clientCoopStatus`（客户合作状态）、`supplierCoopStatus`（供应商合作状态）。

### 只读计算字段（仅输出，Add/Edit 不可填）
| 字段 | 类型 | 计算规则 |
| :--- | :--- | :--- |
| `clientCoopSince` | DateTime? | 该客户关联 `TransportOrder` 的**最早 ETD** |
| `clientLastTxnTime` | DateTime? | 该客户关联 `TransportOrder` 的**最大 ETD** |
| `yearTeu` | int? | ETD 属**今年**的订单，其箱型 `CtnCode.TEU` 求和 |
| `yearTicketCount` | int? | ETD 属**今年**的订单**数量** |

### 列表新增返回
`clientLaneCodes`（优质航线，`ClientLaneDto[]`，每项 `{ id: 航线id, laneName: 航线中文名 }`，**与详情一致**）、干系人四角色列表 `sales`/`customerServices`/`operations`/`documentations`（与详情一致，**不再返回扁平 `clientStakeholders`**）、`creatorUserName`（创建人昵称）。

## B. 修改接口（改了哪些字段）

### `GET /Client/GetPagedListAsync`（登录可用，简易列表）
- 入参 `industryCategory` 变为**必填且只能 1 位**。
- 权限规则：传 `p`(委托单位) 时，仅返回 **所属人 `userId` 是自己/下属 或 干系人是自己 或 `isShared=true`** 的客户；其他行业搜全部。
- 出参 `ClientSimpleDto` 新增：`isDishonest`、`enterpriseType`、`isShared`、`showCompanyId`、`showCompany`。

### `GET /ClientAdmin/GetPagedListAsync`（后台列表）
- 入参新增筛选：`codeSourceId`、`laneIds`(long[]，多选 OR)、`clientLevel`(int?)、`address`(模糊，含地址子表)、`name`、`fullName`、`code`、`enFullName`(模糊)、`isDishonest`(bool?)、`enterpriseType`(int?)、`isShared`(bool?)、`showCompanyId`(long?)。
- 入参移除：`clientCoopStatus`、`supplierCoopStatus`。
- 权限规则：**始终**叠加——客户「行业类别含 `p`」的按权限（所属人/干系人是自己 或 `isShared`）过滤，不含 `p` 的全部返回；拥有全部数据权限则不过滤。
- 出参新增：`isDishonest`、`enterpriseType`、`isShared`、`showCompanyId`、`showCompany`、`clientCoopSince`、`clientLastTxnTime`、`yearTeu`、`yearTicketCount`、`clientLaneCodes`（优质航线，与详情一致）、四角色干系人列表、`creatorUserName`；移除 `clientType`/`clientCoopStatus`/`supplierCoopStatus`。

### `GET /ClientAdmin/DetailAsync`、`GET /ClientAdmin/GetSettlementBanksAsync`
- 出参同步上面的新增/删除字段，并返回 `showCompany` 与四个计算字段。

### `POST /ClientAdmin/AddAsync`
- 入参新增：`enterpriseType`、`isShared`、`showCompanyId`；移除 `clientType`/`clientCoopStatus`/`supplierCoopStatus`/`clientCoopSince`/`clientLastTxnTime`。
- `isDishonest` 恒为 false（不接收）。`showCompanyId` 有值时校验组织存在且为公司类型。

### `PUT /ClientAdmin/EditAsync`
- 入参同 Add 的新增/删除；`showCompanyId` 同样校验公司类型。
- **不修改** `isDishonest`。

## C. 新增接口（入参 + 返回）

### `PUT /ClientAdmin/AddDishonestAsync` — 加入失信
- 权限：`Admin.Client.AddDishonest`（加入失信）
- 入参（body，`GuidIdDto`）：

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | guid | 是 | 目标客户 id，**仅单个**（`ids` 字段本接口忽略） |

- 返回：**无返回体**（成功即置该客户 `isDishonest=true`）。
- 失败：客户不存在报「合作客户不存在」；`id` 为空报「请选择需要加入失信的合作客户」。

### `PUT /ClientAdmin/CancelDishonestAsync` — 取消失信
- 权限：`Admin.Client.CancelDishonest`（取消失信）
- 入参：同上 `GuidIdDto`（仅用 `id`，单个）。
- 返回：**无返回体**（成功即置 `isDishonest=false`）。

### `GET /Client/GetGroupedByIndustryCategoryAsync` — 客户按行业类别分组（登录可用）
- 权限：仅需登录（无后台权限）。
- 入参：**无**。
- 数据范围：客户「行业类别含委托单位(`p`)」的走数据权限（所属人/干系人是自己 或 `isShared=true`）；不含 `p` 的全部返回。
- 分组规则：遍历每个客户 `industryCategories` 字符串的**每个单字符**分组，同一客户可归入多个分组。
- 返回：`ClientIndustryCategoryGroupDto[]`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `key` | string | 单个行业类别字符 |
| `value` | ClientSimpleDto[] | 该行业类别下的客户简易列表（含 `showCompany`） |

# 二、客户联系人 ClientContactAdmin

## A. 字段变更
- 新增 `landline`（座机，string，≤64）：Add/Edit/列表/详情。与 `tel`(办公电话)、`mobile`(手机) 相互独立。

## B. 新增接口（入参 + 返回）

### `PUT /ClientContactAdmin/SetDisabledAsync` — 启用/禁用联系人
- 入参（body，`ClientContactSetDisabledDto`）：

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | long | 是 | 联系人 id |
| `isDisabled` | bool | 是 | `true`=禁用，`false`=启用 |

- 返回：**无返回体**。成功提示（「禁用成功/启用成功」）由前端按入参自行展示。
- 失败：联系人不存在报「输入合作客户联系人错误」。
- 备注：列表 `GetPagedListAsync` 已支持 `isDisabled` 筛选。

# 三、客户开票信息 ClientInvoiceInfoAdmin

## 字段变更
- 新增 `require`（开票要求，string，**≤128**）。
- 覆盖接口：`AddAsync`、`EditAsync`、`BatchEditAsync`（入参可传 `require`）；`GetListAsync`、`DetailAsync`（出参含 `require`）；客户详情、开票申请、发票开出中嵌套的开票信息对象也会带出 `require`。
- 注意长度 **128**（与开票申请的 `require` 1024 不同，勿按 1024 提交）。

# 四、客户账期 ClientBillingPeriodAdmin

## 字段变更：增删改查支持扁平附件（不分组）

### 入参新增 `attachments`（`AttachmentItemForItemInputDto[]`，用于 AddAsync / EditAsync）
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `attachmentId` | long | 附件 id |
| `attachmentDtlTypeId` | long? | 附件详细类型 id（托书/提单/发票等） |
| `clientVisible` | bool | 客户是否可见 |
| `displayOrder` | int | 顺序 |
| `url` | string | 文件下载 Url |

### 出参新增 `attachments`（`AttachmentItemDto[]`，DetailAsync / GetListAsync / GetPagedListAsync 均返回）
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | long | 关联 id |
| `attachmentId` | long | 附件 id |
| `attachmentDtlTypeId` | long? | 附件详细类型 id |
| `attachmentDtlType` | object | 附件详细类型简易对象 |
| `clientVisible` | bool | 客户是否可见 |
| `displayOrder` | int | 顺序 |
| `url` | string | 下载地址 |
| `mediaType` | enum | 文件类型 |
| `friendlyFileName` | string | 显示文件名 |
| `fileLength` | long? | 文件大小 |
| `creationTime` | DateTime? | 上传时间 |
| `creatorUserId` | long? | 上传人 id |
| `creatorUserName` | string | 上传人昵称 |

### 接口影响
- `AddAsync`/`EditAsync`/`DeleteAsync`/`DetailAsync`/`GetListAsync`/`GetPagedListAsync` 均已适配附件。
- 编辑为**全量覆盖**：前端须提交当前完整附件列表，否则会被清空。
