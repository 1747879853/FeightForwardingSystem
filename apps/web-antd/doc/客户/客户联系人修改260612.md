# 客户联系人新增是否禁用（IsDisabled）修改记录 2026-06-12

**修改时间：** 2026-06-12

**修改人：** 后端

**关联需求：** `ClientContact`（合作客户联系人）表新增 `IsDisabled` 字段，支持禁用/启用联系人

---

## 一、需求背景

合作客户联系人表（`App_ClientContacts`）原先无禁用状态，无法标记某个联系人为不可用。现新增 `IsDisabled` 字段（`bool`，是否禁用），用于标记联系人是否被禁用，列表接口支持按禁用状态筛选。

---

## 二、修改文件清单

| 文件 | 路径 | 修改类型 |
| --- | --- | --- |
| 实体 | `Core/Entites/ClientContact.cs` | 新增 `bool IsDisabled` 属性 |
| 新增DTO | `Application/App/ClientContact/Dto/ClientContactDto.cs` → `ClientContactAddDto` | 新增 `bool IsDisabled` |
| 编辑DTO | `Application/App/ClientContact/Dto/ClientContactDto.cs` → `ClientContactEditDto` | 新增 `bool IsDisabled` |
| 查询DTO | `Application/App/ClientContact/Dto/ClientContactDto.cs` → `ClientContactQueryDto` | 新增 `bool? IsDisabled` 筛选字段 |
| 输出DTO | `Application/App/ClientContact/Dto/ClientContactDto.cs` → `ClientContactDto` | 新增 `bool IsDisabled` |
| 联系人服务 | `Application/App/ClientContact/ClientContactAdminAppService.cs` | 编辑时赋值 `IsDisabled`；列表增加 `IsDisabled` 筛选 |

## 三、详细修改内容

### 3.1 实体修改（ClientContact.cs）

```csharp
/// <summary>
/// 是否禁用
/// </summary>
public bool IsDisabled { get; set; }
```

### 3.2 DTO修改

#### ClientContactAddDto / ClientContactEditDto（输入）

```csharp
/// <summary>
/// 是否禁用
/// </summary>
public bool IsDisabled { get; set; }
```

#### ClientContactQueryDto（查询输入）

```csharp
/// <summary>
/// 是否禁用
/// </summary>
public bool? IsDisabled { get; set; }
```

**说明：** 可空，为 `null` 时不筛选，返回所有联系人（含禁用与未禁用）。

#### ClientContactDto（输出）

```csharp
/// <summary>
/// 是否禁用
/// </summary>
public bool IsDisabled { get; set; }
```

### 3.3 ClientContactAdminAppService 修改

#### EditAsync — 编辑时增加赋值

```csharp
clientContact.IsDisabled = input.IsDisabled;
```

#### GetPagedListAsync — 列表增加 IsDisabled 筛选

```csharp
// 变更后
var query = _clientContactRepository.GetAll().
    WhereIf(input.ClientId.HasValue, m => m.ClientId == input.ClientId).
    WhereIf(input.IsDefault.HasValue, m => m.IsDefault == input.IsDefault).
    WhereIf(input.InvoiceEnable.HasValue, m => m.InvoiceEnable == input.InvoiceEnable).
    WhereIf(input.StatementEnable.HasValue, m => m.StatementEnable == input.StatementEnable).
    WhereIf(input.IsDisabled.HasValue, m => m.IsDisabled == input.IsDisabled).
    WhereIf(!string.IsNullOrWhiteSpace(input.Keyword), m => m.Name.Contains(input.Keyword) || m.Remark.Contains(input.Keyword));
```

## 四、API 变更详情

### 4.1 新增联系人 — `POST /api/services/app/ClientContactAdmin/Add`

**请求体新增字段：**

| 字段         | 类型   | 必填 | 说明                   |
| ------------ | ------ | ---- | ---------------------- |
| `isDisabled` | `bool` | 否   | 是否禁用，默认 `false` |

**请求示例：**

```json
{
  "clientId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "张三",
  "mobile": "13800138000",
  "email": "zhangsan@example.com",
  "tel": "021-12345678",
  "position": "采购经理",
  "weChat": "zhangsan_wx",
  "isDefault": true,
  "remark": "",
  "qq": "123456",
  "invoiceEnable": true,
  "statementEnable": true,
  "isDisabled": false
}
```

### 4.2 编辑联系人 — `PUT /api/services/app/ClientContactAdmin/Edit`

请求体同 4.1，新增 `isDisabled` 字段，编辑时会更新该字段的值。

### 4.3 联系人列表 — `GET /api/services/app/ClientContactAdmin/GetPagedList`

| 参数         | 类型    | 必填 | 说明                                 |

## 五、数据库变更

`App_ClientContacts` 表新增 `IsDisabled` 列：

| 列名         | 类型  | 可空       | 默认值 | 说明     |
| ------------ | ----- | ---------- | ------ | -------- |
| `IsDisabled` | `bit` | `NOT NULL` | `0`    | 是否禁用 |

**说明：** 本次未生成 EF Core 迁移文件，需另行手动生成迁移或执行如下 SQL 补充字段；已有数据的 `IsDisabled` 值默认为 `0`（未禁用）。

```sql
ALTER TABLE [App_ClientContacts] ADD [IsDisabled] bit NOT NULL DEFAULT 0;
```
