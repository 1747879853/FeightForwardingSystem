# 客户合作统计字段-2026-07-23

## 背景意图

`App_Clients` 表上的 `YearTeu`/`YearTicketCount` 从未回写，实际统计在列表/详情按运输订单实时计算。本次删除这两列，并在 `ClientAdmin` 列表与详情中同时返回**委托单位**与**供应商**各 4 个只读统计字段（共 8 个）。

## 核心逻辑变更

1. **实体**：删除 `Client.YearTeu`、`Client.YearTicketCount`（迁移由你方自行生成）。
2. **委托单位**（规则不变，字段名加 `Client` 前缀区分）：
   - `clientCoopSince` / `clientLastTxnTime` / `clientYearTeu` / `clientYearTicketCount`
   - 数据源：`TransportOrder.ClientId = 客户Id`，按 `ETD` 取最早/最大、今年票数与 TEU。
3. **供应商**（新增计算）：
   - `supplierCoopSince` / `supplierLastTxnTime` / `supplierYearTeu` / `supplierYearTicketCount`
   - 数据源：`SeaExport.BookingAgentId = 客户Id`（`SeaExport.Id = TransportOrder.Id`），规则同委托单位。
4. **新增/编辑**：不再接收 `supplierCoopSince`/`supplierLastTxnTime`；上述 8 字段均为只读。

## 避坑指南

- 前端原 `yearTeu`/`yearTicketCount` 已更名为 `clientYearTeu`/`clientYearTicketCount`。
- 供应商合作时间不再以客户表入库值为准，列表/详情一律覆盖为订舱代理统计结果。
- 无订单时：时间为 `null`，年 TEU/年票数为 `0`。
