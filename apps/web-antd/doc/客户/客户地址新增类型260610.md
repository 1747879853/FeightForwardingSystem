# 客户地址新增类型（AddressType）修改记录 2026-06-10

**修改时间：** 2026-06-10

**修改人：** 后端

**关联需求：** `ClientAddress` 表新增 `AddressType` 字段，支持区分地址类型

---

## 一、需求背景

客户地址表（`App_ClientAddresses`）原先无类型区分，所有地址混在一起。现新增 `AddressType` 字段（`int`），支持按地址类型分类管理，列表接口支持按类型筛选。具体枚举值由前端定义和维护。

---

### 3.3 ClientAddressAdminAppService 修改

#### AddOrEditPrivateAsync — 编辑时增加赋值

```csharp
entity.AddressType = input.AddressType;
```

#### GetPagedListAsync — 列表增加 AddressType 筛选

```csharp
// 变更前
var query = _clientAddressRepository.GetAll()
    .WhereIf(input.ClientId.HasValue && input.ClientId.Value != Guid.Empty, m => m.ClientId == input.ClientId)
    .WhereIf(!string.IsNullOrWhiteSpace(input.Keyword), m => m.Name.Contains(input.Keyword) || m.Remark.Contains(input.Keyword));

// 变更后
var query = _clientAddressRepository.GetAll()
    .WhereIf(input.ClientId.HasValue && input.ClientId.Value != Guid.Empty, m => m.ClientId == input.ClientId)
    .WhereIf(input.AddressType.HasValue, m => m.AddressType == input.AddressType.Value)
    .WhereIf(!string.IsNullOrWhiteSpace(input.Keyword), m => m.Name.Contains(input.Keyword) || m.Remark.Contains(input.Keyword));
```

## 四、API 变更详情

### 4.1 新增/编辑地址 — `POST /api/services/app/ClientAddressAdmin/AddOrEdit`

**请求体新增字段：**

| 字段          | 类型  | 必填 | 说明                                     |
| ------------- | ----- | ---- | ---------------------------------------- |
| `addressType` | `int` | 否   | 地址类型，默认 `0`，具体值由前端枚举定义 |

**请求示例：**

```json
{
  "id": null,
  "clientId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "上海分公司",
  "isDefault": true,
  "addressType": 1,
  "address": "上海市浦东新区xxx路100号",
  "contactPerson": "张三",
  "mobile": "13800138000",
  "tel": "021-12345678",
  "remark": ""
}
```

### 4.2 批量新增/编辑地址 — `POST /api/services/app/ClientAddressAdmin/AddOrEditList`

请求体数组中每个元素同 4.1，新增 `addressType` 字段。

### 4.3 地址列表 — `GET /api/services/app/ClientAddressAdmin/GetPagedList`

**查询参数新增：**

| 参数          | 类型   | 必填 | 说明                               |
| ------------- | ------ | ---- | ---------------------------------- |
| `addressType` | `int?` | 否   | 按地址类型筛选，不传则返回所有类型 |

**请求示例：**

```
GET /api/services/app/ClientAddressAdmin/GetPagedList?clientId=xxx&addressType=0&page=1&pageSize=10&sorting=id desc
```

**响应体新增字段：**

### 4.4 地址详情 — `GET /api/services/app/ClientAddressAdmin/Detail`

## 五、数据库变更

`App_ClientAddresses` 表新增 `AddressType` 列：

| 列名          | 类型  | 可空       | 默认值 | 说明                           |
| ------------- | ----- | ---------- | ------ | ------------------------------ |
| `AddressType` | `int` | `NOT NULL` | `0`    | 地址类型，具体枚举值由前端定义 |

**说明：** 已有数据的 `AddressType` 值会默认为 `0`。
