# 0. 公共类型

## 0.1 `UserSimpleDto`（对接人对象 `user`）

| 字段            | 类型   | 说明               |
| :-------------- | :----- | :----------------- |
| `id`            | long   | 用户id             |
| `nickName`      | string | 昵称（展示用这个） |
| `enName`        | string | 英文名             |
| `employeeID`    | string | 工号               |
| `avatar`        | string | 头像               |
| `userAttribute` | int    | 用户属性（位掩码） |

## 0.2 `ClientContactSimpleDto`（其它模块回显联系人用，本模块不返回）

`id` / `name` / `mobile` / `email` / `tel` / `position` / `weChat`。

## 0.3 数据权限对前端的影响（必读）

- 联系人的**对接人 `userId`** 不填=所有人可见；填了=只有指定人可见；有「全部数据权限」的人可见全部。
- **只作用于本文档这七个接口**：列表里不会出现没权限的联系人；详情/编辑/删除/启用禁用没权限时**报错**（文案见各接口）。
- **业务单据、对账、服务任务、报价里回显已选定的联系人不受影响**，照常返回联系人对象与联系方式，前端无需改动。

# 1. 联系人列表

**GET** `/api/services/app/ClientContactAdmin/GetPagedListAsync`

## 入参（query，`ClientContactQueryDto`）

| 参数 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `clientId` | Guid? | 否 | 合作客户id，不传不筛 |
| `keyword` | string | 否 | 模糊匹配 名字 或 备注 |
| `isDefault` | bool? | 否 | 是否默认 |
| `invoiceEnable` | bool? | 否 | 发票可用 |
| `statementEnable` | bool? | 否 | 对账可用 |
| `isDisabled` | bool? | 否 | 是否禁用，不传返回全部 |
| **`userId`** | long? | 否 | **按对接人筛选**，不传不筛（不传也**不会**因此看到无权限的联系人） |
| `pageIndex` | int | 否 | 页码 |
| `pageSize` | int | 否 | 每页条数 |
| `sorting` | string | 否 | 排序，如 `id desc` |

## 出参（`PagedList<ClientContactDto>`）

| 字段         | 类型               | 说明                             |
| :----------- | :----------------- | :------------------------------- |
| `items`      | ClientContactDto[] | 行数据，字段见下表               |
| `totalCount` | int                | 总条数（**已扣掉没数据权限的**） |
| `skipCount`  | int                | 跳过条数                         |
| `takeCount`  | int                | 本页条数                         |

### `items[]`（`ClientContactDto`）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | long | 主键 |
| `clientId` | Guid | 合作客户id |
| `name` | string | 名字 |
| `mobile` | string | 手机 |
| `email` | string | 邮箱 |
| `tel` | string | 办公电话 |
| `landline` | string | 座机 |
| `position` | string | 职位 |
| `weChat` | string | 微信号 |
| `qq` | string | QQ |
| `isDefault` | bool | 是否默认 |
| `remark` | string | 备注 |
| `invoiceEnable` | bool | 发票可用 |
| `statementEnable` | bool | 对账可用 |
| `isDisabled` | bool | 是否禁用 |
| **`userId`** | long? | **对接人id**，为空=不限定，所有人可见 |
| **`user`** | UserSimpleDto | **对接人对象**，`userId` 为空时为 `null`，字段见 0.1 |
| `creationTime` | DateTime | 创建时间 |
| `creatorUserId` | long? | 创建人id |
| **`creatorUserName`** | string | **创建人昵称** |
| `lastModificationTime` | DateTime? | 修改时间 |
| `lastModifierUserId` | long? | 修改人id |
| **`lastModifierUserName`** | string | **修改人昵称** |

# 3. 新增联系人

**POST** `/api/services/app/ClientContactAdmin/AddAsync`

## 入参（body，`ClientContactAddDto`）

| 参数 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `clientId` | Guid | 是 | 合作客户id |
| `name` | string | 是 | 名字 |
| `mobile` | string | 否 | 手机，≤64 |
| `email` | string | 否 | 邮箱，≤512 |
| `tel` | string | 否 | 办公电话，≤512 |
| `landline` | string | 否 | 座机，≤64 |
| `position` | string | 否 | 职位，≤512 |
| `weChat` | string | 否 | 微信号，≤512 |
| `qq` | string | 否 | QQ，≤32 |
| `isDefault` | bool | 否 | 是否默认，默认 `false`；**不做唯一校验** |
| `remark` | string | 否 | 备注，≤1024 |
| `invoiceEnable` | bool | 否 | 发票可用 |
| `statementEnable` | bool | 否 | 对账可用 |
| `isDisabled` | bool | 否 | 是否禁用，默认 `false` |
| **`userId`** | long? | 否 | **对接人**。不传/传 `0`/传 `null` = 不指定（所有人可见）；传了必须是存在的用户 |

## 出参

`long` — 新联系人 id。

## 报错

| 情况                    | 提示                       |
| :---------------------- | :------------------------- |
| 客户不存在              | 输入合作客户id错误         |
| `name` 为空/空白        | 合作客户联系人名称不能为空 |
| `userId` 对应用户不存在 | 对接人id错误               |

## 示例

```json
{
  "clientId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "张三",
  "mobile": "13800138000",
  "email": "zhangsan@example.com",
  "tel": "021-12345678",
  "landline": "021-87654321",
  "position": "采购经理",
  "weChat": "zhangsan_wx",
  "qq": "123456",
  "isDefault": true,
  "remark": "",
  "invoiceEnable": true,
  "statementEnable": true,
  "isDisabled": false,
  "userId": 25
}
```

# 4. 编辑联系人

**PUT** `/api/services/app/ClientContactAdmin/EditAsync`

## 入参（body，`ClientContactEditDto`）

字段同第 3 节，另加：

| 参数 | 类型 | 必填 | 说明     |
| :--- | :--- | :--- | :------- |
| `id` | long | 是   | 联系人id |

- **`userId` 可改可清空**：传新用户id=改对接人；传 `null` 或 `0`=清空对接人（改回所有人可见）。
- `clientId` 必填且必须存在，但**不会**把联系人挪到别的客户下（保存时不改 `clientId`）。

## 出参

`bool` — 恒 `true`。

## 报错

| 情况                    | 提示                              |
| :---------------------- | :-------------------------------- |
| 客户不存在              | 输入合作客户id错误                |
| `name` 为空/空白        | 合作客户联系人名称不能为空        |
| 联系人不存在            | 输入合作客户联系人错误            |
| 有这条数据但没数据权限  | 没有这条联系人的数据权限,不能编辑 |
| `userId` 对应用户不存在 | 对接人id错误                      |

# 6. 批量保存联系人

**POST** `/api/services/app/ClientContactAdmin/BatchSaveAsync`

Id 存在则编辑、不存在则新增，**不处理删除**（未出现在入参里的既有联系人保持不变）。

## 入参（body，`ClientContactBatchSaveDto`）

| 参数       | 类型                        | 必填 | 说明       |
| :--------- | :-------------------------- | :--- | :--------- |
| `clientId` | Guid                        | 是   | 合作客户id |
| `contacts` | ClientContactBatchItemDto[] | 是   | 联系人列表 |

### `contacts[]`（`ClientContactBatchItemDto`）

| 参数 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `id` | long | 否 | 为空/`0`/本客户下查不到 = 新增；`>0` 且存在 = 编辑 |
| `name` | string | 是 | 名字 |
| `mobile` | string | 否 | 手机 |
| `email` | string | 否 | 邮箱 |
| `tel` | string | 否 | 办公电话 |
| `landline` | string | 否 | 座机 |
| `position` | string | 否 | 职位 |
| `weChat` | string | 否 | 微信号 |
| `qq` | string | 否 | QQ |
| `isDefault` | bool | 否 | 是否默认 |
| `remark` | string | 否 | 备注 |
| `invoiceEnable` | bool | 否 | 发票可用 |
| `statementEnable` | bool | 否 | 对账可用 |
| `isDisabled` | bool | 否 | 是否禁用 |
| **`userId`** | long? | 否 | **对接人**，规则同新增/编辑 |

## 出参

`long[]` — 按输入顺序返回保存后的联系人 id（新增项为新 id，编辑项为原 id）。

## 报错（**任一条不合格整批不保存**）

| 情况                           | 提示                                        |
| :----------------------------- | :------------------------------------------ |
| 客户不存在                     | 输入合作客户id错误                          |
| 任一项 `name` 为空             | 合作客户联系人名称不能为空                  |
| 任一项存在但没编辑权限         | 没有联系人【张三、李四】的数据权限,不能保存 |
| 任一项 `userId` 对应用户不存在 | 对接人id错误                                |

## 示例

```json
{
  "clientId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "contacts": [
    {
      "id": 12,
      "name": "张三",
      "mobile": "13800138000",
      "isDefault": true,
      "invoiceEnable": true,
      "userId": 25
    },
    {
      "id": 0,
      "name": "李四",
      "mobile": "13900139000",
      "isDisabled": false,
      "userId": null
    }
  ]
}
```

```json
[12, 35]
```

# 7. 启用/禁用联系人

**PUT** `/api/services/app/ClientContactAdmin/SetDisabledAsync`

## 入参（body，`ClientContactSetDisabledDto`）

| 参数         | 类型 | 必填 | 说明                      |
| :----------- | :--- | :--- | :------------------------ |
| `id`         | long | 是   | 联系人id                  |
| `isDisabled` | bool | 是   | `true`=禁用，`false`=启用 |

## 出参

**无返回体**。成功提示（禁用成功/启用成功）由前端按入参自行展示。

## 报错

| 情况                   | 提示                                   |
| :--------------------- | :------------------------------------- |
| 联系人不存在           | 输入合作客户联系人错误                 |
| 有这条数据但没数据权限 | 没有这条联系人的数据权限,不能启用/禁用 |

# 8. 前端联调清单

- [ ] 新增/编辑表单加「对接人」用户选择（可清空），提交 `userId`；不选就不传或传 `null`
- [ ] 列表展示对接人用 `user.nickName`，不要用 `userId`
- [ ] 列表加「对接人」筛选，传 `userId`
- [ ] 列表/详情展示创建人用 `creatorUserName`、修改人用 `lastModifierUserName`
- [ ] 详情/编辑/删除/启用禁用要能正确展示「没有这条联系人的数据权限」这类后端文案
- [ ] 业务单据、对账、服务任务、报价上的联系人回显**不用改**，本次不影响它们
