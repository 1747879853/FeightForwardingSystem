# 客户合作统计字段接口-前端-2026-07-23

面向前端：`ClientAdmin` 列表与详情出参变更（只读计算字段）。

## 影响接口

| 接口 | 方法 | 地址 |
| :-- | :-- | :-- |
| 分页列表 | GET | `/api/services/app/ClientAdmin/GetPagedListAsync` |
| 详情 | GET | `/api/services/app/ClientAdmin/DetailAsync` |
| 结算银行（同样填充） | GET | `/api/services/app/ClientAdmin/GetSettlementBanksAsync` |

入参无变更。出参 `ClientDto` 新增/重命名如下字段。

## 出参变更（`ClientDto`）

### 委托单位（4）

| JSON 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `clientCoopSince` | DateTime? | 首次合作时间；无订单为 null |
| `clientLastTxnTime` | DateTime? | 最近交易时间；无订单为 null |
| `clientYearTeu` | int? | 年 TEU；无订单为 0（原 `yearTeu` 更名） |
| `clientYearTicketCount` | int? | 年票数；无订单为 0（原 `yearTicketCount` 更名） |

规则：`TransportOrder.ClientId = 客户Id` 且 `ETD` 有值；首次=最早 ETD，最近=最大 ETD；年票数/年 TEU 仅统计本自然年 ETD。

### 供应商（4）

| JSON 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `supplierCoopSince` | DateTime? | 首次合作时间；无订单为 null（改为只读计算） |
| `supplierLastTxnTime` | DateTime? | 最近交易时间；无订单为 null（改为只读计算） |
| `supplierYearTeu` | int? | 年 TEU；无订单为 0（新增） |
| `supplierYearTicketCount` | int? | 年票数；无订单为 0（新增） |

规则：`SeaExport.BookingAgentId = 客户Id`，关联同 Id 的 `TransportOrder.ETD` 与箱型，计算方式同委托单位。

## 新增/编辑入参

`AddAsync` / `EditAsync` **不再接收**：

- `supplierCoopSince`
- `supplierLastTxnTime`
- （原本也无）`yearTeu` / `yearTicketCount` / `clientYear*` / `supplierYear*`
