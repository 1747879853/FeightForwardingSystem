# 委托单位排除服务项目 (ClientExceptServiceAdmin) 前端对接文档

## 前置条件

- 客户的 `IndustryCategories` 字段必须包含小写字符 `p`（代表委托单位），否则无法使用以下接口。

## 校验规则

| 校验规则 | 错误信息 |
| --- | --- |
| 客户不存在 | "客户不存在" |
| 客户 `IndustryCategories` 不含 `p` (获取时) | "非委托单位无服务项目设置" |
| 客户 `IndustryCategories` 不含 `p` (修改时) | "非委托单位不可修改" |
| 起运港id不存在（polId有值时校验） | "起运港Id {polId} 不存在" |
| polId为空但默认港口配置不存在 | "默认港口配置不存在，无法设置默认港口排除服务项" |

---

## 1. 获取某个Client的排除服务项目配置

**GET** `/api/services/app/ClientExceptServiceAdmin/GetClientExceptServicesAsync`

### Query Parameters

| 参数 | 类型 | 必填 | 说明   |
| ---- | ---- | ---- | ------ |
| id   | Guid | 是   | 客户Id |

### Response

```json
[
  {
    "polId": 1,
    "pol": {
      "id": 1,
      "portName": "SHANGHAI",
      "cnName": "上海"
    },
    "items": [
      {
        "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
        "serviceType": 1,
        "userAttribute": 3,
        "autoComplete": false,
        "manualAllowed": true,
        "reminder": false,
        "sortId": 0,
        "remark": "string",
        "isChecked": true
      },
      {
        "id": "3fa85f64-5717-4562-b3fc-2c963f66afa7",
        "serviceType": 2,
        "userAttribute": 1,
        "autoComplete": true,
        "manualAllowed": false,
        "reminder": true,
        "sortId": 1,
        "remark": "string",
        "isChecked": false
      }
    ]
  },
  {
    "polId": null,
    "pol": null,
    "items": [
      {
        "id": "3fa85f64-5717-4562-b3fc-2c963f66afa8",
        "serviceType": 1,
        "userAttribute": 3,
        "autoComplete": false,
        "manualAllowed": true,
        "reminder": false,
        "sortId": 0,
        "remark": "string",
        "isChecked": true
      }
    ]
  }
]
```

### 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| polId | long? | 起运港id，`null`代表默认港口配置 |
| pol | PortCodeDto | 起运港详细信息，默认港口配置时为`null` |
| items | array | 该港口下的服务项配置列表 |
| ├── id | Guid | SeServiceConfigItem的Id |
| ├── serviceType | int | 服务项枚举(前端定义) |
| ├── userAttribute | long(Flags) | 用户属性 |
| ├── autoComplete | bool | 是否自动完成 |
| ├── manualAllowed | bool | 允许手动完成 |
| ├── reminder | bool | 完成提醒 |
| ├── sortId | int | 排序id |
| ├── remark | string | 备注 |
| └── isChecked | bool | 是否勾选：`true`=启用该服务项, `false`=已排除该服务项 |

### 业务逻辑

1. 校验客户存在且 `IndustryCategories` 包含 `p`
2. 查询该客户所有已排除的服务项记录 (`ClientExceptService` 表中 `ClientId` 匹配的记录)
3. 查询所有海运出口港口服务项配置 (`SeServiceConfig`) 及其明细 (`SeServiceConfigItem`)，包含默认港口配置（`POLId`为空的配置）
4. 对每条配置按港口分组返回，每个明细项额外计算 `isChecked`：
   - 如果 `ClientExceptService` 中存在该港口(`POLId`)和该服务项类型(`ServiceType`)的排除记录 → `isChecked = false`
   - 对于默认港口配置（`POLId`为`null`），匹配 `ClientExceptService` 中 `POLId` 同样为`null`的排除记录
   - 否则 → `isChecked = true`

> **排除项怎么生效（2026-10-02 修正）**：海运出口新建/编辑带出服务项（`SeaExportAdmin/GetServiceTypesByPOLAsync`）和业务联系单算海运出口服务项时，按票的起运港**命中的那份配置**取排除项：起运港有单独配置就取该起运港的排除记录，落到默认港口配置就取 `POLId` 为 `null` 的排除记录。之前一律按票的起运港取，在这里针对默认港口配置勾掉的服务项永远不生效。

## 2. 修改某个Client的排除服务项目

**PUT** `/api/services/app/ClientExceptServiceAdmin/EditClientExceptServicesAsync`

### Request Body

```json
{
  "clientId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "poLs": [
    {
      "polId": 1,
      "serviceTypes": [2, 5]
    },
    {
      "polId": 3,
      "serviceTypes": [1]
    },
    {
      "polId": null,
      "serviceTypes": [2]
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| clientId | Guid | 是 | 客户Id |
| poLs | array | 否 | 按港口分组的排除服务项列表 |
| ├── polId | long? | 否 | 起运港id，`null`代表针对默认港口配置的排除；有值时必须存在 |
| └── serviceTypes | int[] | 否 | 要排除的服务项类型列表 |

### Response

```json
true
```

### 业务逻辑

1. 校验客户存在且 `IndustryCategories` 包含 `p`
2. 校验每个 `polId`：有值时校验对应起运港存在；为`null`时校验默认港口配置存在
3. **清空**该客户所有已有的 `ClientExceptService` 记录
4. 根据输入重新插入排除记录：对每个港口（含默认港口）的每个 `ServiceType`，插入一条 `ClientExceptService` 记录

> **注意：** `serviceTypes` 传入的是要**排除**的服务项类型。如果某个港口不需要排除任何服务项，可以不传该港口或传空数组。如果传空的 `poLs`，则清空该客户所有排除记录(即启用所有服务项)。`polId`为`null`时代表针对默认港口配置的排除。
