# 客户通用 API 文档

> **服务名**：`ClientAppService`
>
> **接口基础路径**：`/api/services/app/Client/`
>

## 1. 获取合作客户简易分页列表

**Summary：** 获取合作客户简易分页列表，返回 `ClientSimpleDto`，仅需登录，无需 `Admin.Client.Get` 后台权限。筛选条件与 `ClientAdmin/GetPagedListAsync` 完全一致，适用于下拉选择委托单位、结算对象、订舱代理等外键关联场景。

**GET** `/api/services/app/Client/GetPagedListAsync`

**权限**：`[AbpAuthorize]`（登录即可）

### 入参 Query Parameters（`ClientQueryDto`）

| 字段 | JSON Key | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| Keyword | `keyword` | `string` | 否 | 关键字，模糊匹配客户简称、代码、全称、英文名、备注 |
| IndustryCategory | `industryCategory` | `string` | 否 | 行业类别，建议传 1 位；有值时按「`industryCategories` 含该字符」筛选，为空不按行业筛选。**数据权限对全部客户生效**，与行业类别无关 |
| CodeSourceId | `codeSourceId` | `long?` | 否 | 业务来源 id，为空不筛选 |
| IsDishonest | `isDishonest` | `bool?` | 否 | 是否失信，为空不筛选 |
| EnterpriseType | `enterpriseType` | `int?` | 否 | 企业类型（前端自定义枚举），为空不筛选 |
| ClientType | `clientType` | `ClientType?` | 否 | 客户类型（`0`同行、`1`直客），为空不筛选 |
| IsShared | `isShared` | `ClientSharedType?` | 否 | 共享类型（`0`不共享、`1`共享本公司、`2`共享所有人），为空不筛选。**2026-09-16 由 `bool?` 改为枚举**，不能再传 `true`/`false` |
| OrgId | `orgId` | `long?` | 否 | 归属组织 id，为空不筛选；有值时按「本组织+其所有下属组织」筛选 |
| PageIndex | `pageIndex` | `int` | 否 | 当前页码，从 `1` 开始，默认 `1` |
| PageSize | `pageSize` | `int` | 否 | 每页条数，默认 `10`，范围 `1~1000` |
| Sorting | `sorting` | `string` | 否 | 排序字段，默认 `CreationTime DESC` |

> 分页入参**仅** `pageIndex`、`pageSize`，详见上文「分页入参（所有分页接口通用）」。
>
> **已移除**：`clientCoopStatus` / `supplierCoopStatus`（合作状态字段已从客户表删除）。详见 `客户模块变更汇总-2026-07-19.md`。

### 业务规则

1. 仅需登录，不校验 `Admin.Client.Get` 等后台权限。
2. 筛选条件：
   - `industryCategory` 有值时按「含该字符」筛选，为空不按行业筛选。
   - `keyword` 为空时不按关键字过滤；有值时匹配 `Name`、`Code`、`FullName`、`EnName`、`Remark`。
   - `codeSourceId` 有值时精确匹配业务来源。
   - `isDishonest`、`enterpriseType`、`clientType`、`isShared` 有值时精确匹配；`orgId` 有值时按「本组织+其所有下属组织」筛选。
3. **可见性（与 `ClientAdmin` 相同，基类 `ClientListDataPermissionFilterAsync`）**：**全部客户**按行判断，满足其一即返回——
   - 拥有「全部数据权限」（不受共享类型限制，非本公司的也能看）；
   - `isShared=2` 共享所有人；
   - `isShared=1` 共享本公司，且 `orgId`（客户归属公司id）是当前用户所属公司之一（用户组织链上的全部公司节点，含上级公司）；
   - 所属人 `userId` 在数据权限可见用户内，或 `orgId` 在组织数据权限（本组织及下属）内；
   - 干系人是自己。
     > `isShared=0` 不共享时就退回最后两条：有数据权限或干系人关联才看得到。 **2026-09-16 起不再有「行业类别不含 `p` 不受限」的豁免**：非委托单位客户同样受上述规则约束，`orgId` 为空/存的是部门、且未共享的历史客户会查不到，需补录归属公司或调整共享类型。
4. 列表查询使用 `ProjectTo<ClientSimpleDto>` 投影，SQL 仅查询简易字段，不加载客户表全部字段及关联子表。
5. 相比 `ClientAdmin/GetPagedListAsync`，本接口**不返回** `ClientDto` 完整字段（币别、业务来源、对账人、附件、创建人等）。

## 2. 客户按行业类别分组

**Summary：** 无入参，一次性返回按行业类别（单字符）分组的客户简易列表。全部客户走数据权限过滤（有权限或已共享）；适用于按行业分组展示/选择客户。

**GET** `/api/services/app/Client/GetGroupedByIndustryCategoryAsync`

### 入参

无。

### 数据范围与分组规则

- 与列表相同，调用基类 `ClientListDataPermissionFilterAsync`，**全部客户**按上文「可见性」规则过滤，不按行业类别区分。
- 遍历每个客户 `industryCategories` 字符串的**每个单字符**分组，同一客户可同时归入多个分组。

## 1. 业务背景说明 (Background)

**白话解释：**

`ClientAppService` 是面向业务系统的**通用客户服务**，与后台管理的 `ClientAdminAppService` 分工不同：

- **ClientAdmin**：面向系统管理员，负责合作客户的增删改查、附件、对账人、干系人等完整管理，需要 `Admin.Client.*` 权限。
- **Client（本服务）**：面向已登录的业务用户，提供合作客户简易分页查询，适合业务单据中选择委托单位、结算对象、订舱代理等外键场景。

典型使用场景包括：业务联系单选择委托单位、费用录入选择结算对象、各类表单下拉搜索客户等。业务页面若用户没有客户管理查看权限，仍可通过本接口完成客户选择。

## 2. 功能与操作说明 (Features & Operations)

| 功能 | 接口 | 说明 |
| :-- | :-- | :-- |
| 合作客户简易分页列表 | `GetPagedListAsync` | 登录即可调用，返回 `ClientSimpleDto`，筛选条件与 Admin 列表一致 |
| 客户按行业类别分组 | `GetGroupedByIndustryCategoryAsync` | 无参，全部客户走可见性过滤，按单字符分组返回 key/value |

### 与 ClientAdmin 分页接口的对比

| 对比项 | `Client/GetPagedListAsync` | `ClientAdmin/GetPagedListAsync` |
| :-- | :-- | :-- |
| 权限 | 仅需登录 | 需要 `Admin.Client.Get` |
| 返回类型 | `ClientSimpleDto` | `ClientDto` |
| 筛选条件 | 与 Admin 相同 | 完整列表筛选 |
| 数据权限 | 全部客户按共享类型+数据权限+干系人过滤 | 同上（共用基类同一方法） |
| 关联子表 | 不加载 | 加载币别、业务来源、对账人、创建人等 |
| 适用场景 | 业务页面选人/选客户 | 后台客户管理列表 |

## 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **卡点 1：权限差异**
>
> 业务页面若只需选择/展示客户，应调用 `Client/GetPagedListAsync`，**不要**调用 `ClientAdmin/GetPagedListAsync`，否则普通业务用户会因缺少 `Admin.Client.Get` 权限而 403。

> [!IMPORTANT] **卡点 2：客户可见性（与行业类别无关）**
>
> 列表与分组都调用基类 `ClientListDataPermissionFilterAsync`，**全部客户**一视同仁：`isShared=2` 所有人可见；`isShared=1` 只有客户归属公司 `orgId` 属于当前用户所属公司时可见；`isShared=0` 要靠数据权限（所属人 `userId` / 组织 `orgId`）或干系人是自己；拥有「全部数据权限」的人不受共享类型限制。与 `ClientAdmin` 规则一致。
>
> 页面里「某个客户下拉搜不到」，先看这条客户的共享类型与归属公司，而不是先怀疑关键字。

> [!IMPORTANT] **卡点 3：分页参数**
>
> 分页请求**仅**传 `pageIndex` 和 `pageSize`，**禁止**传 `skipCount`、`maxResultCount`。响应中使用 `currentPage`、`totalPages`、`totalCount` 驱动分页控件。

> [!IMPORTANT] **卡点 4：返回字段精简**
>
> 本接口返回精简的 `ClientSimpleDto`，不包含创建人、修改人、币别、对账人等。若页面需要完整客户信息，应调用 `ClientAdmin/DetailAsync`（需 `Admin.Client.Get` 权限）。
