# 客户账期接口文档

本文档只写接口：地址、权限、入参全字段、出参全字段。业务口径（生效区间、应结日期怎么算、编辑时增量增改）见同目录《客户账期总逻辑》。

**控制器**：`ClientAdmin`。独立服务 `ClientBillingPeriodAdmin` 已删除。

**所有接口均需要登录认证**。方法名里的 `Async` 后缀不能省。

# 1. 对接总纲

| 项       | 值                                        |
| :------- | :---------------------------------------- |
| 接口基址 | `{host}/api/services/app/ClientAdmin/`    |
| 完整路径 | 基址 + 方法名，**保留 `Async`**           |
| 鉴权头   | `Authorization: Bearer {accessToken}`     |
| 租户头   | `Abp.TenantId: {租户id}`（租户账号必带）  |
| 请求体   | POST / PUT / DELETE 为 `application/json` |

## 1.1 接口一览

账期不再有独立增删改查。客户 `AddAsync` / `EditAsync` / `GetPagedListAsync` / `DetailAsync` 都带 `billingPeriods`。删客户时一并删账期及子表、附件。只剩「同步账期」是单独接口。

| # | 动作 | HTTP | 完整路径 | 参数位置 | 账期怎么带 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | 新增客户 | POST | `/api/services/app/ClientAdmin/AddAsync` | Body | 入参 `billingPeriods`（`ClientBillingPeriodAddDto[]`） |
| 2 | 编辑客户 | PUT | `/api/services/app/ClientAdmin/EditAsync` | Body | 入参 `billingPeriods`（`ClientBillingPeriodEditDto[]`）。`id=0` 或不传=新增；`id>0`=修改该条。库里有、本次没带的账期会删掉 |
| 3 | 客户分页列表 | GET | `/api/services/app/ClientAdmin/GetPagedListAsync` | Query | 出参每条客户带 `billingPeriods` |
| 4 | 客户详情 | GET | `/api/services/app/ClientAdmin/DetailAsync` | Query | 出参带 `billingPeriods` |
| 5 | 删除客户 | DELETE | `/api/services/app/ClientAdmin/DeleteAsync` | Body | 同步删该客户全部账期、部门/销售/业务来源子表、账期附件 |
| 6 | 同步账期 | POST | `/api/services/app/ClientAdmin/SyncBillingPeriodAsync` | Body | 入参账期 `id`，出参改动票数 `int` |

**2026-09-21 由独立 `ClientBillingPeriodAdmin` 并入 `ClientAdmin`**。下列地址已不存在，调用会 404：

- `/api/services/app/ClientBillingPeriodAdmin/AddAsync`
- `/api/services/app/ClientBillingPeriodAdmin/EditAsync`
- `/api/services/app/ClientBillingPeriodAdmin/DeleteAsync`
- `/api/services/app/ClientBillingPeriodAdmin/GetListAsync`
- `/api/services/app/ClientBillingPeriodAdmin/GetPagedListAsync`
- `/api/services/app/ClientBillingPeriodAdmin/DetailAsync`

# 2. 枚举

### `settlementType`（`SettlementType`）

| 值  | 含义     | 要填的子字段                       |
| :-: | :------- | :--------------------------------- |
| `0` | 票结     | `addDays` 可选，不填不加           |
| `1` | 月结     | `months`、`settlementDay` **必填** |
| `2` | 约定天数 | `days` **必填**                    |

`addDays` 和 `days` 不是同一个字段。票结看 `addDays`，约定天数看 `days`。

### `dateType`（`BillingPeriodDateType`）

| 值  | 含义     |
| :-: | :------- |
| `0` | 开船日期 |

值类型，不传后端默认为 `0`。表单仍按必填处理。

### `bizTypes`（`BizType`）

| 值  | 含义     |
| :-: | :------- |
| `0` | 海运出口 |
| `1` | 海运进口 |
| `2` | 空运出口 |

入参传数组；出参同时给 `bizTypes` 和存库串 `bizTypeStrs`（数字拼接）。

# 5. 编辑客户时的账期入参

### `PUT /api/services/app/ClientAdmin/EditAsync`

**权限**：`Admin.Client.Edit`

Body `ClientEditDto.billingPeriods`：`ClientBillingPeriodEditDto[]`。字段同第 4 节，多一个 `id`。

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-: | :-- |
| `id` | `long` | 否 | **0 或不传=新增**；**大于 0=修改该账期**。Id 必须属于当前客户，重复 Id 报「账期Id不能重复」 |
| （其余） |  |  | 同第 4 节 |

**2026-09-21 编辑改为增量增改，禁止全删再插：**

- 入参里 `id>0` 且属于本客户：只改这一条的主表字段；部门/销售/业务来源按 id 列表做差量（少的删、多的增、已有的不动）。
- 入参里 `id=0` 或不传：新增一条账期。
- 库里有、本次 `billingPeriods` 没出现的账期：删除（含子表和附件）。
- `billingPeriods` **不传或传空数组**：该客户下已有账期全部删除。编辑时必须把当前要保留的账期整包提交回来。
- 每条账期的 `attachments`：**全量覆盖**。不传或传空会清掉该账期全部附件关联。

**出参** `result`：`true`。

# 7. 同步账期

### `POST /api/services/app/ClientAdmin/SyncBillingPeriodAsync`

**权限**：`Admin.Client.Edit`（**2026-09-21 由 `Admin.Client.BillingPeriod.Sync` 改到客户编辑权限**）

账期规则是下单当时的快照，改了规则不会自动回刷历史业务。这个接口用来把**该客户票结的历史业务**按当前账期规则重算一遍应结日期与结算方式。

**入参** Body `IdDto`：

| 字段  | 类型     | 必填 | 说明                  |
| :---- | :------- | :--: | :-------------------- |
| `id`  | `long`   |  是  | 账期 id，客户由它带出 |
| `ids` | `long[]` |  否  | 本接口不用            |

**处理范围**（三层筛选，任一层不过就跳过该票）：

| 层 | 条件 |
| :-- | :-- |
| 账期本身 | 当前生效（长期有效，或落在生效/失效区间内）；不生效直接返回 `0`，一条都不动 |
| 业务范围 | 该账期客户下 `settlementType=0`（票结）的业务；月结/约定天数的业务不动 |
| 账期限定 | 业务类型、销售、组织机构、业务来源四个维度全部命中该账期（账期对应子表为空表示该维度不限定） |

命中后按《客户账期总逻辑》应结日期口径重算，与新增/编辑业务时用的是同一套算法（基准时间取业务开船日期 `ETD`，没有开船日期则取当前时间）。算出来和库里一致的不动，不一致的才写回。

**出参** `result`：实际改动的业务票数 `int`。返回 `0` 表示没有需要回刷的业务。

找不到账期报「账期记录不存在」。

# 8. 错误文案

| 文案 | 场景 |
| :-- | :-- |
| 非永久账期必须提供生效时间 | `permanent=false` 且未传 `effectiveTime` |
| 间隔月份不能为空 | 月结未传 `months` |
| 结算日期不能为空 | 月结未传 `settlementDay` |
| 结算日期错误 | 月结 `settlementDay` 不在 1–31 |
| 约定天数不能为空 | 约定天数未传 `days` |
| 约定天数错误 | `days` 小于 1 |
| 票结加的天数不能小于0 | `addDays` 有值且小于 0 |
| 一个或多个组织机构ID无效 | `organizationUnitIds` 有无效 id |
| 一个或多个用户ID无效 | `userIds` 有无效 id |
| 一个或多个业务来源ID无效 | `codeSourceIds` 有无效 id |
| 授信币别不存在 | `creditCurrencyId` 有值但币别不存在 |
| 账期Id不能重复 | 编辑时同一请求里出现重复的账期 `id` |
| 账期记录不存在 | 编辑传入的账期 `id` 不属于该客户；同步账期找不到该 id |
