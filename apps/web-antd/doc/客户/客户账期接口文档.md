# 客户账期接口文档

本文档只写接口：地址、权限、入参全字段、出参全字段。业务口径（生效区间、应结日期怎么算）见同目录《客户账期总逻辑》。

**控制器**：`ClientBillingPeriodAdmin`

**所有接口均需要登录认证**。方法名里的 `Async` 后缀不能省。

# 1. 对接总纲

| 项       | 值                                                  |
| :------- | :-------------------------------------------------- |
| 接口基址 | `{host}/api/services/app/ClientBillingPeriodAdmin/` |

| # | 动作 | HTTP | 完整路径 | 参数位置 | `result` |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | 新增 | POST | `/api/services/app/ClientBillingPeriodAdmin/AddAsync` | Body | `long`（新 id） |

成功时业务数据在 `result`。失败时 `success=false`，文案在 `error.message`。

# 2. 枚举

### `settlementType`（`SettlementType`）

| 值  | 含义     | 要填的子字段                       |
| :-: | :------- | :--------------------------------- |
| `0` | 票结     | `addDays` 可选，不填不加           |
| `1` | 月结     | `months`、`settlementDay` **必填** |
| `2` | 约定天数 | `days` **必填**                    |

`addDays` 和 `days` 不是同一个字段。票结看 `addDays`，约定天数看 `days`。

### `dateType`（`BillingPeriodDateType`）

| 值  | 含义     |
| :-: | :------- |
| `0` | 开船日期 |

值类型，不传后端默认为 `0`。表单仍按必填处理。

### `bizTypes`（`BizType`）

| 值  | 含义     |
| :-: | :------- |
| `0` | 海运出口 |
| `1` | 海运进口 |
| `2` | 空运出口 |

入参传数组；出参同时给 `bizTypes` 和存库串 `bizTypeStrs`（数字拼接）。

# 5. 编辑

### `PUT /api/services/app/ClientBillingPeriodAdmin/EditAsync`

**权限**：`Admin.Client.Edit`

**入参** Body `ClientBillingPeriodEditDto`：在新增入参之上多一个 `id`（`long`，必填）。其余字段同第 4 节。

- `clientId` 必填且客户须存在，但**不会改库里的所属客户**。
- 部门 / 销售 / 业务来源子表：**先删后插**，按本次传入的 id 列表重建。
- `attachments`：**全量覆盖**。不传或传空会清掉该账期全部附件关联。
- `addDays` 会写回主表（局部赋值，不调 `UpdateAsync`）。

**出参** `result`：`true`。

# 10. 错误文案

| 文案                       | 场景                                     |
| :------------------------- | :--------------------------------------- |
| 合作客户不存在             | 新增/编辑 `clientId` 无效                |
| 非永久账期必须提供生效时间 | `permanent=false` 且未传 `effectiveTime` |
| 间隔月份不能为空           | 月结未传 `months`                        |
| 结算日期不能为空           | 月结未传 `settlementDay`                 |
| 结算日期错误               | 月结 `settlementDay` 不在 1–31           |
| 约定天数不能为空           | 约定天数未传 `days`                      |
| 约定天数错误               | `days` 小于 1                            |
| 票结加的天数不能小于0      | `addDays` 有值且小于 0                   |
| 一个或多个组织机构ID无效   | `organizationUnitIds` 有无效 id          |
| 一个或多个用户ID无效       | `userIds` 有无效 id                      |
| 一个或多个业务来源ID无效   | `codeSourceIds` 有无效 id                |
| 授信币别不存在             | `creditCurrencyId` 有值但币别不存在      |
| 账期记录不存在             | 编辑/详情找不到该 id                     |
