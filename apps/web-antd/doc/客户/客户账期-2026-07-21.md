> 字段名均为接口 JSON（camelCase）。Migration 由后端自行生成，前端无需关心。

---

# 一、新增字段

| 字段 | 类型 | Add/Edit | 列表/详情 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `contractNo` | string | ✓ | ✓ | 合同号，可选，最长 **64** |
| `dateType` | int（枚举） | ✓ **必填** | ✓ | 日期类型，见下表 |
| `creditCurrencyId` | long? | ✓ | ✓ | 授信币别 id，可选；有值须为有效币别 |
| `creditCurrency` | CurrencySimpleDto | ✗ | ✓ | 授信币别简易对象（只读） |
| `creditLimit` | decimal? | ✓ | ✓ | 授信额度，可选 |
| `warningLimit` | decimal? | ✓ | ✓ | 预警额度，可选 |

### `dateType` 枚举 `BillingPeriodDateType`
| 值 | 含义 |
| :---: | :--- |
| `0` | 开船日期 |

### `creditCurrency`（CurrencySimpleDto）结构
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `code` | string | 币别代码 |
| `cnName` | string | 中文名 |
| `enName` | string | 英文名 |
| `defaultRate` | decimal | 默认对人民币汇率 |

> 无 `id`；币别主键请用同级的 `creditCurrencyId`。

---

# 二、受影响接口

| 方法 | 地址 | 变化 |
| :--- | :--- | :--- |
| POST | `/ClientBillingPeriodAdmin/AddAsync` | 入参可传上表 5 个可写字段；`dateType` 必填；`creditCurrencyId` 无效时报「授信币别不存在」 |
| PUT | `/ClientBillingPeriodAdmin/EditAsync` | 同上；编辑后返回 `true` |
| GET | `/ClientBillingPeriodAdmin/DetailAsync` | 出参含新字段 + `creditCurrency` |
| GET | `/ClientBillingPeriodAdmin/GetListAsync` | 同上 |
| GET | `/ClientBillingPeriodAdmin/GetPagedListAsync` | 同上 |

删除接口无字段变化。

---

# 三、避坑

1. `dateType` 为值类型枚举，不传时后端默认为 `0`（开船日期）；前端表单仍应按必填处理。
2. 清空授信币别：Edit 传 `creditCurrencyId: null`。
3. 附件、组织/销售/业务来源子表逻辑未变；Edit 附件仍为**全量覆盖**。
