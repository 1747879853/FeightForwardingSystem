# 运价API修改文档

**修改时间**：2026-06-05

---

## 修改概述

SeFreiPrice（海运出口运价）主表新增 `BookingAgentId`（订舱代理id）字段，关联客户表（App_Clients）。订舱代理是给货代公司供货的国内代理供应商。

---

## 一、表结构变更

### 主表 App_SeFreiPrices —— 已有字段（本次无新增，字段已存在于实体中）

| 字段名         | 类型  | 可空 | 说明                                |
| -------------- | ----- | ---- | ----------------------------------- |
| BookingAgentId | Guid? | 是   | 订舱代理id，关联 App_Clients 表主键 |

### 外键关系

新增导航属性 `BookingAgent`（`[ForeignKey("BookingAgentId")]`），指向 `Client` 实体。

---

## 三、AppService 接口变更

### 3.1 AddAsync（新增运价）

- 输入新增 `BookingAgentId` 字段
- `ValidateForeignKeysAsync` 增加 `BookingAgentId` 校验（有值时检查客户是否存在）
- 实体创建时写入 `BookingAgentId`

### 3.2 EditAsync（编辑运价）

- 输入新增 `BookingAgentId` 字段
- `ValidateForeignKeysAsync` 增加 `BookingAgentId` 校验
- 实体更新时写入 `BookingAgentId`

### 3.3 BatchEditAsync（批量编辑运价）

- 输入新增 `BookingAgentId` 字段
- 为 `null` 不修改，有值时校验客户是否存在、是否包含订舱代理行业类别，校验通过后赋值

### 3.4 BatchAddSimpleAsync（批量简单新增）

- 输入新增 `BookingAgentId` 字段
- `ValidateForeignKeysAsync` 增加 `BookingAgentId` 校验
- 实体创建时写入 `BookingAgentId`

### 3.5 BatchEditSimpleAsync（批量简单编辑）

- 输入新增 `BookingAgentId` 字段
- `ValidateForeignKeysAsync` 增加 `BookingAgentId` 校验
- 实体更新时写入 `BookingAgentId`

### 3.6 GetPagedListAsync（运价列表）

- 查询新增 `.Include(x => x.BookingAgent)` 加载订舱代理导航属性
- 查询新增 `BookingAgentId` 筛选条件
- 输出 `BookingAgentId` 和 `BookingAgentName`

### 3.7 DetailAsync（运价详情）

- 查询新增 `.Include(x => x.BookingAgent)` 加载订舱代理导航属性
- 输出 `BookingAgentId` 和 `BookingAgentName`

### 3.8 其他接口（无变更）

- DeleteAsync：无变化
- GetAllLaneCodesAsync：无变化
- GetCtnCodesByPriceIdsAsync：无变化
- ChangeRecommendAsync：无变化

## 四、私有方法变更

### ValidateForeignKeysAsync

签名变更：增加 `Guid? bookingAgentId = null` 可选参数。

```
变更前: ValidateForeignKeysAsync(long carrierId, long polId, long podId, long? pot1Id, long? pot2Id, long currencyId)
变更后: ValidateForeignKeysAsync(long carrierId, long polId, long podId, long? pot1Id, long? pot2Id, long currencyId, Guid? bookingAgentId = null)
```

新增逻辑：`bookingAgentId` 有值时查询 `_clientRepository`，不存在则抛出 "订舱代理不存在"；存在但行业类别不包含订舱代理（`IndustryCategories` 不含 `"o"`）则抛出 "该客户不包含订舱代理属性"。

### MapToOutDto

新增两行映射：

- `BookingAgentId = entity.BookingAgentId`
- `BookingAgentName = entity.BookingAgent?.Name`

## 八、前端对接注意事项

1. 新增/编辑表单需新增"订舱代理"选择器（下拉搜索客户列表），绑定 `bookingAgentId`（Guid），可空
2. 订舱代理选择器应只展示行业类别包含"订舱代理"的客户（即 `IndustryCategories` 包含 `"o"` 的客户）
3. 批量编辑表单：`bookingAgentId` 为 null 不修改，有值则统一更新
4. 列表页面：可新增 `bookingAgentName` 列展示订舱代理名称
5. 列表筛选：可新增按 `bookingAgentId` 筛选
6. 后端会校验传入的客户必须包含订舱代理行业类别，否则报错"该客户不包含订舱代理属性"
