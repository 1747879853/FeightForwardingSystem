# 运价API修改文档

**修改时间**：2026-05-21 12:09:19

---

## 修改概述

1. 子表重命名：`SeFreiPriceETD` → `SeFreiPriceDay`（关联日），`SeFreiPriceETDDay` → `SeFreiPriceWeekDay`（关联周几）
2. 将主表 `SeFreiPrice` 的6个日期字段迁移至重命名后的子表中
3. 三种日期（开船日ETD、截单时间CloseDocTime、截港时间ClosingTime）现在是配套填写的，存储在同一子表记录中

---

## 一、表结构变更

### 1. 主表 SeFreiPrice —— 移除以下字段

| 字段名            | 类型       | 说明                    |
| ----------------- | ---------- | ----------------------- |
| CloseDocTime      | DateTime?  | 截单时间                |
| CloseDocDayOfWeek | DayOfWeek? | 截单时间 周几           |
| CloseDocDayTime   | TimeSpan?  | 截单时间 一天中的时间点 |
| ClosingTime       | DateTime?  | 截港时间/截关时间       |
| ClosingDayOfWeek  | DayOfWeek? | 截港时间 周几           |
| ClosingDayTime    | TimeSpan?  | 截港时间 一天中的时间点 |

### 2. SeFreiPriceDay（原 SeFreiPriceETD）—— 新增字段

原表仅有 `ETD`（开船日），现新增：

| 字段名       | 类型      | 说明              |
| ------------ | --------- | ----------------- |
| CloseDocTime | DateTime? | 截单时间          |
| ClosingTime  | DateTime? | 截港时间/截关时间 |

变更后完整字段：`Id`, `SeFreiPriceId`, `ETD`, `CloseDocTime`, `ClosingTime`

### 3. SeFreiPriceWeekDay（原 SeFreiPriceETDDay）—— 新增字段

原表仅有 `ETDDayOfWeek`、`ETDDayTime`，现新增：

| 字段名            | 类型       | 说明                    |
| ----------------- | ---------- | ----------------------- |
| CloseDocDayOfWeek | DayOfWeek? | 截单时间 周几           |
| CloseDocDayTime   | TimeSpan?  | 截单时间 一天中的时间点 |
| ClosingDayOfWeek  | DayOfWeek? | 截港时间 周几           |
| ClosingDayTime    | TimeSpan?  | 截港时间 一天中的时间点 |

变更后完整字段：`Id`, `SeFreiPriceId`, `ETDDayOfWeek`, `ETDDayTime`, `CloseDocDayOfWeek`, `CloseDocDayTime`, `ClosingDayOfWeek`, `ClosingDayTime`

> **注意**：原来 `ETDDayOfWeek` (DayOfWeek) 和 `ETDDayTime` (TimeSpan) 为非空类型，现在全部改为可空类型（DayOfWeek? / TimeSpan?），与其他字段保持一致。

---

## 二、DTO变更

### 1. 以下DTO移除6个日期字段

- `SeFreiPriceAddDto`（新建输入）
- `SeFreiPriceEditDto`（编辑输入）
- `SeFreiPriceBatchEditDto`（批量编辑输入）
- `SeFreiPriceOutDto`（列表和详情输出）
- `SeFreiPriceSimpleAddDto`（简单新建输入）
- `SeFreiPriceSimpleEditDto`（简单编辑输入）

移除的字段：`CloseDocTime`, `CloseDocDayOfWeek`, `CloseDocDayTime`, `ClosingTime`, `ClosingDayOfWeek`, `ClosingDayTime`

### 2. SeFreiPriceDayAddDto（原 SeFreiPriceETDAddDto）

变更前：

| 字段名 | 类型     | 说明           |
| ------ | -------- | -------------- |
| ETD    | DateTime | 开船日（非空） |

变更后：

| 字段名       | 类型      | 说明              |
| ------------ | --------- | ----------------- |
| ETD          | DateTime? | 开船日（可空）    |
| CloseDocTime | DateTime? | 截单时间          |
| ClosingTime  | DateTime? | 截港时间/截关时间 |

### 3. SeFreiPriceWeekDayAddDto（原 SeFreiPriceETDDayAddDto）

变更前：

| 字段名       | 类型      | 说明                          |
| ------------ | --------- | ----------------------------- |
| ETDDayOfWeek | DayOfWeek | 开船日 周几（非空）           |
| ETDDayTime   | TimeSpan  | 开船日 一天中的时间点（非空） |

变更后：

| 字段名            | 类型       | 说明                    |
| ----------------- | ---------- | ----------------------- |
| ETDDayOfWeek      | DayOfWeek? | 开船日 周几             |
| ETDDayTime        | TimeSpan?  | 开船日 一天中的时间点   |
| CloseDocDayOfWeek | DayOfWeek? | 截单时间 周几           |
| CloseDocDayTime   | TimeSpan?  | 截单时间 一天中的时间点 |
| ClosingDayOfWeek  | DayOfWeek? | 截港时间 周几           |
| ClosingDayTime    | TimeSpan?  | 截港时间 一天中的时间点 |

### 4. SeFreiPriceDayOutDto 和 SeFreiPriceWeekDayOutDto

与上述 AddDto 变更一致，新增相同字段。

---

## 三、AppService 接口变更

以下接口均已适配新的表结构：

| 接口 | 变更内容 |
| --- | --- |
| AddAsync | 主表创建移除6个日期字段；SeFreiPriceDay创建新增CloseDocTime、ClosingTime；SeFreiPriceWeekDay创建新增4个字段 |
| EditAsync | 主表更新移除6个日期字段；关联日/关联周几子表删除重建时包含新字段 |
| DeleteAsync | 无变化（已使用新表名） |
| GetPagedListAsync | 输出映射移除主表6个日期字段，子表输出包含新字段 |
| DetailAsync | 同上 |
| BatchEditAsync | 主表批量更新移除6个日期字段；子表删除重建包含新字段 |
| BatchAddSimpleAsync | 主表创建移除6个日期字段；子表创建包含新字段 |
| BatchEditSimpleAsync | 主表更新移除6个日期字段；子表删除重建包含新字段 |
