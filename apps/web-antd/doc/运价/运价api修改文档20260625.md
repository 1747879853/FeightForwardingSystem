# 运价 API 修改记录 2026-06-25

## 背景意图

运价列表需支持按**录入人**筛选，便于查看指定用户录入的运价数据。

## 核心逻辑变更

### GetPagedListAsync（运价列表）

查询参数 `SeFreiPriceQueryDto` 新增可选字段 `CreatorUserId`（录入人id），按主表 `CreatorUserId` 精确匹配筛选。

```csharp
.WhereIf(input.CreatorUserId.HasValue, m => m.CreatorUserId == input.CreatorUserId.Value)
```

#### 请求参数

| 参数          | 类型  | 说明                                                 |
| ------------- | ----- | ---------------------------------------------------- |
| CreatorUserId | long? | 录入人id（创建人Id，精确匹配）。不传则不按录入人筛选 |

#### 请求体示例

```json
{
  "CreatorUserId": 123,
  "PageIndex": 1,
  "PageSize": 20
}
```
