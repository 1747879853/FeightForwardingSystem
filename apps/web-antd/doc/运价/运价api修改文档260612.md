# 运价API修改文档

**修改时间**：2026-06-12

---

## 修改概述

`SeFreiPriceAdminAppService.GetPagedListAsync`（运价列表）查询条件补全：将主表 `SeFreiPrice`（App_SeFreiPrices）的所有业务字段全部加入查询筛选条件。原查询仅支持部分字段（船公司、订舱代理、起运港、目的港、是否推荐、约号等），本次扩展后支持按主表全部业务字段筛选。

> 说明：审计字段（CreationTime/CreatorUserId/LastModificationTime/LastModifierUserId）及 TenantId 不作为业务查询条件，不在本次扩展范围内。

---

## 三、AppService 接口变更

### GetPagedListAsync（运价列表）

在主查询链路新增以下 `WhereIf` 筛选条件（位于原 `Recommend` 之后、`IsValid` 之前）：

```
.WhereIf(input.POT1Id.HasValue, m => m.POT1Id == input.POT1Id.Value)
.WhereIf(input.POT2Id.HasValue, m => m.POT2Id == input.POT2Id.Value)
.WhereIf(input.CurrencyId.HasValue, m => m.CurrencyId == input.CurrencyId.Value)
.WhereIf(input.IsDirect.HasValue, m => m.IsDirect == input.IsDirect.Value)
.WhereIf(input.POLFreeDays.HasValue, m => m.POLFreeDays == input.POLFreeDays.Value)
.WhereIf(input.PODFreeDays.HasValue, m => m.PODFreeDays == input.PODFreeDays.Value)
.WhereIf(input.PODDEM.HasValue, m => m.PODDEM == input.PODDEM.Value)
.WhereIf(input.PODDET.HasValue, m => m.PODDET == input.PODDET.Value)
.WhereIf(!string.IsNullOrWhiteSpace(input.Voyage), m => m.Voyage.Contains(input.Voyage))
.WhereIf(!string.IsNullOrWhiteSpace(input.Remark), m => m.Remark.Contains(input.Remark))
.WhereIf(input.ValidTimeStartBegin.HasValue, m => m.ValidTimeStart >= input.ValidTimeStartBegin.Value)
.WhereIf(input.ValidTimeStartEnd.HasValue, m => m.ValidTimeStart <= input.ValidTimeStartEnd.Value)
.WhereIf(input.ValidTimeEndBegin.HasValue, m => m.ValidTimeEnd >= input.ValidTimeEndBegin.Value)
.WhereIf(input.ValidTimeEndEnd.HasValue, m => m.ValidTimeEnd <= input.ValidTimeEndEnd.Value)
```

其余逻辑（分页、排序、导航属性批量加载、船公司Logo、输出映射）均无变化。

## 五、前端对接注意事项

1. 列表筛选区可按需新增：是否直达、中转港1/2、币别、各类免费天数、航程、备注、有效期区间等筛选项。
2. 字符串字段（Voyage、Remark）为模糊匹配（Contains）。
3. 有效期采用区间筛选：
   - `ValidTimeStartBegin` / `ValidTimeStartEnd` 限定"有效时间起"落在区间内；
   - `ValidTimeEndBegin` / `ValidTimeEndEnd` 限定"有效时间止"落在区间内。
4. 免费天数（POLFreeDays/PODFreeDays/PODDEM/PODDET）为精确匹配，如需区间筛选可后续再扩展。
5. 所有新增条件均为可选，不传即不参与筛选，原有调用方式完全兼容。
