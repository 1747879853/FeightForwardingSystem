# 港口接口新增 country 字段

**修改时间**：2026-05-26

---

## 变更说明

所有返回 `PortCodeDto` 的接口，港口对象中新增 `country` 字段，返回该港口对应的国家信息。

---

## 影响的接口

| 接口路径 |
| --- |
| `GET /api/services/app/portCodeAdmin/GetPagedListAsync` |
| `GET /api/services/app/portCodeAdmin/DetailAsync` |
| `GET /api/services/app/seFreiPriceAdmin/GetPagedListAsync` |
| `GET /api/services/app/seFreiPriceAdmin/DetailAsync` |
| `GET /api/services/app/seServiceConfigAdmin/GetPagedListAsync` |
| `GET /api/services/app/seServiceConfigAdmin/DetailAsync` |
| `GET /api/services/app/seServiceTaskAdmin/GetPagedListAsync` |
| `GET /api/services/app/seServiceTaskAdmin/GetWorkbenchListAsync` |
| `GET /api/services/app/clientExceptServiceAdmin/GetClientExceptServicesAsync` |

---

## 新增字段

`PortCodeDto` 中新增：

| 字段名  | 类型           | 说明                            |
| ------- | -------------- | ------------------------------- |
| country | CountryCodeDto | 港口对应的国家对象，无则为 null |

`CountryCodeDto` 结构：

| 字段名        | 类型   | 说明             |
| ------------- | ------ | ---------------- |
| id            | long   | 主键Id           |
| code          | string | 国家唯一代码     |
| countryName   | string | 国家名称         |
| countryEnName | string | 国家英文名称     |
| chau          | string | 所在大洲         |
| capital       | string | 首都             |
| tariff        | int    | 关税等级         |
| tonnageTax    | int    | 吨位税           |
| countryCode3  | string | 国家3字代码      |
| explain       | string | 国家描述         |
| remark        | string | 备注             |
| status        | int    | 状态 0启用 1禁用 |
