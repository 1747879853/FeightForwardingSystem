# 运价列表「涨跌 / 上一条」后端对接说明

> **已落地（2026-09-30）**：列表箱型直接返回 `costDelta` / `sugDelta`（TAPD #1000196）。前端已改为只读字段，不再补拉历史。

**接口**：`GetPagedListAsync`（`SeFreiPriceAdmin`）  
**出参位置**：`items[].seFreiPriceCtns[]`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `costDelta` | `decimal?` | 成本现价 − 上一条；涨为正、跌为负；无上一条/对不上/差额为 0 → `null` |
| `sugDelta` | `decimal?` | 指导价现价 − 上一条；任一侧未填或差额为 0 → `null` |

详情 `DetailAsync` 不计算，两字段为 `null`。
