# 运价 API 修改记录 2026-07-04

## 背景意图

运价列表需支持按**录入时间起止**筛选，便于按创建时间区间查询运价数据。

## 核心逻辑变更

### GetPagedListAsync（运价列表）

查询参数 `SeFreiPriceQueryDto` 新增可选字段 `CreationTimeStart`、`CreationTimeEnd`，按主表 `CreationTime`（录入时间）区间筛选。

```csharp
.WhereIf(input.CreationTimeStart.HasValue, m => m.CreationTime >= input.CreationTimeStart.Value)
.WhereIf(input.CreationTimeEnd.HasValue, m => m.CreationTime <= input.CreationTimeEnd.Value)
```

#### 请求参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| CreationTimeStart | DateTime? | 录入时间起（CreationTime >= 此值）。不传则不限制 |
| CreationTimeEnd | DateTime? | 录入时间止（CreationTime <= 此值）。不传则不限制 |

#### 请求体示例

```json
{
  "CreationTimeStart": "2026-07-01T00:00:00",
  "CreationTimeEnd": "2026-07-04T23:59:59",
  "PageIndex": 1,
  "PageSize": 20
}
```
