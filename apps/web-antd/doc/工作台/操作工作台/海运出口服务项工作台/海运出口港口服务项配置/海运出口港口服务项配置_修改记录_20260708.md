# 海运出口港口服务项配置 - SortId 同优先级支持

## 背景意图

业务需要多个服务项配置处于同一优先级并行执行，全部完成后再进入下一优先级。原先编辑接口按数组下标强制重写 SortId，无法配置相同优先级。

## 核心逻辑变更

1. `SeServiceConfigItemEditDto` 新增 `sortId` 字段，编辑接口按前端传入值保存。
2. 新增/编辑校验 `sortId >= 0`，允许同一配置下多个明细使用相同 `sortId`。
3. 列表与详情按 `sortId` + `serviceType` 稳定排序。

## 避坑指南

- 前端编辑时必须显式传入每个明细的 `sortId`，不再由后端按数组顺序自动生成。
- `ServiceType` 仍不可重复；`SortId` 可重复。
