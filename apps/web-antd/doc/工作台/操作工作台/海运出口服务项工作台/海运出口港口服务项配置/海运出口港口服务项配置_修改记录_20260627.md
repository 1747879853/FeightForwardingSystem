## 一、需求描述

`SeServiceConfigItem` 新增 `RequireFee` 字段和子表 `SeServiceRequireFee`，用于配置完成服务时必须存在的费用（区分收付）。完成服务任务时，系统校验当前海运出口的 `OrderFee` 中是否包含配置要求的费用记录。

## 三、新增实体结构

### SeServiceRequireFee (App_SeServiceRequireFees)

| 字段                  | 类型          | 说明                 |
| --------------------- | ------------- | -------------------- |
| Id                    | Guid          | 主键                 |
| SeServiceConfigItemId | Guid          | 所属服务项配置明细Id |
| PaySide               | PaySide(enum) | 收付类型(0=收, 1=付) |
| FeeCodeId             | long          | 费用代码Id           |

外键关系：

- `SeServiceConfigItemId` → `App_SeServiceConfigItems.Id`
- `FeeCodeId` → `App_FeeCodes.Id`

### SeServiceConfigItem 新增字段

| 字段       | 类型 | 说明                 |
| ---------- | ---- | -------------------- |
| RequireFee | bool | 完成是否需要必填费用 |

## 五、接口变更详情

### 5.1 新增 (AddAsync)

输入 `seServiceConfigItems` 每项新增：

- `requireFee` (bool): 是否需要必填费用
- `seServiceRequireFees` (array): 必填费用列表

```json
{
  "requireFee": true,
  "seServiceRequireFees": [
    { "paySide": 0, "feeCodeId": 1 },
    { "paySide": 1, "feeCodeId": 2 }
  ]
}
```

### 5.2 删除 (DeleteAsync)

级联删除新增 `SeServiceRequireFee` 子表数据。

### 5.3 编辑 (EditAsync)

- `seServiceConfigItems` 每项新增 `requireFee` 和 `seServiceRequireFees`
- `seServiceRequireFees` 使用差异更新规则（有id=修改，无id=新增，不传的=删除）

```json
{
  "requireFee": true,
  "seServiceRequireFees": [
    { "id": "...", "paySide": 0, "feeCodeId": 1 },
    { "paySide": 1, "feeCodeId": 3 }
  ]
}
```

### 5.4 列表 (GetPagedListAsync)

`seServiceConfigItems` 每项返回新增 `requireFee` 字段。

### 5.5 详情 (DetailAsync)

`seServiceConfigItems` 每项返回新增：

- `requireFee` (bool)
- `seServiceRequireFees` (array): 包含 `id`, `paySide`, `feeCodeId`, `feeCodeName`

`feeCodeName` 由后端根据 `FeeCodeId` 查询 `FeeCode.CnName` 获得。

### 5.6 完成任务 (CompleteAsync) - 新增费用校验

当任务对应的 `SeServiceConfigItem.RequireFee = true` 时：

1. 查询该配置项的 `SeServiceRequireFees` 列表
2. 查询当前海运出口的所有 `OrderFee` 记录
3. 逐条校验：每条 `SeServiceRequireFee` 的 `PaySide` + `FeeCodeId` 组合必须在 `OrderFee` 中存在
4. 若缺少，返回错误：`"完成任务需要以下费用: [收]报关费、[付]拖车费"`

### 5.7 任务查询接口

`GetPagedListAsync` 和 `GetWorkbenchListAsync` 返回的 `SeServiceConfigItem` 层级新增：

- `requireFee` (bool): 标识该服务项是否需要必填费用
- `seServiceRequireFees` (array): 必填费用列表，含 `id`, `paySide`, `feeCodeId`, `feeCodeName`

前端可据此在完成按钮前提示用户需要先录入哪些费用。

## 六、校验规则变更

| 场景 | 新增规则 |
| --- | --- |
| 完成任务时 `RequireFee=true` | 校验 OrderFee 中存在对应 PaySide+FeeCodeId 的记录 |

新增错误信息：`"完成任务需要以下费用: [收/付]费用名称、..."`

---

## 七、对前端的影响

| 影响项 | 说明 |
| --- | --- |
| 配置页面 | 服务项明细新增"必填费用"开关和费用列表编辑 |
| 工作台 | 查询返回中可获取 `requireFee` 和 `seServiceRequireFees`，用于前端提示 |
| 完成任务 | 若 `requireFee=true` 且未录入对应费用，后端会拒绝完成并返回缺少的费用列表 |
| 费用代码选择 | 配置页面选择费用时传 `feeCodeId`，详情/查询接口返回 `feeCodeName` 供展示 |
