# 海运出口服务项任务 - SortId 同优先级并行

## 背景意图

同一 `SortId` 代表相同优先级，可存在多个并行任务；必须该优先级全部完成后，才生成下一优先级任务。

## 核心逻辑变更

1. 新建海运出口时，`GenerateFirstServiceTaskAsync` 为最小 `SortId` 下所有已启用配置项批量生成任务。
2. `CompleteAsync` 完成单条任务后，先判断同 `SortId` 是否全部完成，再为下一 `SortId` 批量生成任务。
3. 抽取 `SeServiceTaskHelper` 统一优先级判断与任务实体创建逻辑。
4. `ValidateServiceTypesAsync` 改为按 `SortId` 校验顺序，同优先级内允许任意排列。

## 避坑指南

- 取消完成逻辑仍按 `SortId > 当前` 删除后续任务，同优先级其他任务不会被误删。
- 生成下一优先级时会跳过已存在任务的配置项，避免重复插入。
