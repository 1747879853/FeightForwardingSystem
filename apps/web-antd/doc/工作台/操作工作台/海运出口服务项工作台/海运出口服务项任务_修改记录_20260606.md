# 海运出口服务项任务 - 修改记录 2026-06-06

## 修改概述

本次修改涉及两部分：

1. **海运出口编辑接口（EditAsync）**：服务项与任务变更逻辑调整
2. **服务项任务接口（SeServiceTaskAdmin）**：新增「取消完成」功能

---

## 一、海运出口编辑接口 - 服务项变更逻辑调整

### 修改前逻辑

- 起运港变了 → 删除并重新生成服务项和任务
- 起运港没变 → 校验服务项增删是否允许：
  - 不允许删除已有"已完成"或"待处理"任务的服务项
  - 不允许新增排序在已生成任务之后的服务项
  - 校验通过后编辑服务项并按需生成下一个待处理任务

### 修改后逻辑

- **起运港变了 或 服务项变了**（无论新增还是删除）→ 删除所有现有服务项和已生成的任务，重新生成服务项和第一个任务
- **起运港没变 且 服务项没变** → 不做任何处理

### 变更原因

原逻辑对服务项变更有严格限制（不允许删除有任务的服务项、不允许在已生成任务前插入新服务项），导致业务灵活性不足。新逻辑简化为：只要服务项发生变化就全部重建，避免复杂的增量校验。

### 影响范围

- 文件：`SeaExportAdminAppService.cs` → `EditAsync` 方法
- 接口：`PUT /api/services/app/SeaExportAdmin/Edit`
- 移除的错误提示：
  - "已有任务的服务项不允许删除"
  - "新增的服务项后面已有生成的任务，不允许新增"

## 二、新增接口 - 取消完成单个任务（CancelCompleteAsync）

### 接口信息

| 项目 | 内容                                                  |
| ---- | ----------------------------------------------------- |
| 方法 | POST                                                  |
| 路径 | `/api/services/app/SeServiceTaskAdmin/CancelComplete` |
| 权限 | `Admin.Workbench.Operation.Processe`                  |

### 请求参数

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

| 字段 | 类型 | 必填 | 说明               |
| ---- | ---- | ---- | ------------------ |
| id   | Guid | 是   | 要取消完成的任务id |

### 响应

```json
true
```

### 业务逻辑

1. 校验任务存在且状态为**已完成**（Processed）
2. 获取当前任务的 SortId（通过 SeServiceConfigItem.SortId）
3. 查询同一海运出口下所有 SortId **大于**当前任务的后续任务
4. 删除所有后续任务（包括关联的 SeServiceTaskUsers）
5. 将当前任务状态改为 Pending（待处理），清空 CompletionUserId 和 CompletionTime

### 示例场景

假设某海运出口有任务序列 1→2→3→4（按 SortId 排序），当前任务4状态为 Pending，任务1、2、3为 Processed：

| 操作          | 效果                                   |
| ------------- | -------------------------------------- |
| 取消完成任务3 | 删除任务4，任务3状态变为 Pending       |
| 取消完成任务2 | 删除任务3和4，任务2状态变为 Pending    |
| 取消完成任务1 | 删除任务2、3、4，任务1状态变为 Pending |

### 错误信息

| 条件             | 错误信息                           |
| ---------------- | ---------------------------------- |
| 输入为空         | "输入不能为空"                     |
| 任务不存在       | "任务不存在"                       |
| 任务状态非已完成 | "任务不是已完成状态，无法取消完成" |
