# 海运进口服务项任务模块接口文档

前端专属，只写接口。规则见同目录《海运进口服务项任务模块总逻辑文档》。JSON 字段 camelCase；业务报错走 ABP 统一信封。

与海出任务接口(`SeServiceTaskAdmin`)一一对应，改名对照：`seaExportId/seaExport` → `seaImportId/seaImport`；`seServiceXxx` → `siServiceXxx`；分组的 `polId/pol` → `podId/pod`；筛选的 `podId` → `polId`；`seaExportPropEnum` → `seaImportPropEnum`。

## 接口一览

| # | 动作 | HTTP | 路径 | 权限 |
| :-- | :-- | :-- | :-- | :-- |
| 1 | 查询(多层结构) | GET | `/api/services/app/SiServiceTaskAdmin/GetPagedListAsync` | `Admin.Workbench.Operation.Get` |
| 2 | 工作台综合查询 | GET | `/api/services/app/SiServiceTaskAdmin/GetWorkbenchListAsync` | `Admin.Workbench.Operation.Get` |
| 3 | 工作台统计 | GET | `/api/services/app/SiServiceTaskAdmin/GetWorkbenchCountAsync` | `Admin.Workbench.Operation.Get` |
| 4 | 工作台分页 | GET | `/api/services/app/SiServiceTaskAdmin/GetWorkbenchPagedListAsync` | `Admin.Workbench.Operation.Get` |
| 5 | 批量转交 | POST | `/api/services/app/SiServiceTaskAdmin/TransferAsync` | `Admin.Workbench.Operation.Appoint` |
| 6 | 完成 | POST | `/api/services/app/SiServiceTaskAdmin/CompleteAsync` | `Admin.Workbench.Operation.Processe` |
| 7 | 取消完成 | POST | `/api/services/app/SiServiceTaskAdmin/CancelCompleteAsync` | `Admin.Workbench.Operation.Processe` |

## 公共结构

### 任务 `SiServiceTaskItemDto` / `SiServiceTaskWorkbenchItemDto`（两者字段相同）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| id | Guid | 任务 id |
| seaImportId | Guid | 海运进口 id |
| siServiceConfigItemId | Guid | 配置明细 id |
| serviceTaskStatus | int | 0 待处理 1 已处理 |
| completionUserId / completionTime | long? / datetime? | 完成人、完成时间 |
| assigneeTime / assigneeUserId / assigneeRemark | - | 转交时间、被转交人、转交备注 |
| sortId / remark | - | 排序、备注 |
| creationTime / creatorUserId / lastModificationTime / lastModifierUserId | - | 审计 |
| seaImport | 对象 | 见下 |
| siServiceTaskUsers | 数组 | 处理人 `{ id, siServiceTaskId, userId, userNickName, completionTime }` |

### `seaImport`（SiServiceTaskSeaImportDto）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| id | Guid | 海运进口 id |
| vessel / innerVoyno / terminalVoyno | string | 船名、航次、码头航次 |
| carrierId / carrier | long? / 对象 | 船公司 `{ id, cnName, cnShortName, enName, code, ediCode }` |
| polId / pol / polRemark | - | 起运港，`pol` 为港口对象 `{ id, portName, cnName, ediCode, lane, country }` |
| podId / pod / podRemark | - | 目的港，结构同上 |
| clientNum | string | 客户编号 |
| terminalId / terminal | Guid? / 对象 | 码头 `{ id, name, fullName, address, taxRate }`（`address` 恒为 null） |
| throughBillNum / hblNum / batchNum | string | 联运单号、分单号、批次号 |
| tradeMode | int? | 贸易方式。前端枚举，枚举管理 Name：`TradeMode` |
| originCountryId / originCountry | long? / 对象 | 原产国 `{ id, code, countryName, countryEnName }` |
| totalNetWeight | decimal? | 净重合计 |
| exchangeBillDate / pickUpDate / customsDeclareDate / transferStationDate / ctnUseDate | datetime? | 换单、提货、报关、转站、箱使日期 |
| freeDays | int? | 免箱期 |
| transportOrder | 对象 | `{ id, commissionNum, mblNum, bookingNum, contractNum, etd(到港日期), eta(预抵日期), clientId, client, pkgs, kgs, cbm, totalCtn, orderUsers[] { userId, userNickName, userAttribute } }`；`client` 结构同 `terminal` |

### 配置明细字段（分组第二层共有）

`id`、`siServiceConfigId`、`serviceType`（枚举管理 Name：`ServiceType`）、`userAttribute`、`autoComplete`、`requireFee`、`manualAllowed`、`reminder`、`sortId`、`remark`、`siServiceShows[] { id, seaImportPropEnum }`（枚举管理 Name：`SeaImportPropEnum`）、`siServiceRequireFees[] { id, paySide, feeCodeId, feeCode }`。

## 1. 查询 GetPagedListAsync

### 入参（QueryString）

| 参数 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| serviceTaskStatus | int? | 否 | 0/1 |
| etdStart / etdEnd | datetime? | 否 | **到港日期**区间 |
| clientId | Guid? | 否 | 委托单位 |
| carrierId | long? | 否 | 船公司 |
| mblNum | string | 否 | 主提单号，模糊 |
| polId | long? | 否 | **起运港** |
| isAssigned | bool | **是** | `true` 转交给我的；`false` 没转交且我在处理人里的 |
| sorting | string | 否 | 默认 `Id DESC` |

### 出参

`{ totalCount, items[] }`，`items[]`（目的港分组）：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| siServiceConfigId | Guid | 配置 id |
| podId | long | 分组目的港（默认配置按票的目的港拆组） |
| pod | 对象 | 港口对象（含 `country`） |
| taskCount | int | 本组任务数 |
| siServiceConfigItems | 数组 | 配置明细字段 + `siServiceTasks[]`（任务结构见公共结构） |

## 2. 工作台综合查询 GetWorkbenchListAsync

### 入参（QueryString）

`serviceTaskStatus`、`etdStart`、`etdEnd`、`clientId`、`carrierId`、`mblNum`、`polId`、`sorting` 同上，另有：

| 参数    | 类型   | 说明                                 |
| :------ | :----- | :----------------------------------- |
| keyword | string | 模糊匹配主提单号、订舱编号、委托编号 |

不区分是否指派，返回与我相关的全部任务。

### 出参

`{ totalCount, items[] }`，`items[]` 同查询的分组，区别：`siServiceConfigItems[]` 的明细只装**未转交**任务；最后追加一个元素，`id`、`serviceType`、`userAttribute`、`autoComplete`、`requireFee`、`manualAllowed`、`reminder`、`sortId`、`remark` 都为 `null`，`siServiceShows`/`siServiceRequireFees` 为空数组，`siServiceTasks` 装本组全部**转交**任务。

## 3. 工作台统计 GetWorkbenchCountAsync

### 入参

同工作台综合查询。

### 出参

`{ items[] }`，`items[]`：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| podId | long | 目的港 |
| pod | 对象 | 港口对象 |
| totalCount | int | 本组任务总数 |
| serviceItems | 数组 | `{ serviceType, count }`：配置全部明细各自的未转交任务数（没有为 0）；最后一项 `serviceType=null` 为转交任务数 |

## 4. 工作台分页 GetWorkbenchPagedListAsync

### 入参（QueryString）

工作台综合查询全部参数 + ：

| 参数        | 类型 | 必填   | 说明                                       |
| :---------- | :--- | :----- | :----------------------------------------- |
| podId       | long | **是** | 目的港（统计里的分组目的港）               |
| serviceType | int? | 否     | 有值 = 该服务项的未转交任务；空 = 转交任务 |
| pageIndex   | int  | 否     | 默认 1                                     |
| pageSize    | int  | 否     | 默认 20                                    |

### 出参

分页外壳 `{ totalCount, items[] }`，`items[]` 为任务（公共结构）。

### 报错

| 文案 | 条件 |
| :-- | :-- |
| 未找到该目的港对应的服务项配置,请配置该港口或配置默认港口服务项 | 目的港没有配置也没有默认配置 |

## 5. 批量转交 TransferAsync

### 入参（请求体）

| 参数           | 类型         | 必填 | 说明     |
| :------------- | :----------- | :--- | :------- |
| ids            | Guid[]       | 是   | 任务 id  |
| assigneeUserId | long         | 是   | 被转交人 |
| assigneeRemark | string(1024) | 否   | 转交备注 |

### 出参

`result`：`true`。

### 报错

| 文案 | 条件 |
| :-- | :-- |
| 输入不能为空 | `ids` 为空 |
| 被转交人不存在 | `assigneeUserId` 查不到 |
| 部分任务不存在 | 有 id 查不到 |
| 任务{id}不是待处理状态，无法转交 | 已处理 |
| 任务{id}的被转交人不是当前用户，无法转交 | 转交任务、被转交人不是我 |
| 当前用户不在任务{id}的处理人列表中，无法转交 | 未转交任务、我不是处理人 |
| 被转交人已在任务{id}的处理人列表中，不能转交给处理人 | 被转交人本来就是该任务的处理人 |

## 6. 完成 CompleteAsync

### 入参（请求体）

| 参数 | 类型 | 必填 | 说明    |
| :--- | :--- | :--- | :------ |
| id   | Guid | 是   | 任务 id |

### 出参

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| generatedFeeCount | int | 本次按自动费用模板生成的费用条数，没生成为 0 |
| generatedFees | 数组 | 按 `sortId` 升序：`{ id, paySide, feeCodeId, feeCode, settlementId, settlement, currencyId, currency, exchangeRate, unitPrice, amount, unit, quantity, taxRate, sortId }`；`feeCode`/`settlement`/`currency` 与业务费用接口的简易对象一致，`settlement` 取不到时为 `null` |

### 报错（按顺序）

| 文案 | 条件 |
| :-- | :-- |
| 任务不存在 | id 查不到 |
| 任务对应的服务项配置已被删除 | 配置明细已删 |
| 未找到对应的海运进口数据 | 票或业务表不存在 |
| 海运进口的目的港为空 | 票目的港为空 |
| 业务未配置关联用户，无法完成 | 票没有关联人员 |
| 任务不是待处理状态，无法完成 | 已处理 |
| 该任务为转交任务,只能由被转交人[{昵称}]完成,当前用户无法完成 | 转交任务、我不是被转交人 |
| 当前任务处理人为[{昵称,…}],当前用户不在任务的处理人列表中，无法完成 | 未转交任务、我不是处理人 |
| 必填字段{字段名}不能为空 | 当前+已完成任务的必填字段为空 |
| 完成任务需要上传以下附件: {类型名、…} | 必填附件没传 |
| 完成任务需要以下费用: [收]{费用名}、[付]{费用名} | 必填费用缺失 |
| [{目的港中文名}]港的[{服务项值}]服务项任务需要用户属性为[{属性名}]的处理人，当前票未配置此用户属性 | 下一档匹配不到处理人 |
| 当前公司未配置本位币 | 有命中的费用模板但公司没本位币 |
| 自动费用模板配置有误,无法生成费用: … | 模板明细费用代码/币别缺失 |

任何一条报错都不会落库（任务状态、费用、下一档任务都不写）。

## 7. 取消完成 CancelCompleteAsync

### 入参（请求体）

| 参数 | 类型 | 必填 | 说明    |
| :--- | :--- | :--- | :------ |
| id   | Guid | 是   | 任务 id |

### 出参

`result`：`true`。本任务回到待处理，本票排序号比它大的任务全部删除；已生成费用不删。

### 报错

| 文案                             | 条件       |
| :------------------------------- | :--------- |
| 任务不存在                       | id 查不到  |
| 任务不是已完成状态，无法取消完成 | 不是已处理 |
