# 1. 业务背景说明 (Background)

**白话解释：**

一票海运出口业务（`TransportOrder`）在费用录入过程中，可能存在费用尚未全部确认完结的情况。为避免在费用未完结时误操作锁定主单费用，系统增加 **未完结** 标记。操作员可将业务标记为“未完结”，待费用处理完毕后再切换为“已完结”，方可对 **主单** 进行费用锁定。更改单有独立的费用锁定流程，不受主单未完结状态限制。

# 2. 功能与操作说明 (Features & Operations)

- **查看未完结状态：** 在海运出口列表/详情、业务列表/详情、费用锁定列表中，通过 `transportOrder.isUnfinished` 字段展示。
- **切换未完结状态：** 调用 `TransportOrderAdmin/ChangeIsUnfinishedAsync`，传入业务 `id`，系统在 `true` 与 `false` 之间切换。
- **查询是否已完结：** 调用 `TransportOrderAdmin/GetIsFinishedAsync`，传入业务 `id`，返回 `true` 表示已完结（等价于 `!isUnfinished`）。
- **新建业务：** 通过海运出口新建、业务直接新建、海运出口复制创建的业务，`isUnfinished` 固定为 `false`，前端无需传参。
- **编辑业务：** 海运出口编辑、业务编辑接口 **不可修改** `isUnfinished`，只能通过专用切换接口变更。
- **主单费用锁定：** 调用 `FeeLockAsync` 锁定主单时，若 `isUnfinished == true`，系统拒绝并提示“业务费用未完结,不可锁定费用”。
- **更改单费用锁定：** 传入 `changeOrderId` 锁定更改单时，**不判断** 主单 `isUnfinished`。

# 3. 状态流转说明 (Status Transitions)

| 当前状态 | 触发人/动作 | 目标状态 | 状态说明 |
| :-- | :-- | :-- | :-- |
| 已完结（`false`） | 操作员调用 `ChangeIsUnfinishedAsync` | 未完结（`true`） | 标记该票业务费用尚未完结 |
| 未完结（`true`） | 操作员调用 `ChangeIsUnfinishedAsync` | 已完结（`false`） | 费用处理完毕，允许主单费用锁定 |
| 未完结（`true`） | 操作员尝试主单费用锁定 | 保持未完结 | 系统拦截，报错不可锁定 |
| 未完结（`true`） | 操作员锁定更改单费用 | 保持未完结 | 允许，更改单独立锁定 |
| （新建） | 新建/复制业务 | 已完结（`false`） | 默认值，不可通过新建入参修改 |

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：未完结禁止主单费用锁定]** 主单 `isUnfinished == true` 时调用 `FeeLockAsync`（`changeOrderId` 为空）-> 后端报错 `业务费用未完结,不可锁定费用`。前端建议在锁定按钮处提前禁用或提示。

> [!IMPORTANT] **[卡点 2：更改单不受未完结限制]** 主单未完结时，仍可对更改单执行费用锁定（`changeOrderId` 有值）。前端更改单锁定入口无需因主单未完结而隐藏。

> [!IMPORTANT] **[卡点 3：编辑接口不可改未完结]** `SeaExportAdmin/EditAsync`、`TransportOrderAdmin/EditAsync` 均不更新 `isUnfinished`。若前端在编辑表单中提交该字段，后端会忽略（字段不在 EditDto 中）。
