## 使用约定

- **用户 ID、组织 ID** 以当前环境数据库为准；换库或清库后需重新核对或重建。
- 测试账号密码仅用于**非生产**环境，禁止写入生产配置。
- 新增造数后在本索引追加一行，并新建或更新对应数据集 Markdown 文件。
- **跨会话**：Agent 用 browser-use 在页面上造数时，必须先读本索引再写回数据集（见 `.cursor/skills/browser-use-ui-test/SKILL.md`「测试数据跨会话持久化」）。禁止只把名称留在对话里。
- 同一功能不要另起一套名字；已落库的用关键字搜名称复用。清库后把数据集状态改回「待建」。
