# Application 入参字符串自动 Trim — 前端说明

**日期：** 2026-07-29  
**范围：** 全部 `CsprojBuilder.Application` 对外接口（增删改查入参）

## 行为说明

- 后端在接收到请求并进入 ApplicationService 前，会对入参中所有 `string` 字段执行 `Trim()`（含嵌套对象与数组项）。
- 前端仍建议在提交前自行 Trim，但即使未处理，后端也会清理首尾空格。
- **返回值不会**因本功能被 Trim；展示侧若需去空格请自行处理或依赖入库时已 Trim 的数据。

## 对接注意

1. 唯一性、模糊搜索、精确匹配均以 Trim 后的值为准。
2. 纯空格字符串 Trim 后变为 `""`，可能触发必填校验失败（符合预期）。
3. 一般无需改前端接口文档字段；无新增/删除字段。
