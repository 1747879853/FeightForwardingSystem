# 1. 背景意图 (Background)

管理端费用代码列表与详情需要展示创建人姓名，统一走用户信息缓存的昵称字段，避免直接查用户表。

# 2. 核心逻辑变更 (Core Changes)

| 项 | 变更 |
| :-- | :-- |
| `FeeCodeDto` | 新增 `CreatorUserName`（创建人昵称） |
| `GetPagedListAsync` | `GetUserInfoMapAsync` + `users.GetNickName(CreatorUserId)` 填充 |
| `DetailAsync` | 同上 |
| 查询 | 列表/详情相关查询使用 `AsNoTracking()` |

# 3. 避坑指南 (Pitfalls)

- 返回的是 `NickName`，不是 `UserName`。
- 创建人为空或缓存未命中时，`CreatorUserName` 为 `null`。
- 接口路径是 `FeeCodeAdmin/GetPagedListAsync`、`FeeCodeAdmin/DetailAsync`。
