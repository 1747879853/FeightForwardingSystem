# 1. 背景意图 (Background)

前端费用录入需要快速拉取费用代码下拉，且要带默认币别当前汇率，不宜走 Admin 分页权限接口。新增登录即可访问的 `FeeCodeAppService.GetListAsync`。

# 2. 核心逻辑变更 (Core Changes)

| 项 | 变更 |
| :-- | :-- |
| `FeeCodeAppService` / `IFeeCodeAppService` | 新增；`GET GetListAsync` |
| `FeeCodeSimpleDto` | 精简出参 + `exchangeRate` |
| `ExchangeRateSimpleDto` | 仅 `id`、`drValue`、`crValue` |
| `FeeCodeCacheItem` / `GetFeeCodesAsync` | 缓存完整业务列（筛选/排序用） |
| 过滤 | 仅 `Enable == true`；可选业务线开关精确匹配 |
| 汇率 | 按 `currencyId`，Enable + 起止时间命中，SortId/Id 降序取第一条 |
| `FeeCodeListQueryDto` | 入参：`isSea`/`isAir`/`isTrucking`/`isTruckingFixed`/`isWms`（均可空） |

# 3. 避坑指南 (Pitfalls)

- 接口路径是 `FeeCode/GetListAsync`，不是 `FeeCodeAdmin`。
- 无需业务权限，但仍需登录。
- `exchangeRate` 可能为 null，且仅含应收/应付汇率。
- 业务线开关只作入参筛选，不出现在出参。
- 改费用代码后依赖缓存失效，否则列表可能短暂旧数据。
