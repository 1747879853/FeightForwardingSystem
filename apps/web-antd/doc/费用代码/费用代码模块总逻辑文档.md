# 1. 业务背景说明 (Background)

**白话解释：**  
费用代码是费用录入时的主数据字典（代码、名称、默认币别、税率、计费标准、业务线开关等）。  
`FeeCodeAppService` 面向前端下拉/选费场景：登录即可拉取**已启用**全量列表，并附带该费用默认币别在**当前时间点有效**的汇率（仅应收/应付）。

与 `FeeCodeAdminAppService` 区别：Admin 负责增删改查（带权限、可分页）；本服务只读、无权限点、不分页、走缓存。

# 2. 功能与操作说明 (Features & Operations)

- **全量已启用列表：** 调用 `GET FeeCode/GetListAsync`，可选用 Query 过滤 `isSea`/`isAir`/`isTrucking`/`isTruckingFixed`/`isWms`（均可空）；每条带精简 `exchangeRate`（`id`/`drValue`/`crValue`）。
- **管理端维护：** 仍走 `FeeCodeAdmin`；维护后由 `BasicDataCacheInvalidator` 失效缓存，下次列表自动拿到新数据。
- **管理端列表/详情：** `GET FeeCodeAdmin/GetPagedListAsync`、`GET FeeCodeAdmin/DetailAsync` 返回 `CreatorUserName`（创建人昵称，来自用户缓存 `GetNickName`）。

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：汇率为空]** 费用有默认币别，但汇率表无「启用且当前时间落在有效期内」的记录时，`exchangeRate` 为 `null`。

> [!IMPORTANT] **[卡点 2：缓存未刷新]** 管理端刚改费用代码后，若缓存未失效，列表可能短暂为旧数据。

> [!IMPORTANT] **[卡点 3：多条汇率取第一条]** 同一币别多条同时有效时，按 `SortId`、`Id` 降序取一条。
