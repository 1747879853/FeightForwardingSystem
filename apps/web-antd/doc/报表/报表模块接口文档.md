# 0. 说明

本文档只写接口：地址、入参全字段、出参全字段。功能口径与业务逻辑见同目录下《报表模块总逻辑文档.md》。

**接口清单：**

| 接口 | 方法 | 地址 |
| :-- | :-- | :-- |
| 利润报表列表 | POST | `/api/services/app/ReportAdmin/GetProfitReportListAsync` |
| 欠费报表列表 | POST | `/api/services/app/ReportAdmin/GetArrearsReportListAsync` |
| 海空港口合并分页列表 | GET | `/api/services/app/PortCodeAdmin/GetSeaAirPortPagedListAsync` |

**两个报表都不分页**，直接返回数组。

---

# 1. 前端必须先知道的三件事

## 1.1 港口条件要成对传

海运港和空运港是两张独立的表，主键都是 `long` 且会重复。所以起运港/目的港必须传两个字段：

```
POLId + POLIsSeaPort
PODId + PODIsSeaPort
```

只传 id 不传 `IsSeaPort`，接口会直接报错「传了起运港id就必须同时传起运港是否海运港」。

港口下拉用 `GetSeaAirPortPagedList` 取，返回的每一项自带 `IsSeaPort`，原样回传即可。

## 1.2 条件字段在某些业务类型上不存在，填了会把那类业务整个排除

| 填了这个条件                      | 结果里会消失的业务类型             |
| :-------------------------------- | :--------------------------------- |
| 船公司 `CarrierId`                | 空运出口                           |
| 订舱代理 `BookingAgentId`         | 海运进口                           |
| 场站 `YardId`                     | 海运进口、空运出口（只剩海运出口） |
| 装运方式 `BLType`                 | 海运进口、空运出口（只剩海运出口） |
| 船名 `Vessel` / 航次 `InnerVoyno` | 空运出口                           |
| 起运港/目的港 `IsSeaPort=true`    | 空运出口                           |
| 起运港/目的港 `IsSeaPort=false`   | 海运出口、海运进口                 |

返回时同理：空运出口行的 `Carrier`/`Yard`/`Vessel`/`InnerVoyno`/`BLType` 为 null，`Ctns` 为空数组；海运进口行的 `BookingAgent`/`Yard`/`BLType` 为 null。

## 1.3 权限

| 接口 | 权限 |
| :-- | :-- |
| 利润报表 | `Admin.Report.Profit.Get`（不分应收应付，一个权限看全部） |
| 欠费报表 `PaySide=0`(收) | `Admin.Report.Arrears.Receive.Get` |
| 欠费报表 `PaySide=1`(付) | `Admin.Report.Arrears.Pay.Get` |

另外没有 `Admin.OrderFee.Confidential.Get` 权限的用户，机密费用不参与统计，金额会比有权限的人看到的小。

# 2. 利润报表列表

**`POST /api/services/app/ReportAdmin/GetProfitReportListAsync`**

方法名 `GetProfitReportListAsync`，入参放 body。

## 2.1 入参 `ProfitReportQueryDto`

| 字段名 | 类型 | 必填 | 含义 |
| :-- | :-- | :-: | :-- |
| `IsMergeChangeOrder` | `bool` | **是** | 是否合并更改单。true=原票和所有更改单合成一组；false=原票一组、每个更改单各一组 |
| `BizType` | `int?` |  | 业务类型 0海运出口 1海运进口 2空运出口，不传=三种都查 |
| `ClientId` | `Guid?` |  | 委托单位id |
| `MblNum` | `string` |  | 主提单号，模糊匹配 |
| `CommissionNum` | `string` |  | 委托编号，模糊匹配 |
| `BizDateStart` | `DateTime?` |  | 业务日期起，以天为单位，含当天 |
| `BizDateEnd` | `DateTime?` |  | 业务日期止，以天为单位，含当天 |
| `CargoId` | `int?` |  | 货物类型 0普通货 1冻柜 2危险品 3超限箱 |
| `SettlementType` | `int?` |  | 结算方式 0票结 1月结 2约定天数 |
| `OrgId` | `long?` |  | 所属组织id，实际搜索该组织及其所有下属组织 |
| `BookingAgentId` | `Guid?` |  | 订舱代理id |
| `CarrierId` | `long?` |  | 船公司id |
| `YardId` | `Guid?` |  | 场站id |
| `BLType` | `int?` |  | 装运方式 0整箱 1拼箱主票 2拼箱分票 |
| `Vessel` | `string` |  | 船名，模糊匹配 |
| `InnerVoyno` | `string` |  | 航次，模糊匹配 |
| `POLId` | `long?` |  | 起运港id，必须与 `POLIsSeaPort` 同时传 |
| `POLIsSeaPort` | `bool?` |  | 起运港是否海运港 |
| `PODId` | `long?` |  | 目的港id，必须与 `PODIsSeaPort` 同时传 |
| `PODIsSeaPort` | `bool?` |  | 目的港是否海运港 |
| `SaleUserIds` | `long[]` |  | 销售，多选 |
| `OperationUserIds` | `long[]` |  | 操作，多选 |
| `CustomerServiceUserIds` | `long[]` |  | 客服，多选 |
| `DocumentationUserIds` | `long[]` |  | 单证，多选 |
| `LanerUserIds` | `long[]` |  | 航线，多选（干系人角色，不是港口上挂的航线） |
| `OverseasCustomerServiceUserIds` | `long[]` |  | 海外客服，多选 |
| `AccountDateStart` | `DateTime?` |  | 会计期间起，以月为单位，含当月 |
| `AccountDateEnd` | `DateTime?` |  | 会计期间止，以月为单位，含当月 |

同一类人员多选之间是「或」，不同类人员之间是「且」。

## 2.2 出参 `ProfitReportDto[]`

默认按业务日期倒序、委托编号倒序。

### 业务信息

| 字段名 | 类型 | 含义 |
| :-- | :-- | :-- |
| `TransportOrderId` | `Guid` | 业务id，跳转业务详情用 |
| `ChangeOrderId` | `Guid?` | 更改单id，合并模式恒为 null |
| `BizType` | `int` | 业务类型 0海运出口 1海运进口 2空运出口 |
| `IsOriginal` | `bool` | 是否原票，合并模式恒为 true |
| `Client` | `ClientSimpleDto` | 委托单位 |
| `BookingAgent` | `ClientSimpleDto` | 订舱代理，海运进口为 null |
| `Carrier` | `CarrierSimpleDto` | 船公司，空运出口为 null |
| `Yard` | `ClientSimpleDto` | 场站，只有海运出口有值 |
| `BizDate` | `DateTime?` | 业务日期 |
| `AccountDate` | `DateTime` | 会计期间 |
| `MblNum` | `string` | 主提单号 |
| `CommissionNum` | `string` | 委托编号 |
| `POL` | `SeaAirPortSimpleDto` | 起运港 |
| `POD` | `SeaAirPortSimpleDto` | 目的港 |
| `Vessel` | `string` | 船名，空运出口为 null |
| `InnerVoyno` | `string` | 航次，空运出口为 null |
| `Ctns` | `ReportCtnSimpleDto[]` | 箱型箱量，空运出口为空数组 |
| `CargoId` | `int` | 货物类型 |
| `BLType` | `int?` | 装运方式，只有海运出口有值 |
| `SettlementType` | `int?` | 结算方式，存量业务为 null |
| `Orgs` | `OrganizationUnitSimpleDto[]` | 所属组织串，从最高级到本组织 |
| `Sales` | `UserSimpleDto[]` | 销售 |
| `Operations` | `UserSimpleDto[]` | 操作 |
| `CustomerServices` | `UserSimpleDto[]` | 客服 |
| `Documentations` | `UserSimpleDto[]` | 单证 |
| `Laners` | `UserSimpleDto[]` | 航线 |
| `OverseasCustomerServices` | `UserSimpleDto[]` | 海外客服 |
| `CodeGoodss` | `CodeGoodsSimpleDto[]` | 品名 |
| `PKGS` | `int?` | 件数 |
| `Kgs` | `decimal?` | 重量 |
| `Cbm` | `decimal?` | 尺码 |

### 金额

| 字段名 | 类型 | 含义 |
| :-- | :-- | :-- |
| `Currencies` | `ProfitCurrencyDto[]` | 按币别分组的原币明细 |
| `TotalReceivable` | `decimal` | 合计应收（本位币人民币） |
| `TotalUnReceived` | `decimal` | 合计未收（本位币） |
| `TotalPayable` | `decimal` | 合计应付（本位币） |
| `TotalUnPaid` | `decimal` | 合计未付（本位币） |
| `TotalProfit` | `decimal` | 合计利润 = 合计应收 − 合计应付 |
| `TotalProfitRate` | `decimal?` | 合计利润率 = 合计利润 / 合计应付，**合计应付为 0 时返回 null** |

**`ProfitCurrencyDto`（原币，不折算）：**

| 字段名       | 类型                | 含义               |
| :----------- | :------------------ | :----------------- |
| `Currency`   | `CurrencySimpleDto` | 币别               |
| `Receivable` | `decimal`           | 应收               |
| `UnReceived` | `decimal`           | 未收               |
| `Payable`    | `decimal`           | 应付               |
| `UnPaid`     | `decimal`           | 未付               |
| `Profit`     | `decimal`           | 利润 = 应收 − 应付 |

# 3. 欠费报表列表

**`POST /api/services/app/ReportAdmin/GetArrearsReportListAsync`**

方法名 `GetArrearsReportListAsync`，入参放 body。

## 3.1 入参 `ArrearsReportQueryDto`

**包含利润报表 2.1 节的全部字段**，另加下面这些：

| 字段名 | 类型 | 必填 | 含义 |
| :-- | :-- | :-: | :-- |
| `PaySide` | `int` | **是** | 收付类型 0收 1付。决定校验哪个权限，也决定金额字段读作应收还是应付 |
| `SettlementId` | `Guid?` |  | 结算对象id（欠谁的钱/谁欠我们的钱） |
| `SettlementStatus` | `int?` |  | 结算状态 0未结算 1部分结算 2结算完毕 |
| `PaymentApplyStatus` | `int?` |  | 付费申请状态 0未提交 1提交了部分 2已全额提交 |
| `InvoiceStatus` | `int?` |  | 开票状态 0未开票 1部分开票 2已开票 |
| `IsStatemented` | `bool?` |  | 是否对账 |
| `FeeLocked` | `bool?` |  | 是否费用锁定 |

## 3.2 出参 `ArrearsReportDto[]`

默认按超期天数倒序、业务日期倒序。

**业务信息字段与利润报表 2.2 节完全一致**，另加下面这些：

| 字段名 | 类型 | 含义 |
| :-- | :-- | :-- |
| `Settlement` | `ClientSimpleDto` | 结算对象。费用录入状态时可以为空，空结算对象的费用单独归成一组，此时返回 null |
| `FeeLocked` | `bool` | 费用锁定 |
| `SettlementDate` | `DateTime` | 应结日期 |
| `OverdueDays` | `int` | 超期天数 = 今天 − 应结日期（舍掉小时）。**未到期是负数** |
| `InvoiceNos` | `string[]` | 发票号，组内去重合并 |
| `Currencies` | `ArrearsCurrencyDto[]` | 按币别分组的原币明细 |
| `TotalReceivable` | `decimal` | 合计应收/应付（本位币人民币） |
| `TotalReceived` | `decimal` | 合计已收/已付（本位币） |
| `TotalUnReceived` | `decimal` | 合计未收/未付（本位币） |

**`ArrearsCurrencyDto`（原币，不折算）：**

| 字段名       | 类型                | 含义        |
| :----------- | :------------------ | :---------- |
| `Currency`   | `CurrencySimpleDto` | 币别        |
| `Receivable` | `decimal`           | 应收 / 应付 |
| `Received`   | `decimal`           | 已收 / 已付 |
| `UnReceived` | `decimal`           | 未收 / 未付 |

> 收付类型 = 收 时这三个字段读作「应收/已收/未收」，= 付 时读作「应付/已付/未付」，**字段名复用同一套**，表头由前端按 `PaySide` 切换。

# 4. 海空港口合并分页列表

**`GET /api/services/app/PortCodeAdmin/GetSeaAirPortPagedListAsync`**

方法名 `GetSeaAirPortPagedListAsync`，入参走 query string。

## 4.1 入参 `SeaAirPortQueryDto`

| 字段名      | 类型     | 含义                                               |
| :---------- | :------- | :------------------------------------------------- |
| `PageIndex` | `int`    | 页码，从 1 开始，默认 1                            |
| `PageSize`  | `int`    | 每页条数，默认 10                                  |
| `Keyword`   | `string` | 关键字，模糊匹配中文名、英文名、代码               |
| `IsSeaPort` | `bool?`  | 不传=海空一起查；true=只查海运港；false=只查空运港 |
| `Status`    | `int?`   | 0启用 1禁用，不传=不过滤                           |

**没有 `Sorting` 参数。** 排序固定为「先海运港后空运港，各自按中文名升序」。

## 4.2 出参 `PagedList<SeaAirPortSimpleDto>`

| 字段名           | 类型                    | 含义     |
| :--------------- | :---------------------- | :------- |
| `Items`          | `SeaAirPortSimpleDto[]` | 数据     |
| `TotalCount`     | `int`                   | 总条数   |
| `SkipCount`      | `int`                   | 跳过条数 |
| `MaxResultCount` | `int`                   | 每页条数 |
| `CurrentPage`    | `int`                   | 当前页   |
| `TotalPages`     | `int`                   | 总页数   |

**`SeaAirPortSimpleDto`：**

| 字段名 | 类型 | 含义 |
| :-- | :-- | :-- |
| `Id` | `long` | 港口id。海运港和空运港的 id 会重复，必须配合 `IsSeaPort` 使用 |
| `IsSeaPort` | `bool` | 是否海运港 |
| `CnName` | `string` | 中文名 |
| `EnName` | `string` | 英文名 |
| `Code` | `string` | 代码。海运港是 EDI 代码，空运港是三字码 |

# 5. 复用的公共结构

| `DishonestRemark` | `string`                      | 失信说明   |
