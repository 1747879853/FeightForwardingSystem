# 1. 背景意图 (Background)

`InvoiceIssueAdminAppService` 的列表 `GetPagedListAsync` 与详情 `DetailAsync` 此前已返回 `ClientInvoiceBank`（客户银行简易信息 `ClientInvoiceBankSimpleDto`），但缺少该银行所属的**客户开票信息**（抬头、税号、地址、电话等）。本次让两个接口**额外返回 `ClientInvoiceBankId` 对应的 `ClientInvoiceInfo` 的 DTO**，无对应数据时为 `null`。

# 2. 核心逻辑变更 (Core Logic)

涉及文件：

- `src/CsprojBuilder.Application/App/InvoiceIssue/InvoiceIssueAdminAppService.cs`
- `src/CsprojBuilder.Application/App/InvoiceIssue/Dto/InvoiceIssueDto.cs`

## 2.1 DTO 变更

`InvoiceIssueListDto`、`InvoiceIssueDetailDto` 各在 `ClientInvoiceBank` 之后新增：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `ClientInvoiceInfo` | `ClientInvoiceInfoDto` | 客户银行(`ClientInvoiceBankId`)对应的客户开票信息，无则 `null`，含其下银行列表 `ClientInvoiceBanks`（带 `CurrencyCode`） |

`InvoiceIssueDto.cs` 已有 `using CsprojBuilder.App.ClientInvoiceInfo.Dto;`，无需新增。

## 2.2 解析逻辑（私有方法）

新增私有方法 `GetClientInvoiceInfoMapByBankIdsAsync(List<Guid> clientInvoiceBankIds)`（与开票申请模块同构），返回 `银行id -> ClientInvoiceInfoDto` 字典：

1. 过滤空 `Guid`、去重；为空返回空字典。
2. `_clientInvoiceBankRepository` + `.Include(b => b.ClientInvoiceInfo).ThenInclude(i => i.ClientInvoiceBanks)` 一次性加载。
3. 批量取币别回填 `ClientInvoiceBankDto.CurrencyCode`，银行列表按 `IsDefault`、`SortId` 倒序。
4. 列表方法在已有 `clientBanks` 加载处一并构建字典；详情方法单 id 调用；均 `GetValueOrDefault` 取值。

> 本模块未注入 `ClientInvoiceInfo` 仓储，统一通过 `ClientInvoiceBank` 的导航属性 `Include` 解析，避免新增依赖。

# 3. 避坑指南 (Pitfalls)

- **`Currency` 命名冲突**：与 `CsprojBuilder.App.Currency` 命名空间撞名，新建空列表须写 `new List<Entites.Currency>()`，否则 CS0118/CS0173。
- **`ClientInvoiceBank`(简易) 与 `ClientInvoiceInfo` 并存**：前者是当前选中的银行简易信息，后者是该银行所属开票信息（含其全部银行），二者用途不同。
- **无数据返回 `null`**：`ClientInvoiceBankId` 为空或查不到时 `ClientInvoiceInfo` 为 `null`。
