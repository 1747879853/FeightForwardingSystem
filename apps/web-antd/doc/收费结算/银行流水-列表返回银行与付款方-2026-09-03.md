# 1. 背景意图 (Background)

列表页要直接展示我司银行、对方银行、付款方，不能再靠 id 二次去查，也不能再取已删除的平铺名称字段。

# 2. 核心逻辑变更

`BankStatementListDto` 补上 `clientInvoiceBank`（`ClientInvoiceBankSimpleDto`）。`settlement`（付款方）和 `orgBankAccount`（我司银行）列表里本来就有，本次只把对方银行按详情同一套 SimpleDto 填上。

| 业务含义 | JSON 字段 | 类型 | 本次 |
| :-- | :-- | :-- | :-- |
| 付款方 | `settlement` | `ClientSimpleDtoForOrder` | 已有，注释改为明确「付款方」 |
| 我司银行 | `orgBankAccount` | `OrgBankAccountSimpleDto` | 已有 |
| 对方银行 | `clientInvoiceBank` | `ClientInvoiceBankSimpleDto` | **新增**。`clientInvoiceBankId` 为空时为 null |

Admin / 非 Admin 共用这份 ListDto，两边 `GetPagedListAsync` 都按 id 批量查出对方银行再 `ObjectMapper.Map`。关联查询加了 `AsNoTracking()`。

接口地址：

| 接口          | 路径                                                         |
| :------------ | :----------------------------------------------------------- |
| Admin 列表    | `GET /api/services/app/BankStatementAdmin/GetPagedListAsync` |
| 非 Admin 列表 | `GET /api/services/app/BankStatement/GetPagedListAsync`      |

嵌套字段表见《银行流水.md》详情/列表出参。

# 3. 避坑指南 (Pitfalls)

> [!IMPORTANT] **不要再取 `orgBankAccountName` / `clientInvoiceBankName` / `settlementName`。** 这几个平铺字段已经删了，银行名称在 `orgBankAccount.bankName`、`clientInvoiceBank.bankName`，付款方简称在 `settlement.name`。

> [!IMPORTANT] **`orgBankAccount.currencyCode` 可能是 null。** `OrgBankAccount` 实体没有币种代码列，SimpleDto 上这一项不会自动映上；币别请用行上的 `currency.code`。
