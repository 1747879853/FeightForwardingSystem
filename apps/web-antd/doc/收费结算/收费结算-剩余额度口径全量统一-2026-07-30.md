# 1. 背景意图 (Background)

付费申请、收费结算、业务费用等多处“剩余额度/未申请/未结算”原先有的扣 `ReceiveSettlementInvoiceItems`，有的扣 `InvoiceApplicationItems`，口径不一致，会高估可结算/可申请金额。

本次把所有共用池剩余额度统一为同一公式。

# 2. 统一口径

```text
remaining
= Amount
- Sum(PaymentApplicationItems.AppliedAmount)
- Sum(ReceiveSettlementItems.SettledAmount)
- Sum(InvoiceApplicationItems.AppliedAmount)
```

# 4. 按开票申请结算的总额口径

按开票申请是兑现已占用的开票申请额，不能只扣 `IA` 否则无法结算。总额口径定义为：

```text
poolRemaining = Amount - 付费申请 - 按费用结算 - 开票申请占用
invoiceSettleable = max(0, 已开票 - 已现金结算)
totalRemaining = poolRemaining + invoiceSettleable
```

发票口径仍为 `invoiceSettleable`。
