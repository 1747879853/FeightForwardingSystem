# 1. 背景意图 (Background)

非 Admin 银行流水详情 `BankStatement/DetailAsync` 原先对 `receiveSettlements` 按当前用户创建人过滤，导致同一流水下他人创建的收费结算看不到。现调整为与 Admin 详情一致，返回该流水下全部收费结算。

# 2. 核心逻辑变更 (Core Changes)

| 位置 | 变更前 | 变更后 |
| :-- | :-- | :-- |
| `BankStatementAppService.DetailAsync` | `GetDetailsByBankStatementAsync(id, AbpSession.GetUserId())` | `GetDetailsByBankStatementAsync(id)`（不传创建人，返回全部） |

`GetDetailsByBankStatementAsync` 的可选 `creatorUserId` 参数仍保留，其它调用方可按需过滤。

# 3. 避坑指南 (Pitfalls)

- 列表侧「操作人权限」与详情内「收费结算列表」是不同维度：能打开流水详情后，其下收费结算不再按创建人裁剪。
- 非 Admin 分页接口 `GetReceiveSettlementPagedListAsync` 仍走 `DataPermissionFilterAsync`，本次未改。
