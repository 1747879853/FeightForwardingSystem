# 1. 业务背景说明 (Background)

提单随海运出口主单、分单自动生成。操作管理下的 `/bill-of-lading` 用于提单签入、换签、扣单、申请审核及签出，无人工新增、编辑或删除入口。查看权限为 `Admin.BillOfLading.Get`。

# 2. 功能与操作说明 (Features & Operations)

- 按提单号、状态、委托单位、签单方式、船公司、船名航次、开船/签入/签出日期、人员、委托编号及主分单检索。
- 通过通用分组设置按钮和横向标签，按委托单位、船公司、签单方式分组下钻；空分组显示「未填写」。卡片进入全部、待签出、超期未收或待我审核。
- 勾选后在顶部执行有权限且满足状态的操作；双击打开详情和完整历史；移除顶部「详情 / 历史」「审核详情」按钮。
- 签入要求一个扫描件；日期默认当天。换签、扣单、签出支持批量；签出需要重新选择签单方式和签出方式。
- 提交审核按结算对象同批，超期提单分别填写承诺日期、超期备注、证明。撤销提交为整批撤销，已有审核结果时由后端拒绝。

- 分组复用 `GroupingSettings`、`GroupingTabs`、`useListGrouping`：启用维度后清空并禁用对应搜索项，关闭后恢复；用户分组偏好以 `group_config_BillOfLadingList` 保存。分组切换和分页不重复加载统计，搜索条件变化、操作成功和重新进入页面时更新统计。

# 3. 状态流转说明 (Status Transitions)

| 当前状态 | 触发人/动作 | 目标状态 | 状态说明 |
| :-- | :-- | :-- | :-- |
| 待签入 | 有签入权限的操作人签入 | 已签入 | 正本且一个扫描件 |
| 已签入/已驳回 | 提交审核 | 签出审核中/可签出 | 无需审核人时直接通过 |
| 已签入/已驳回 | 换签/取消换签 | 不变 | 正本换电放或恢复换签前方式 |
| 签出审核中 | 撤销提交 | 提交前状态 | 整批、没有任何已审结果 |
| 可签出 | 签出 | 已签出 | 批量共用签出信息 |
| 已签出 | 取消签出 | 可签出 | 不回退签单方式 |
| 非审核中/非已扣单 | 扣单 | 已扣单 | 记录原状态 |
| 已扣单 | 取消扣单 | 扣单前状态 | 仅此操作可用 |

# 4. 核心字段说明 (Field Definitions)

| 字段名 | 字段含义说明 | 数据来源 | 联动规则 | 校验限制 |
| :-- | :-- | :-- | :-- | :-- |
| `settlement.id` | 主单委托单位或分单结算对象 | 提单接口 | 批量提交比较此值 | 必须相同且非空 |
| `isOverdue` | 提交是否需要超期证明 | 提单接口 | 展示逐张补充表单 | 超期必填三项 |
| `promisePayDate` | 承诺付款日期 | 操作录入 | 比主单应结日期 | 必须晚于应结日期 |
| `CarrierIdEmpty` / `CodeIssueTypeIdEmpty` | 分组为空的筛选 | 分组选择 | 替换具体 ID 条件 | 不与具体 ID 同传 |
| `taskBaseId` | 最近签出审核批次 | 列表/详情 | 撤销、查看审核 | 撤销影响整批 |
| 附件 ID | 先上传的文件标识 | 公共上传接口 | 后端绑定模块与业务 | 保留字符串精度 |

# 5. 核心业务卡点 (Business Blockers)

- 页面内容区必须保持纵向 flex 高度约束，卡片不收缩，表格及分组仅使用剩余高度；否则 VXE 自动测高可能反复撑大父容器。

- 已扣单仅能取消扣单；审核中仅能撤销提交。非正本不能签入或换签；已换签不能取消签入。
- 超期未收卡片不考虑承诺日期；提交是否超期采用另一个后端字段，不能混用。
- 待审核数量按子任务统计，跳审核页面；不要映射为提单状态筛选。
- 存量票不会补建提单；没有启用的提单签出工作流时无法提交。
