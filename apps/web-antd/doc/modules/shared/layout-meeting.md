# 1. 业务背景说明 (Background)

**白话解释：**  
登录后顶栏提供「进入会议」入口，打开佳越在线会议页，按当前部署品牌带入对应会议号与当前用户昵称，便于同品牌同事快速进同一房间。

# 2. 功能与操作说明 (Features & Operations)

- **进入会议：** 点击顶栏会议图标 → 新窗口打开会议页，URL 携带 `room`、`password`、`name`。
- **会议号按品牌：** 津海通 `999999`；浩瀚远洋与佳越软件 `123456`。
