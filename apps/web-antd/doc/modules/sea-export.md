# SeaExport 模块活文档

## 模块范围

- 页面范围：`apps/web-antd/src/views/sea-export-admin/`（列表、详情/表单、业务子模块）。
- 本文聚焦本次改动涉及的只读信息展示链路：`form.vue` -> `modules/readonly-form-item.vue`。

## 核心逻辑（当前现状）

- 左侧“委托信息”区通过 `ReadonlyFormItem` 展示如委托编号、会计期间、应结日期、所属公司等只读字段。
- `ReadonlyFormItem` 内部统一处理空值占位（默认 `-`），并将输入值转换为字符串展示。
- 只读值区域已启用单行省略（ellipsis），当内容超出容器宽度时自动截断，同时通过 `title` 在 hover 时展示完整内容。

## 当前架构与约束

- 省略策略在通用组件层实现，页面侧无需逐字段添加 Tooltip，能保证一致性并减少维护成本。
- 当前悬浮提示依赖浏览器原生 `title`，交互轻量但样式不可定制，且移动端体验有限。
- 样式生效依赖值容器 `min-width: 0` 与 `flex` 布局协作，布局重构时需验证省略仍可触发。

## 注意事项

- 若某些字段未来需要复制按钮、富文本提示或多行展示，应在组件层新增可配置能力（如 `tooltip`、`multiline`），避免页面分叉实现。
- 若引入 UI 库 Tooltip 组件，需评估性能与渲染层级（弹层容器）对当前页面的影响。
