# 1. 业务背景说明 (Background)

`/audit-approval/bill-of-lading-review` 展示当前人参与的签出审核批次。一次提交是一行，一个批次可包含多个海出主单/分单提单，审核人可以只处理其中几张。权限为 `Admin.BillOfLading.Audit`。

# 2. 功能与操作说明 (Features & Operations)

- 默认「待我审核」，支持我已审核、是否完成、提单号、委托单位、提交日期筛选。
- 双击审核批次行打开详情，列表不再提供详情按钮或批次勾选列；保留 `taskId` 深链接兼容。
- 列表只保留「批次状态」一列，标签显示整批状态。鼠标悬浮该标签时，浮层展示我的审核状态，以及本批审批流程。流程用列表已返回的 `workFlowInstance`，不再单独占一列。主提单号、分提单号可点击复制，不显示复制图标；同一格有多个号码时各自复制。
- 详情里申请放单、压单、后续新单、应收欠费、客户历史异常表上的主提单号和分提单号同样可点击复制。双击列表行仍打开详情。
- 申请放单不再单独列出「我的审核状态」。提单状态标签悬浮后，浮层先显示本人在这张提单上的审核状态，再列出审批层级。这张提单已驳回时，浮层顶部单独列出红色「驳回原因」，没填意见显示「未填写」。审核人的结论跟这张提单走：驳回的提单显示已驳回，不沿用主流程上的整批结论。压单、后续新单仍只显示提单状态。
- 详情顶部为结算对象、批次状态和摘要（申请人、申请时间、提单数量 / 未完成、本批未收、客户欠款）。客户欠款把本页应收欠费按本位币加总；超期天数大于 0 的未收另外用红色标在标题旁。没有欠费报表权限时这一格显示「未能读取」。页签放申请放单、压单、后续新单、客户信息、应收欠费、客户历史异常，页签上的数量是浅底圆角胶囊。不再在右侧单独展示审批流程。各表格占满页签剩余高度；滚动时表头和合计行保持不动，只滚动数据行。申请放单里有压单时，该行淡橙底，行首红色「压单」；整批都没有压单时不占这一列。申请放单、压单、后续新单在结算对象一致时不重复结算对象列；分提单号、超期备注、审核人、审核意见整列为空时隐藏，有内容才显示。三张表各有「超期证明」列，只列出该行提单自己的证明文件名，没有则留空；签入扫描件不在审核页展示。客户历史异常仍保留原「证明文件」列。应收欠费表保留结算对象，避免合计行错位。
- 申请放单的通过、驳回固定在表格下方。通过是主按钮，驳回是危险色幽灵按钮。全选只勾当前可审核的提单；全部通过先勾可以通过的提单，再走原来的确认框。未勾选记录不受影响，确认前不提交。
- 附件使用统一查看器；无客户/报表权限的部分单独显示空态。
- 应收欠费的超期天数与欠费报表同一口径：负数是未到期，显示绿色；当天到期为黄，已超期为红。表上金额是折算后的本位币。鼠标悬浮应收、已收、未收，浮层按币别分块列出折算前的三项原币，并加亮当前这一列；合计行的金额同样悬浮，按同一本位币把各行原币再加总。表底仍按本位币合计，不同本位币分行列出。本位币金额显示对应币种符号，不再写死人民币符号；本位币列显示币种代码。申请放单、压单、后续新单的未收金额，客户历史异常的未结金额，以及摘要上的本批未收和客户欠款，同样悬浮查看折算前原币；金额列右对齐。原币按票从本页应收欠费明细汇总，没有对应欠费行时不出现浮层。摘要金额的下划线只跟数字一样宽。审核列表的未收金额同样带本位币符号；鼠标悬浮时按本批提单取折算前原币，口径与详情摘要一致。原币浮层挂在页面上，不跟表格一起裁切；列表金额读取中、读失败都会提示，金额下只留虚线。

# 3. 状态流转说明 (Status Transitions)

| 当前状态 | 触发人/动作 | 目标状态 | 状态说明 |
| :-- | :-- | :-- | :-- |
| 审核中且待我审核 | 当前审核人通过 | 审核中/可签出 | 多级审批可能还有后续节点 |
| 审核中且待我审核 | 当前审核人驳回 | 已驳回 | 未选提单不变 |
| 可签出且本人曾通过 | 原通过人驳回 | 已驳回 | 同一审核接口，传失败 |
| 已签出 | 无审核动作 | 不变 | 不能再驳回 |

# 4. 核心字段说明 (Field Definitions)

| `isHeldUp` | 本张是否压单 | 本批提单明细 | 为真时申请放单行淡橙底，行首红色「压单」 | 整批都没有压单时不显示该列；普通提单列表不展示 |

# 5. 核心业务卡点 (Business Blockers)

- 列表不带提单明细，不能从列表直接跨批审核。
- 前端按本人状态提示和控制，最终审核权限及最新批次由后端校验。
- 批次全部通过、全部驳回、部分通过和处理中分别展示；卡片待审核数量与批次行数不是同一单位。
- 工作流类型 11 只支持用户/角色，条件 11001 委托单位、11002 提交人组织、11003 是否超期。
