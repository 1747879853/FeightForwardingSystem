# 1. 业务背景说明 (Background)

`/audit-approval/bill-of-lading-review` 展示当前人参与的签出审核批次。一次提交是一行，一个批次可包含多个海出主单/分单提单，审核人可以只处理其中几张。权限为 `Admin.BillOfLading.Audit`。

# 2. 功能与操作说明 (Features & Operations)

- 默认「待我审核」，支持我已审核、是否完成、提单号、委托单位、提交日期筛选。
- 双击审核批次行打开详情，列表不再提供详情按钮或批次勾选列；保留 `taskId` 深链接兼容。
- 列表只保留「批次状态」一列，标签显示整批状态。鼠标悬浮该标签时，浮层展示我的审核状态，以及本批审批流程。流程用列表已返回的 `workFlowInstance`，不再单独占一列。
- 详情顶部为结算对象、批次状态和摘要（申请人、申请时间、提单数量 / 未完成、未收金额）。页签放申请放单、压单、后续新单、客户信息、应收欠费、客户历史异常，不再在右侧单独展示审批流程。申请放单、压单、后续新单三张表各有「超期证明」列，只列出该行提单自己的证明文件名，没有则留空；签入扫描件不在审核页展示。客户历史异常仍保留原「证明文件」列。
- 只在本批提单明细中勾选审核；通过、驳回都二次确认并可填意见，未勾选记录不受影响。
- 附件使用统一查看器；无客户/报表权限的部分单独显示空态。
- 应收欠费的超期天数与欠费报表同一口径：负数是未到期，显示绿色；当天到期为黄，已超期为红。表底按本位币合计应收、已收、未收，不同本位币分行列出。

# 3. 状态流转说明 (Status Transitions)

| 当前状态 | 触发人/动作 | 目标状态 | 状态说明 |
| :-- | :-- | :-- | :-- |
| 审核中且待我审核 | 当前审核人通过 | 审核中/可签出 | 多级审批可能还有后续节点 |
| 审核中且待我审核 | 当前审核人驳回 | 已驳回 | 未选提单不变 |
| 可签出且本人曾通过 | 原通过人驳回 | 已驳回 | 同一审核接口，传失败 |
| 已签出 | 无审核动作 | 不变 | 不能再驳回 |

# 4. 核心字段说明 (Field Definitions)

# 5. 核心业务卡点 (Business Blockers)

- 列表不带提单明细，不能从列表直接跨批审核。
- 前端按本人状态提示和控制，最终审核权限及最新批次由后端校验。
- 批次全部通过、全部驳回、部分通过和处理中分别展示；卡片待审核数量与批次行数不是同一单位。
- 工作流类型 11 只支持用户/角色，条件 11001 委托单位、11002 提交人组织、11003 是否超期。
