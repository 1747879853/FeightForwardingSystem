# 1. 业务背景说明 (Background)

**白话解释：** 销售提交的业务联系单会形成审核任务，落到对应审核人名下。这一页把「待我审核」和「我审核过的」任务集中列出来，审核人从这里定位到单据，再进入单据详情执行通过或驳回。

# 2. 功能与操作说明 (Features & Operations)

- **任务列表：** 调 `PreOrderAdmin/PreOrderTaskListAsync`，行上同时展示任务信息（我的审核状态、任务状态、审核人、审核时间）与单据信息（业务编号、委托单位、起运港 / 目的港、ETD）。
- **检索：** 关键字、我的审核状态（**默认「审核中」**）、单据状态、委托单位、起运港、审核时间区间。
- **进入单据：** 双击行，或勾选后点「打开单据」，跳转 `/pre-order/:id/edit`；审核动作在单据编辑页完成，不在本页直接审。
- **审核流程：** 勾选行后点「审核流程」，复用 `workflow-timeline`（`taskType = TaskType.PreOrder`）查看各级审批人与意见。

# 3. 状态流转说明 (Status Transitions)

本页不直接改状态，仅作为任务入口。

| 当前状态 | 触发人/动作 | 目标状态 | 状态说明 |
| :-- | :-- | :-- | :-- |
| 待审核(1) | 审核人在本页双击进单据后审核 | 通过(2) / 驳回(3) | 实际流转发生在 `/pre-order/:id/edit` |

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：审核动作不在本页]** 本页只提供定位与跳转，审核通过 / 驳回统一在单据详情页执行，避免审核弹窗与「操作干系人必填」等前置校验逻辑在两处重复实现。

> [!IMPORTANT] **[卡点 2：菜单权限]** 入口受 `Admin.PreOrder.Audit` 控制；「审核审批」父菜单的权限白名单已同步追加该权限码。
