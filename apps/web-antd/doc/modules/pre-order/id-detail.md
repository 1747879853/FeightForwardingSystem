# 1. 业务背景说明 (Background)

**白话解释：** 业务联系单进入「待审核」或「通过」后，单据本身不可再改（通过后关联海运出口仍可按海出权限编辑）。详情页是独立的纯展示页：用描述列表与只读表格呈现数据，不用表单控件；审核人在此完成通过、驳回与流程查看。

# 2. 功能与操作说明 (Features & Operations)

- **入口：**
  - 列表双击「待审核 / 通过」行 → `/pre-order/:id/detail`
  - 审核中心 / 工作台「业务联系单审核」打开单据 → 详情
  - 编辑页提交审核成功后，自动 `replace` 到详情
- **展示：** 独立组件 `detail.vue`；**布局复用编辑页**（`form.css` + 主栏分区 / 右侧干系人 / 港口流转卡片 / 货物左右分栏），字段改为纯文本，**不挂载** Input/Select/DatePicker；服务流水线复用只读 `ServicePanel`；箱型/费用/干系人为只读 Table。
- **分区：** 与编辑页一致——顶部服务项 + 审核按钮；基础信息 meta；收发通；港口信息；货物与箱型；费用；右侧干系人。
- **工具栏（按状态）：** 审核流程；待审核时可撤回、审核通过/驳回；通过时有权限可审核后驳回；通过且有关联出口时显示「关联海运出口」Tab（内嵌海出编辑器）。
- **状态回退：** 撤回或驳回到「录入 / 驳回」后，自动 `replace` 回 `/pre-order/:id/edit`。

# 3. 状态流转说明 (Status Transitions)

本页不新增状态机，流转动作与编辑页一致，仅入口与展示形态不同。

| 当前状态 | 触发人/动作 | 目标状态 | 状态说明 |
| :-- | :-- | :-- | :-- |
| 待审核(1) | 提交人点「撤回」 | 录入状态(0) | 路由切回 `/edit` |
| 待审核(1) | 审核人通过 / 驳回 | 通过(2) / 驳回(3) | 通过留在详情；驳回切 `/edit` |
| 通过(2) | 审核后驳回 | 驳回(3) | 须先删关联海运出口；成功后切 `/edit` |

# 4. 核心字段说明 (Field Definitions)

| 字段名 | 📖 字段含义说明 | 🔌 数据来源 (接口/字典) | 🔗 联动规则 (依赖与触发) | 🛡️ 校验限制 (Validation) |
| :-- | :-- | :-- | :-- | :-- |
| **路由 id** | 业务联系单主键 | 路径参数 UUID | 与编辑页、海运出口同 Id | 只读 |
| **status** | 决定按钮与是否留在详情 | `PreOrderStatus` | 待审核/通过才应停留在本路由 | 非此二态会 `replace` 到 `/edit` |
| **嵌套名称** | 委托单位/港口/费用等展示名 | 详情 DTO 的 `*.name` | 缺名称时用列表兜底字段 | 只读文本 |

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：路由与状态必须对齐]** 手工打开 `/detail` 但单据为录入/驳回，或打开 `/edit` 但单据为待审核/通过 → 加载详情后 `syncRouteByStatus` 强制 `replace` 到正确路径。

> [!IMPORTANT] **[卡点 2：详情与编辑分离]** 详情是纯展示组件，不再复用 `editor.vue` 禁用表单；审核意见弹窗 `AuditModal` 仍可使用表单控件。

> [!IMPORTANT] **[卡点 3：行业类别展示按 key]** 费用 `industryCategory` 存的是枚举 `key`（数字），展示匹配 `getIndustryCategoryOptions().key`，不要按字母 `value`。
