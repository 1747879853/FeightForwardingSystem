# 发邮件弹窗与五个业务页接入

对应 TAPD：

- [#1000224](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000224) 发邮件弹窗
- [#1000225](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000225) 五个业务页接入

接口以 `邮件模板模块接口文档.md` 第 2 章为准。`frightModule` 用 FrightModule（海出 0、海进 4、空出 5、件杂货 12、发票开出 15），不用 BizType。

## 1. 组件边界

一个通用弹窗 `SendMailModal`，五个页面只负责打开它并传入当前票。

| 入参 | 说明 |
| :-- | :-- |
| `frightModule` | 上表数值 |
| `entityId` | 详情 id；发票开出传发票开出 id |
| `viewCode` | 打开按钮所需查看权限，如 `Admin.SeaExport.Get` |
| `printJsonType` | 有打印数据源才传。海出 `0`、海进 `4000`、空出 `5000`、件杂货 `7000`。发票开出没有打印数据源，不传，弹窗不出现「打印文件」 |
| `bizType` | 筛打印模板。海出 0、海进 1、空出 2、件杂货 3。`0` 是有效值 |
| `resolvePrintFilter` | 可选。生成打印文件前调用，返回当票签单方式 / 船公司 / 分公司，筛选规则与该页「打印」按钮一致。返回 `null` 表示用户取消（例如未保存确认） |

入口只放在**已保存详情**的工具栏。新建未保存不显示。列表行不加「发邮件」：需求写明要和产品确认，本期先不做，避免列表和详情两套入口。

件杂货详情页当前仓库里还没有页面。弹窗按 `frightModule = 12`、`printJsonType = 7000` 实现；页面落地后把同一个按钮挂到详情工具栏即可。

## 2. 弹窗流程

两个页签：**写信**、**本票发送记录**。发送记录页签复用发送记录列表，固定传入当前 `frightModule` 和 `entityId`。

写信：

1. 打开后调 `MailTemplate/GetUsableListAsync`。空列表提示「没有可用的邮件模板」，编辑区不可用。后端已按启用和服务项任务过滤，前端不再滤一遍。
2. 选一个模板调 `GenerateAsync`。把 `subject`、`body`、`toAddresses`、`ccAddresses`、`systemAttachments` 填进编辑区。`invalidAddresses` 有值时提示「以下邮箱格式不正确，已忽略：…」。
3. 再选另一个模板且当前内容已改过时，先确认再重新生成，避免盖掉手改内容。
4. 收件人、抄送人用已有标签输入，可增删，只收纯邮箱。
5. 标题单行，正文用现有富文本，`body` 按 HTML 提交。

底部按钮不走弹窗默认「确定」：

| 按钮 | 权限 | 接口 |
| :-- | :-- | :-- |
| 存草稿 | `Admin.PersonalMail.Draft` | `SaveDraftAsync`，收件人可空，不传 `mailTemplateId` |
| 发送 | `Admin.PersonalMail.Send` | `SendAsync`，收件人至少一个，带回生成结果里的 `mailTemplateId` |

没权限的按钮不显示。`mailAccountId` 不传。

没配置个人邮箱时，提示原文并给出跳到 `/profile?tab=mail` 的入口。其余报错用接口返回的原文。

## 3. 三类附件

| 类 | 做法 | 限制 |
| :-- | :-- | :-- |
| 系统附件 | 勾选 `systemAttachments`，提交勾中的 `attachmentId` | 只使用生成接口返回的列表，不另查附件 |
| 打印文件 | 弹窗内拉打印模板列表，再调 `PrintFormatAdmin/GetPrintAsync`，把返回的文件名放进 `printFileNames` | 不上传。文件名可带 `PrintTempFile/` 前缀，按接口原样传 |
| 本地上传 | `FileReader` 转 base64，放进 `attachments: [{ fileName, content }]` | 不走系统附件上传。本地文件合计不超过 20MB（base64 会膨胀，避开约 30MB 的请求体上限） |

系统附件字节数加上本地原文件大小，前端先拦超过 50MB 的情况。打印文件大小要等服务器生成，超过 50MB 时展示接口原文「附件合计不能超过50MB」。

## 4. 五个页面怎么接

按钮组件 `SendMailButton` 自带弹窗，页面只放一行。

| 页面 | 位置 | frightModule | 打印 |
| :-- | :-- | :-- | :-- |
| 海运出口基础信息工具栏 | 「打印」左侧 | 0 | `PrintJsonType.SeaExportDetail`，筛选复用现有 `resolvePrintContext` |
| 海运进口基础信息工具栏 | AI 识别右侧 | 4 | `SeaImportDetail = 4000`，`bizType = 1` |
| 空运出口基础信息工具栏 | 「打印」左侧 | 5 | `AirExportDetail = 5000`，筛选复用现有 `resolvePrintContext` |
| 件杂货 | 详情页尚未落地 | 12 | `BreakBulkDetail = 7000`，`bizType = 3` |
| 发票开出顶部操作区 | 已有 id 时 | 15 | 无打印数据源 |

海运出口、海运进口的可用模板由后端按服务项任务决定：通用模板一直在，配了服务项的模板只在该服务项待处理时出现。空运出口、件杂货、发票开出只会看到通用模板。前端不复制这套规则。

字段被屏蔽时邮件里替换成空，按接口说明展示，不额外报错。

## 5. 和发送记录的关系

发送成功后关弹窗并提示成功。本票记录在弹窗第二个页签，独立列表在「我的发送记录」菜单。存草稿不产生发送记录，草稿去个人邮箱草稿箱查看。
