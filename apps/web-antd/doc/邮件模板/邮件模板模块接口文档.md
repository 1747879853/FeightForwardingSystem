# 0. 先看这里

- **两个服务**：
  - 模板维护 `MailTemplateAdmin`，地址前缀 `/api/services/app/MailTemplateAdmin/`；
  - 业务里使用 `MailTemplate`，地址前缀 `/api/services/app/MailTemplate/`。
  - **方法名里的 `Async` 不能省**。
- **鉴权**：都要登录。各接口的权限见 0.1。
- **出参**：都包在 ABP 统一返回结构的 `result` 里。
- **模块数字是 `FrightModule`**：海运出口 `0`、海运进口 `4`、空运出口 `5`、件杂货 `12`、发票开出 `15`。**不是**快捷文本用的 `BizType`（0/1/2/3）。
- **业务id（`entityId`）**：海运出口/海运进口/空运出口/件杂货传业务id（就是详情的 `id`），发票开出传发票开出 `id`。
- **占位符写法**：`{{占位符名}}`，例如 `{{订舱号}}`。各模块能用哪些，调 `GetModuleOptionListAsync` 拿，前端不要写死。
- **系统不保存生成的邮件**：生成结果只返回给前端，用户改完再调存草稿或发送。

## 0.1 接口一览

| 服务 | 接口 | 方法 | 权限 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `MailTemplateAdmin` | `AddAsync` | POST | `Admin.MailTemplate.Add` | 新增模板 |
|  | `EditAsync` | PUT | `Admin.MailTemplate.Edit` | 编辑模板（适用模块不能改，收件人整份替换） |
|  | `DeleteAsync` | DELETE | `Admin.MailTemplate.Delete` | 删除模板，支持批量 |
|  | `GetPagedListAsync` | GET | `Admin.MailTemplate.Get` | 模板分页列表 |
|  | `DetailAsync` | GET | `Admin.MailTemplate.Get` | 模板详情（带收件人） |
|  | `GetModuleOptionListAsync` | GET | 登录即可 | 各模块可用的占位符与收件人来源 |
| `MailTemplate` | `GetUsableListAsync` | GET | 登录 + 业务查看权限 | 某票业务可用的模板 |
|  | `GenerateAsync` | POST | 登录 + 业务查看权限 | 按模板生成邮件 |
|  | `SaveDraftAsync` | POST | `Admin.PersonalMail.Draft`（个人邮箱「存草稿」）+ 业务查看权限 | 存进个人邮箱草稿箱 |
|  | `SendAsync` | POST | `Admin.PersonalMail.Send`（个人邮箱「写邮件」）+ 业务查看权限 | 用个人邮箱发送 |
|  | `GetMySendRecordPagedListAsync` | GET | 登录 | 我的发送记录 |

「业务查看权限」= 该模块的查看权限（`Admin.SeaExport.Get` 等）+ 这条业务的数据权限 + 表级权限，不通过时报「没有xx的查看权限」「没有这条数据的数据权限,不能查看」等。

## 0.2 枚举

**`recipientType` 收件人类型**：`0` 收件人，`1` 抄送人。

**`recipientSource` 收件人来源**（各模块能用哪些以 `GetModuleOptionListAsync` 为准）：

| 值 | 名称 | 适用模块 |
| :-- | :-- | :-- |
| 0 | 当前登录人邮箱 | 全部 |
| 1 | 委托单位联系人邮箱（业务上选中的） | 海出 / 海进 / 空出 / 件杂货 |
| 2 | 委托单位所有联系人邮箱 | 海出 / 海进 / 空出 / 件杂货 |
| 3 | 订舱代理联系人邮箱（业务上选中的） | 海出 / 空出 / 件杂货 |
| 4 | 订舱代理所有联系人邮箱 | 海出 / 空出 / 件杂货 |
| 5 | 发票结算单位联系人邮箱（发票可用的） | 发票开出 |
| 10～16 | 业务关联 销售 / 商务 / 操作 / 客服 / 单证 / 海外客服 / 航线 邮箱 | 海出 / 海进 / 空出 / 件杂货 |

# 1. 模板维护 `MailTemplateAdmin`

## 1.1 各模块可选项 — `GET /api/services/app/MailTemplateAdmin/GetModuleOptionListAsync`

无入参。返回数组，每个可建模板的模块一条，顺序固定：海运出口、海运进口、空运出口、件杂货、发票开出。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `frightModule` | int | 模块 |
| `frightModuleName` | string | 模块中文名 |
| `placeholders` | string[] | 可用占位符名（不带大括号），插入编辑器时包成 `{{名}}` |
| `recipientSources` | 对象数组 | 可用收件人来源，元素见下 |

`recipientSources[]`：

| 字段    | 类型   | 说明               |
| :------ | :----- | :----------------- |
| `value` | int    | 收件人来源，见 0.2 |
| `name`  | string | 中文名             |

## 1.2 新增 — `POST /api/services/app/MailTemplateAdmin/AddAsync`

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `name` | string | 是 | 模板名，去首尾空格，最长 64，同一适用模块下不能重名 |
| `frightModule` | int | 是 | 适用模块：0 / 4 / 5 / 12 / 15，**创建后不能改** |
| `serviceType` | int? | 否 | 服务项。前端枚举，枚举管理 Name：ServiceType。不传表示通用模板。空运出口、件杂货、发票开出也能配，但目前这几个模块没有服务项任务，配了服务项的模板在业务里不会出现 |
| `isEnabled` | bool | 否 | 是否启用 |
| `subject` | string | 是 | 邮件标题，最长 512，可含占位符 |
| `body` | string | 否 | 邮件正文 HTML，可含占位符，原样保存 |
| `sortId` | int | 否 | 排序id，降序 |
| `mailTemplateRecipients` | 对象数组 | 否 | 收件人与抄送人，按数组顺序保存，元素见下 |

`mailTemplateRecipients[]`：

| 字段              | 类型   | 必填   | 说明                               |
| :---------------- | :----- | :----- | :--------------------------------- |
| `recipientType`   | int    | 是     | 0 收件人 / 1 抄送人                |
| `recipientSource` | int?   | 二选一 | 收件人来源，必须是适用模块可用的   |
| `email`           | string | 二选一 | 直接填的邮箱，只收纯地址，最长 256 |

**出参**：新模板 id（Guid）。

**报错**：模板名为空/超长/重名；适用模块不对；标题为空/超长；`占位符【x】在xx中不可用`；收件人「只能二选一」、邮箱格式不正确、来源在该模块不可用、同一类型里重复。

## 1.3 编辑 — `PUT /api/services/app/MailTemplateAdmin/EditAsync`

入参同新增，**多一个 `id`（Guid，必填），少一个 `frightModule`**（不能改，按原模块校验）。`mailTemplateRecipients` 整份替换，传空数组即清空。出参 `true`。

## 1.4 删除 — `DELETE /api/services/app/MailTemplateAdmin/DeleteAsync`

| 字段  | 类型   | 必填 | 说明                                  |
| :---- | :----- | :--- | :------------------------------------ |
| `ids` | Guid[] | 是   | 要删除的模板 id，有一条不存在整批不删 |

出参 `true`。发送过的模板也能删，发送记录里存了模板名快照。

## 1.5 分页列表 — `GET /api/services/app/MailTemplateAdmin/GetPagedListAsync`

| 入参 | 类型 | 说明 |
| :-- | :-- | :-- |
| `pageIndex` / `pageSize` | int | 分页 |
| `keyword` | string | 模糊匹配模板名、邮件标题 |
| `frightModule` | int? | 适用模块 |
| `serviceType` | int? | 服务项。前端枚举，枚举管理 Name：ServiceType |
| `isEnabled` | bool? | 是否启用 |

排序：适用模块升序、排序id降序、创建时间降序。出参 `PagedList`，`items[]` 字段：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | Guid | 模板 id |
| `name` | string | 模板名 |
| `frightModule` | int | 适用模块 |
| `serviceType` | int? | 服务项。前端枚举，枚举管理 Name：ServiceType |
| `isEnabled` | bool | 是否启用 |
| `subject` | string | 邮件标题（占位符原文） |
| `body` | string | 邮件正文（占位符原文） |
| `sortId` | int | 排序id |
| `creationTime` / `creatorUserId` / `creatorUserName` |  | 创建时间 / 创建人 id / 创建人昵称 |
| `lastModificationTime` / `lastModifierUserId` / `lastModifierUserName` |  | 最后修改时间 / 修改人 id / 修改人昵称 |

列表不带收件人。

## 1.6 详情 — `GET /api/services/app/MailTemplateAdmin/DetailAsync?id=xxx`

出参字段同列表，再多一个 `mailTemplateRecipients`（按排序id升序）：

| 字段              | 类型   | 说明                              |
| :---------------- | :----- | :-------------------------------- |
| `id`              | Guid   | 收件人行 id                       |
| `recipientType`   | int    | 0 收件人 / 1 抄送人               |
| `recipientSource` | int?   | 收件人来源，直接填邮箱时为 `null` |
| `email`           | string | 直接填的邮箱，选来源时为 `null`   |
| `sortId`          | int    | 排序id                            |

# 2. 业务里使用 `MailTemplate`

页面流程：`GetUsableListAsync` 列出模板 → 用户点一个调 `GenerateAsync` → 把结果填进编辑框让用户改、勾附件 → 调 `SendAsync` 或 `SaveDraftAsync`。

## 2.1 可用模板 — `GET /api/services/app/MailTemplate/GetUsableListAsync`

| 入参           | 类型 | 必填 | 说明         |
| :------------- | :--- | :--- | :----------- |
| `frightModule` | int  | 是   | 业务所属模块 |
| `entityId`     | Guid | 是   | 业务id       |

返回数组（排序id降序、创建时间降序）。只返回：适用模块一致、已启用，且服务项为空或是这票业务正在进行（服务项任务待处理）的服务项的模板。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | Guid | 模板 id |
| `name` | string | 模板名 |
| `serviceType` | int? | 服务项。前端枚举，枚举管理 Name：ServiceType。`null` 是通用模板 |
| `sortId` | int | 排序id |

## 2.2 生成邮件 — `POST /api/services/app/MailTemplate/GenerateAsync`

| 入参             | 类型 | 必填 | 说明                         |
| :--------------- | :--- | :--- | :--------------------------- |
| `mailTemplateId` | Guid | 是   | 模板 id                      |
| `frightModule`   | int  | 是   | 业务所属模块，必须与模板一致 |
| `entityId`       | Guid | 是   | 业务id                       |

| 出参 | 类型 | 说明 |
| :-- | :-- | :-- |
| `mailTemplateId` | Guid | 模板 id，发送时原样传回 |
| `subject` | string | 标题，占位符已替换，单行 |
| `body` | string | 正文 HTML，占位符已替换（值已转义，换行变 `<br>`） |
| `toAddresses` | string[] | 收件人，已去重；一个都没算出来时为空数组 |
| `ccAddresses` | string[] | 抄送人，已去重，已在收件人里的不出现 |
| `invalidAddresses` | string[] | 算出来但格式不正确、被丢掉的邮箱（多半是联系人邮箱填错了），有值时提示用户 |
| `systemAttachments` | 对象数组 | 这票业务自己的系统附件，供勾选；附件对当前用户被屏蔽时为空数组。元素是系统通用的附件对象 `AttachmentItemDto`，常用字段见下 |

`systemAttachments[]` 常用字段：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `attachmentId` | long | 附件 id，**发送/存草稿时放进 `systemAttachmentIds`** |
| `friendlyFileName` | string | 文件名 |
| `fileLength` | long? | 文件大小（字节） |
| `url` | string | 下载地址 |
| `attachmentDtlType` | 对象 | 附件类型（托书、提单等），可能为 `null` |
| `creationTime` / `creatorUserName` |  | 上传时间 / 上传人昵称 |

取不到值的占位符（业务上没填、或对当前用户屏蔽的字段）替换成空；业务上没选的收件人来源（比如没选订舱代理）就是没有邮箱，不报错。

**发票开出（`frightModule = 15`）**：发票开出自己有收件人或抄送人（详情里的 `invoiceIssueMailRecipients`）时，`toAddresses` / `ccAddresses` **整份取发票开出的**，模板配置的收件人、抄送人都不用；发票开出一个都没有时才按模板算。只返回邮箱，不带名字。

**报错**：模板不存在 / 不适用于这个模块 / 未启用；`这票业务当前没有进行中的该服务项，不能用这个模板`；业务查看权限相关。

## 2.3 存草稿 — `POST /api/services/app/MailTemplate/SaveDraftAsync`

| 入参 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `frightModule` | int | 是 | 业务所属模块 |
| `entityId` | Guid | 是 | 业务id |
| `mailAccountId` | Guid? | 否 | 用哪个个人邮箱，**本期不用传**（每人只能配一个） |
| `toAddresses` | string[] | 否 | 收件人，存草稿可以为空 |
| `ccAddresses` | string[] | 否 | 抄送人 |
| `subject` | string | 是 | 标题，最长 1024 |
| `body` | string | 否 | 正文 HTML |
| `systemAttachmentIds` | long[] | 否 | 勾选的系统附件 `attachmentId`，只能是这票业务自己的 |
| `printFileNames` | string[] | 否 | 打印文件：传打印接口返回的文件名（也接受 `PrintTempFile/xxx`、`/PrintTempFile/xxx`）。附件名会去掉文件名末尾的「-时间戳」 |
| `attachments` | 对象数组 | 否 | 用户自己上传的附件：`fileName`（带扩展名，必填）+ `content`（base64，必填），不走系统附件上传 |

出参 `true`。草稿存进当前登录人个人邮箱的草稿箱，之后去个人邮箱里处理；系统不记录、不返回草稿序号。

**报错**：标题为空/超长；`邮箱【x】格式不正确`；业务查看权限相关；`还没有配置个人邮箱，请先在个人设置里配置`；`所选系统附件不属于这票业务或已被删除`；`系统附件【x】在服务器上不存在`；`打印文件【x】不正确`；`打印文件【x】不存在，请重新打印`；`附件文件名不能为空`；`附件【x】内容为空`；`附件合计不能超过50MB`。

## 2.4 发送 — `POST /api/services/app/MailTemplate/SendAsync`

入参同存草稿，再多一个：

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `mailTemplateId` | Guid | 是 | 模板 id（生成结果里的 `mailTemplateId`），记发送记录用，必须与 `frightModule` 一致 |

发送时 `toAddresses` **至少一个**，否则报「收件人不能为空」。用当前登录人的个人邮箱发出，并存一份到「已发送」。

| 出参 | 类型 | 说明 |
| :-- | :-- | :-- |
| `messageId` | string | 这封邮件的唯一标识 |
| `subject` | string | 实际发出的标题 |
| `toAddresses` / `ccAddresses` / `bccAddresses` | string[] | 实际收件人 / 抄送人 / 密送人（已去重） |

## 2.5 我的发送记录 — `GET /api/services/app/MailTemplate/GetMySendRecordPagedListAsync`

只返回当前登录人自己发的，按发送时间倒序。

| 入参 | 类型 | 说明 |
| :-- | :-- | :-- |
| `pageIndex` / `pageSize` | int | 分页 |
| `frightModule` | int? | 业务所属模块 |
| `entityId` | Guid? | 业务id，业务页面里看「这票发过哪些邮件」时传 |
| `mailTemplateId` | Guid? | 模板 id |
| `keyword` | string | 模糊匹配标题、收件人、抄送人 |
| `sendTimeStart` | DateTime? | 发送时间起（含） |
| `sendTimeEnd` | DateTime? | 发送时间止（含当天） |

出参 `PagedList`，`items[]`：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | Guid | 记录 id |
| `creationTime` | DateTime | 发送时间 |
| `creatorUserId` / `creatorUserName` |  | 发送人 id / 昵称 |
| `frightModule` | int | 业务所属模块 |
| `entityId` | Guid | 业务id |
| `entityNo` | string | 业务编号：业务是委托编号，发票开出是申请单号；业务已删除时为 `null` |
| `mailTemplateId` | Guid | 模板 id |
| `mailTemplateName` | string | 发送时的模板名 |
| `fromAddress` | string | 发件箱 |
| `toAddresses` | string | 收件人，英文分号分隔 |
| `ccAddresses` | string | 抄送人，英文分号分隔，没有时为空串 |
| `subject` | string | 标题 |
| `messageId` | string | 邮件唯一标识，拿不到时为 `null` |
