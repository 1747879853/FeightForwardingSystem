# 海运出口 / 业务往来单位与船公司对象化 — 前端对接文档

**变更日期**：2026-07-24  
**受众**：前端  
**性质**：**破坏性变更**（删除扁平 `*Name` 字符串，改为对象字段）

---

## 一、变更概述

| # | 变更点 | 说明 |
| --- | --- | --- |
| 1 | `SeaExportDto` 往来单位 | 第二通知人 / 目的港代理 / 订舱代理 / 船代 / 场站 → `ClientSimpleDtoForOrder` |
| 2 | `SeaExportDto` 船公司 | `carrierName`/`carrierCnShortName`/`carrierCode` → `carrier`（`CarrierSimpleDto`）；`carrierLogo` 仍保留 |
| 3 | `TransportOrderDto` 往来单位 | 委托单位 / 车队 / 报关行 / 仓库 / 保险公司 / 收发通 → `ClientSimpleDtoForOrder` |
| 4 | `PayAppFeeGroupDto` | 继承 `TransportOrderDto`，同样用 `client` 对象，**删除** `clientName` |
| 5 | `CarrierSimpleDto` 扩字段 | 补齐中文简称、EDI 代码；`code` 含义明确为英文简称（所有挂载该类型的接口一并受益） |

**未改**：`*Id` 主键字段、`*Content` 文本内容字段、`TransportOrderSimpleDto.clientName`（简易业务 DTO 仍为字符串）。

---

## 二、公共类型（请前端统一按此对接）

### 2.1 `ClientSimpleDtoForOrder`（业务单据用客户简易对象）

| 字段        | 类型     | 说明     |
| ----------- | -------- | -------- |
| `id`        | `Guid`   | 客户主键 |
| `name`      | `string` | 客户简称 |
| `fullName`  | `string` | 客户全称 |
| `address`   | `string` | 地址     |
| `enAddress` | `string` | 英文地址 |

无客户时字段为 `null`（对象整体为 `null`）。

### 2.2 `CarrierSimpleDto`（船公司简易对象）

| 字段          | 类型     | 说明         |
| ------------- | -------- | ------------ |
| `id`          | `long`   | 船公司主键   |
| `cnName`      | `string` | 中文名称     |
| `cnShortName` | `string` | 中文简称     |
| `enName`      | `string` | 英文名称     |
| `code`        | `string` | **英文简称** |
| `ediCode`     | `string` | EDI 代码     |

无船公司时 `carrier` 为 `null`。

## 三、受影响接口一览

### 3.1 直接返回 / 嵌套 `SeaExportDto`（往来单位 + 船公司均变）

| 模块 | 接口地址 | 影响说明 |
| --- | --- | --- |
| 海运出口 | `GET /api/services/app/SeaExportAdmin/GetPagedListAsync` | 列表项为 `SeaExportDto` |
| 海运出口 | `GET /api/services/app/SeaExportAdmin/DetailAsync` | 详情为 `SeaExportDto` |
| 海出服务项任务 | `GET /api/services/app/SeServiceTaskAdmin/GetPagedListAsync` | 任务内 `seaExport` 同列表结构 |
| 海出服务项任务 | `GET /api/services/app/SeServiceTaskAdmin/GetWorkbenchListAsync` | 同上 |
| 海出服务项任务 | `GET /api/services/app/SeServiceTaskAdmin/GetWorkbenchPagedListAsync` | 同上 |

### 3.2 返回 / 继承 `TransportOrderDto`（往来单位变）

| 模块 | 接口地址 | 影响说明 |
| --- | --- | --- |
| 付费申请 | `GET /api/services/app/PaymentApplicationAdmin/GetOrderFeeGroupAsync` | `PayAppFeeGroupDto` 继承 `TransportOrderDto`：`clientName` → `client` |
| 其它 | 凡响应中嵌套完整 `TransportOrderDto` 的接口 | 如海运出口列表/详情里的 `transportOrder` |

### 3.3 `CarrierSimpleDto` 字段扩充（兼容增强，非删字段）

以下接口中已有的 `carrier` 对象会多返回 `cnShortName`、`ediCode`（原 `code`/`cnName`/`enName` 仍在）：

| 模块 | 接口地址（示例） |
| --- | --- |
| 开票申请 | `GET /api/services/app/InvoiceApplicationAdmin/GetOrderFeeGroupAsync`、`DetailAsync`（`transportOrder.seaExport.carrier`） |
| 发票开出 | `GET /api/services/app/InvoiceIssueAdmin/GetSubmittedApplicationListAsync`（`orderFee.transportOrder.seaExport.carrier`） |
| 业务费用 | 打印相关返回 `SeaExportSimpleDto.carrier` 的接口 |
| 打印格式 / 预订单 / 费用模板 | 组装 `CarrierSimpleDto` 的接口 |

## 六、前端迁移对照（必改）

| 旧写法 | 新写法 |
| --- | --- |
| `row.carrierName` | `row.carrier?.cnName` |
| `row.carrierCnShortName` | `row.carrier?.cnShortName` |
| `row.carrierCode` | `row.carrier?.code` |
| `row.bookingAgentName` | `row.bookingAgent?.name`（全称用 `?.fullName`） |
| `row.yardName` | `row.yard?.name` |
| `row.secondNotifierName` | `row.secondNotifier?.name` |
| `row.podAgentName` | `row.podAgent?.name` |
| `row.shipAgentName` | `row.shipAgent?.name` |
| `row.transportOrder.clientName` | `row.transportOrder.client?.name` |
| `row.transportOrder.consigneeName` | `row.transportOrder.consignee?.name` |
| `feeGroup.clientName`（付费申请） | `feeGroup.client?.name` |
| `seaExport.carrier.cnName`（简易 DTO） | 仍可用；可增用 `cnShortName` / `ediCode` |

## 七、避坑

1. **破坏性**：旧扁平 `*Name` 字段已从响应中移除，继续读会得到 `undefined`。
2. **Logo 不在 `carrier` 内**：Logo 仍是同级的 `carrierLogo`。
3. **`TransportOrderSimpleDto` 未改**：开票/发票开出等简易业务上的 `clientName` 字符串仍存在，不要和完整 `TransportOrderDto.client` 混用。
4. **`code` = 英文简称**，不是 EDI；EDI 用 `ediCode`。
5. 对象可能为 `null`，展示时请空值保护。
