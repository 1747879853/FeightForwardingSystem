# 海运出口-2026-07-23

## 背景意图

海运出口详情打印/单据需要展示业务所属公司的抬头信息（名称、地址、税号、Logo、默认银行）。原详情仅返回 `orgId`/`orgs`，前端无法直接拿到完整公司打印字段。

## 核心逻辑变更

1. `CsprojBuilderAppServiceBase` 新增 `GetCompanyPrintInfoAsync(orgId)`：先用 `GetCompanyOrgIdAsync` 将业务组织解析到公司节点，再加载公司实体、Logo（`OrganizationUnitLogo`）、`OrgBankAccount` 默认银行（含 RMB/USD 快捷字段）。
2. `SeaExportDto` 新增 `companyPrintInfo`（`CompanyPrintInfoDto`）。
3. `SeaExportAdminAppService.DetailAsync` 在 `SetDataPermissionPropsAsync` 之后赋值：`CompanyPrintInfo = await GetCompanyPrintInfoAsync(result.OrgId)`。

## 避坑指南

- 银行账户挂在**公司**节点上；业务 `orgId` 若是部门，必须先解析公司，不能直接用部门 id 查银行。
- 无 `orgId` 或组织树中找不到公司时，`companyPrintInfo` 为 `null`，前端需判空。
