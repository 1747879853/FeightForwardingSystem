# 背景意图

海运出口列表分组看板需要支持按**场站**统计，并支持筛选「场站未填写」的数据；按**船公司**分组时，前端需要展示中文简称与船公司 Logo，与列表、详情中船公司展示方式保持一致。

# 核心逻辑变更

## 1. 列表筛选 — GetPagedListAsync

- 新增入参 `yardIdEmpty`（bool?）：`true` 时仅查 `YardId` 为空的数据。
- 与 `yardId` 互斥，同时传入时报错「场站筛选：未填写与指定id不可同时传入」。
- 筛选逻辑在 `BuildSeaExportFilterQuery` 中与分组统计共用。

## 2. 分组统计 — GetGroupedListAsync

- `SeaExportGroupField` 新增 `Yard = 10`（场站）。
- 按场站分组：依据 `SeaExport.YardId`，`name` 取 `Client.Name`（场站为客户类型）。
- 按船公司分组（groupField=4）：
  - `name` 由 `Carrier.CnName` 改为 **`Carrier.CnShortName`**。
  - 新增响应字段 **`logo`**（`AttachmentItemDto`），来源模块 `160010`（船公司 logo）。
  - 无 logo 或未配置附件时为 `null`。

## 3. 响应 DTO — SeaExportGroupDto

| 字段  | 说明                           |
| ----- | ------------------------------ |
| id    | 分组值 id，场站为 Guid 字符串  |
| name  | 分组名称；船公司为 CnShortName |
| count | 条数                           |
| logo  | 仅船公司分组有值，其余为 null  |

# 前端对接要点

| 场景                   | 参数                     |
| ---------------------- | ------------------------ |
| 列表筛选场站为空       | `yardIdEmpty=true`       |
| 按场站分组             | `groupField=10`          |
| 点击某场站分组         | `yardId={分组Id}`        |
| 点击场站「未填写」分组 | `yardIdEmpty=true`       |
| 按船公司分组展示       | 使用 `name` + `logo.url` |

# 避坑指南

- `yardIdEmpty` 与 `yardId` 不可同时使用。
- `logo` 仅在 `groupField=4` 时有意义，其他分组类型恒为 `null`，前端不必解析。
- 场站 id 类型为 **Guid**，与船公司（long）不同，点击分组传参时注意类型。
