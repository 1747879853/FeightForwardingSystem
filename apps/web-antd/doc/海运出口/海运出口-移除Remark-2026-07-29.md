# 1. 背景意图 (Background)

**白话解释：** `SeaExport` 实体上的 `Remark`（备注）字段已注释停用。业务备注统一走 `TransportOrder.Remark`，需同步清理海运出口相关 DTO、校验、筛选与业务联系单转单赋值。

# 2. 核心逻辑变更 (Core Changes)

- 实体：`SeaExport.Remark` 已注释（由业务侧完成）。
- DTO 移除 `Remark`：`SeaExportAddDto` / `SeaExportEditDto` / `SeaExportQueryDto` / `SeaExportDto`。
- `SeaExportAdminAppService`：删除新增/编辑长度校验；删除列表 `Remark` 模糊筛选。
- `PreOrderAdminAppService`：业务联系单转海运出口时不再写 `SeaExport.Remark`（`TransportOrder.Remark` 仍从联系单备注带入）。

> Migration 由开发者自行生成，本次不提交。

# 3. 避坑指南 (Pitfalls)

> [!IMPORTANT]
>
> 1. 不要与港口备注（`POLRemark`/`PODRemark` 等）或 `TransportOrder.Remark` / `InternalRemark` 混淆；仅移除海运出口主表自身的 `Remark`。
> 2. 列表关键字仍可匹配 `TransportOrder.Remark`。
> 3. 前端请停止传/读海运出口根级 `remark`；业务备注用 `transportOrder.remark`。
