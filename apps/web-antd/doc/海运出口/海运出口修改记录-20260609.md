## 三、详细修改内容

### 3.1 GetServiceTypesByPOLAsync（SeaExportAdminAppService.cs）

**接口：** `GET /api/services/app/SeaExportAdmin/GetServiceTypesByPOL`

#### 变更前

- `polId` 为可选参数（`long?`），为空时直接返回 `null`
- 找不到该港口的配置时返回 `null`

#### 变更后

- `polId` 为**必填**参数，为空时抛出异常 "起运港不能为空"
- 找不到该港口的专属配置时，回退查找默认配置（`POLId == null`）
- 若两者都不存在，抛出异常 "未找到该起运港对应的服务项配置,请配置该港口或配置默认港口服务项"

```csharp
// 变更前
if (!input.POLId.HasValue) return null;
var config = await ...FirstOrDefaultAsync(x => x.POLId == input.POLId.Value);
if (config == null) return null;

// 变更后
if (!input.POLId.HasValue) throw new UserFriendlyException("起运港不能为空");
var config = await ...FirstOrDefaultAsync(x => x.POLId == input.POLId.Value);
if (config == null)
{
    config = await ...FirstOrDefaultAsync(x => x.POLId == null);
}
if (config == null) throw new UserFriendlyException("未找到该起运港对应的服务项配置,请配置该港口或配置默认港口服务项");
```

### 3.2 ValidateServiceTypesAsync（SeaExportAdminAppService.cs）

**调用场景：** 新建/编辑海运出口时校验服务项的值和顺序

#### 变更前

- 只查指定港口的配置，找不到时根据是否有输入服务项决定报错或返回空

#### 变更后

- 先查指定港口配置，找不到时回退查默认配置（`POLId == null`）
- 两者都不存在时，行为与原来一致（有服务项输入则报错，无则返回空）

```csharp
// 变更后增加的回退逻辑
if (config == null)
{
    config = await ...FirstOrDefaultAsync(x => x.POLId == null);
}
```

### 3.4 GetClientExceptServicesAsync（ClientExceptServiceAdminAppService.cs）

#### 变更前

- 加载所有 `SeServiceConfig`（包括默认配置），`IsChecked` 比较 `ces.POLId == config.POLId` 在默认配置（null）时语义错误

#### 变更后

- 过滤掉默认配置（`POLId == null`），只返回有具体港口的配置。默认配置不参与委托单位排除服务项的管理
- `IsChecked` 比较改为 `ces.POLId == config.POLId.Value`，避免空引用

```csharp
// 变更前
var configs = await _seServiceConfigRepository.GetAll()...ToListAsync();
IsChecked = !clientExceptServices.Any(ces => ces.POLId == config.POLId && ...)

// 变更后
var configs = await _seServiceConfigRepository.GetAll()
    ...
    .Where(x => x.POLId != null)  // 排除默认配置
    .ToListAsync();
IsChecked = !clientExceptServices.Any(ces => ces.POLId == config.POLId.Value && ...)
```

## 四、API 变更对前端的影响

### GetServiceTypesByPOLAsync

| 项           | 变更前          | 变更后                         |
| ------------ | --------------- | ------------------------------ |
| `polId` 参数 | `long?`（可选） | `long`（**必填**）             |
| 为空时行为   | 返回 `null`     | 报错 "起运港不能为空"          |
| 找不到配置时 | 返回 `null`     | 自动回退默认配置；都没有则报错 |

### 新增错误信息

| 错误信息 | 触发场景 |
| --- | --- |
| 起运港不能为空 | GetServiceTypesByPOLAsync 未传 polId |
| 未找到该起运港对应的服务项配置,请配置该港口或配置默认港口服务项 | 该港口无专属配置且无默认配置 |
