# 海运出口列表/详情港口对象化 — 前端对接文档

**变更日期**：2026-08-06  
**受众**：前端  
**性质**：**破坏性变更**（删除扁平港口 `*Name`/`*EdiCode`/`countryName`/`laneName`，改为 `PortCodeSimpleDtoForOrder` 对象）

---

## 一、变更概述

| # | 变更点 | 说明 |
| --- | --- | --- |
| 1 | `SeaExportDto` 全部港口 | 付费地点/签单地点/起运港/目的港/中转港1/2/收货地/交货地 → `PortCodeSimpleDtoForOrder` |
| 2 | 顶层航线/国家 | 删除 `countryName`/`countryEnName`/`laneName`，改读 `pod.lane` / `pod.country` |
| 3 | EDI 代码 | 删除各港口平铺 `*EdiCode`，改读对象内 `ediCode` |

**未改**：各港口 `*Id`、`*Remark`；新增/编辑入参仍只传 Id。

---

## 二、公共类型 `PortCodeSimpleDtoForOrder`

| 字段       | 类型                           | 说明            |
| ---------- | ------------------------------ | --------------- |
| `id`       | `long`                         | 港口主键        |
| `portName` | `string`                       | 港口代码/英文名 |
| `cnName`   | `string`                       | 中文名称        |
| `ediCode`  | `string`                       | EDI 代码        |
| `lane`     | `LaneCodeSimpleDto` \| null    | 航线对象        |
| `country`  | `CountryCodeSimpleDto` \| null | 国家对象        |

### `lane`（LaneCodeSimpleDto）

| 字段         | 类型     | 说明       |
| ------------ | -------- | ---------- |
| `id`         | `long`   | 航线主键   |
| `code`       | `string` | 航线代码   |
| `laneName`   | `string` | 航线中文名 |
| `laneEnName` | `string` | 航线英文名 |
| `ediCode`    | `string` | EDI 代码   |

### `country`（CountryCodeSimpleDto）

| 字段            | 类型     | 说明       |
| --------------- | -------- | ---------- |
| `id`            | `long`   | 国家主键   |
| `code`          | `string` | 国家代码   |
| `countryName`   | `string` | 国家中文名 |
| `countryEnName` | `string` | 国家英文名 |

无港口时对应对象整体为 `null`。

---

## 三、受影响接口

| 模块 | 接口地址 | 影响说明 |
| --- | --- | --- |
| 海运出口 | `GET /api/services/app/SeaExportAdmin/GetPagedListAsync` | 列表项 `SeaExportDto` |
| 海运出口 | `GET /api/services/app/SeaExportAdmin/DetailAsync` | 详情 `SeaExportDto` |
| 海出服务项任务 | `GET /api/services/app/SeServiceTaskAdmin/GetPagedListAsync` 等 | 任务内 `seaExport` 同列表结构 |
| 业务联系单 | `PreOrderAdmin/TransportOrderDetailAsync`（海出时） | 调用海出详情，结构一致 |

## 四、字段对照（删除 / 新增）

| 操作 | 旧字段（已删除） | 新字段 | 类型 |
| --- | --- | --- | --- |
| 删→增 | `prepareAtName` / `prepareAtEdiCode` | `prepareAt` | `PortCodeSimpleDtoForOrder` |
| 删→增 | `signingPortName` / `signingPortEdiCode` | `signingPort` | 同上 |
| 删→增 | `podName` / `podEdiCode` | `pod` | 同上 |
| 删→增 | `countryName` / `countryEnName` / `laneName` | （并入 `pod.country` / `pod.lane`） | — |
| 删→增 | `polName` / `polEdiCode` | `pol` | 同上 |
| 删→增 | `pot1Name` / `pot1EdiCode` | `pot1` | 同上 |
| 删→增 | `pot2Name` / `pot2EdiCode` | `pot2` | 同上 |
| 删→增 | `receivePortName` / `receivePortEdiCode` | `receivePort` | 同上 |
| 删→增 | `deliverPortName` / `deliverPortEdiCode` | `deliverPort` | 同上 |
| 保留 | 各 `*Id`、`*Remark` | 同左 | 不变 |

---

## 五、前端取值示例

```js
// 起运港中文名
row.pol?.cnName;
// 目的港英文/代码
row.pod?.portName;
// 目的港 EDI
row.pod?.ediCode;
// 航线（海运出口取自目的港）
row.pod?.lane?.laneName;
// 国家
row.pod?.country?.countryName;
row.pod?.country?.countryEnName;
```

> **注意**：海运出口的航线/国家挂在**目的港**；海运进口挂在**起运港**。不要混用。
