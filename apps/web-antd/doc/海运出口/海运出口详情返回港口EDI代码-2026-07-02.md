# 海运出口详情返回港口 EDI 代码 修改记录 2026-07-02

**修改时间：** 2026-07-02

**修改人：** 后端

**关联需求：** `DetailAsync`（`api/services/app/SeaExportAdmin/DetailAsync`）需额外返回各港口对应的 EDI 代码。

---

## 一、需求背景

海运出口详情接口原本仅返回各港口的名称（`PODName`、`POLName` 等），前端在做 EDI 报文 / 舱单相关处理时需要港口的 EDI 代码（`App_PortCodes.EdiCode`）。本次改动在详情返回中补齐各港口字段对应的 EDI 代码。

涉及的港口字段：

| 前端字段        | 港口含义 | 新增 EDI 字段        |
| --------------- | -------- | -------------------- |
| `receivePortId` | 收货地   | `receivePortEdiCode` |
| `polId`         | 起运港   | `polEdiCode`         |
| `poT1Id`        | 中转港1  | `poT1EdiCode`        |
| `poT2Id`        | 中转港2  | `poT2EdiCode`        |
| `podId`         | 目的港   | `podEdiCode`         |
| `deliverPortId` | 交货地   | `deliverPortEdiCode` |
| `prepareAtId`   | 付费地点 | `prepareAtEdiCode`   |
| `signingPortId` | 签单地点 | `signingPortEdiCode` |

---

## 二、改动范围

| 文件 | 路径 | 修改类型 |
| --- | --- | --- |

---

## 三、核心逻辑

1. `DetailAsync` 中原有的港口批量查询增加 `EdiCode` 列：

```csharp
.Select(p => new { p.Id, p.PortName, p.EdiCode, p.Country.CountryName, p.Country.CountryEnName, p.Lane.LaneName })
```

2. 复用已有的港口内存集合 `ports`，对各目标港口分别赋值：

```csharp
result.SigningPortEdiCode = signingPort?.EdiCode;
result.PODEdiCode = pod?.EdiCode;
result.POLEdiCode = pol?.EdiCode;
result.POT1EdiCode = pot1?.EdiCode;
result.POT2EdiCode = pot2?.EdiCode;
result.ReceivePortEdiCode = receivePort?.EdiCode;
result.PrepareAtEdiCode = prepareAt?.EdiCode;
result.DeliverPortEdiCode = deliverPort?.EdiCode;
```

EDI 代码来源为港口表 `App_PortCodes.EdiCode` 字段。

| 字段名               | 字段含义          | 数据来源                |
| -------------------- | ----------------- | ----------------------- |
| `podEdiCode`         | 目的港 EDI 代码   | `App_PortCodes.EdiCode` |
| `polEdiCode`         | 起运港 EDI 代码   | `App_PortCodes.EdiCode` |
| `poT1EdiCode`        | 中转港1 EDI 代码  | `App_PortCodes.EdiCode` |
| `poT2EdiCode`        | 中转港2 EDI 代码  | `App_PortCodes.EdiCode` |
| `receivePortEdiCode` | 收货地 EDI 代码   | `App_PortCodes.EdiCode` |
| `deliverPortEdiCode` | 交货地 EDI 代码   | `App_PortCodes.EdiCode` |
| `prepareAtEdiCode`   | 付费地点 EDI 代码 | `App_PortCodes.EdiCode` |
| `signingPortEdiCode` | 签单地点 EDI 代码 | `App_PortCodes.EdiCode` |

---

## 五、避坑指南

1. **复用已有港口查询，无额外数据库开销**：EDI 代码与港口名称在同一次查询中取出，未新增查询。
2. **字段可空**：若港口 Id 为空或港口未维护 EDI 代码，对应 `*EdiCode` 返回 `null`。
