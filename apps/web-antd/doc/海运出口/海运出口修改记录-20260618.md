# 海运出口 修改记录 2026-06-18

**修改时间：** 2026-06-18

**修改人：** 后端

**关联需求：** 海运出口分页列表返回船公司代码（CarrierCode）

---

## 一、需求背景

`GetPagedListAsync` 列表接口此前只返回船公司的中文名称（`CarrierName`）和中文简称（`CarrierCnShortName`），前端在列表展示/单证处理时还需要 `carrierId` 对应的船公司代码（`Carrier.Code`，即英文简称代码）。本次新增 `CarrierCode` 字段返回。

---

## 二、修改文件清单

| 文件 | 路径 | 修改类型 |
| --- | --- | --- |
| 海运出口列表DTO | `Application/App/SeaExport/Dto/SeaExportDto.cs` | 新增 `CarrierCode` 字段 |
| 海运出口服务 | `Application/App/SeaExport/SeaExportAdminAppService.cs` | `GetPagedListAsync` 船公司批量查询与结果映射补充 `Code` |

---

## 三、详细修改内容

### 3.1 SeaExportDto 新增字段

```csharp
/// <summary>
/// 船公司代码
/// </summary>
[Description("船公司代码")]
public string CarrierCode { get; set; }
```

### 3.2 GetPagedListAsync（SeaExportAdminAppService.cs）

**接口：** `GET /api/services/app/SeaExportAdmin/GetPagedListAsync`

船公司批量查询的投影补充 `Code` 字段：

```csharp
// 变更前
.Select(x => new { x.Id, x.CnName, x.CnShortName })
// 变更后
.Select(x => new { x.Id, x.CnName, x.CnShortName, x.Code })
```

结果映射补充 `CarrierCode`：

```csharp
var carrierEntity = carriers.FirstOrDefault(x => x.Id == seaExport.CarrierId);
data.CarrierName = carrierEntity?.CnName;
data.CarrierCnShortName = carrierEntity?.CnShortName;
data.CarrierCode = carrierEntity?.Code;   // 新增
```

---

## 四、API 变更对前端的影响

| 字段名 | 含义 | 数据来源 | 说明 |
| --- | --- | --- | --- |
| `CarrierCode` | 船公司代码 | `App_Carriers.Code`（船公司英文简称代码） | 通过 `carrierId` 关联取得，船公司为空时返回 `null` |

> 仅 `GetPagedListAsync` 列表项每条数据新增该字段，无破坏性变更。

---

## 五、验收标准

| 序号 | 验收项 | 期望结果 |
| --- | --- | --- |
| 1 | 列表数据存在 `CarrierId` 且对应船公司有 `Code` | 返回项中 `CarrierCode` 为该船公司代码 |
| 2 | 列表数据 `CarrierId` 为空 | `CarrierCode` 返回 `null` |
| 3 | 船公司无 `Code` 值 | `CarrierCode` 返回 `null` |
