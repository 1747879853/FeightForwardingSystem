## 1. 公共类型 ClientContactSimpleDto

| 字段     | JSON     | 类型   | 说明      |
| :------- | :------- | :----- | :-------- |
| 主键     | id       | long   | 联系人 Id |
| 名字     | name     | string |           |
| 手机     | mobile   | string |           |
| 邮箱     | email    | string |           |
| 办公电话 | tel      | string |           |
| 职位     | position | string |           |
| 微信     | weChat   | string |           |

无联系人时对象整体为 null。

---

## 2. 海运出口 SeaExportAdmin

路由前缀：`/api/services/app/SeaExportAdmin`

### 2.1 新建 — POST SeaExportAdmin/AddAsync

| 字段 | JSON | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| 订舱代理联系人id | bookingAgentContactId | long? | 否 | 须属于 bookingAgentId |
| 委托单位联系人id | transportOrder.clientContactId | long? | 否 | 须属于 transportOrder.clientId |

### 2.2 编辑 — PUT SeaExportAdmin/EditAsync

入参同新建（含 bookingAgentContactId、transportOrder.clientContactId）。

### 2.3 列表/详情 — GetPagedListAsync / DetailAsync

| 字段 | JSON | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| 订舱代理联系人id | bookingAgentContactId | long? |  |
| 订舱代理联系人 | bookingAgentContact | ClientContactSimpleDto | 对象返回 |
| 委托单位联系人id | transportOrder.clientContactId | long? |  |
| 委托单位联系人 | transportOrder.clientContact | ClientContactSimpleDto | 对象返回 |

### 前端适配

- [ ] 订舱代理下拉后加载该客户联系人，提交 bookingAgentContactId
- [ ] 委托单位下拉后加载该客户联系人，提交 transportOrder.clientContactId
- [ ] 展示用 bookingAgentContact / transportOrder.clientContact 对象，禁止再要平铺 Name 字段
- [ ] 清空订舱代理时同步清空订舱代理联系人

| 海运进口 | 仅 transportOrder.clientContactId / clientContact |
