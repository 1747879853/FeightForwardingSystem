# 海运出口移除 SeaExport.Remark — 前端对接

**日期：** 2026-07-29

## 破坏性变更

海运出口主表不再提供 `remark` 字段。

| 接口 | 变更 |
| :-- | :-- |
| `AddAsync` / `EditAsync` | 入参去掉根级 `remark`；勿再传 |
| `GetPagedListAsync` | 筛选去掉 `remark`；关键字仍可搜业务备注 `transportOrder.remark` |
| `GetAsync` / 列表项 | 出参去掉根级 `remark` |

## 业务备注怎么用

请使用：

- `transportOrder.remark`（业务备注）
- `transportOrder.internalRemark`（内部备注）

港口备注字段（`polRemark`/`podRemark` 等）不变。
