# 海运出口模块修改记录 - 2026年5月18日

## 修改概述

修复海运出口编辑接口（EditAsync）中 `ATD`（实际开船日期）字段无法更新的 Bug。

---

## 问题排查

### 1. DTO 映射问题

**排查结果**：无问题

`TransportOrderEditDto` 中已正确定义 `ATD` 字段：

```csharp
/// <summary>
/// 实际开船日期
/// </summary>
public DateTime? ATD { get; set; }
```

涉及的 4 个 DTO 类均已包含 ATD 字段：

- `TransportOrderAddDto` — 新增输入
- `TransportOrderEditDto` — 编辑输入
- `TransportOrderDto` — 列表/详情输出
- `TransportOrderSimpleDto` — 简易输出

### 2. AutoMapper / 实体映射

**排查结果**：**发现问题**

本项目 `EditAsync` 方法中对 `TransportOrder` 实体采用**逐字段手动赋值**方式（非 AutoMapper 映射），在赋值列表中遗漏了 `ATD` 字段。

**原代码（第 968-970 行）**：

```csharp
transportOrder.GoodsCompleteTime = input.TransportOrder.GoodsCompleteTime;
transportOrder.ETD = input.TransportOrder.ETD;
// ← 此处缺少 ATD 赋值
transportOrder.ETA = input.TransportOrder.ETA;
```

`ETD` 赋值后直接跳到了 `ETA`，导致前端传入的 `ATD` 值被丢弃，数据库中该字段始终不会被编辑操作更新。

### 3. 权限或业务逻辑拦截

**排查结果**：无问题

不存在针对 `ATD` 字段的业务逻辑拦截或条件限制。该字段的修改未被任何领域服务层拦截。

---

## 修改内容

### 文件：`SeaExportAdminAppService.cs`

**路径**：`src/CsprojBuilder.Application/App/SeaExport/SeaExportAdminAppService.cs`

**方法**：`EditAsync`

**修改内容**：在 `ETD` 和 `ETA` 赋值之间补充 `ATD` 的赋值语句。

**修改后代码**：

```csharp
transportOrder.GoodsCompleteTime = input.TransportOrder.GoodsCompleteTime;
transportOrder.ETD = input.TransportOrder.ETD;
transportOrder.ATD = input.TransportOrder.ATD;
transportOrder.ETA = input.TransportOrder.ETA;
```

### 文件：`海运出口api.md`

**路径**：`文档/海运出口/海运出口api.md`

**修改内容**：在编辑接口说明中明确标注 `transportOrder` 中所有日期字段（`goodsCompleteTime`、`etd`、`atd`、`eta`）均可编辑更新。

## 影响范围

| 接口 | 影响 |
| --- | --- |
| AddAsync（新增） | 无影响，新增使用 AutoMapper 整体映射，ATD 正常写入 |
| EditAsync（编辑） | **已修复**，ATD 字段现在可正常更新 |
| GetPagedListAsync（列表） | 无影响，ATD 搜索条件和输出均正常 |
| DetailAsync（详情） | 无影响，ATD 正常输出 |

## 根本原因

`EditAsync` 方法对 `TransportOrder` 实体采用逐字段手动赋值，在添加 `ATD` 字段时仅更新了 DTO 定义和列表查询条件，遗漏了编辑方法中的手动赋值语句。
