# 海运出口列表「未填写」筛选 修改记录 2026-06-28

**修改时间：** 2026-06-28

**修改人：** 后端

**关联需求：** 海运出口列表支持可空字段「未填写」筛选，与分组统计接口联动

---

## 一、需求背景

分组统计接口（`GetGroupedListAsync`）对船公司、起运港、目的港、付费方式、签单方式等可空字段分组时，未填写记录会出现在 `id`/`name` 均为 null 的分组中。前端点击该分组后需跳转列表并只展示对应未填写记录，列表接口此前无法表达「查空值」条件。

---

## 二、改动范围

| 文件 | 路径 | 修改类型 |

|------|------|----------|

| DTO | `Application/App/SeaExport/Dto/SeaExportDto.cs` | `SeaExportQueryDto` 新增 5 个 `bool?` 未填写筛选字段 |

| 服务 | `Application/App/SeaExport/SeaExportAdminAppService.cs` | `BuildSeaExportFilterQuery` 增加未填写筛选与互斥校验 |

| 文档 | `文档/海运出口/海运出口api.md` | 补充查询参数说明 |

---

## 三、新增查询参数

| 字段 | 类型 | 对应业务字段 | 分组 groupField |

|------|------|--------------|-----------------|

| carrierIdEmpty | bool? | SeaExport.CarrierId | 4 船公司 |

| polIdEmpty | bool? | SeaExport.POLId | 5 起运港 |

| podIdEmpty | bool? | SeaExport.PODId | 6 目的港 |

| codeFrtIdEmpty | bool? | TransportOrder.CodeFrtId | 8 付费方式 |

| codeIssueTypeIdEmpty | bool? | SeaExport.CodeIssueTypeId | 9 签单方式 |

传 `true` 时仅返回该字段为空的记录；不传或传 `false` 时不生效。与同名 id 参数（如 `codeFrtId`）**不可同时传入**，否则返回友好错误提示。

---

## 四、核心逻辑

筛选条件写入共用方法 `BuildSeaExportFilterQuery`，列表与分组统计口径一致。示例：

```csharp

.WhereIf(input.CodeFrtIdEmpty == true, m => !m.TransportOrder.CodeFrtId.HasValue)

.WhereIf(input.CodeFrtId.HasValue, m => m.TransportOrder.CodeFrtId == input.CodeFrtId.Value)

```

---

## 五、前端对接

1. 分组统计返回 `{ "id": null, "name": null, "count": N }` 时，列表请求传对应 `*Empty=true`。

2. 分组返回具体 id 时，仍传原有 id 参数（如 `codeFrtId=123`）。

3. 可与日期区间、委托单位、OrgId 等其他列表条件组合使用。

---

## 六、避坑指南

1. **互斥校验**：同一字段不可同时传 id 与 `*Empty=true`。

2. **仅 true 生效**：`*Empty` 只有显式传 `true` 才筛选未填写；`false` 或不传等同于不筛选。

3. **分组接口无需改动**：`SeaExportGroupQueryDto` 继承 `SeaExportQueryDto`，分组前筛选同样支持 `*Empty` 参数。
