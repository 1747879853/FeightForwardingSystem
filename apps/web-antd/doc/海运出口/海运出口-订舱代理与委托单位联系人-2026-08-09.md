# 订舱代理/委托单位联系人字段-2026-08-09

## 背景意图

海运出口、空运出口需记录订舱代理下的联系人；业务主表需记录委托单位联系人。联系人取自 ClientContact，仅存 Id（无外键），新建/编辑校验归属，列表/详情以 ClientContactSimpleDto 对象返回。

## 核心逻辑变更

1. 实体（无 FK / 无导航）
   - SeaExport / AirExport：long? BookingAgentContactId
   - TransportOrder：long? ClientContactId（委托单位联系人）
2. DTO
   - 新增 ClientContactSimpleDto（Id/Name/Mobile/Email/Tel/Position/WeChat）
   - Add/Edit 入参增加对应 Id；输出增加 Id + SimpleDto 对象（BookingAgentContact / ClientContact）
3. 校验（新建与编辑）
   - 有联系人 Id 时：联系人必须存在，且 ClientContact.ClientId 必须等于父客户 Id
   - 订舱代理为空时不允许填订舱代理联系人
   - 提示语：{父名称}联系人id错误 / {父名称}与联系人id不一致 / {父名称}未填写时不能选择联系人
4. 映射
   - SeaExport / AirExport / SeaImport 列表与详情批量查联系人并填充对象
   - SeServiceTask 嵌套 SeaExportDto 同步填充

## 避坑指南

- 不生成 Migration：本地自行 Add-Migration，列类型 bigint 可空，不要加外键/索引（业务约定弱关联）。
- 字段屏蔽：海运出口 PropMask 恢复 BookingAgentId/ClientId 时已同步恢复对应联系人 Id，避免被前端空值覆盖。
- 删除联系人前暂不做业务引用校验（后续如需再开）。
