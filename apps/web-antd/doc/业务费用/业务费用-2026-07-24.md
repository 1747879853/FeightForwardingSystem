# 1. 背景意图

费用列表打印需要业务单与海运出口字段。普通列表不挂载这些对象以保持轻量，增加可选入参 `IsPrint`，为 true 时批量赋值。

# 2. 核心逻辑

- `OrderFeeQueryDto` 新增 `IsPrint`。
- `GetPagedListAsync`：`IsPrint==true` 时按本页 `TransportOrderId` 批量查 `TransportOrderSimpleDto`，再查 `SeaExport` 组装 `SeaExportSimpleDto`（含港口/船公司名称）挂到 `TransportOrder.SeaExport`，最后赋给每条费用的 `TransportOrder`。
- `PrintFormatAdmin` 普通费用打印取数时强制 `IsPrint=true`。

# 3. 避坑

- `TransportOrderSimpleDto.SeaExport` 类型为开票模块的 `SeaExportSimpleDto`（简要字段），非海出详情全量 DTO。
- 非海运出口业务无对应 `SeaExport` 时 `seaExport` 为 null，`transportOrder` 仍会赋值。
