# 1. 背景意图 (Background)

**白话解释：** 继续将 `GetSeaExportFeesAsync` 出参中残留的名称字符串改为与费用模板等模块一致的简要对象，方便前端统一展示与取值。

# 2. 核心逻辑变更 (Core Changes)

| 位置             | 原字段           | 新字段       | 类型                |
| :--------------- | :--------------- | :----------- | :------------------ |
| `transportOrder` | `ClientName`     | `Client`     | `ClientSimpleDto`   |
| `orderFees[]`    | `FeeCodeName`    | `FeeCode`    | `FeeCodeSimpleDto`  |
| `orderFees[]`    | `SettlementName` | `Settlement` | `ClientSimpleDto`   |
| `orderFees[]`    | `CurrencyCode`   | `Currency`   | `CurrencySimpleDto` |

接口：`GetSeaExportFeesAsync`

# 3. 避坑指南 (Pitfalls)

> [!IMPORTANT]
>
> 1. `CurrencySimpleDto` 无 `id` 字段，仅有 `code`/`cnName`/`enName`/`defaultRate`。
> 2. 结算对象可空时 `settlement` 为 `null`。
> 3. 旧字符串字段已删除，前端需改读对象。
