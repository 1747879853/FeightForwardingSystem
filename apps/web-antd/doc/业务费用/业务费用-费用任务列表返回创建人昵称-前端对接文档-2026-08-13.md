# 业务费用任务列表返回创建人昵称 — 前端对接文档

**变更日期**：2026-08-13

**变更概述**：`OrderFeeTaskListAsync` / `OrderFeeTaskDetailAsync` 的 `OrderFeeTaskListDto` 新增行级字段 `creatorUserName`：取本行（业务+更改单）最新一条任务（与 `creationTime` / `LastCreationTime` 同一条）的创建人昵称。

---

## 一、受影响的接口

| # | 接口 | 方法 | 路径 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| 1 | OrderFeeTaskListAsync | GET | `/api/services/app/OrderFeeAdmin/OrderFeeTaskListAsync` | 列表行新增 `creatorUserName` |
| 2 | OrderFeeTaskDetailAsync | GET | `/api/services/app/OrderFeeAdmin/OrderFeeTaskDetailAsync` | 详情行级同步返回 `creationTime`、`creatorUserName` |

---

## 二、接口 1 — OrderFeeTaskListAsync

**Summary：** 费用所有任务分页列表；按业务+更改单拆行；行级创建人为该行最新任务创建人。

**路径：** `GET /api/services/app/OrderFeeAdmin/OrderFeeTaskListAsync`

**权限：** `Admin.OrderFee.Audit`

### 2.1 请求参数

入参无变化，仍为 `OrderFeeTaskListInputDto`（`pageIndex` / `pageSize` 及既有筛选）。

### 2.2 本次出参变化（OrderFeeTaskListDto）

| 字段名 | JSON Key | 类型 | 变化 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| CreationTime | `creationTime` | DateTime | 既有 | 本行最新一条任务创建时间，`LastCreationTime = Max(CreationTime)`，亦为排序字段 |
| CreatorUserName | `creatorUserName` | string | **新增** | 上述 `creationTime` 对应任务的创建人昵称（`NickName`）；无创建人或缓存未命中时为 `null` |

> 继承自 `FullAuditedEntityDto` 的 `creatorUserId` 本接口仍未赋值，请用 `creatorUserName`，勿依赖 `creatorUserId`。

### 2.3 响应示例（节选）

```json
{
  "result": {
    "totalCount": 1,
    "items": [
      {
        "entityId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "changeOrderId": null,
        "creationTime": "2026-08-13T10:12:33",
        "creatorUserName": "张三",
        "submitOrderFeeItemCount": 2,
        "modifyOrderFeeItemCount": 0,
        "deleteOrderFeeItemCount": 0
      }
    ]
  }
}
```

## 三、接口 2 — OrderFeeTaskDetailAsync

**路径：** `GET /api/services/app/OrderFeeAdmin/OrderFeeTaskDetailAsync`

### 3.1 本次出参变化（行级）

| 字段名 | JSON Key | 类型 | 变化 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| CreationTime | `creationTime` | DateTime | **本次赋值** | 本行最新一条任务创建时间 |
| CreatorUserName | `creatorUserName` | string | **新增** | 本行最新一条任务创建人昵称 |

> 费用级 `orderFeeTasks[].creatorUserName` 仍是费用录入人，含义与行级不同，勿混用。详见 [业务费用-费用任务详情返回录入人-前端对接文档-2026-08-09.md](./业务费用-费用任务详情返回录入人-前端对接文档-2026-08-09.md)。

---

## 四、前端注意点

1. 列表行展示「最近提交人」用根级 `creatorUserName`，不要取 `orderFeeTasks` 内字段（列表本身也不填费用级录入人）。
2. 与 `creationTime` 成对使用：时间与人属于同一条最新任务。
3. 值为 `null` 时按无创建人展示即可。
