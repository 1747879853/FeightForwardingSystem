# 业务费用-批量引入汇率按会计期间重取-前端对接文档-2026-08-11

路由前缀：`/api/services/app/OrderFeeAdmin`  
权限：`Admin.OrderFee.Add`  
接口：`POST /api/services/app/OrderFeeAdmin/ImportOrderFeesToTransportOrderAsync`

---

## 1. 行为变更（无入参/出参字段变更）

| 项 | 旧行为 | 新行为 |
| :-- | :-- | :-- |
| 新费用 `exchangeRate` | 直接复制源费用汇率 | 按目标业务（或更改单）`accountDate` + 币别重查汇率 |
| 收付取值 | — | 应收取 `DRValue`，应付取 `CRValue`（与模板自动生成费用一致） |
| 匹配不到 | — | 写入 `0`（不报错、不跳过该条） |

入参 `ImportOrderFeesToTransportOrderInputDto`、出参 `List<Guid>` 均不变。

---

## 2. 前端适配清单

- [ ] 引入成功后刷新费用列表，展示的汇率可能与源费用不同，勿默认认为与勾选源费用一致
- [ ] 若引入后汇率为 `0`，提交前需提示用户补录（提交接口仍会报「汇率为0的费用不可提交」）
- [ ] 无需改调用参数；`orderFeeIds` / `transportOrderId` / `changeOrderId` / `importOriginalSettlement` 用法不变
