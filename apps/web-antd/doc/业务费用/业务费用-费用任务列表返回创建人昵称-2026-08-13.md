# 业务费用任务列表返回行级创建人昵称

**日期**：2026-08-13  
**类型**：`Feature`  
**模块**：业务费用 / OrderFeeAdmin

---

## 背景意图

费用任务列表按「业务 + 更改单」分组后，行上的 `creationTime` 已取该组最新任务时间（`LastCreationTime = g.Max(m => m.CreationTime)`），但未返回对应创建人。前端需要在列表行展示「最近一次任务提交人」昵称。

---

## 核心逻辑变更

**接口：**

- `GET /api/services/app/OrderFeeAdmin/OrderFeeTaskListAsync`
- `GET /api/services/app/OrderFeeAdmin/OrderFeeTaskDetailAsync`（同行级口径同步）

**实现：** `OrderFeeAdminAppService.OrderFeeTaskListAsync` / `OrderFeeTaskDetailAsync`  
**DTO：** `OrderFeeTaskListDto.CreatorUserName`

1. 分组投影补充 `CreatorUserId`：`Select` 匿名对象增加 `x.CreatorUserId`。
2. 行级赋值：`CreationTime = LastCreationTime`；`CreatorUserName` 取 `TaskDatas` 中 `CreationTime == LastCreationTime` 那条任务的 `CreatorUserId`，再经 `GetUserInfoMapAsync` + `GetNickName` 得到昵称。
3. 详情同步：对本行 `taskBases` 按 `CreationTime` 倒序取最新一条，赋值 `CreationTime` / `CreatorUserName`，与列表口径一致。

### 字段说明

| 字段 | 含义 | 来源 |
| :-- | :-- | :-- |
| `creationTime` | 本行最新任务创建时间（既有） | `g.Max(m => m.CreationTime)` |
| `creatorUserName` | 本行最新任务创建人昵称（新增） | 对应 `LastCreationTime` 任务的 `CreatorUserId` → 用户缓存 `NickName` |

---

## 避坑指南

1. **行级创建人 ≠ 费用录入人。** 行上 `creatorUserName` 是「该业务+更改单」下最新一条 `TaskBase` 的创建人；费用级录入人仍在 `orderFeeTasks[].creatorUserName`（仅详情有赋值）。
2. **统一返回 Nickname。** 禁止回退查 `User.Name`；空 id 或缓存未命中返回 `null`。
3. **同一毫秒多条任务**时 `FirstOrDefault(CreationTime == LastCreationTime)` 取其中一条，与原先只暴露 `Max(CreationTime)` 的排序口径一致，一般可接受。
4. **复用已有用户缓存。** 列表里工作流已调用 `GetUserInfoMapAsync()`，行级昵称直接复用该字典，不额外查库。
