# 接口

入参、出参不变，仅新增服务端校验报错。

| 接口     | 方法 | 路径                                                  |
| :------- | :--- | :---------------------------------------------------- |
| 申请修改 | POST | `/api/services/app/OrderFeeAdmin/ModifyOrderFeeAsync` |
| 申请删除 | POST | `/api/services/app/OrderFeeAdmin/DeleteOrderFeeAsync` |

# 新增报错

| 报错文案 | 触发条件 |
| :-- | :-- |
| `已进行收费结算的费用不可申请修改` | 勾选费用中存在 `ReceiveSettlementItem`（按费用收费结算） |
| `已进行收费结算的费用不可申请删除` | 同上 |

# 前端建议

费用已参与收费结算时，禁用「申请修改」「申请删除」；与已对账 / 已付费申请 / 已开票申请的禁用规则并列。
