# 费用代码前端接口文档（FeeCode）

**控制器**：`FeeCode`（`FeeCodeAppService`，非 Admin）

**说明**：登录即可访问，**无需业务权限**；数据来自 `BasicDataCache`，不分页。

---

## 一、获取已启用费用代码全量列表

### `GET /api/services/app/FeeCode/GetListAsync`

**权限**：仅需登录（`[AbpAuthorize]`，无具体权限点）

**入参** `FeeCodeListQueryDto`（Query，均可空；不传则不过滤该条件）：

| 字段              | 类型    | 必填 | 说明                                   |
| ----------------- | ------- | ---- | -------------------------------------- |
| `isSea`           | `bool?` | 否   | 海运相关；传 `true`/`false` 时精确匹配 |
| `isAir`           | `bool?` | 否   | 空运相关                               |
| `isTrucking`      | `bool?` | 否   | 陆运相关                               |
| `isTruckingFixed` | `bool?` | 否   | 是否陆运固定费用                       |
| `isWms`           | `bool?` | 否   | 仓储相关                               |

**出参**：`List<FeeCodeSimpleDto>`

### `FeeCodeSimpleDto` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `long` | 主键ID |
| `code` | `string` | 费用代码 |
| `cnName` | `string` | 中文名称 |
| `enName` | `string` | 英文名称 |
| `currencyId` | `long` | 默认币别ID |
| `defaultUnit` | `string` | 默认计费标准代码 |
| `defaultUnitName` | `string` | 默认计费标准名称 |
| `defaultDebit` | `string` | 默认收费客户类型 |
| `defaultDebitName` | `string` | 默认收费客户类型名称（IndustryCategory 字母） |
| `defaultCredit` | `string` | 默认付费客户类型 |
| `defaultCreditName` | `string` | 默认付费客户类型名称（IndustryCategory 字母） |
| `isConfidential` | `bool` | 是否机密 |
| `isInvoiceProhibit` | `bool` | 禁开发票 |
| `taxRate` | `decimal` | 费用默认税率 |
| `exchangeRate` | `ExchangeRateSimpleDto` | 默认币别当前有效汇率；无匹配则为 `null` |

### `exchangeRate`（`ExchangeRateSimpleDto`）字段

| 字段      | 类型       | 说明     |
| --------- | ---------- | -------- |
| `id`      | `long`     | 汇率主键 |
| `drValue` | `decimal?` | 应收汇率 |
| `crValue` | `decimal?` | 应付汇率 |

### 业务规则

1. **仅返回已启用**：`Enable == true`（启用字段不出现在出参中）。
2. **业务线筛选**：`isSea` / `isAir` / `isTrucking` / `isTruckingFixed` / `isWms` 均可空；有值时与费用代码对应字段精确相等（筛选用，不出现在出参中）。
3. **排序**：`SortId` 升序，再按 `Code` 升序。
4. **汇率匹配**（按费用代码的 `currencyId`）：
   - `Enable == true`
   - `StartDate == null || StartDate <= 当前时间`
   - `EndDate == null || EndDate >= 当前时间`
   - 同一币别多条时：按 `SortId` 降序、`Id` 降序，取**第一条**。
5. 费用代码本体走 `BasicDataCache.GetFeeCodesAsync()`；汇率另查库（`AsNoTracking`）。
