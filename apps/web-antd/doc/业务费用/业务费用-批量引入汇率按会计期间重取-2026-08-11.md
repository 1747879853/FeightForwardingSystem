# 1. 业务背景说明 (Background)

**白话解释：** 批量引入历史费用时，原先直接复制源费用的 `ExchangeRate`。源业务与目标业务会计期间往往不同，复制过来的汇率可能已过期或与目标期间不符。现改为与完成服务项按模板生成费用（`GenerateOrderFeesByTemplateAsync`）同一套规则：按目标会计期间 + 币别重查汇率。

# 2. 功能与操作说明 (Features & Operations)

- **批量引入费用（ImportOrderFeesToTransportOrderAsync）：** 写入新费用前，按目标 `AccountDate`（有更改单取更改单会计期间，否则取业务会计期间）与费用 `CurrencyId` 预取汇率；应收取 `DRValue`、应付取 `CRValue`；匹配不到写 `0`。

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：匹配不到汇率时写入 0]** 与模板生成一致，不报错、不跳过该条费用。用户需在提交前补录汇率，否则提交会被「汇率为0的费用不可提交」拦截。
