# 1. 背景意图 (Background)

**白话解释：** `GetSeaExportFeesAsync` 原先返回港口/船公司/订舱代理名称字符串，前端不便复用统一简要对象结构。改为与海运出口等模块一致的对象返回。

# 2. 核心逻辑变更 (Core Changes)

`SeaExportFeeListDto` 结构调整：

| 原字段 | 新字段 | 类型 |
| :-- | :-- | :-- |
| `POLName` | `POL` | `PortCodeSimpleDto` |
| `PODName` | `POD` | `PortCodeSimpleDto` |
| `CarrierName` | `Carrier` | `CarrierSimpleDto` |
| `transportOrder.BookingAgentName` | `BookingAgent`（提升到列表 DTO） | `ClientSimpleDto` |

接口：`GetSeaExportFeesAsync`（`OrderFeeAdmin/GetSeaExportFees`）

# 3. 避坑指南 (Pitfalls)

> [!IMPORTANT]
>
> 1. 项目港口简要对象类名是 `PortCodeSimpleDto`（不是 PortSimpleDto）。
> 2. 前端需改读 `pol`/`pod`/`carrier`/`bookingAgent` 对象，旧字符串字段已删除。
> 3. 订舱代理未维护时 `bookingAgent` 为 `null`。
