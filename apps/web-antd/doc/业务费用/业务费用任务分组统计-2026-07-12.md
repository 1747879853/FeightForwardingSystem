# 背景意图

费用所有任务列表的分组看板需与海运出口分组能力对齐：支持**场站**维度统计及「场站未填写」筛选；按**船公司**分组时展示中文简称与 Logo。

# 核心逻辑变更

## 1. 列表 / 分组共用筛选 — OrderFeeTaskListInputDto

- 新增 `yardIdEmpty`（bool?）：`true` 时筛选 `SeaExport == null || !SeaExport.YardId.HasValue`。
- `OrderFeeTaskListAsync` 与 `OrderFeeTaskGroupedListAsync` 共用同一套 orderSearched / seaexportSearched 判定。

## 2. 分组统计 — OrderFeeTaskGroupedListAsync

- `SeaExportGroupField.Yard = 10`：按 `SeaExport.YardId` 分组，`name` 为 `Client.Name`。
- 船公司分组（groupField=4）：
  - `name` 改为 **`Carrier.CnShortName`**。
  - 新增 **`logo`**，批量查询船公司附件（模块 `160010`）。
- 海运字段通过 **`TransportOrder.SeaExport` 导航属性**一次性投影，不再单独查 `_seaExportRepository` 做 Dictionary 映射。

## 3. 响应 DTO — OrderFeeTaskGroupDto

新增 `logo` 字段，语义与海运出口 `SeaExportGroupDto.logo` 一致。

# 前端对接要点

| 场景                    | 参数                       |
| ----------------------- | -------------------------- |
| 列表 / 分组筛选场站为空 | `yardIdEmpty=true`         |
| 按场站分组              | `groupField=10`            |
| 点击场站「未填写」      | `yardIdEmpty=true`         |
| 船公司分组 UI           | `name`（简称）+ `logo.url` |

# 避坑指南

- 分组统计按 **TransportOrderId 去重**，与任务主表条数、费用条数不同。
- `groupField` 有效范围为 **1~10**，超出报「不支持的分组字段」。
- 费用模块注入 `IAttachmentAppService` 用于加载船公司 logo，与海运出口实现一致。
