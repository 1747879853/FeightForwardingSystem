# 业务费用批量引入 — 出参对象化 前端对接

**日期：** 2026-07-29  
**接口：** `GET` `OrderFeeAdmin/GetSeaExportFees`（`GetSeaExportFeesAsync`）

## 破坏性变更（出参）

`SeaExportFeeListDto`：

| 已删除 | 新字段 | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| `pOLName` | `pol` | `PortCodeSimpleDto` | `{ id, portName, cnName }` |
| `pODName` | `pod` | `PortCodeSimpleDto` | `{ id, portName, cnName }` |
| `carrierName` | `carrier` | `CarrierSimpleDto` | `{ id, code, cnName, cnShortName, enName, ediCode }` |
| `transportOrder.bookingAgentName` | `bookingAgent` | `ClientSimpleDto` | `{ id, name, code, fullName, enName, ... }`；可空 |

`transportOrder` 仍含：`commissionNum` / `mblNum` / `clientName` / `totalCtn`。

展示名称时可取：`pol.portName` / `pod.portName` / `carrier.cnName` / `bookingAgent.name`。
