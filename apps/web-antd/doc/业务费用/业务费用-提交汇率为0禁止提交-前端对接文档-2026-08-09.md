# 业务费用-提交汇率为0禁止提交-前端对接文档-2026-08-09

路由前缀：`/api/services/app/OrderFeeAdmin`  
权限：`Admin.OrderFee.Edit`

---

## 1. 提交 — `POST /api/services/app/OrderFeeAdmin/SubmitOrderFeeAsync`

### 新增校验

| 条件                           | HTTP/业务异常提示     |
| :----------------------------- | :-------------------- |
| 任一条费用 `exchangeRate == 0` | 汇率为0的费用不可提交 |

与既有校验并存：

- `exchangeRate < 0` → 汇率不能为负数
- `amount == 0` → 金额为0的费用不可提交

### 入参相关字段（`orderFees[]`）

| 字段 | JSON           | 类型    | 说明                            |
| :--- | :------------- | :------ | :------------------------------ |
| 汇率 | `exchangeRate` | decimal | 提交时必须 `!= 0`（且不能为负） |
| 金额 | `amount`       | decimal | 提交时必须 `!= 0`（既有）       |
