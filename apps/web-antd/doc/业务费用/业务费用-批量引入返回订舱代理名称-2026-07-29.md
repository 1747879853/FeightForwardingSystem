# 1. 背景意图 (Background)

**白话解释：** 费用批量引入查询接口 `GetSeaExportFeesAsync` 返回的业务子对象 `SeaExportFeeTransportOrderDto` 原先只有委托单位名称，前端列表还需要展示订舱代理名称。

# 2. 核心逻辑变更 (Core Changes)

- `SeaExportFeeTransportOrderDto` 新增 `BookingAgentName`（订舱代理名称）。
- `GetSeaExportFeesAsync` 批量查客户时并入 `SeaExport.BookingAgentId`，组装时填充 `BookingAgentName`。

| 接口 | 地址/方法 | 变更 |
| :-- | :-- | :-- |
| `GetSeaExportFeesAsync` | `GET` `OrderFeeAdmin/GetSeaExportFees` | `transportOrder.bookingAgentName` 新增返回 |

# 3. 避坑指南 (Pitfalls)

> [!IMPORTANT] 订舱代理在海运出口上可空；未维护时 `BookingAgentName` 为 `null`。
