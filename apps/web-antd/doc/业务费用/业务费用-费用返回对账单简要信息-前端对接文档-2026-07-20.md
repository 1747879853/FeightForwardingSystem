# 业务费用返回对账单简要信息 — 前端对接文档

**变更日期**：2026-07-20

**变更概述**：费用输出 `OrderFeeDto` 新增 `statementId` 与 `statement`（对账单简要信息，仅含 `id`、`statementNum`）。`OrderFeeAdmin/GetPagedListAsync` 与 `ChangeOrderAdmin/DetailAsync` 均同步返回；更改单详情 `DetailAsync` 额外支持按费用 `ids` 过滤。

---

## 一、新增字段（OrderFeeDto）

| 字段名 | JSON Key | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| StatementId | `statementId` | Guid? | 客户对账 id，为空代表未参与对账 |
| Statement | `statement` | object? | 对账单简要信息；`statementId` 为空时为 null |
| Statement.Id | `statement.id` | Guid | 对账 id |
| Statement.StatementNum | `statement.statementNum` | string | 对账单号 |

> `statement` 仅返回 `id`、`statementNum` 两列，不含客户、时间等其它信息。

---

## 二、受影响的接口

| # | 接口 | 方法 | 路径 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| 1 | GetPagedListAsync | GET | `/api/services/app/OrderFeeAdmin/GetPagedListAsync` | 业务费用分页列表，每条 `OrderFeeDto` 返回 |
| 2 | DetailAsync | GET | `/api/services/app/ChangeOrderAdmin/DetailAsync` | 更改单详情，`orderFees[]` 每条费用返回 |

---

## 三、接口 1 — GetPagedListAsync

**Summary：** 分页查询业务费用（不含更改单），每条费用返回对账单简要信息。

**权限：** `Admin.OrderFee.Get`

### 3.1 请求参数（OrderFeeQueryDto，节选）

继承 `PagingAndSorting`。

| 字段名           | JSON Key           | 类型   | 必填 | 说明                 |
| :--------------- | :----------------- | :----- | :--- | :------------------- |
| PageIndex        | `pageIndex`        | int    | 否   | 当前页码，默认 1     |
| PageSize         | `pageSize`         | int    | 否   | 每页条数，默认 10    |
| TransportOrderId | `transportOrderId` | Guid?  | 否   | 业务 id              |
| Ids              | `ids`              | Guid[] | 否   | 按费用 id 列表过滤   |
| PaySide          | `paySide`          | int?   | 否   | 收付类型。0=收，1=付 |
| SettlementId     | `settlementId`     | Guid?  | 否   | 结算对象 id          |
| Keyword          | `keyword`          | string | 否   | 备注模糊匹配         |

### 3.2 请求示例

```
GET /api/services/app/OrderFeeAdmin/GetPagedListAsync?transportOrderId=a1b2c3d4-e5f6-7890-abcd-ef1234567890&pageIndex=1&pageSize=20
```

### 3.3 响应示例（节选）

```json
{
  "result": {
    "items": [
      {
        "id": "fee-guid-001",
        "transportOrderId": "order-guid-001",
        "paySide": 0,
        "feeCodeName": "海运费",
        "amount": 1000.0,
        "settlementId": "client-guid-001",
        "statementId": "statement-guid-001",
        "statement": {
          "id": "statement-guid-001",
          "statementNum": "SOA20260720001"
        }
      },
      {
        "id": "fee-guid-002",
        "statementId": null,
        "statement": null
      }
    ],
    "totalCount": 2
  },
  "success": true
}
```

## 四、接口 2 — ChangeOrderAdmin/DetailAsync

**Summary：** 更改单详情，返回更改单及其下费用；费用每条返回对账单简要信息，可按费用 id 过滤。

### 4.1 请求参数（GuidIdDto）

| 字段名 | JSON Key | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| Id | `id` | Guid | 是 | 更改单 id |
| Ids | `ids` | Guid[] | 否 | 按费用 id 过滤 `orderFees`，不传返回该更改单全部费用 |

### 4.2 请求示例

```
GET /api/services/app/ChangeOrderAdmin/DetailAsync?id=change-guid-001&ids=fee-guid-001&ids=fee-guid-002
```

### 4.3 响应示例（节选）

```json
{
  "result": {
    "id": "change-guid-001",
    "orderFees": [
      {
        "id": "fee-guid-001",
        "changeOrderId": "change-guid-001",
        "feeCodeName": "海运费",
        "amount": 500.0,
        "statementId": "statement-guid-001",
        "statement": {
          "id": "statement-guid-001",
          "statementNum": "SOA20260720001"
        }
      }
    ]
  },
  "success": true
}
```

---

## 五、前端改动建议

1. **展示对账单号**：费用行有 `statement` 时展示 `statement.statementNum`，可点击跳转对账单详情。
2. **操作禁用**：`statementId` 有值（已参与对账）时，前端应禁用该费用的编辑、删除、申请修改/删除按钮（服务端也会拦截）。
3. **更改单详情过滤**：需要只看部分费用时，通过 `ids` 传入费用 id 列表。
