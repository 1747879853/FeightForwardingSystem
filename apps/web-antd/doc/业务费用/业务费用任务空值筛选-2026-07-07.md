# 1. 背景意图 (Background)

**白话解释：**

费用所有任务列表 `OrderFeeTaskListAsync` 需要支持针对关键业务字段做「未填写/空值」筛选，便于快速定位委托单位、船名、船公司、港口、付费方式、签单方式等尚未维护完整的数据。空值筛选与分组统计接口 `OrderFeeTaskGroupedListAsync` 共用同一套查询条件，保证列表 `totalCount` 与分组 `count` 口径一致。

# 2. 接口说明 — OrderFeeTaskListAsync

**接口地址：** `GET /api/services/app/OrderFeeAdmin/OrderFeeTaskListAsync`

**请求方式：** GET（Query 参数）

**权限：** `Admin.OrderFee.Audit`（审核）

**功能说明：** 分页查询费用所有任务（提交费用 / 修改费用 / 删除费用三类任务合并展示）。按 `TransportOrderId`（业务单）去重，每个业务单返回一条汇总记录，包含该业务下待审核任务数量及业务简要信息。

### 2.1.3 空值筛选（本次新增）

以下字段均为 `bool?` 类型，**仅当传入 `true` 时生效**；未传、`false` 均不触发空值筛选。可与分组统计中 `id`/`name` 为 null 的分组联动：点击「未填写」分组后，列表传对应 `*Empty=true`。

| 字段名 | JSON Key | 类型 | 筛选语义 | 后端过滤条件 |
| :-- | :-- | :-- | :-- | :-- |
| ClientIdEmpty | `clientIdEmpty` | bool? | 委托单位未填写 | `TransportOrder.ClientId == Guid.Empty` |
| VesselEmpty | `vesselEmpty` | bool? | 船名未填写 | `SeaExport == null` **或** `SeaExport.Vessel` 为空/空白 |
| BLTypeEmpty | `bLTypeEmpty` | bool? | 装运方式未填写 | `SeaExport == null`（装运方式字段本身非空，语义为无海运出口记录） |
| BillTypeEmpty | `billTypeEmpty` | bool? | 订单类型未填写 | `SeaExport == null`（同上） |
| CarrierIdEmpty | `carrierIdEmpty` | bool? | 船公司未填写 | `SeaExport == null` **或** `SeaExport.CarrierId` 无值 |
| POLIdEmpty | `pOLIdEmpty` | bool? | 起运港未填写 | `SeaExport == null` **或** `SeaExport.POLId` 无值 |
| PODIdEmpty | `pODIdEmpty` | bool? | 目的港未填写 | `SeaExport == null` **或** `SeaExport.PODId` 无值 |
| CodeFrtIdEmpty | `codeFrtIdEmpty` | bool? | 付费方式未填写 | `TransportOrder.CodeFrtId` 无值 |
| CodeIssueTypeIdEmpty | `codeIssueTypeIdEmpty` | bool? | 签单方式未填写 | `SeaExport == null` **或** `SeaExport.CodeIssueTypeId` 无值 |

**联动说明：**

- 空值筛选与同名精确筛选（如 `clientId`）可同时存在时以后端 AND 逻辑叠加；建议前端在点击「未填写」分组时只传 `*Empty=true`，不要再传对应的 id 筛选。
- 分组统计接口 `OrderFeeTaskGroupedListAsync` 复用完全相同的空值筛选逻辑。

# 3. 避坑指南 (Pitfalls)

- `xxxEmpty` 仅在传 `true` 时生效，未传或 `false` 均不触发。
- `BLTypeEmpty` / `BillTypeEmpty` 的实际语义是「无海运出口记录（SeaExport == null）」，而非枚举值为空。
- `VesselEmpty` 同时覆盖「无 SeaExport」和「Vessel 为空字符串」两种情况。
- 列表按 `TransportOrderId` 去重统计 `totalCount`，与任务主表原始条数不同。
- 空值筛选与分组统计共用逻辑；前端从分组面板点「未填写」时，应传对应 `*Empty=true`，此时 `totalCount` 应与该分组 `count` 一致。
- `remark` 入参当前未参与后端筛选，请勿依赖。
- 列表 `orderFeeTasks` 不含 `task` 字段；需任务明细时调 `OrderFeeTaskDetailAsync`。
- `combinedFeeStatus` 说明见 [业务费用-组合费用状态-前端对接文档-2026-07-12.md](./业务费用-组合费用状态-前端对接文档-2026-07-12.md)。
