# 业务费用-提交汇率为0禁止提交-2026-08-09

## 背景意图

费用录入阶段允许临时存在汇率为 0（例如币别未配默认汇率、待补），新建/编辑不限制；提交审核时汇率为 0 会导致本位币折算无效，故在 `SubmitOrderFeeAsync` 禁止提交。

## 核心逻辑变更

涉及：`OrderFeeAdminAppService.SubmitOrderFeeAsync`

| 接口 | 是否限制 ExchangeRate=0 |
| :-- | :-- |
| `AddAsync` / `EditAsync` 等 | 不限制（仍禁止负数） |
| `SubmitOrderFeeAsync` | **限制**：`ExchangeRate==0` 抛出「汇率为0的费用不可提交」 |

校验位置：与「金额为0不可提交」相邻，使用入参 `item.ExchangeRate`。

## 避坑指南

- 只拦 0，不拦负数（负数仍走「汇率不能为负数」）。
- 申请修改 `ModifyOrderFeeAsync` 本次未加同等限制；若也要拦请另提。
