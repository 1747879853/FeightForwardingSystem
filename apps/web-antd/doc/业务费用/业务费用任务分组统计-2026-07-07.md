# 1. 背景意图 (Background)

**白话解释：**

海运出口列表已有 `GetGroupedListAsync` 分组统计能力。费用所有任务列表 `OrderFeeTaskListAsync` 也需要同样的分组看板：在相同筛选条件下，按装运方式、委托单位、船公司等维度统计各分组的数据条数，便于前端做筛选面板。统计维度为「有费用任务的业务单」（按 `TransportOrderId` 去重），与任务主表条数不同。

# 2. 接口说明 — OrderFeeTaskGroupedListAsync

**接口地址：** `GET /api/services/app/OrderFeeAdmin/OrderFeeTaskGroupedListAsync`

**请求方式：** GET（Query 参数）

**权限：** `Admin.OrderFee.Audit`（审核）

**功能说明：** 查询条件与 `OrderFeeTaskListAsync` **完全一致**，额外指定 `groupField` 分组字段。先按条件筛出存在费用任务（提交/修改/删除）的业务单，再按指定字段分组，返回每组的 id、名称、count。结果按 `count` 倒序排列。**不分页**，返回全部分组。

| groupField | 含义 | 分组依据字段 | id 格式 | name 来源 |

| 2 | 订单类型 | `SeaExport.BillType` | 枚举 int 字符串，如 `"0"` | 枚举描述（主票M/分票H） |
| 3 | 委托单位 | `TransportOrder.ClientId` | Guid 字符串 | `Client.Name`（含软删除数据回填） |
| 4 | 船公司 | `SeaExport.CarrierId` | long 字符串 | `Carrier.CnShortName`（含软删除数据回填）；额外返回 `logo` |
| 5 | 起运港 | `SeaExport.POLId` | long 字符串 | `PortCode.PortName`（含软删除数据回填） |
| 6 | 目的港 | `SeaExport.PODId` | long 字符串 | `PortCode.PortName`（含软删除数据回填） |
| 7 | 船名 | `SeaExport.Vessel` | 船名字符串 | 与 id 相同（船名本身） |

# 3. 核心逻辑说明

1. **任务范围：** 仅统计存在 `TaskType` 为 `SubmitOrderFee`、`ModifyOrderFee`、`DeleteOrderFee` 且 `EntityId` 有值的 `TaskBase` 记录所关联的业务单。
2. **去重维度：** 同一 `TransportOrderId` 只计 1 条，不论该业务下有多少条任务主表记录。
3. **筛选顺序：** 先按 `OrderFeeTaskListInputDto` 全部条件（含 `*Empty`）过滤 TransportOrder，再与 TaskBase 的 `Processed` 等条件取交集得到业务单 id 集合，最后按 `groupField` 分组计数。
4. **名称回填：** 委托单位、船公司、港口、付费方式、签单方式查询名称时禁用软删除过滤（`DisableFilter(SoftDelete)`），避免只返回 id 无名称。
5. **排序：** 分组结果按 `count` 降序。

---

# 4. 避坑指南 (Pitfalls)

- 分组统计基于「费用任务业务维度」（`TransportOrderId` 去重），与任务主表条数、费用条数均不同。
- 分页参数对本接口无效，返回全部分组。
- `groupField=1/2` 时分组值为枚举；无 SeaExport 时 id/name 均为 null。
- `groupField=7`（船名）时 id 与 name 均为船名字符串；空船名归入 null 分组。
- 点击 null 分组联动列表时，对应 `*Empty` 参数：`clientIdEmpty` / `vesselEmpty` / `bLTypeEmpty` / `billTypeEmpty` / `carrierIdEmpty` / `pOLIdEmpty` / `pODIdEmpty` / `codeFrtIdEmpty` / `codeIssueTypeIdEmpty` / `yardIdEmpty`。
- `remark` 入参当前未参与后端筛选。
- 不支持的分组字段会抛 `UserFriendlyException`。
