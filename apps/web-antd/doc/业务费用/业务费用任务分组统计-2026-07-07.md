# 业务费用任务分组统计-2026-07-07

## 背景意图

- 之前海运出口列表已支持 `GetGroupedListAsync` 分组统计。
- 业务费用任务列表 `OrderFeeTaskListAsync` 也需要同样的分组统计能力，便于前端按同一套字段做筛选看板。

## 核心逻辑变更

- 新增接口 `OrderFeeTaskGroupedListAsync`（`GET`）：
  - 查询条件与 `OrderFeeTaskListAsync` 保持一致；
  - 分组字段复用 `SeaExportGroupField`，支持：
    - 装运方式(BLType)
    - 订单类型(BillType)
    - 委托单位(Client)
    - 船公司(Carrier)
    - 起运港(POL)
    - 目的港(POD)
    - 船名(Vessel)
    - 付费方式(CodeFrt)
    - 签单方式(CodeIssueType)
  - 返回每组 `Id/Name/Count`。
- 新增 DTO：
  - `OrderFeeTaskGroupQueryDto : OrderFeeTaskListInputDto`
  - `OrderFeeTaskGroupDto`
- 新增接口定义：
  - `IOrderFeeAdminAppService.OrderFeeTaskGroupedListAsync(OrderFeeTaskGroupQueryDto input)`

## 避坑指南

- 分组统计基于“费用任务业务维度”（按 `TransportOrderId` 去重后统计），与任务主表条数不同。
- 对于可能被软删除的基础资料（委托单位、船公司、港口、付费方式、签单方式），统计时已兼容名称回填逻辑，避免只返回ID无名称。
