# 业务费用应收/应付费用数量统计 — 前端对接文档

**变更日期**：2026-07-20

**变更概述**：`OrderFeeAdminAppService` 新增接口 `GetOrderFeeCountAsync`，输入业务 id（`TransportOrderId`），返回该条业务对应的应收费用数量与应付费用数量。

---

## 一、接口信息

| 项      | 内容                                                    |
| :------ | :------------------------------------------------------ |
| 接口名  | GetOrderFeeCountAsync                                   |
| 方法    | GET                                                     |
| 路径    | `/api/services/app/OrderFeeAdmin/GetOrderFeeCountAsync` |
| 权限    | `Admin.OrderFee.Get`                                    |
| Summary | 根据业务 id 统计对应的应收费用数量和应付费用数量        |

---

## 二、请求参数（OrderFeeCountQueryDto）

| 字段名 | JSON Key | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| TransportOrderId | `transportOrderId` | Guid | 是 | 业务 id，为空报错「业务id不能为空」 |

### 请求示例

```
GET /api/services/app/OrderFeeAdmin/GetOrderFeeCountAsync?transportOrderId=a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

---

## 三、响应参数（OrderFeeCountDto）

| 字段名 | JSON Key | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| ReceivableCount | `receivableCount` | int | 应收费用数量（`PaySide=收`，即 0） |
| PayableCount | `payableCount` | int | 应付费用数量（`PaySide=付`，即 1） |

> 数量为该业务下费用记录条数（按 `PaySide` 分别计数），不做金额汇总。

### 响应示例

```json
{
  "result": {
    "receivableCount": 3,
    "payableCount": 2
  },
  "success": true
}
```

---

## 四、接口路径速查

| 接口路径 | 方法 | 入参 | 出参 |
| :-- | :-- | :-- | :-- |
| `/api/services/app/OrderFeeAdmin/GetOrderFeeCountAsync` | GET | `transportOrderId` | `receivableCount`、`payableCount` |
