## 一、功能概述

自动费用模板管理模块提供了海运出口业务中费用自动生成规则的配置功能。通过预设模板，系统可以根据订单的起运港、目的港、船公司、委托单位等条件自动匹配并生成相应的费用项。

### 1.1 核心特性

- **条件匹配**：支持多维度条件配置（港口、船公司、贸易条款等）
- **批量管理**：支持批量删除、分组统计
- **可视化编辑**：使用Handsontable组件进行费用明细的表格化编辑
- **权限控制**：基于ABP权限系统进行细粒度控制

## 七、注意事项

### 7.1 必填校验

1. **基础信息**：
   - 模板名称（name）
   - 业务类型（bizType）
   - 收付类型（paySide）

2. **费用明细**：
   - 至少需要一条费用明细
   - 每条明细的费用代码、行业类别、结算对象、币别、单价、税率均为必填

### 7.2 字段联动

当前版本未实现字段联动，后续可以优化：

- 选择费用代码后，自动填充币别、税率
- 选择行业类别后，过滤结算对象列表
- 输入含税单价和税率，自动计算不含税单价

### 7.3 Handsontable许可证

当前使用的是评估版许可证：

```typescript
licenseKey: 'non-commercial-and-evaluation';
```

**生产环境需要购买商业许可证**，否则会有水印和功能限制。

### 7.4 下拉数据源

当前代码中下拉数据源（费用代码、币别、客户）使用的是空数组，实际使用时需要：

1. 调用对应的API获取数据
2. 缓存到本地避免重复请求
3. 根据行业类别过滤客户列表

示例：

```typescript
async function loadDropdownData() {
  // 获取费用代码列表
  const feeCodes = await getFeeCodeList();
  feeCodeList.value = feeCodes.map((item) => ({
    label: item.cnName,
    value: item.id,
    currencyId: item.currencyId,
  }));

  // 获取币别列表
  const currencies = await getCurrencyList();
  currencyList.value = currencies.map((item) => ({
    label: item.code,
    value: item.id,
  }));

  // 获取客户列表
  const clients = await getClientList();
  clientList.value = clients.map((item) => ({
    label: item.name,
    value: item.id,
    industryCategory: item.industryCategory,
  }));
}
```

### 7.5 性能优化

对于大数据量场景，建议：

1. 启用虚拟滚动（Handsontable专业版功能）
2. 分页加载费用明细
3. 防抖处理输入事件
4. 使用Web Worker处理复杂计算

## 九、常见问题

### Q1: Handsontable表格无法显示？

**A**: 检查是否正确引入CSS：

```typescript
import 'handsontable/dist/handsontable.full.min.css';
```

### Q2: 下拉选项为空？

**A**: 需要在`loadDropdownData()`中调用对应的API获取数据。

### Q3: 保存时提示"至少需要一条费用明细"？

**A**: 确保Handsontable中至少有一行数据，且必填字段都已填写。

### Q4: 权限控制不生效？

**A**: 检查用户是否有对应的权限标识，可以在控制台打印`userStore.userFunctions`查看。
