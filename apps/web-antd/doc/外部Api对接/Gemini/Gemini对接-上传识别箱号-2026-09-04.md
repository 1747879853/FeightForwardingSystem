# Gemini对接-上传识别箱号-2026-09-04

# 1. 背景意图

监装等场景要拍箱门照片并回填箱号。需要一次请求完成两件事：按通用上传口径把图片落成附件，同时用 AI 从照片里认出箱号。认不出时不能把整次上传打成失败。

# 2. 核心逻辑变更

| 项 | 说明 |
| :-- | :-- |
| 新接口 | `POST /api/services/app/GeminiAdmin/UploadAndExtractCtnNoAsync` |
| 入参 | `multipart/form-data`，**只能一张图片** |
| 落库 | 口径同 `UploadController.UploadFile`：`IStoreProvider` 存文件 + `CreateOrUpdateAttachmentAsync` 写附件表。媒体类型为图片，上限 5MB |
| 出参 | `GeminiCtnNoUploadDto`：`filePath` / `fileUrl` / `fileName` / `attachmentId` + `ctnNo` |
| 识别失败 | **`ctnNo` 为 null**，附件四个字段照常返回，接口不抛错 |

完整入参见《Gemini对接-前端对接》第 6 节。

# 3. 避坑指南

> [!IMPORTANT] **识别失败不是接口失败。** AI 超时、解析失败、图里没有箱号时 `success` 仍为 true。前端必须单独判断 `ctnNo` 是否为 null，让用户手工填箱号。

> [!IMPORTANT] **只收一张图。** 0 张报 `请上传图片`，多于 1 张报 `只支持上传一张图片`。不要按其它 Gemini 接口「取第一个、忽略其余」来传。
