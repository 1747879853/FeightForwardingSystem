# 1. 背景意图 (Background)

Gemini 官方在高峰时常返回 **HTTP 503**（服务繁忙），英文原文不宜直接展示给前端。需要在外网服务器 `Freight.GlobalServer` 内：

1. 对 503 **自动重试**；
2. 重试次数/间隔放在 `appsettings.json`，运维可调；
3. 最终仍失败时返回汉化提示「AI识别服务繁忙，请稍后重试」。

# 2. 核心逻辑变更

| 项 | 说明 |
| :-- | :-- |
| 配置 | `RetryCount`、`RetryDelayMilliseconds`、`FallbackModels`（数组） |
| 重试范围 | **仅 HTTP 503** |
| 模型链 | 业务端原模型 → `gemini-3.5-flash` → `gemini-3.1-flash-lite` → `gemini-3-flash`；每个模型各自重试，仍 503 则切下一个 |
| 实现位置 | `GeminiForwarder.GenerateContentAsync` |
| 日志 | 记请求模型、实际模型、是否兜底、`AttemptCount` |
| 文案 | 503 →「AI识别服务繁忙，请稍后重试」 |

# 3. 避坑指南

- `RetryCount=1` 表示每个模型最多「首次 + 1 次重试」；再加 3 个兜底模型，最坏请求次数会明显变多，注意与业务端 180 秒超时的关系。
- `FallbackModels` 为空数组时只打原模型。
- 官方 503 英文原文只写进外网失败日志，不下发给前端。
