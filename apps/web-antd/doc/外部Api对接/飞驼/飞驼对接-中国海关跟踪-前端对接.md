# 1. 说明

中国海关跟踪只需对接 **一个接口**，调一次：传业务单Id，拿回该票在中国海关的关务节点。

提单号、进出口标识都由后端从业务单自己取，前端不用传。token、中转站等前端也无需关心。

> [!IMPORTANT] **纯查询接口，不会改任何数据。** 结果只用于展示，后端不回填业务单。

# 2. 接口

| 项目     | 内容                                                             |
| :------- | :--------------------------------------------------------------- |
| 方法     | `POST`                                                           |
| 地址     | `/api/services/app/FeituoAdmin/QueryCustomsTrackingAsync`        |
| 请求体   | JSON，见第 3 节                                                  |
| 返回     | JSON，见第 4 节（ABP 统一包一层 `result`）                       |
| 权限     | 需登录且具备「第三方接口 > 查询」权限（`Admin.ExternalApi.Get`） |
| 适用业务 | 仅 **海运出口** 与 **海运进口**；空运出口会报错                  |

# 3. 请求参数

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| transportOrderId | Guid | 是 | 业务单Id（海运出口/海运进口的Id，与业务表Id同值） |

```json
{
  "transportOrderId": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

# 4. 返回结构

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| transportOrderId | Guid | 业务单Id |
| bizType | int | 业务类型：`0` 海运出口、`1` 海运进口 |
| mblNum | string | 本次查询用的主提单号（后端从业务单取的，字段名与业务单一致） |
| isExport | string | 本次查询用的进出口标识：`E` 出口、`I` 进口。判业务类型请用 `bizType` |
| data | object | 关务数据，见 4.1；**未查到时为 `null`** |
| message | string | 提示信息，仅"未查到"时有值，正常有数据时为 `null` |

## 4.1 data 关务数据

飞驼原样字段。**所有时间都是字符串**，没数据时为 `null`。

| 字段      | 类型   | 说明                       |
| :-------- | :----- | :------------------------- |
| ieid      | string | 进出口标识（飞驼原样回显） |
| blno      | string | 单号，即查询用的提运单号   |
| entryid   | string | 报关单号                   |
| entdeclno | string | 船代代码                   |
| endtime   | string | 结束时间                   |
| status    | 数组   | 关务状态节点，见 4.2       |

## 4.2 status[] 关务状态节点

| 字段        | 类型   | 说明                          |
| :---------- | :----- | :---------------------------- |
| note        | string | 回执状态描述                  |
| noticedate  | string | 发生时间                      |
| statuscd    | string | 回执状态码，**可能为 `null`** |
| channelname | string | 回执状态描述（通道名）        |
| entryid     | string | 报关单号                      |

# 5. 前端注意事项

- **没查到时 `data` 是 `null`（不是空对象）**，判空之后弹 `message` 即可。
- **`status` 可能为空数组**，表示有报关单但还没有回执节点。
- **`statuscd` 可能为 `null`**，别拿它当必有值去做映射，展示用 `note` 或 `channelname` 更稳。
- **时间都是字符串**，要排序或做日期计算得自己转。建议按 `noticedate` 升序展示成时间轴。
- **只支持海运**，空运出口调用会报「海关跟踪仅支持海运出口与海运进口」。
- **这个接口不写库**，调完不需要刷新单据。
- **常见报错**（HTTP 500，按 `success` 判断，原文在 `error.message`）：
  - `请提供业务单Id`
  - `未找到指定的业务单`
  - `海关跟踪仅支持海运出口与海运进口`
  - `该业务单未填写主提单号，无法查询海关跟踪` —— 需先在单据上补主提单号
  - `请求外部接口异常: xxx` —— 外部接口不通，稍后重试
