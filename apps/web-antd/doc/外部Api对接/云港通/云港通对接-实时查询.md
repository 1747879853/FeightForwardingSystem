# 1. 背景意图 (Background)

业务需要对接「云港通」平台，根据提单号/订舱号(`bno`)实时查询箱货明细、联系人等信息。云港通提供 HTTP 接口：

- **地址**：`POST http://118.190.106.151:5678/v1/real/query`
- **请求体**：平台鉴权(`user_key`/`user_secret`)、客户信息(`customer_id`/`customer_name`)、网站登录账号(`web_user`/`web_psw`)、查询参数(`web_code`/`bno`/`req_type`)

本次在 `App/ExternalApi` 下新增 `Ygdj` 模块封装实时查询，并按职责拆分配置来源：

| 信息类型 | 来源 |
| :-- | :-- |
| `user_key` / `user_secret` / `customer_id` / `customer_name` | `appsettings.json` → `Ygdj` 节点 |
| `web_user` / `web_psw` | 数据库 `App_ExternalAccounts`（`Platform = "Ygdj"`，随机择一启用账号） |
| `bno` | 根据入参 `SeaExportId` 查海运出口关联业务表 `TransportOrder.MblNum`（主提单号） |
| `web_code` | 根据入参 `SeaExportId` 查海运出口关联场站 `Yard.Code`（场站代码，如 `GLJ`） |
| `req_type` | 前端入参（未传默认 `0`） |

## 2.3 接口与服务

- `src/CsprojBuilder.Application/App/ExternalApi/Ygdj/IYgdjAdminAppService.cs`：定义 `RealQueryAsync`。
- `src/CsprojBuilder.Application/App/ExternalApi/Ygdj/YgdjAdminAppService.cs`：
  - `[AbpAuthorize]` 服务级鉴权；`RealQueryAsync` 标注 `[HttpPost]` + `[AbpAuthorize(FreightPermissions.Admin_ExternalApi_Use)]`。
  - 校验 `SeaExportId` 必填；加载 `SeaExport` 及关联 `TransportOrder`、`Yard`（场站）。
  - `bno` 取 `TransportOrder.MblNum`（主提单号）；`web_code` 取 `Yard.Code`（场站代码）。
  - 主提单号、场站或场站代码为空时拒绝查询。
  - `PickEnabledAccountAsync()`：从 `Platform = "Ygdj"` 且 `IsEnabled = true` 的账号中**随机择一**。
  - 组装请求体：平台级字段读配置，网站账号读 `ExternalAccount`，`bno`/`web_code` 读海运出口关联数据。
  - 反序列化为 `YgdjRealQueryResultDto`；`Code != 200` 抛 `UserFriendlyException`；成功后回填 `Raw`。
  - `Code == 200` 时调用 `WriteBackAsync` 回写海运出口与箱货明细（见 2.7）。

## 2.3.1 查询成功回写 (WriteBackAsync)

`Code == 200` 时按下列规则回写（注入 `IRepository<OrderCtn, long>`、`IRepository<CtnCode, long>`、`IRepository<CodePackage, long>`）：

**① 场站联系信息 → `SeaExport`（取首个 `contact_list`，非空才回写）**

| 云港通字段      | SeaExport 字段           | 最大长度 |
| :-------------- | :----------------------- | :------- |
| `contact_email` | `YardEmail` 场站邮箱     | 64       |
| `contact_name`  | `YardContact` 场站联系人 | 32       |
| `contact_tel1`  | `YardTel` 场站电话       | 32       |
| `contact_tel2`  | `YardMobile` 场站手机    | 32       |

**② 船名/航次 → `SeaExport`（取首个 `data`，非空才回写）**

| 云港通字段 | SeaExport 字段    |
| :--------- | :---------------- |
| `VESSEL`   | `Vessel` 船名     |
| `VOYNO`    | `InnerVoyno` 航次 |

**③ 箱货明细 → 新建 `OrderCtn`（遍历 `data`，每条一条记录，`TransportOrderId = SeaExport.Id`）**

| 云港通字段 | OrderCtn 字段 | 匹配/说明 |
| :-- | :-- | :-- |
| `CBM` | `Volume` | 体积 |
| `CNTRNO` | `CtnNo` | 箱号 |
| `KGS` | `GrossWeight` | 毛重 |
| `CTNALL` | `CtnCodeId` | 查 `CtnCode.CtnName` **完全相等** 取 Id |
| `KINDPKGS` | `CodePackageId` | 查 `CodePackage.Name`/`Description`/`AfrCode` **任一完全相等** 取 Id |
| `PKGS` | `PKGS` | 件数 |
| `SEALNO` | `SealNo` | 封号 |
| `TAREWEIGHT` | `TareWeight` | 皮重 |

- **箱型匹配不到则跳过该箱**：`OrderCtn.CtnCodeId` 是必填外键，`CTNALL` 为空或在 `CtnCode.CtnName` 中找不到完全相等项时，跳过该条箱货明细（不插入、不报错）。
- 包装匹配不到时 `CodePackageId` 置空（可空外键）。

# 3. 避坑指南 (Pitfalls)

- **网站账号走账号池，不走配置**：`web_user`/`web_psw` 必须在 `App_ExternalAccounts` 中维护（`Platform = "Ygdj"`、`IsEnabled = 1`）；账号池为空时查询会抛「没有可用的云港通账号」。
- **主提单号与场站代码来自海运出口**：入参仅传 `SeaExportId`；`bno` 取 `TransportOrder.MblNum`，`web_code` 取场站 `Client.Code`（`SeaExport.YardId` 关联）；未填场站或场站代码为空时直接报错。
- **随机择号**：`PickEnabledAccountAsync` 从启用账号中随机选取网站登录账号。
- **主键为 Guid**：`ExternalAccount` 使用 `FullAuditedEntity<Guid>`，非 `long`。
- **BaseAddress 为 http 明文**：对接地址带端口 `5678`，注册命名客户端时不要误写成 https。
- **业务码判断**：HTTP 2xx 且 `code == 200` 才视为成功；`code != 200` 时抛异常并带回 `msg`。
- **迁移**：`App_ExternalAccounts` 表、`App_SeaExports` 新增 4 个场站联系字段均需自行生成迁移后才生效。
- **回写箱型必填外键**：`OrderCtn.CtnCodeId` 为必填外键，`CTNALL` 匹配不到 `CtnCode.CtnName` 时跳过该箱（不插入、不报错），避免外键约束报错回滚。注意云港通 `CTNALL` 常见值如 `40HC`，而 `CtnCode.CtnName` 可能为 `40HQ`，需保证基础资料箱型代码一致才能匹配成功。

## SeaExport 新增字段（增删改查同步）

`src/CsprojBuilder.Core/Entites/SeaExport.cs` 新增 4 个场站联系字段（`YardEmail`/`YardContact`/`YardTel`/`YardMobile`），已同步到 `SeaExportAdminAppService` 与 DTO：

- **新增/编辑**：`SeaExportAddDto`、`SeaExportEditDto` 增加 4 字段；新增走 `ObjectMapper.Map` 自动映射，编辑在更新方法内手动赋值；均含长度校验（邮箱 64、其余 32）。
- **详情/列表**：`SeaExportDto` 增加 4 字段，经 `ObjectMapper.Map<SeaExportDto>` 自动填充。
- 查询过滤 DTO `SeaExportQueryDto` **不含** 这 4 字段（非过滤项）。
