# 背景意图

海运出口订阅云当后，前端需要在详情页展示订阅结果与货物跟踪动态。此前仅有批量订阅接口，缺少按海运出口Id查询已落库数据的只读接口。本次新增 `GetOceanPushInfoAsync`，统一返回订阅记录 + 解析后的运单动态（含箱/轨迹/航段/海运节点）。

# 核心逻辑变更

## 新增接口

- **方法：** `GET /api/services/app/YundangAdmin/GetOceanPushInfoAsync`
- **入参：** `seaExportId`（Query）
- **出参：** `YundangOceanPushInfoDto`（`subscription` + `shipment`）
- **权限：** `Admin.ExternalApi.Get`

## 数据范围

| 包含 | 不包含 |
| :-- | :-- |
| `App_YundangOceanSubscriptions` 订阅记录 | 原始报文 `RawJson` / `LatestPushJson` |
| 运单动态主表及子表（箱、轨迹、航段、节点） | `YundangPushLog` 推送日志 |

## 关联改动

- 海运出口列表/详情 `SeaExportDto` 新增 `isYundangSubscribed`、`isYundangSubscribeSuccess`，用于入口展示；详情页查看完整动态仍调用本接口。

# 避坑指南

1. **订阅成功 ≠ 立即有 shipment**：需等待云当推送，前端应处理 `shipment=null` 空态。
2. **以 SeaExportId 定位**：与订阅判重规则一致，一条海运出口一条订阅记录。
3. **权限与订阅接口不同**：订阅用 `Admin.ExternalApi.Use`，查询用 `Admin.ExternalApi.Get`。
