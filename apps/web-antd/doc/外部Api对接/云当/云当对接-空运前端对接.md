# 1. 说明

本文档面向前端，汇总云当空运相关**前端需对接的接口**（均在 `YundangAdminAppService` 中）。token 获取、中转站、推送接收/回写等均由后端处理，前端无需关心。

> 功能与架构说明见：`云当对接-空运运单对接.md`、`云当对接-中转站与推送接收.md`

> [!WARNING] **2026-08-09 接口地址已变更。** 云当空运的接口合并到了 `YundangAdmin` 服务，地址前缀由 `YundangAirAdmin` 改为 `YundangAdmin`。方法名与入参出参**完全没变**，只需改地址前缀。云当**海运**的接口地址不变。详见《外部Api对接/接口地址变更-2026-08-09-外部对接服务合并.md》。

# 2. 接口清单

| 接口                         | 用途                               | 章节    |
| :--------------------------- | :--------------------------------- | :------ |
| `BatchSubscribeAirBillAsync` | 空运运单批量订阅                   | 见「3」 |
| `GetAirPushInfoAsync`        | 查询某空运出口的云当订阅与运单动态 | 见「4」 |
| `ResubscribeAirBillAsync`    | 空运运单重新订阅                   | 见「5」 |

> **空运出口列表/详情已直接返回运踪**：`AirExportAdmin/GetPagedListAsync`、`DetailAsync` 返回 `isYundangSubscribed`、`isYundangSubscribeSuccess`、`yundangAirShipmentNode`(最后一个有实际时间的空运节点)，可用于控制「订阅」按钮与列表运踪列展示，无需额外调用本文档接口。字段见「6」。

# 3. 空运运单批量订阅 (BatchSubscribeAirBillAsync)

## 3.1 接口

| 项目   | 内容                                                           |
| :----- | :------------------------------------------------------------- |
| 方法   | `POST`                                                         |
| 地址   | `/api/services/app/YundangAdmin/BatchSubscribeAirBillAsync`    |
| 请求体 | JSON，见「3.2」                                                |
| 返回   | JSON，见「3.3」(ABP 统一包一层 `result`)                       |
| 权限   | 需登录且具备「第三方接口 > 使用」权限(`Admin.ExternalApi.Use`) |

## 3.2 请求参数 (YundangAirBatchSubscribeInputDto)

| 字段名 | 类型 | 含义 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| **airExportIds** | Guid[] | 待订阅的空运出口Id集合 | 是 | 单次最多 30 条，超出后端自动分批 |

> 订阅方式由后端自动判断，前端无需传单号/航司：
>
> - `referenceNo` 取空运出口主运单号 `MblNum`；`carrierCd` 留空交云当自动识别。
> - 起降机场三字码齐全时上传 `extendNo={org,dest}`(厦门航空 MF 必需)。

**请求示例：**

```json
{
  "airExportIds": ["11111111-1111-1111-1111-111111111111"]
}
```

## 3.3 返回结构 (YundangAirBatchSubscribeResultDto)

| 字段名       | 类型  | 含义                        |
| :----------- | :---- | :-------------------------- |
| totalCount   | int   | 请求总条数                  |
| successCount | int   | 订阅成功条数                |
| failCount    | int   | 订阅失败条数                |
| items        | array | 各明细结果，元素见「3.3.1」 |

### 3.3.1 明细结果 (items[] - YundangAirSubscribeItemResultDto)

| 字段名       | 类型   | 含义                                         |
| :----------- | :----- | :------------------------------------------- |
| airExportId  | Guid   | 关联的空运出口Id                             |
| localKey     | string | 本地业务键(空运出口Id无连字符+序号)          |
| referenceNo  | string | 订阅单号(主运单号 AWB)                       |
| carrierCd    | string | 航司代码(云当识别后可能回填)                 |
| isSuccess    | bool   | 是否订阅成功                                 |
| yundangId    | string | 云当返回的订阅Id                             |
| itemCode     | int?   | 明细处理码(200 成功)                         |
| itemCodeDesc | string | 明细处理码描述(如 success)                   |
| itemMessage  | string | 明细处理消息(失败原因；本地校验失败也写此处) |

# 5. 空运运单重新订阅 (ResubscribeAirBillAsync)

## 5.1 接口

| 项目 | 内容 |
| :-- | :-- |
| 方法 | `POST` |
| 地址 | `/api/services/app/YundangAdmin/ResubscribeAirBillAsync` |
| 请求体 | JSON，见「5.2」 |
| 返回 | JSON，单条明细(`YundangAirSubscribeItemResultDto`，额外含 `yundangIdChanged`/`oldPushDataCleared`) |
| 权限 | 需登录且具备「第三方接口 > 使用」权限(`Admin.ExternalApi.Use`) |

## 5.2 请求参数 (YundangAirResubscribeInputDto)

| 字段名 | 类型 | 含义 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| **airExportId** | Guid | 待重新订阅的空运出口Id | 是 | 须已有订阅记录 |
| **forceResubscribe** | bool | 是否强制重新订阅 | 否 | 单号+航司未变且上次失败时须为 true |

## 5.3 返回结构

字段同「3.3.1」，并额外包含：

| 字段名             | 类型  | 含义                                          |
| :----------------- | :---- | :-------------------------------------------- |
| yundangIdChanged   | bool? | 云当返回的 YundangId 相对上次是否变化         |
| oldPushDataCleared | bool  | 是否已清除原 YundangId 关联的运单动态推送数据 |

# 6. 空运出口列表/详情中的运踪字段

`AirExportAdmin/GetPagedListAsync`(列表) 与 `AirExportAdmin/DetailAsync`(详情) 的返回对象(`AirExportDto`)中已包含以下字段，口径与海运出口一致：

| 字段名 | 类型 | 含义 |
| :-- | :-- | :-- |
| isYundangSubscribed | bool | 是否已订阅云当空运运单(存在订阅记录即为 true) |
| isYundangSubscribeSuccess | bool | 云当空运运单是否订阅成功 |
| yundangAirShipmentNode | object \| null | 云当运踪：**最后一个有实际时间(`actualityTime`)的空运节点**；无推送或无实际节点为 null |

## 6.1 运踪节点 (yundangAirShipmentNode - YundangAirShipmentNodeSimpleDto)

| 字段名        | 类型   | 含义                              |
| :------------ | :----- | :-------------------------------- |
| id            | Guid   | 空运节点记录Id                    |
| sno           | int?   | 节点序号                          |
| stateCode     | string | 节点状态代码(如 DEP/ARR/DLV)      |
| stateDesc     | string | 节点描述(英文)                    |
| stateDescCN   | string | 节点描述(中文，如 起飞/抵达/提货) |
| transport     | string | 运输节点(地点三字码)              |
| isActuality   | bool?  | 是否已实际发生                    |
| count         | int?   | 已完成数量                        |
| total         | int?   | 总数量                            |
| planTime      | string | 计划时间                          |
| estimateTime  | string | 预计时间                          |
| actualityTime | string | 实际时间                          |

> 「最后一个」的判定：仅取 `actualityTime` 非空的节点，按实际时间最晚排序（时间解析失败时依次按 `sno`、时间字符串、Id 倒序兜底），与海运出口口径一致。
