# 付费结算接口文档

**控制器**：`PaymentSettlementAdmin`

**所有接口均需要登录认证**

---

## 零、汇率规则（2026-08-10 变更）

付费结算**不再录入汇率**，所有写接口都已删除 `paymentSettlementRates` 入参，`App_PaymentSettlementRates` 表已废弃。汇率一律由后端从付费申请取，并快照到 `PaymentSettlementItem.Rate` 上：

| 付费申请类型 | 判定 | 结算币别约束 | 汇率来源 |
| --- | --- | --- | --- |
| 固定币别申请 | `PaymentApplication.CurrencyId` 有值 | 申请币别必须**等于**结算单的 `currencyId`，否则报错 | 逐条取 `PaymentApplicationItem.Rate` |
| 原币申请 | `PaymentApplication.CurrencyId` 为空 | 只能结算原币**等于**结算单 `currencyId` 的费用，其他币别的费用不能选进来 | 恒为 `1` |

两类申请可以挂在同一张结算单上。金额按逐条明细 `SettledAmount × Rate` 折算，`Rate` 是逐条明细的快照；行金额与合计再按行取整并补汇兑尾差，口径见 ByCurrency 接口文档。

前端选择付费申请时，请给 `PaymentApplicationAdmin/GetPagedListForSettlementAsync` 和 `GetPagedListByCurrencyForSettlementAsync` 传 `settlementCurrencyId`，接口会直接过滤掉不能选的申请和行。ByCurrency 选择列表每行额外返回 `totalUnSettledPrice`（结算币别未结净额，已按逐条汇率折算），结满一行时直接把该值当 `settledPrice` 提交。

> **新增、追加明细、详情只有 ByCurrency 一套**：`AddByCurrencyAsync` / `AddItemsByCurrencyAsync` / `DeleteItemsByCurrencyAsync` / `DetailByCurrencyAsync`，详见 [付费结算-按原币和付费申请-接口文档.md](./付费结算-按原币和付费申请-接口文档.md)。原来的 `AddAsync` / `AddItemsAsync` / `DetailAsync` 已于 **2026-10-02 从代码中删除**，调用会 404。本文只记其余接口。

## 一、修改主表

### `PUT /api/services/app/PaymentSettlementAdmin/EditAsync`

**权限**：`Admin.PaymentSettlement.Edit`

**入参** `PaymentSettlementEditDto`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `Guid` | 是 | 付费结算ID |
| `settlementTime` | `DateTime` | 是 | 结算时间 |
| `payType` | `int?` | 否 | 付款方式 |
| `orgBankAccountId` | `Guid?` | 否 | 我司银行ID |
| `clientInvoiceBankId` | `Guid?` | 否 | 结算对象银行ID |
| `transactionFee` | `decimal?` | 否 | 手续费 |
| `transactionFeeCurrencyId` | `long?` | 否 | 手续费币别ID。不传则列表/详情回显用结算币别 `currencyId` 填充 `transactionFeeCurrency` |
| `remark` | `string` | 否 | 备注 |
| `attachments` | `List<AttachmentItemForItemInputDto>` | 否 | 附件列表（全量替换） |

**出参**：`bool`

**业务规则**：

- 已锁定的付费结算不能编辑
- 不能修改结算对象和结算币别
- 手续费币别 `transactionFeeCurrencyId` 可改、可空；传了值但币别不存在时报「手续费币别不存在」。列表/详情回显时若该字段为空，`transactionFeeCurrency` 用结算币别 `currencyId` 填充
- 汇率跟随付费申请，本接口不再维护汇率。付费申请汇率填错只能删明细、改申请后重新结算
- 附件全量替换

## 二、删除结算明细（按付费申请）

### `POST /api/services/app/PaymentSettlementAdmin/DeleteItemsAsync`

**权限**：`Admin.PaymentSettlement.Edit`

**入参** `PaymentSettlementDeleteItemsDto`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `Guid` | 是 | 付费结算ID |
| `paymentApplicationIds` | `List<Guid>` | 是 | 要删除的付费申请ID列表（删除该结算单中属于这些付费申请的所有结算明细） |

**入参示例**：

```json
{
  "id": "settlement-guid",
  "paymentApplicationIds": ["pa-guid-1", "pa-guid-2"]
}
```

**出参**：`bool`

**业务规则**：

- 已锁定的不能编辑
- 按付费申请维度删除：传入付费申请ID列表，删除该结算单中属于这些付费申请的所有结算明细。一张结算单里同一付费申请只有一行，所以效果与 `DeleteItemsByCurrencyAsync` 按行删除相同
- 删除后自动回滚：OrderFee.SettledAmount / SettlementStatus、PaymentApplicationItem.UnSettledAmount、PaymentApplication.Status

## 五、锁定

### `PUT /api/services/app/PaymentSettlementAdmin/LockAsync`

**权限**：`Admin.PaymentSettlement.Lock`

**入参** `PaymentSettlementLockDto`：

| 字段 | 类型   | 必填 | 说明       |
| ---- | ------ | ---- | ---------- |
| `id` | `Guid` | 是   | 付费结算ID |

**出参**：`bool`

**业务规则**：

- 已锁定的不能重复锁定（`locked == true` 时拒绝）
- 锁定后 `locked` 置为 `true`，`lockeTime` 赋值为当前时间
- 锁定后不能进行任何编辑/删除操作，除非解锁

---

## 六、解锁

### `PUT /api/services/app/PaymentSettlementAdmin/UnLockAsync`

**权限**：`Admin.PaymentSettlement.Unlock`

**入参** `PaymentSettlementLockDto`：

| 字段 | 类型   | 必填 | 说明       |
| ---- | ------ | ---- | ---------- |
| `id` | `Guid` | 是   | 付费结算ID |

**出参**：`bool`

**业务规则**：

- 未锁定的不能解锁（`locked == false` 时拒绝）
- 解锁后 `locked` 置为 `false`，`lockeTime` 置为 `null`

## 九、错误提示汇总

| 错误信息 | 触发条件 |
| --- | --- |
| `输入不能为空` | 入参为null |
| `结算对象不存在` | settlementId 无效 |
| `结算币别不存在` | currencyId 无效 |
| `我司银行不存在` | orgBankAccountId 无效 |
| `结算对象银行不存在` | clientInvoiceBankId 无效 |
| `部分付费申请不存在` | paymentApplicationId 无效 |
| `付费申请【xx】状态不是审核通过或部分结算,不能结算` | 付费申请状态不对 |
| `付费申请【xx】的申请币别【xx】与结算币别【xx】不一致,不能结算` | 固定币别申请的申请币别不等于结算单币别 |
| `付费申请【xx】是原币申请,只能结算币别为【xx】的费用,不能结算【xx】的费用` | 原币申请选了原币不等于结算币别的费用 |
| `付费申请【xx】是固定币别申请,结算行的申请币别应为【xx】,不能传【xx】` | 固定币别申请的结算行 `applyCurrencyId` 不等于申请币别 |
| `付费申请【xx】存在明细未录入有效汇率,不能结算` | 固定币别申请的明细 Rate 为空或 ≤ 0 |
| `付费申请【xx】币别【xx】的结算金额xx不在可结算范围[xx, xx]内` | ByCurrency 写接口本行 settledPrice 超出结算币别可结算上下限 |
| `付费结算已锁定,不能编辑` | 对已锁定的结算进行编辑 |
| `付费结算已锁定,不能删除` | 对已锁定的结算进行删除 |
| `以下付费申请+申请币别已在该结算单中,不能重复添加: 【xx-xx】` | AddItemsByCurrencyAsync 时重复添加 |
| `要删除的付费申请ID列表不能为空` | DeleteItemsAsync时paymentApplicationIds为空 |
| `未找到对应付费申请的结算明细` | 传入的付费申请ID在该结算单中无对应明细 |
| `付费结算已锁定,不能重复锁定` | 重复锁定 |
| `付费结算未锁定,不能解锁` | 对未锁定的结算解锁 |
