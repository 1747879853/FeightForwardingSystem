# 付费结算搜索条件 - 快速参考

## 📋 搜索字段说明

### 1️⃣ 编号 (keyword)

**用途**: 同时搜索主提单号和委托编号  
**匹配方式**: 模糊匹配  
**后端逻辑**: 匹配 `TransportOrder.MblNum` **或** `TransportOrder.CommissionNum`

```typescript
// 示例
keyword: 'ABC123'; // 会搜索主提单号或委托编号包含 "ABC123" 的记录
```

**使用场景**:

- ✅ 不确定是主提单号还是委托编号
- ✅ 快速统一搜索
- ✅ 用户只记得部分编号信息

---

### 2️⃣ 委托编号 (commissionNum)

**用途**: 专门搜索委托编号  
**匹配方式**: 模糊匹配  
**后端逻辑**: 只匹配 `TransportOrder.CommissionNum`

```typescript
// 示例
commissionNum: 'PO20260727'; // 只搜索委托编号包含此值的记录
```

**使用场景**:

- ✅ 明确知道要搜索委托编号
- ✅ 需要精确过滤委托编号
- ✅ 与其他条件组合使用

---

## 🔗 组合使用规则

### AND 组合逻辑

多个条件同时使用时，后端会进行 **AND** 组合：

```typescript
{
  keyword: "ABC",           // 主提单号或委托编号包含 "ABC"
  commissionNum: "PO2026",  // 且 委托编号包含 "PO2026"
  settlementId: "123",      // 且 结算对象ID为 "123"
}
```

**结果**: 只有同时满足所有条件的记录才会返回

## 💡 使用建议

### 推荐用法

#### 场景1: 只知道部分编号

```typescript
// 使用"编号"字段
keyword: 'ABC123';
```

#### 场景2: 明确搜索委托编号

```typescript
// 使用"委托编号"字段
commissionNum: 'PO20260727';
```

#### 场景3: 组合精确搜索

```typescript
// 同时使用两个字段
keyword: "ABC",              // 先缩小范围
commissionNum: "PO2026"      // 再精确过滤
```

### 不推荐用法

❌ **不要同时输入相同的内容到两个字段**

```typescript
// 这样会导致过度过滤
keyword: "ABC123",
commissionNum: "ABC123"  // 冗余且可能导致无结果
```

❌ **不要在空值时进行搜索**

```typescript
// 确保至少有一个搜索条件
if (!keyword && !commissionNum && !otherFilters) {
  message.warning('请输入搜索条件');
  return;
}
```

## ⚠️ 重要提示

### 数据路径

```
PaymentSettlementQueryDto
  ↓ (通过 OrderFeeId)
PaymentSettlementItem
  ↓ (关联)
OrderFee
  ↓ (关联)
TransportOrder
  ↓ (匹配字段)
MblNum | CommissionNum
```

### 关键特性

- 🔍 **模糊匹配**: 不需要输入完整内容
- 🔗 **关联查询**: 通过费用关联的业务单号
- 🎯 **AND 组合**: 多条件同时生效
- ♻️ **向后兼容**: 保留了 mblNum 字段定义
