# 背景意图

付费结算列表需按费用关联业务单号检索：除原有主提单号 `mblNum` 外，增加委托编号精确条件及关键字同时匹配主提单号/委托编号。

# 核心逻辑变更

文件：`PaymentSettlementQueryDto`、`PaymentSettlementAdminAppService.GetPagedListAsync`

| 入参 | 说明 |
| :-- | :-- |
| `keyword` | 模糊匹配 `TransportOrder.MblNum` 或 `TransportOrder.CommissionNum` |
| `commissionNum` | 模糊匹配 `TransportOrder.CommissionNum` |
| `mblNum` | 原有逻辑不变 |

多个条件同时传入时 **AND** 组合；命中任一关联费用的结算单即出现在列表中（与 `mblNum` 筛选口径一致）。

# 避坑指南

- 筛选走 `PaymentSettlementItem.OrderFeeId` → `OrderFee.TransportOrder`，非结算主表字段。
- `keyword` 与 `commissionNum`/`mblNum` 可同时使用，会叠加过滤。
