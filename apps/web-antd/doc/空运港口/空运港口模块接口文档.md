# 0. 通用说明

## 0.1 鉴权

所有接口都需要登录，请求头带 `Authorization: Bearer {token}`。管理端接口另需对应权限点，无权限返回 403。

## 0.2 返回包装

所有接口返回都被框架包了一层：

```json
{
  "result": {},
  "targetUrl": null,
  "success": true,
  "error": null,
  "unAuthorizedRequest": false,
  "__abp": true
}
```

- 业务数据在 `result` 里，下文各接口的「输出参数」都是指 `result` 内部的结构。
- 业务校验失败时 `success = false`，`error.message` 是可直接展示给用户的中文提示，HTTP 状态码仍是 500。

## 0.3 分页约定

分页入参是**页码 + 每页条数**，不是 skipCount：

| 字段      | 类型 | 必填 | 默认值 | 说明                        |
| :-------- | :--- | :--- | :----- | :-------------------------- |
| pageIndex | int  | 否   | 1      | 当前页码，从 1 开始，最小 1 |
| pageSize  | int  | 否   | 10     | 每页条数，取值 1~100000     |

分页出参统一为 `PagedList` 结构：

| 字段           | 类型  | 说明                                          |
| :------------- | :---- | :-------------------------------------------- |
| items          | array | 当前页数据集合                                |
| totalCount     | int   | 满足条件的总条数                              |
| skipCount      | int   | 本次跳过的条数（= (pageIndex-1) \* pageSize） |
| maxResultCount | int   | 本次返回的最大条数（= pageSize）              |

## 0.4 接口一览

| # | 接口地址 | 方法 | 权限点 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| 1 | `/api/services/app/AirPortAdmin/GetPagedListAsync` | GET | 仅需登录 | 管理端分页列表 |
| 2 | `/api/services/app/AirPortAdmin/DetailAsync` | GET | 仅需登录 | 详情 |
| 3 | `/api/services/app/AirPortAdmin/AddAsync` | POST | `Admin.AirPort.Add` | 新增 |
| 4 | `/api/services/app/AirPortAdmin/EditAsync` | PUT | `Admin.AirPort.Edit` | 编辑 |
| 5 | `/api/services/app/AirPortAdmin/DeleteAsync` | DELETE | `Admin.AirPort.Delete` | 删除 |
| 6 | `/api/services/app/AirPort/GetPagedListAsync` | GET | 仅需登录 | 业务端选机场分页列表 |

> 权限点 `Admin.AirPort` 是父节点（菜单级），`Admin.AirPort.Get` 已注册但**未挂到任何接口上**，列表和详情只校验登录，与现有港口信息模块的做法一致。

# 1. 管理端分页列表

**接口地址**：`GET /api/services/app/AirPortAdmin/GetPagedListAsync` **权限**：仅需登录 **说明**：管理页面的分页列表。排序由后端固定为 `SortId` 降序、`Id` 降序，**不接受前端指定排序字段**。

## 1.1 输入参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| keyword | string | 否 | 关键字，模糊匹配（`LIKE %关键字%`）以下全部文本列，命中任意一个即返回：三字码 `iataCode`、英文名称 `enName`、中文名称 `cnName`、ICAO 码 `icaoCode`、城市 `city`、备注 `remark`、所属国家的代码 `country.code`、国家中文名 `country.countryName`、国家英文名 `country.countryEnName`、国家三字代码 `country.countryCode3`。大小写不敏感，首尾空格自动去掉 |
| status | int? | 否 | 状态筛选。`0` 只看启用，`1` 只看禁用，不传看全部 |
| countryId | long? | 否 | 国家 id 精确筛选。注意未选国家的机场在传了该条件时不会出现 |
| pageIndex | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |

## 1.2 输出参数

`result` 为 `PagedList`，`items` 内每个元素字段如下：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| id | long | 主键 id |
| iataCode | string | 三字码，库中已是大写 |
| enName | string | 英文名称 |
| cnName | string | 机场名称（中文名称），可能为 null |
| icaoCode | string | ICAO 码，可能为 null |
| countryId | long? | 国家 id，未选国家时为 null |
| city | string | 城市，可能为 null |
| timeZone | decimal? | 时区，相对 UTC 的小时偏移，可能为 null，可能带小数（如 5.75） |
| status | int | 状态。**0 启用、1 禁用** |
| sortId | int | 排序 id，降序，大的在前 |
| remark | string | 备注，可能为 null |
| country | object | 国家对象，未选国家时为 **null**，前端必须判空 |
| country.id | long | 国家 id |
| country.code | string | 国家唯一代码 |
| country.countryName | string | 国家中文名称 |
| country.countryEnName | string | 国家英文名称 |
| creationTime | datetime | 创建时间 |
| creatorUserId | long? | 创建人用户 id |
| creatorUserName | string | 创建人昵称，取不到时为 null |
| lastModificationTime | datetime? | 最后修改时间，未修改过为 null |
| lastModifierUserId | long? | 最后修改人用户 id |
| lastModifierUserName | string | 最后修改人昵称，取不到时为 null |

## 1.3 报文样例

请求：

# 3. 新增

**接口地址**：`POST /api/services/app/AirPortAdmin/AddAsync` **权限**：`Admin.AirPort.Add`

## 3.1 输入参数（Body，JSON）

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| iataCode | string | **是** | 三字码。**后端自动去首尾空格并转大写**；最长 8 位；不校验必须 3 位字母；不可与已有机场重复（大小写不敏感，已删除数据不算重复） |
| enName | string | **是** | 英文名称。后端自动去首尾空格；不做大小写转换；不可与已有机场重复（大小写不敏感） |
| cnName | string | 否 | 机场名称（中文名称），允许重名 |
| icaoCode | string | 否 | ICAO 码，允许重复，不转大小写，不校验位数 |
| countryId | long? | 否 | 国家 id。不传或传 null 表示不选国家；传了则必须是真实存在的国家 |
| city | string | 否 | 城市，纯文本，不与国家联动 |
| timeZone | decimal? | 否 | 时区，相对 UTC 的小时偏移。东区为正、西区为负；支持小数（`5.5`、`5.75`）；小数最多 2 位，多余位数四舍五入；**绝对值必须小于 100** |
| status | int | **是** | 状态。**0 启用、1 禁用**，只接受这两个值 |
| sortId | int | **是** | 排序 id，降序，大的在前。允许重复，允许 0 和负数；后端不会自动生成，前端必须传 |
| remark | string | 否 | 备注，最长 1024 |

## 3.2 输出参数

| 字段   | 类型 | 说明                    |
| :----- | :--- | :---------------------- |
| result | long | 新增成功后的机场主键 id |

## 3.3 报文样例

```json
{
  "iataCode": "pvg",
  "enName": "Shanghai Pudong International Airport",
  "cnName": "上海浦东国际机场",
  "icaoCode": "ZSPD",
  "countryId": 12,
  "city": "上海",
  "timeZone": 8,
  "status": 0,
  "sortId": 90,
  "remark": null
}
```

上例的 `iataCode` 入库后为 `PVG`。

## 3.4 异常提示

| 提示文案               | 触发条件                                   |
| :--------------------- | :----------------------------------------- |
| 三字码不能为空         | `iataCode` 为空、null 或纯空格             |
| 英文名称不能为空       | `enName` 为空、null 或纯空格               |
| 三字码长度不能超过8位  | 去空格后长度大于 8                         |
| 状态只能是0启用或1禁用 | `status` 传了 0/1 以外的值                 |
| 时区绝对值必须小于100  | `timeZone` 绝对值 ≥ 100                    |
| 国家id错误             | `countryId` 大于 0 但该国家不存在          |
| 三字码【XXX】已存在    | 三字码与未删除的机场重复（大小写不敏感）   |
| 英文名称【XXX】已存在  | 英文名称与未删除的机场重复（大小写不敏感） |

# 4. 编辑

**接口地址**：`PUT /api/services/app/AirPortAdmin/EditAsync` **权限**：`Admin.AirPort.Edit` **说明**：**全量提交**。所有字段都会按传入值覆盖，非必填字段传 null 即清空原值，因此前端必须把当前完整表单一起提交，不能只传改动的字段。后端内部走局部更新，只有真正变化的列才会生成 UPDATE。

## 4.1 输入参数（Body，JSON）

| 字段      | 类型     | 必填   | 说明                           |
| :-------- | :------- | :----- | :----------------------------- |
| id        | long     | **是** | 机场主键 id                    |
| iataCode  | string   | **是** | 同新增；重复判断会**排除自己** |
| enName    | string   | **是** | 同新增；重复判断会**排除自己** |
| cnName    | string   | 否     | 同新增；传 null 清空           |
| icaoCode  | string   | 否     | 同新增；传 null 清空           |
| countryId | long?    | 否     | 同新增；传 null 表示清空国家   |
| city      | string   | 否     | 同新增；传 null 清空           |
| timeZone  | decimal? | 否     | 同新增；传 null 清空           |
| status    | int      | **是** | 同新增                         |
| sortId    | int      | **是** | 同新增                         |
| remark    | string   | 否     | 同新增；传 null 清空           |

## 4.2 输出参数

| 字段   | 类型 | 说明                            |
| :----- | :--- | :------------------------------ |
| result | bool | 固定 `true`，失败一律走 `error` |

## 4.3 异常提示

除新增的全部提示外，另有：

| 提示文案         | 触发条件            |
| :--------------- | :------------------ |
| 输入空运港口错误 | id 不存在或已被删除 |

# 5. 删除

**接口地址**：`DELETE /api/services/app/AirPortAdmin/DeleteAsync` **权限**：`Admin.AirPort.Delete` **说明**：软删除。删除后该机场的三字码和英文名会被释放，可以重新录入相同的码。

## 5.1 输入参数（Body，JSON）

| 字段 | 类型 | 必填 | 说明        |
| :--- | :--- | :--- | :---------- |
| id   | long | 是   | 机场主键 id |

> 入参结构里还有一个 `ids` 数组字段（通用 DTO 自带），本接口**不使用**，传了也不生效，一次只删一条。

## 5.2 输出参数

| 字段   | 类型 | 说明        |
| :----- | :--- | :---------- |
| result | bool | 固定 `true` |

## 5.3 异常提示

| 提示文案 | 触发条件 |
| :-- | :-- |
| 输入空运港口错误 | id 不存在或已被删除 |
| 该空运港口已被【xx】模块引用,禁止删除 | 预留。当前系统没有任何模块引用机场，**此提示暂不会出现**；空运出口/进口/运价上线后才会触发 |

# 6. 业务端选机场分页列表

**接口地址**：`GET /api/services/app/AirPort/GetPagedListAsync` **权限**：仅需登录，无业务权限点 **说明**：给业务界面选机场用。**分页返回，系统不提供一次性返回全部机场的接口。** 正确用法是把用户输入的关键字传给后端做搜索，再配合翻页/滚动加载。排序同样固定为 `SortId` 降序、`Id` 降序。**不按状态过滤**，禁用的机场也会返回，是否隐藏或置灰由前端决定。

## 6.1 输入参数（Query）

与第 1.1 节完全一致：`keyword`、`status`、`countryId`、`pageIndex`、`pageSize`。

## 6.2 输出参数

`result` 为 `PagedList`，`items` 内每个元素字段如下（比管理端精简，不含备注、排序 id 和审计信息）：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| id | long | 主键 id，业务单据存的就是这个值 |
| iataCode | string | 三字码 |
| enName | string | 英文名称 |
| cnName | string | 机场名称（中文名称），可能为 null |
| icaoCode | string | ICAO 码，可能为 null |
| city | string | 城市，可能为 null |
| timeZone | decimal? | 时区，可能为 null |
| status | int | 状态。0 启用、1 禁用。本接口不过滤，前端可据此置灰 |
| country | object | 国家对象，未选国家时为 null |
| country.id | long | 国家 id |
| country.code | string | 国家唯一代码 |
| country.countryName | string | 国家中文名称 |
| country.countryEnName | string | 国家英文名称 |

## 6.3 报文样例

请求：

```
GET /api/services/app/AirPort/GetPagedListAsync?keyword=浦东&pageIndex=1&pageSize=20
```

响应 `result`：

```json
{
  "items": [
    {
      "id": 2,
      "iataCode": "PVG",
      "enName": "Shanghai Pudong International Airport",
      "cnName": "上海浦东国际机场",
      "icaoCode": "ZSPD",
      "city": "上海",
      "timeZone": 8.0,
      "status": 0,
      "country": {
        "id": 12,
        "code": "CN",
        "countryName": "中国",
        "countryEnName": "China"
      }
    }
  ],
  "totalCount": 1,
  "skipCount": 0,
  "maxResultCount": 20
}
```

## 6.4 前端接入注意

1. 单据回显机场名称时，不要依赖下拉当前页的数据，按机场 id 走详情接口或在保存时把机场对象一起缓存。
2. 不要用「循环翻页拉全量再本地过滤」的方式实现搜索，关键字一律交给后端。
3. `country` 可能为 `null`，展示国家列时必须判空。
