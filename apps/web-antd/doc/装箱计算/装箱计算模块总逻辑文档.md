# 1. 业务背景说明 (Background)

**白话解释：** 按调用方这次传来的柜子内径、限重和货物长宽高，算出这票货要几只柜，以及每一件放在柜子里的坐标。不算业务单上的件毛体，不读箱型主数据，结果不落库。

# 2. 功能与操作说明 (Features & Operations)

- **计算装箱（CalculateAsync）：** 前端把柜子和货物清单整包传入。返回实际开柜数、每一只柜里每一件的位置、容积率、载重率、重心偏移，以及没装下的件数和原因。

坐标：X 沿柜长，0 在里端（远离箱门），增大方向朝箱门；Y 离地高度；Z 沿柜宽，0 在左侧。摆放后的长、宽、高分别是沿这三根轴的尺寸。装载顺序先里端、再左侧、再下面。

# 4. 核心字段说明 (Field Definitions)

| 字段名 | 📖 字段含义说明 | 🔌 数据来源 (接口/字典) | 🔗 联动规则 (依赖与触发) | 🛡️ 校验限制 (Validation) |
| :-- | :-- | :-- | :-- | :-- |
| **length / width / height** | 柜内长宽高，厘米 | 调用方传入 | 每一只柜都用这一套内径 | 大于 0，不超过 5000 |
| **limitWeight** | 限重，千克。0 表示不限重 | 调用方传入 | 为 0 时载重率返回 0 | 0 到 1000000 |
| **maxContainerCount** | 最多开几只柜 | 调用方传入 | 装不完的件数进入未装清单 | 1 到 50 |
| **selfStack** | 货物自叠 | 调用方传入 | 为 true 时只有行号相同的货才能上下叠 | 布尔 |
| **flatLay** | 平铺 | 调用方传入 | 为 true 时只放一层。与自叠同时为 true 时只平铺 | 布尔 |
| **gapLength / gapWidth** | 相邻货物之间的长向、宽向间隙，厘米 | 调用方传入 | 不加在靠柜壁的外侧 | 0 到 5000 |
| **cargos** | 货物清单 | 调用方传入 | 同一行按同一种规格展开 | 不能为空；总件数不超过 800 |
| **lineNo** | 货物行号 | 调用方传入，空则按顺序从 1 编 | 自叠用它判断是不是同一种货 | 不传或小于等于 0 时自动编号 |
| **allowRotate** | 是否允许旋转 | 调用方传入 | false 时长沿柜长、宽沿柜宽、高竖直；true 时六个朝向都试 | 布尔 |

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：单件本身就进不了柜]** 六个允许的朝向里，没有一个能同时满足柜内长宽高 → 该行全部件数未装，原因「单件尺寸超过柜内尺寸」，不占柜数。单重大于限重时原因是「单件重量超过限重」。

> [!IMPORTANT] **[卡点 2：开柜数到顶]** 已经开到 `maxContainerCount` 还有剩余 → 剩余行原因「已达到最多开柜数」。

> [!IMPORTANT] **[卡点 3：平铺打开后不再往上叠]** `flatLay` 为 true 时每一件都贴地。这时即使 `selfStack` 为 true，也不会出现第二层。

> [!IMPORTANT] **[卡点 4：一排的进深按这一排第一件]** 沿柜宽并排的货物，这一排沿柜长的占用按第一件的尺寸。后面如果有更短的件，短出来的那一截不再放别的货。地面先铺满，铺满之后才把货放到已有货物上面；上面的货底面必须落在下面那件的顶面之内。

> [!IMPORTANT] **[卡点 5：自叠看行号]** 行号相同就当成同一种货，可以上下叠。两行尺寸不同但行号相同，也会叠在一起。不传行号时每行各用自己的序号，彼此不能叠。
