# 装箱计算模块接口文档

本文档只讲怎么调用装箱试算。业务口径见同目录《装箱计算模块总逻辑文档》。

尺寸单位是厘米，重量单位是千克，体积单位是立方米。柜子内径、限重、货物长宽高都由调用方传入，接口不查箱型、不查业务单。结果不保存。

---

# 1. 对接总纲

## 1.1 服务地址与鉴权

| 项         | 值                                           |
| :--------- | :------------------------------------------- |
| 接口基址   | `{host}/api/services/app/PackingAdmin/`      |
| 完整路径   | 基址 + 方法名，**方法名保留 `Async` 后缀**   |
| 鉴权头     | `Authorization: Bearer {accessToken}`        |
| 租户头     | `Abp.TenantId: {租户id}`（租户账号登录时带） |
| 请求体类型 | `Content-Type: application/json`             |

需要已登录。没有单独的功能权限点。

## 1.2 接口一览

| # | 业务动作 | HTTP | 完整路径 | 参数位置 | `result` 类型 | 权限 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | 计算装箱 | POST | `/api/services/app/PackingAdmin/CalculateAsync` | 请求体 | 对象 | 登录即可 |

业务数据在 ABP 标准包装的 `result` 里。

# 2. 计算装箱

`POST /api/services/app/PackingAdmin/CalculateAsync`

## 2.1 入参 `PackingCalculateInputDto`

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `length` | `decimal` | 是 | 柜内长（厘米），从里端到箱门。大于 0 且不超过 5000，否则「柜内长必须大于 0 且不超过 5000 厘米」 |
| `width` | `decimal` | 是 | 柜内宽（厘米）。大于 0 且不超过 5000 |
| `height` | `decimal` | 是 | 柜内高（厘米）。大于 0 且不超过 5000 |
| `limitWeight` | `decimal` | 是 | 限重（千克）。0 表示不限重。不能小于 0，不能超过 1000000 |
| `maxContainerCount` | `int` | 是 | 最多开几只柜，1 到 50。超出报「最多开柜数必须在 1 到 50 之间」 |
| `selfStack` | `bool` | 是 | 货物自叠。true 时只有 `lineNo` 相同的货才能上下叠 |
| `flatLay` | `bool` | 是 | 平铺。true 时只放一层。与自叠同时为 true 时只平铺 |
| `gapLength` | `decimal` | 是 | 间隙长（厘米），加在沿柜长相邻的两件之间，不靠柜壁再加。0 到 5000 |
| `gapWidth` | `decimal` | 是 | 间隙宽（厘米），加在沿柜宽相邻的两件之间。0 到 5000 |
| `maxSelfStackLayers` | `int?` | 否 | **扩展**：同种货自叠最大层数；0/不传=不限。旧后端可忽略 |
| `forkliftClearance` | `decimal?` | 否 | **扩展**：顶部叉车预留（厘米）。前端也会先扣减柜高再提交，旧后端同样生效 |
| `cargos` | `PackingCargoInputDto[]` | 是 | 货物清单。空则「货物清单不能为空」。全部行件数合计不能超过 800 |

### `cargos[]` 每一行 `PackingCargoInputDto`

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `lineNo` | `int?` | 否 | 货物行号。自叠按这个号区分种类。不传或小于等于 0 时，按清单顺序从 1 编号 |
| `name` | `string` | 否 | 货物名称，原样带回。超过 200 个字符报错 |
| `length` | `decimal` | 是 | 长（厘米）。`allowRotate` 为 false 时这条边沿柜长 |
| `width` | `decimal` | 是 | 宽（厘米）。不允许旋转时沿柜宽 |
| `height` | `decimal` | 是 | 高（厘米）。不允许旋转时竖直 |
| `weight` | `decimal` | 是 | 单件毛重（千克），0 到 1000000 |
| `quantity` | `int` | 是 | 件数，大于 0，单行不超过 800 |
| `allowRotate` | `bool` | 是 | true 时六个朝向都试；false 时只用上面的长宽高朝向 |
| `groupKey` | `string?` | 否 | **扩展**：分组键，同组尽量同柜不拆散 |
| `supportLoad` | `bool?` | 否 | **扩展**：是否可承重 |
| `damaged` | `bool?` | 否 | **扩展**：破损/变形置顶 |
| `expandLength` / `expandWidth` / `expandHeight` | `decimal?` | 否 | **扩展**：膨胀厘米；前端也会先加进尺寸再提交 |

长宽高为 0 或超过 5000 时，报错带行号，例如「第1行货物长必须大于 0 且不超过 5000 厘米」。`cargos` 里某一项为 null 时报「第n行货物不能为空」。

柜内尺寸可以参考常用内径自己传入，接口不提供柜型：20GP 约 589×235×239，40GP 约 1203×235×239，40HQ 约 1203×235×269，单位厘米。限重按这次要算的柜子填。

## 2.2 出参 `result`：`PackingCalculateResultDto`

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `length` | `decimal` | 柜内长（厘米），与入参相同 |
| `width` | `decimal` | 柜内宽（厘米） |
| `height` | `decimal` | 柜内高（厘米） |
| `limitWeight` | `decimal` | 限重（千克） |
| `selfStack` | `bool` | 是否自叠 |
| `flatLay` | `bool` | 是否平铺 |
| `gapLength` | `decimal` | 间隙长（厘米） |
| `gapWidth` | `decimal` | 间隙宽（厘米） |
| `containerCount` | `int` | 实际开柜数。一件都装不下时为 0 |
| `placedQuantity` | `int` | 已装件数 |
| `unplacedQuantity` | `int` | 未装件数 |
| `cargoVolume` | `decimal` | 全部货物体积（立方米），含未装，保留 4 位小数 |
| `cargoWeight` | `decimal` | 全部货物毛重（千克），含未装，保留 2 位小数 |
| `placedVolume` | `decimal` | 已装体积（立方米）。间隙不计入 |
| `placedWeight` | `decimal` | 已装毛重（千克） |
| `containers` | `PackingContainerResultDto[]` | 每一只柜，按开柜顺序。没有装上任何货时为空数组 |
| `unplacedCargos` | `PackingUnplacedCargoDto[]` | 未装货物。全部装完时为空数组 |

### `containers[]`：`PackingContainerResultDto`

每一只柜的内径、限重都与本次入参相同，不再重复放在柜对象上。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `index` | `int` | 柜序号，从 1 开始 |
| `placedQuantity` | `int` | 本柜件数 |
| `placedVolume` | `decimal` | 本柜体积（立方米） |
| `placedWeight` | `decimal` | 本柜毛重（千克） |
| `volumeRate` | `decimal` | 容积率，0 到 100，已装体积除以柜内容积 |
| `weightRate` | `decimal` | 载重率，0 到 100。未限重时为 0 |
| `gravityOffsetLength` | `decimal` | 重心沿柜长偏离中心（厘米）。正数偏向箱门，负数偏向里端。都没有重量时为 0 |
| `gravityOffsetWidth` | `decimal` | 重心沿柜宽偏离中心（厘米）。正数偏向右侧 |
| `placements` | `PackingPlacementResultDto[]` | 本柜每一件，已按装载顺序排好 |

### `placements[]`：`PackingPlacementResultDto`

| 字段         | 类型      | 说明                                            |
| :----------- | :-------- | :---------------------------------------------- |
| `lineNo`     | `int`     | 货物行号                                        |
| `name`       | `string`  | 货物名称                                        |
| `pieceIndex` | `int`     | 该行内的件序号，从 1 开始                       |
| `loadOrder`  | `int`     | 装载顺序，从 1 开始。先装里端，同一位置先装下面 |
| `x`          | `decimal` | 沿柜长的起点（厘米），从里端量起                |
| `y`          | `decimal` | 离地高度（厘米）                                |
| `z`          | `decimal` | 沿柜宽的起点（厘米），从左侧量起                |
| `length`     | `decimal` | 摆放后沿柜长的尺寸（厘米）                      |
| `width`      | `decimal` | 摆放后沿柜宽的尺寸（厘米）                      |
| `height`     | `decimal` | 摆放后的竖直尺寸（厘米）                        |
| `weight`     | `decimal` | 单件毛重（千克）                                |

画箱子时，这件货占 `[x, x+length] × [y, y+height] × [z, z+width]`。

### `unplacedCargos[]`：`PackingUnplacedCargoDto`

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `lineNo` | `int` | 货物行号 |
| `name` | `string` | 货物名称 |
| `quantity` | `int` | 未装件数 |
| `reason` | `string` | `单件尺寸超过柜内尺寸`、`单件重量超过限重`、`按当前规则装不下`、`已达到最多开柜数` 之一 |
