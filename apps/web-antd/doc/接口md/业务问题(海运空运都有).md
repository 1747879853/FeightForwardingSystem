# 业务问题（TransportOrderQuestion）接口文档

## 基础信息

- **接口基础路径**: `/api/services/app/TransportOrderQuestionAdmin`
- **权限要求**: 所有接口需要登录认证，具体操作需要 `Admin.TransportOrder` 相关权限
- **ModuleTypeId**: `160008`（附件模块标识）

---

## 1. 新增业务问题

- **URL**: `POST /api/services/app/TransportOrderQuestionAdmin/AddAsync`
- **权限**: `Admin.TransportOrder.Add`
- **Content-Type**: `application/json`

### 请求参数

| 字段名           | 类型          | 必填 | 说明                           |
| ---------------- | ------------- | ---- | ------------------------------ |
| transportOrderId | Guid(string)  | 是   | 业务id，必须是已存在的业务记录 |
| questionType     | int           | 否   | 问题类型，前端自定义枚举       |
| question         | string        | 是   | 问题，不能为空                 |
| description      | string        | 否   | 说明                           |
| quesTime         | datetime/null | 否   | 发生时间                       |
| solved           | bool          | 否   | 是否解决，默认false            |
| solvedTime       | datetime/null | 否   | 解决时间                       |
| solution         | string        | 否   | 解决方案                       |
| attachments      | array/null    | 否   | 附件列表                       |

### attachments 子项说明

| 字段名       | 类型 | 必填 | 说明            |
| ------------ | ---- | ---- | --------------- |
| attachmentId | long | 是   | 附件id，需大于0 |
| displayOrder | int  | 否   | 排序顺序        |

### 请求示例

```json
{
  "transportOrderId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "questionType": 1,
  "question": "货物破损",
  "description": "运输途中发现货物外包装破损",
  "quesTime": "2026-04-25T10:00:00",
  "solved": false,
  "solvedTime": null,
  "solution": null,
  "attachments": [
    {
      "attachmentId": 100,
      "displayOrder": 1
    }
  ]
}
```

### 返回结果

```json
{
  "result": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "success": true,
  "error": null
}
```

返回新增记录的 Guid。

## 2. 删除业务问题

- **URL**: `DELETE /api/services/app/TransportOrderQuestionAdmin/DeleteAsync`
- **权限**: `Admin.TransportOrder.Delete`
- **Content-Type**: `application/json`

### 请求参数

| 字段名 | 类型           | 必填 | 说明           |
| ------ | -------------- | ---- | -------------- |
| id     | Guid(string)   | 否   | 单个删除时使用 |
| ids    | Guid(string)[] | 否   | 批量删除时使用 |

### 请求示例

```json
{
  "ids": [
    "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "4fa85f64-5717-4562-b3fc-2c963f66afa7"
  ]
}
```

### 返回结果

```json
{
  "result": true,
  "success": true,
  "error": null
}
```

> 删除时会同时删除关联的附件。

## 3. 编辑业务问题

- **URL**: `PUT /api/services/app/TransportOrderQuestionAdmin/EditAsync`
- **权限**: `Admin.TransportOrder.Edit`
- **Content-Type**: `application/json`

### 请求参数

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Guid(string) | 是 | 业务问题主键Id |
| transportOrderId | Guid(string) | 是 | 业务id，必须是已存在的业务记录 |
| questionType | int | 否 | 问题类型，前端自定义枚举 |
| question | string | 是 | 问题，不能为空 |
| description | string | 否 | 说明 |
| quesTime | datetime/null | 否 | 发生时间 |
| solved | bool | 否 | 是否解决 |
| solvedTime | datetime/null | 否 | 解决时间 |
| solution | string | 否 | 解决方案 |
| attachments | array/null | 否 | 附件列表（编辑时会先删除原有附件再重新创建） |

### attachments 子项说明

| 字段名       | 类型 | 必填 | 说明            |
| ------------ | ---- | ---- | --------------- |
| attachmentId | long | 是   | 附件id，需大于0 |
| displayOrder | int  | 否   | 排序顺序        |

### 请求示例

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",

  "questionType": 1,

      "displayOrder": 1
    },
    {
      "attachmentId": 101,
      "displayOrder": 2
    }
  ]
}
```

### 返回结果

```json
{
  "result": true,
  "success": true,
  "error": null
}
```

## 附件上传说明

附件需要先通过附件上传接口上传文件获取 `attachmentId`，然后在新增/编辑接口中传入附件列表。

编辑时，附件采用**先删后增**策略：会先清空该记录下所有旧附件，再根据传入的 `attachments` 列表重新创建，因此编辑时需要传入完整的附件列表（包括未变化的附件）。

海运出口的列表和详情返回了未处理问题数量UnsolvedQuestionCount
