# 海运出口派车（SeaExportDispatch）前端对接文档

## 概述

海运出口派车模块是海运出口（SeaExport）的子模块，用于管理海运出口的派车信息。每条派车记录关联一个海运出口主表，且派车记录下可包含多条箱型箱量子表（SeaExportDispatchCtn）数据。

**权限说明**：所有接口均使用海运出口（SeaExport）的权限验证，不需要单独的派车权限。

| 操作      | 权限标识                 |
| --------- | ------------------------ |
| 新增      | `Admin.SeaExport.Add`    |
| 删除      | `Admin.SeaExport.Delete` |
| 编辑      | `Admin.SeaExport.Edit`   |
| 查询/详情 | `Admin.SeaExport.Get`    |

## 1. 新增派车 - AddAsync

**请求方式**：`POST`

**接口路径**：`/api/services/app/SeaExportDispatchAdmin/Add`

**Content-Type**：`application/json`

### 请求参数

| 字段名                | 类型      | 必填 | 说明                      |
| --------------------- | --------- | ---- | ------------------------- |
| seaExportId           | Guid      | 是   | 海运出口主键              |
| teamId                | Guid?     | 否   | 车队id（合作客户）        |
| requiredTime          | DateTime? | 否   | 要求到厂时间              |
| dispatchTime          | DateTime? | 否   | 派车日期                  |
| factoryContact        | string    | 否   | 工厂联系人（最大128字符） |
| factoryTel            | string    | 否   | 工厂电话（最大64字符）    |
| yardId                | Guid?     | 否   | 场站id（合作客户）        |
| closingTime           | DateTime? | 否   | 截港日期                  |
| factoryId             | Guid?     | 否   | 工厂id（合作客户）        |
| areaId                | string    | 否   | 所在省市（最大16字符）    |
| address               | string    | 否   | 详细地址（最大1024字符）  |
| precautions           | string    | 否   | 注意事项（最大256字符）   |
| sortId                | int       | 否   | 排序id，默认0             |
| remark                | string    | 否   | 备注（最大1024字符）      |
| seaExportDispatchCtns | Array     | 否   | 箱型箱量子表列表          |

#### 子表 seaExportDispatchCtns 字段

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| ctnCodeId | long | 是 | 箱型id |
| ctnNo | string | 否 | 箱号（最大32字符） |
| sealNo | string | 否 | 封号（最大32字符） |
| pkgs | int? | 否 | 件数 |
| codePackageId | long? | 否 | 包装id |
| grossWeight | decimal? | 否 | 毛重，`decimal(20,4)`，**小数最多 4 位**，超出的位数在反序列化时四舍五入 |
| tareWeight | decimal? | 否 | 皮重，`decimal(20,4)`，**小数最多 4 位** |
| overLength | decimal? | 否 | 超长，`decimal(18,2)`，**小数最多 2 位** |
| overWidth | decimal? | 否 | 超宽，`decimal(18,2)`，**小数最多 2 位** |
| overHeight | decimal? | 否 | 超高，`decimal(18,2)`，**小数最多 2 位** |
| volume | decimal? | 否 | 体积，`decimal(20,4)`，**小数最多 4 位** |
| codeGoodsId | long? | 否 | 商品信息（品名）id |
| bookingNo | string | 否 | 订舱号（最大64字符） |
| remark | string | 否 | 备注（最大1024字符） |

### 请求示例

### 返回值

| 类型 | 说明             |
| ---- | ---------------- |

### 外键校验说明

- `seaExportId`：校验海运出口主表是否存在
- `teamId`：校验合作客户（车队）是否存在
- `yardId`：校验合作客户（场站）是否存在
- `factoryId`：校验合作客户（工厂）是否存在
- 子表 `ctnCodeId`：校验箱型是否存在
- 子表 `codePackageId`：校验包装类型是否存在
- 子表 `codeGoodsId`：校验商品信息（品名）是否存在

## 2. 删除派车 - DeleteAsync

**请求方式**：`DELETE`

**接口路径**：`/api/services/app/SeaExportDispatchAdmin/Delete`

**Content-Type**：`application/json`

### 请求参数

| 字段名 | 类型   | 必填 | 说明           |
| ------ | ------ | ---- | -------------- |
| id     | Guid   | 否   | 单条删除时传入 |
| ids    | Guid[] | 否   | 批量删除时传入 |

> id 和 ids 至少传一个。优先使用 ids 进行批量删除。

### 请求示例（单条删除）

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afb0"
}
```

### 请求示例（批量删除）

```json
{
  "ids": [
    "3fa85f64-5717-4562-b3fc-2c963f66afb0",
    "3fa85f64-5717-4562-b3fc-2c963f66afb1"
  ]
}
```

### 返回值

| 类型 | 说明         |
| ---- | ------------ |
| bool | 是否删除成功 |

### 返回示例

```json
{
  "result": true,
  "success": true,
  "error": null
}
```

### 说明

删除派车记录时会同时删除关联的箱型箱量子表（SeaExportDispatchCtn）数据。

## 错误处理

所有接口在出错时返回统一格式：

```json
{
  "result": null,
  "success": false,
  "error": {
    "code": 0,
    "message": "错误描述信息",
    "details": null,
    "validationErrors": null
  }
}
```

### 常见错误信息

| 错误信息                 | 说明                               |
| ------------------------ | ---------------------------------- |
| 输入不能为空             | 未传入请求参数                     |
| 海运出口不存在           | SeaExportId 对应的记录不存在       |
| 车队不存在               | TeamId 对应的合作客户不存在        |
| 场站不存在               | YardId 对应的合作客户不存在        |
| 工厂不存在               | FactoryId 对应的合作客户不存在     |
| 箱型ID:X不存在           | CtnCodeId 对应的箱型记录不存在     |
