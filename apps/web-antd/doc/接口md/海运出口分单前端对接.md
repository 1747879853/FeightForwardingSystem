# 海运出口分单（SeaExportSeparate）前端对接文档

## 接口基础路径

```
/api/services/app/SeaExportSeparateAdmin
```

---

## 1. 新增海运出口分单

### 请求

- **URL**: `/api/services/app/SeaExportSeparateAdmin/AddAsync`
- **Method**: `POST`
- **Content-Type**: `application/json`
- **权限**: `Admin.SeaExport.Add`

### 请求参数（Body JSON）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| seaExportId | Guid | 是 | 海运出口id |
| settlementId | Guid | 是 | 结算对象id。**2026-09-19 新增，必填**。分单费用结算给谁；应结日期按它的账期算，**不接受前端录入 `settlementDate`** |
| consigneeId | Guid? | 否 | 收货人id |
| consigneeContent | string | 否 | 收货人内容（最大1024字符） |
| shipperId | Guid? | 否 | 发货人id |
| shipperContent | string | 否 | 发货人内容（最大1024字符） |
| notifierId | Guid? | 否 | 通知人id |
| notifierContent | string | 否 | 通知人内容（最大1024字符） |
| podAgentId | Guid? | 否 | 目的港代理id |
| podAgentContent | string | 否 | 目的港代理内容（最大1024字符） |
| blNum | string | 否 | 分提单号（最大64字符） |
| marks | string | 否 | 唛头 |
| pkgs | int? | 否 | 件数 |
| codePackageId | long? | 否 | 包装id |
| kgs | decimal? | 否 | 毛重KGS，`decimal(20,4)` |
| cbm | decimal? | 否 | 体积CBM，`decimal(20,4)` |
| goodsDes | string | 否 | 货物描述 |
| codeIssueTypeId | long? | 否 | 签单方式 |
| signingPortId | long? | 否 | 签单地点(港口) |
| signingTime | DateTime? | 否 | 签单日期 |
| codeFrtId | long? | 否 | 付费方式id |
| prepareAtId | long? | 否 | 付费地点Id |

| tareWeight | decimal? | 否 | 皮重，`decimal(20,4)`，**小数最多 4 位** |
| overLength | decimal? | 否 | 超长，`decimal(18,2)`，**小数最多 2 位** |
| overWidth | decimal? | 否 | 超宽，`decimal(18,2)`，**小数最多 2 位** |
| overHeight | decimal? | 否 | 超高，`decimal(18,2)`，**小数最多 2 位** |
| volume | decimal? | 否 | 体积，`decimal(20,4)`，**小数最多 4 位** |
| codeGoodsId | long? | 否 | 商品信息(品名)id |
| bookingNo | string | 否 | 订舱号 |
| remark | string | 否 | 备注 |

## 2. 删除海运出口分单

### 请求

- **URL**: `/api/services/app/SeaExportSeparateAdmin/DeleteAsync`
- **Method**: `DELETE`
- **Content-Type**: `application/json`
- **权限**: `Admin.SeaExport.Delete`

### 请求参数（Body JSON）

| 字段名 | 类型   | 必填 | 说明               |
| ------ | ------ | ---- | ------------------ |
| id     | Guid   | 否   | 单个删除时传此字段 |
| ids    | Guid[] | 否   | 批量删除时传此字段 |

> 注意：`id` 和 `ids` 至少传一个。删除分单时会自动删除其关联的箱型箱量子表数据。

### 请求示例

单个删除：

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "ids": null
}
```

批量删除：

```json
{
  "id": "00000000-0000-0000-0000-000000000000",
  "ids": [
    "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "4fa85f64-5717-4562-b3fc-2c963f66afa7"
  ]
}
```

### 返回结果

```json
{
  "result": true,
  "success": true,
  "error": null
}
```

## 5. 分单详情

### 请求

- **URL**: `/api/services/app/SeaExportSeparateAdmin/DetailAsync`
- **Method**: `GET`
- **权限**: `Admin.SeaExport.Get`

### 请求参数（Query String）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Guid | 是 | 分单主键 |
| isPrint | bool? | 否 | `true` 时额外返回 `seaExport`、`companyPrintInfo`。列表接口忽略这个参数 |

### 请求示例

```
GET /api/services/app/SeaExportSeparateAdmin/DetailAsync?id=3fa85f64-5717-4562-b3fc-2c963f66afa6&isPrint=true
```

### 返回结果

返回结构与列表中单条数据一致（`SeaExportSeparateDto`），含结算对象、应结日期、以及子表 `seaExportSeparateCtns`。新增字段见上一节「列表/详情行级字段」。

`isPrint=true` 时多下面这些，其余情况都是 `null`：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| totalCtn | string | 分单箱型箱量合计。**2026-09-30 新增，仅打印**。按箱型名分组，形如 `20GP*2 40HQ*1` |
| upperPKGS | string | 件数大写。**2026-09-30 新增，仅打印**。分单件数转英文大写再拼包装名，如 `FIVE PACKAGES` |
| companyPrintInfo | object | 所属公司打印信息。分单没有组织，取所属海运出口的 `OrgId` 向上找到公司 |
| seaExport | object | 所属海运出口打印快照。**2026-09-29 新增**。见下节 |

#### seaExport `SeaExportSeparateSeaExportDto`

只在详情 `isPrint=true` 时有值。港口、船名、航次、船公司来自海运出口。开船日期、主提单号在 `transportOrder`，不在这一层。

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | Guid | 海运出口 id |
| vessel | string | 船名 |
| innerVoyno | string | 航次（船公司航次） |
| terminalVoyno | string | 码头航次 |
| carrier | object | 船公司。未选为 null。见下表 |
| noBillEnumStr | string | 提单份数英文。与前端下拉一致：1 `One` … 10 `Ten`。未填或不在范围内为 null。数字 `noBillEnum` 不在这个对象里返回 |
| copyNoBillEnumStr | string | 副本份数英文。对照关系与提单份数相同 |
| transportOrder | object | 业务主表。见下表 |
| prepareAt | object | 付费地点。未选为 null。港口对象见下表 |
| signingPort | object | 签单地点。未选为 null |
| pol | object | 起运港。未选为 null |
| polRemark | string | 起运港备注 |
| pod | object | 目的港。未选为 null |
| podRemark | string | 目的港备注 |
| pot1 | object | 中转港1。未选为 null |
| pot1Remark | string | 中转港1备注 |
| pot2 | object | 中转港2。未选为 null |
| pot2Remark | string | 中转港2备注 |
| receivePort | object | 收货地。未选为 null |
| receivePortRemark | string | 收货地备注 |
| deliverPort | object | 交货地。未选为 null |
| deliverPortRemark | string | 交货地备注 |

## 6. 复制海运出口分单

### 请求

- **URL**: `/api/services/app/SeaExportSeparateAdmin/CopyAsync`
- **Method**: `POST`
- **Content-Type**: `application/json`
- **权限**: `Admin.SeaExport.Edit`

### 请求参数（Body JSON）

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Guid | 是 | 要复制的分单主键。只认这一个字段，`ids` / `isPrint` 忽略 |

### 请求示例

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

### 复制规则

| 处理 | 内容 |
| :-- | :-- |
| **原样复制** | 主表全部业务字段（含**结算对象**、收发通、目的港代理、唛头、件数包装、毛重体积、货物描述、签单/付费/运输条款、**备注**），以及所属海运出口 `seaExportId` |
| **置空** | `blNum` 分提单号 |
| **不复制** | `seaExportSeparateCtns` 箱型箱量子表。新分单子表为空，需用户自行补录 |
| **重新生成** | 主键 `id`、创建人、创建时间；**应结日期按当前账期重算**，不照抄源分单那一刻的 `settlementDate` |

复制结果挂在**同一张海运出口**下，不是新开一票。复制成功后用返回的新 id 调 `DetailAsync` 打开。

### 返回结果

```json
{
  "result": "4fa85f64-5717-4562-b3fc-2c963f66afa7",
  "success": true,
  "error": null
}
```

- `result`: 新分单的 Guid 主键

## 错误返回格式

当请求失败时，返回格式如下：

```json
{
  "result": null,
  "success": false,
  "error": {
    "code": 0,
    "message": "错误提示信息",
    "details": null
  }
}
```

常见错误提示：

- `输入不能为空`
- `海运出口不存在`
- `结算对象不能为空`
- `结算对象不存在`
- `分单记录不存在`
- `收货人不存在` / `发货人不存在` / `通知人不存在` / `目的港代理不存在`
- `包装ID:xxx不存在`
- `签单方式ID:xxx不存在`
- `签单地点ID:xxx不存在`
- `付费方式ID:xxx不存在`
- `付费地点ID:xxx不存在`
- `运输条款ID:xxx不存在`
- `箱型ID不能为空` / `箱型ID:xxx不存在`
- `商品信息(品名)ID:xxx不存在`
- `收货人内容长度不能超过1024个字符`
- `分提单号长度不能超过64个字符`
- `备注长度不能超过1024个字符`
- `海出id不能为空`
