1.概述
1.1.1.接口概述
即时运价第一步调用创建运价查询任务接口生成一个查询运价的任务号，第二步调用查询任务状态接口，通过任务号查询指定任务的状态，任务状态完成（子任务完成）第三步调用获取运价查询结果接口，通过任务号、船司获取运价详细信息。
订阅运价调用添加订阅接口发起订阅（荣e通平台配置订阅触发频次、查询时间区间，通知回调地址）。
1.1.2.适用范围
本接口规范仅适用于第三方合作伙伴（简称：调用方）。
2.接口调用方式
调用方采用https协议通信，无特殊说明情况下，接口输入输出数据都是结构化的JSON数据格式。
调用地址	
数据传输方式	post同步传输
提交数据	请求报文
返回数据	响应报文

3.请求报文通用字段解释
1.	nonce 随机数
唯一的标识符，服务器能够防止请求被多次使用（记录所有用过的nonce以阻止它们被二次使用）
2.	timestamp 时间戳
采用unix时间戳，保留到毫秒。
用于判断调用方提交请求时间是否在有效时间内，如果超出15分钟则拒绝请求
3.	accessKey 请求唯一标识
请求唯一标识由荣e通平台生成，并发放给调用方使用，每个调用方只分配一个请求唯一标识，且不会重复。
4.	secretKey调用方秘钥
调用方秘钥由荣e通平台生成，并发放给调用方使用，每个秘钥都与请求唯一标识对应，且不会重复。

4.接口签名方式
第一步：将请求参数（除sign之外）模型转换为json字符串（假设存在三个业务参数aparam、bparam、cparam）
strStep1={"aparam":"test1","bparam":"test2","cparam":"{\"subMember1\":\"对象模型内的字段1\",\"subMember2\":\"对象模型内的字段2\"}","accessKey":"xxxxxx","nonce":1000,"timestamp":10000100}

第二步：将参数以key=value的格式拼接，并按照参数名ASCII字典序排序如下： 
strStep2="accessKey=xxxxxx&aparam=test1&bparam=test2&cparam={\"subMember1\":\"对象模型内的字段1\",\"subMember2\":\"对象模型内的字段2\"} &nonce=1000&timestamp=10000100”;

第三步：拼接API密钥：（secretKey为平台生成的访问密钥）
strStep3 = strStep2 + "&secretKey=192006250b4c09247ec02edce69f6"

第四步：使用MD5算法加密第二步拼接好的明文，将加密结果转为英文大写：
sign = MD5(strStep3).toUpperCase()

以下为java签名的示例代码：
        public String getSign(Map<String, String> reqParam) {
                // 1. 将请求参数Map按照参数名ASCII字典序排序
                Map<String, String> sortReqParam = new TreeMap<>(reqParam);
                // 2. 如果有sign，则删除sign
                sortReqParam.remove("sign");
                // 3. 将排好序的Map转为key=value格式的字符串
                StringBuilder sb = new StringBuilder();
                for (Map.Entry<String, String> entry : sortReqParam.entrySet()) {
                        sb.append(entry.getKey()).append("=").append(String.valueOf(entry.getValue())).append("&");
                }
                // 4. 在最后拼接上secretKey的key和value
                sb.append("secretKey").append("=").append(secretKey);
                // 5. 将拼接完成的参数字符串md5加密并转大写
                return DigestUtils.md5DigestAsHex(sb.toString().getBytes()).toUpperCase();
        }




5.即时运价

5.1.1.接口说明

5.1.2.正式环境地址
https://api.cargonpay.com/api/rpasearch/openapi/spot/createTask

    "timestamp": "1753341720928",

        "polServiceType": "CY",
        "podCode": "DEHAM",
        "podServiceType": "CY",
        "sizeTypes": [
            "20GP",
            "40HC"
        ]
    }
}
