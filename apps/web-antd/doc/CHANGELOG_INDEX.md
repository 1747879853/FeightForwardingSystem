# CHANGELOG 索引（固定模板）

> 用途：集中索引 `apps/web-antd/doc` 下的改动归档文档。  
> 规则：新记录按“时间倒序”插入对应月份分组顶部；标题格式保持一致。  
> 命名建议：`change-log-YYYY-MM-DD-<topic>.md`

## 维护规范

- 月份分组格式：`## YYYY-MM`
- 条目格式：`- [YYYY-MM-DD <变更标题>](./change-log-YYYY-MM-DD-<topic>.md)`
- 同一天多条可在标题后加简短后缀区分
- 无对应月份时先新增月份分组，再添加条目
