# 用户或角色字段级别权限 - 接口文档

## 概述

本模块用于控制用户或角色在各业务模块中**不可见**的字段。管理员可以为指定用户或角色配置字段屏蔽规则，被屏蔽的字段将**不出现在 API 的 JSON 响应中**（字段完全省略，而非返回 null）。

前端需根据 `PropName`（PascalCase，与 C# 属性名一致）自行维护字段名与界面显示名称的映射。

---

## 基础路径

```
/api/services/app/UserPropPermissionAdmin
```

所有接口均需登录（携带有效 Token）。

---

## FrightModule 枚举值

| 枚举值             | 数值 | 说明     |
| ------------------ | ---- | -------- |
| SeaExport          | 0    | 海运出口 |
| OrderFee           | 1    | 业务费用 |
| TransportOrder     | 2    | 业务表   |
| PaymentApplication | 3    | 付费申请 |
| SeaImport          | 4    | 海运进口 |
| AirExport          | 5    | 空运出口 |
| AirImport          | 6    | 空运进口 |
| SeFreiPrice        | 7    | 运价     |

---

## 重要：各页面涉及的模块

> 一个页面/列表可能包含多个模块的 DTO 嵌套，需要配置多个模块的屏蔽规则才能完整屏蔽。

| 业务页面 | 涉及的 FrightModule | 说明 |
| --- | --- | --- |
| 海运出口列表/详情 | `SeaExport` + `TransportOrder` | SeaExportDto 内嵌套了 TransportOrderDto |
| 业务费用列表 | `OrderFee` + `TransportOrder` | OrderFeeDto 内嵌套了 TransportOrderSimpleDto |
| 运价列表/详情 | `SeFreiPrice` | 独立模块，无嵌套 |
| 业务表列表/详情 | `TransportOrder` + `OrderFee` | TransportOrderDto 内嵌套了 OrderFeeDto 列表 |

**举例**：如果要在海运出口页面屏蔽"委托编号"字段，需要为 `TransportOrder` 模块配置 `PropName = "CommissionNum"` 的规则，因为委托编号属于 TransportOrderDto 而非 SeaExportDto。

## 接口列表

### 1. 新增屏蔽规则

**POST** `/api/services/app/UserPropPermissionAdmin/Add`

**权限**：`Admin.UserPropPermission.Add`

**请求体**：

```json
{
  "userId": 1, // 用户Id，与 roleId 二选一
  "roleId": null, // 角色Id，与 userId 二选一
  "frightModule": 0, // FrightModule 枚举值
  "propName": "Vessel" // 要屏蔽的属性名（PascalCase，与C#属性名一致）
}
```

**说明**：

- `userId` 和 `roleId` 二选一填写：填 userId 表示对指定用户生效，填 roleId 表示对指定角色下所有用户生效
- `propName` 必须与后端 DTO 的属性名完全一致（PascalCase），例如 `Vessel`、`CommissionNum`、`Amount`
- 同一用户/角色对同一模块的同一字段不要重复添加

**返回**：`long` - 新增记录的 Id

---

### 2. 删除屏蔽规则

**DELETE** `/api/services/app/UserPropPermissionAdmin/Delete`

**权限**：`Admin.UserPropPermission.Delete`

**请求体**：

```json
{
  "id": 1 // 规则记录的 Id
}
```

**返回**：`bool` - 是否成功

---

### 3. 编辑屏蔽规则

**PUT** `/api/services/app/UserPropPermissionAdmin/Edit`

**权限**：`Admin.UserPropPermission.Edit`

**请求体**：

```json
{
  "id": 1,
  "userId": 1,
  "roleId": null,
  "frightModule": 0,
  "propName": "Vessel"
}
```

**返回**：`bool` - 是否成功

---

### 4. 屏蔽规则列表（分页）

**GET** `/api/services/app/UserPropPermissionAdmin/GetPagedList`

**权限**：`Admin.UserPropPermission.Get`

**查询参数**：

| 参数           | 类型   | 必填 | 说明              |
| -------------- | ------ | ---- | ----------------- |
| keyword        | string | 否   | 模糊匹配 PropName |
| userId         | long?  | 否   | 按用户筛选        |
| roleId         | int?   | 否   | 按角色筛选        |
| sorting        | string | 否   | 排序字段          |
| skipCount      | int    | 否   | 跳过条数          |
| maxResultCount | int    | 否   | 每页条数          |

**返回**：分页列表 `PagedList<UserPropPermissionDto>`

```json
{
  "items": [
    {
      "id": 1,
      "userId": 1,
      "roleId": null,
      "frightModule": 0,
      "propName": "Vessel"
    }
  ],
  "totalCount": 1
}
```

**查询参数**：

| 参数 | 类型 | 必填 | 说明          |
| ---- | ---- | ---- | ------------- |

**返回**：`UserPropPermissionDto`

---

### 6. 获取当前用户不可见字段列表

**GET** `/api/services/app/UserPropPermissionAdmin/GetCurrentUserMaskedFields`

**权限**：`Admin.UserPropPermission.Get`

**查询参数**：无

**返回**：`List<PropPermissionModuleFieldsDto>` - 按模块分组

```json
[
  {
    "frightModule": 0,
    "frightModuleName": "SeaExport",
    "fields": [
      { "propName": "Vessel", "description": "规则描述文本" },
      { "propName": "Remark", "description": "规则描述文本" }
    ]
  },
  {
    "frightModule": 2,
    "frightModuleName": "TransportOrder",
    "fields": [{ "propName": "CommissionNum", "description": "规则描述文本" }]
  }
]
```

**说明**：

- 返回当前登录用户（包括直接配置和通过角色继承的）的所有被屏蔽字段
- 如果没有任何屏蔽规则，返回空数组
- `description` 是规则的描述信息，不是字段含义，前端自行维护字段名映射

---

### 7. 获取指定用户不可见字段列表

**GET** `/api/services/app/UserPropPermissionAdmin/GetUserMaskedFields`

**权限**：仅需登录

**查询参数**：

| 参数   | 类型 | 必填 | 说明           |
| ------ | ---- | ---- | -------------- |
| userId | long | 是   | 要查询的用户Id |

**返回**：与接口 6 格式相同

---

## 前端使用建议

1. **登录后获取屏蔽规则**：调用 `GetCurrentUserMaskedFields` 获取当前用户的所有屏蔽字段，缓存在前端
2. **隐藏列/字段**：根据返回的 `propName` 列表，在表格和表单中隐藏对应列和字段
3. **注意嵌套关系**：一个列表页可能涉及多个模块，需要合并多个模块的屏蔽规则。例如海运出口页需要同时检查 `SeaExport` 和 `TransportOrder` 两个模块的屏蔽字段
4. **字段名映射**：后端返回的 `propName` 是 PascalCase（如 `CommissionNum`），API 响应 JSON 中的字段名是 camelCase（如 `commissionNum`），前端注意统一处理
5. **实时生效**：后端无缓存，管理员修改规则后下次请求即生效。前端可在管理员修改规则后提示刷新或重新拉取
