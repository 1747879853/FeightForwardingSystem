# 租户配置模块接口文档

本文档只写接口：地址、权限、入参全字段、出参全字段（按嵌套层级分节）。业务口径（表层级、预定义名隔离、值为空 vs 不存在）见同目录《租户配置模块总逻辑文档》。

**控制器**：`TenantConfig`。物理表 **`Sys_Settings`**。

**所有接口均需要登录认证**，**不需要任何权限点**。方法名里的 `Async` 后缀不能省。

---

# 1. 对接总纲

| 项 | 值 |
| :-- | :-- |
| 接口基址 | `{host}/api/services/app/TenantConfig/` |
| 完整路径 | 基址 + 方法名，**保留 `Async`** |
| 鉴权头 | `Authorization: Bearer {accessToken}` |
| 租户头 | `Abp.TenantId: {租户id}`（租户账号必带；宿主账号会报「宿主用户不能使用租户配置」） |
| 请求体 | POST / PUT / DELETE 为 `application/json` |
| 存储表 | `Sys_Settings`（实体 `Abp.Configuration.Setting`） |
| 数据范围 | `TenantId = 当前登录租户` 且 `UserId IS NULL`，且 `Name` 不是系统预定义设置。前端传不了 `TenantId` / `UserId` |

## 1.1 接口一览

| # | 动作 | HTTP | 完整路径 | 参数位置 | 返回 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | 新增 | POST | `/api/services/app/TenantConfig/AddAsync` | Body | `long`（自增 id） |
| 2 | 编辑 | PUT | `/api/services/app/TenantConfig/EditAsync` | Body | `bool` |
| 3 | 删除（单条/批量） | DELETE | `/api/services/app/TenantConfig/DeleteAsync` | Body | `bool` |
| 4 | 分页列表 | GET | `/api/services/app/TenantConfig/GetPagedListAsync` | Query | `PagedList<TenantConfigDto>` |
| 5 | 详情 | GET | `/api/services/app/TenantConfig/DetailAsync` | Query | `TenantConfigDto`，没配过为 `null` |

写掉 `Async` 会 404。本项目动态 API **不会**剥方法名后缀。

## 1.2 不要和租户设置页搞混

`Sys_Settings` 还被设置页使用。那是另一套接口，**不是本模块**：

| 用途 | 地址 | 权限 | 读写方式 |
| :-- | :-- | :-- | :-- |
| **自定义键值对**（本模块） | `/api/services/app/TenantConfig/GetPagedListAsync` | 仅登录 | 仓储直写，配置名前端自定义 |
| 系统预定义设置（站点名、密码策略、时区等） | `/api/services/app/TenantSettings/GetAllSettings` | `Admin.Setting.Tenant` | `SettingManager`，**方法名没有 `Async`** |
| Host 全局设置 | `/api/services/app/HostSettings/GetAllSettings` | Host 设置权限 | `SettingManager`，**方法名没有 `Async`** |

`App.Site.SiteName`、`Abp.Zero.UserManagement.*` 这类名字走设置页。拿本模块去增删改会报「配置名{name}是系统预定义设置,请换一个名称」；列表也看不到它们。

## 1.3 权限

| 权限     | 说明                                      |
| :------- | :---------------------------------------- |
| 无权限点 | 类级 `[AbpAuthorize]`，登录即可调五个接口 |

租户内任何登录用户都能读写全部自定义配置，不要往这里存密钥、密码。

## 1.4 统一响应信封

成功时业务数据在 `result`。失败时 `success=false`，文案在 `error.message`。下文「输出参数」都指 `result` 这一层。

```json
{
  "result": {},
  "targetUrl": null,
  "success": true,
  "unAuthorizedRequest": false,
  "__abp": true,
  "error": null
}
```

## 1.5 全局约束

- **配置名是唯一的业务主键**。编辑、删除、详情都按 `name` 定位，不使用自增 `id`。
- **配置名不能改**。要改名就删掉旧的再新增一条。
- 同一租户下配置名不允许重复，数据库唯一索引 `(TenantId, Name, UserId)` 兜底。SQL Server 默认**大小写不敏感**，`web.a` 与 `Web.A` 算同一个。
- 配置名最长 **256 字符**；配置值 `value` 是 `nvarchar(max)`，不限长度。
- 配置值后端原样存储、原样返回，不做解析。要存对象或数组请前端自己 `JSON.stringify`。
- 所有字符串入参会被后端自动 Trim（全站行为），配置值的首尾空格会被去掉。
- 宿主账号不可用。
- 分页参数是 `pageIndex` / `pageSize`，默认 `1` / `10`，`pageSize` 范围 1～100000。

# 2. 公共出参 `TenantConfigDto`

列表 `items[]` 和详情 `result` 都是这一份。没有再嵌套业务对象。

## 2.1 行级字段

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | `long` | `Sys_Settings.Id`，自增。业务定位不用它，仅供调试对账 |
| `name` | `string` | 配置名 |
| `value` | `string` | 配置值，**可能为 null** |
| `creationTime` | `DateTime` | 创建时间 |
| `creatorUserId` | `long?` | 创建人 id |
| `creatorUserName` | `string` | 创建人昵称（NickName），不是 `name` |
| `lastModificationTime` | `DateTime?` | 最后修改时间，从未修改过为 null |
| `lastModifierUserId` | `long?` | 最后修改人 id |
| `lastModifierUserName` | `string` | 最后修改人昵称，从未修改过为 null |

`TenantId`、`UserId` **不返回**。

# 3. 新增租户配置

| 项目         | 值                                        |
| :----------- | :---------------------------------------- |
| **接口地址** | `/api/services/app/TenantConfig/AddAsync` |
| **请求方式** | `POST`                                    |
| **参数位置** | Body (JSON)                               |
| **权限**     | 仅需登录                                  |

重名报错，不会静默覆盖。

## 3.1 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `name` | `string` | **是** | — | 配置名，前端自定义，最长 256 字符。Trim 后不能为空；同一租户下不能重复；不能是系统预定义设置名 |
| `value` | `string` | 否 | `null` | 配置值，不限长度，原样存储。复杂结构请自行序列化成 json 字符串 |

请求示例：

```json
{
  "name": "Web.OrderList.DefaultColumns",
  "value": "[\"blNo\",\"vessel\",\"etd\"]"
}
```

## 3.2 输出参数

`result` 是标量，没有嵌套对象。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `result` | `long` | 新增成功后的主键 id。后续操作都用 `name`，这个 id 前端可以不存 |

响应示例：

```json
{
  "result": 1024,
  "success": true,
  "error": null
}
```

## 3.3 失败提示

| 提示文案 | 触发条件 |
| :-- | :-- |
| 输入不能为空 | Body 为空 |
| 宿主用户不能使用租户配置 | 当前账号未归属任何租户 |
| 配置名不能为空 | `name` 为空、纯空格 |
| 配置名长度不能超过256 | `name` 超长 |
| 配置名{name}是系统预定义设置,请换一个名称 | `name` 撞上了 `SettingProvider` 里已声明的设置名 |
| 配置名{name}已存在,请直接修改 | 当前租户下该配置名已有记录 |

# 4. 编辑租户配置

| 项目         | 值                                         |
| :----------- | :----------------------------------------- |
| **接口地址** | `/api/services/app/TenantConfig/EditAsync` |
| **请求方式** | `PUT`                                      |
| **参数位置** | Body (JSON)                                |
| **权限**     | 仅需登录                                   |

只更新配置值。**配置名是定位条件，不是可改字段**。该配置名不存在时报错，不会自动新增。UPDATE 只含 `Value` 与审计列。

## 4.1 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `name` | `string` | **是** | — | 配置名，用于定位记录 |
| `value` | `string` | 否 | `null` | 新的配置值。传 `null` 或空字符串即把值清空；记录还在 |

请求示例：

```json
{
  "name": "Web.OrderList.DefaultColumns",
  "value": "[\"blNo\",\"vessel\"]"
}
```

## 4.2 输出参数

`result` 是标量，没有嵌套对象。

| 字段     | 类型   | 说明                          |
| :------- | :----- | :---------------------------- |
| `result` | `bool` | 固定为 `true`，失败走 `error` |

## 4.3 失败提示

| 提示文案                                  | 触发条件                 |
| :---------------------------------------- | :----------------------- |
| 输入不能为空                              | Body 为空                |
| 宿主用户不能使用租户配置                  | 当前账号未归属任何租户   |
| 配置名不能为空                            | `name` 为空、纯空格      |
| 配置名长度不能超过256                     | `name` 超长              |
| 配置名{name}是系统预定义设置,请换一个名称 | `name` 是系统预定义设置  |
| 配置名{name}不存在                        | 当前租户下没有这个配置名 |

# 5. 删除租户配置

| 项目         | 值                                           |
| :----------- | :------------------------------------------- |
| **接口地址** | `/api/services/app/TenantConfig/DeleteAsync` |
| **请求方式** | `DELETE`                                     |
| **参数位置** | Body (JSON)                                  |
| **权限**     | 仅需登录                                     |

**物理删除，不可恢复**（`Sys_Settings` 没有软删除字段），前端必须做二次确认。无外键引用、无子表。

## 5.1 输入参数

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `name` | `string` | 二选一 | 单条删除时传 |
| `names` | `string[]` | 二选一 | 批量删除时传。**只要传了非空的 `names`，就忽略 `name`** |

单条删除示例：

```json
{ "name": "Web.OrderList.DefaultColumns" }
```

批量删除示例：

```json
{
  "names": ["Web.OrderList.DefaultColumns", "Web.OrderList.PageSize"]
}
```

## 5.2 输出参数

`result` 是标量，没有嵌套对象。

| 字段     | 类型   | 说明                          |
| :------- | :----- | :---------------------------- |
| `result` | `bool` | 固定为 `true`，失败走 `error` |

## 5.3 失败提示

| 提示文案 | 触发条件 |
| :-- | :-- |
| 输入不能为空 | Body 为空 |
| 配置名不能为空 | `name` 与 `names` 都没给有效值 |
| 配置名长度不能超过256 | 集合里有超长名 |
| 配置名{name}是系统预定义设置,请换一个名称 | 集合里有系统预定义名，逐条校验 |
| 输入配置名错误 | 传入的配置名中**只要有一条**在当前租户下不存在 |

批量删除是**全有或全无**：集合里只要混进一个不存在的配置名，整批都不删除。集合内部会自动去重、去空。

# 6. 租户配置分页列表

| 项目         | 值                                                 |
| :----------- | :------------------------------------------------- |
| **接口地址** | `/api/services/app/TenantConfig/GetPagedListAsync` |
| **请求方式** | `GET`                                              |
| **参数位置** | QueryString                                        |
| **权限**     | 仅需登录                                           |

排序由后端固定为配置名升序，不支持前端指定。系统预定义设置行不会出现在列表里。

## 6.1 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `pageIndex` | `int` | 否 | `1` | 页码，从 1 开始，最小 1 |
| `pageSize` | `int` | 否 | `10` | 每页条数，范围 1～100000 |
| `keyword` | `string` | 否 | `null` | 关键字，模糊匹配 **配置名、配置值** 两列 |

请求示例：

```
GET /api/services/app/TenantConfig/GetPagedListAsync?pageIndex=1&pageSize=20&keyword=OrderList
```

## 6.2 输出参数 · 分页包装（`result`）

| 字段             | 类型                | 说明                          |
| :--------------- | :------------------ | :---------------------------- |
| `items`          | `TenantConfigDto[]` | 当前页数据，单条结构见第 2 节 |
| `totalCount`     | `int`               | 总记录数                      |
| `skipCount`      | `int`               | 已跳过条数                    |
| `maxResultCount` | `int`               | 每页条数                      |
| `currentPage`    | `int`               | 当前页码                      |
| `totalPages`     | `int`               | 总页数                        |

## 6.3 输出参数 · `items[]` 行级

字段与第 2 节 `TenantConfigDto` 完全一致，恒有值（空列表时 `items` 为空数组）。无更深层嵌套。

响应示例：

```json
{
  "result": {
    "items": [
      {
        "id": 1024,
        "name": "Web.OrderList.DefaultColumns",
        "value": "[\"blNo\",\"vessel\",\"etd\"]",
        "creationTime": "2026-08-18T20:31:07.113",
        "creatorUserId": 8,
        "creatorUserName": "张三",
        "lastModificationTime": null,
        "lastModifierUserId": null,
        "lastModifierUserName": null
      }
    ],
    "totalCount": 1,
    "skipCount": 0,
    "maxResultCount": 20,
    "currentPage": 1,
    "totalPages": 1
  },
  "success": true,
  "error": null
}
```

## 6.4 失败提示

| 提示文案                 | 触发条件                                |
| :----------------------- | :-------------------------------------- |
| 输入不能为空             | 查询对象未绑上（正常传 Query 不会出现） |
| 宿主用户不能使用租户配置 | 当前账号未归属任何租户                  |

分页参数都有默认值，一个都不传等价于 `pageIndex=1&pageSize=10`，不会报错。

| :----------- | :------------------------------------------- |
| **接口地址** | `/api/services/app/TenantConfig/DetailAsync` |
| **请求方式** | `GET`                                        |
| **参数位置** | QueryString                                  |
| **权限**     | 仅需登录                                     |

## 7.1 输入参数

| 字段   | 类型     | 必填   | 说明   |
| :----- | :------- | :----- | :----- |
| `name` | `string` | **是** | 配置名 |

请求示例：

```

```

## 7.2 输出参数 · `result` 为对象时

字段与第 2 节 `TenantConfigDto` 完全一致。无更深层嵌套。

**该配置名没配过时 `result` 返回 `null`，`success` 仍为 `true`，不算错误。** 前端据此判断该调新增还是编辑。

值为空的已有记录：`result` 非 null，且 `value` 为 null。这和「没配过」不是同一状态。

`name` 是系统预定义设置时**直接报错**，不会返回 null。

# 8. 前端对接注意事项

1. **保存流程**：先调 `DetailAsync` 判断 `result` 是否为 `null`，为 `null` 走 `AddAsync`，否则走 `EditAsync`。没有 upsert 单接口。
2. **配置名建议加统一前缀**，例如 `Web.<页面或模块>.<配置项>`，方便用 `keyword` 按模块筛，也避开后端 `App.` / `Abp.` 命名空间。
3. **大小写**：SQL Server 默认不区分大小写。前端请统一写法。
4. **配置值只有字符串一种类型**。数字、布尔、对象都要自己序列化和反序列化。
5. **值是整体覆盖，不是合并**。编辑时必须回传完整 json。
6. **多人同时改同一个配置名会互相覆盖**，后提交的赢，没有版本号。
7. **这是租户级配置，整个租户共用一份**。A 改了 B 立刻能看到。按人存的偏好不要用这个模块。
8. **不要往这里写敏感信息**。无权限点，租户内任何登录用户都能读写全部配置项。
9. 拉系统设置（站点名、安全策略）用 `TenantSettings/GetAllSettings`，不要用本模块。
