# 快捷文本 前端接口文档

## 0. 通用说明

### 0.1 服务划分

| 服务 | 路径前缀 | 用途 | 权限 |
| :-- | :-- | :-- | :-- |
| `QuickTextAdminAppService` | `/api/services/app/QuickTextAdmin/` | 管理页的增删改查 | 需要 `Admin.QuickText.*` 权限点 |
| `QuickTextAppService` | `/api/services/app/QuickText/` | 业务模块面板的只读列表 | **仅需登录，不需要权限点** |

> 业务面板之所以单独走一个服务，是为了让没有配置 `Admin.QuickText.Get` 权限的操作员，在海运出口等业务页面里依然能正常使用快捷文本。

### 0.2 通用返回包装

所有接口都被 ABP 统一包装，前端实际拿到的结构是：

```json
{
  "result": {},
  "targetUrl": null,
  "success": true,
  "unAuthorizedRequest": false,
  "__abp": true,
  "error": null
}
```

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `result` | object | 业务数据。下文各接口的「输出参数」均指这一层的内容 |
| `success` | bool | 是否成功 |
| `error` | object | 失败时的错误信息，`error.message` 为可直接展示给用户的中文提示 |
| `unAuthorizedRequest` | bool | 是否未授权 |

### 0.3 枚举字典

**BizType 业务类型**

| 值  | 含义     |
| :-- | :------- |
| `0` | 海运出口 |
| `1` | 海运进口 |
| `2` | 空运出口 |

> 接口按数字进出，**不返回中文描述**，前端自行维护映射。当前枚举**不含空运进口**。

### 0.4 全局约束

- 所有接口只操作**当前登录用户自己**的数据，`UserId` 由后端从登录态取，前端无需也无法传入。
- 宿主(host)用户无法使用本模块，新增时会返回「宿主用户不能使用快捷文本」。
- 正文 `Text` 与备注 `Remark` 最长 4096 **字符**，标题 `Title` 最长 32 **字符**（按字符数，一个汉字算一个）。
- 字符串入参后端会先 `Trim` 再校验和存储。
- 后端**不解析、不替换、不校验占位符**，`Text` 原样存、原样取。

## 1. 新增快捷文本

| 项目         | 值                                          |
| :----------- | :------------------------------------------ |
| **接口地址** | `/api/services/app/QuickTextAdmin/AddAsync` |
| **请求方式** | `POST`                                      |
| **参数位置** | Body (JSON)                                 |
| **权限**     | `Admin.QuickText.Add`                       |

### 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `bizType` | int | **是** | — | 业务类型。0海运出口 1海运进口 2空运出口。传其他值报「业务类型错误」 |
| `default` | bool | 否 | `false` | 是否设为默认。传 `true` 时后端会自动把当前用户**同一业务类型**下其他记录置为非默认 |
| `title` | string | 否 | `null` | 标题，最长 32 字符，允许重复 |
| `text` | string | **是** | — | 快捷文本正文，最长 4096 字符。Trim 后不能为空，纯空格或纯换行会被拦截 |
| `remark` | string | 否 | `null` | 备注，最长 4096 字符 |
| `sortId` | int | 否 | `0` | 排序值，降序，大的在前。可为负数 |

请求示例：

```json
{
  "bizType": 0,
  "default": true,
  "title": "订舱通知",
  "text": "您好，本票[委托编号]已订舱成功，船名航次[船名航次]，请查收。",
  "remark": "发给客户用",
  "sortId": 10
}
```

### 输出参数

| 字段     | 类型         | 说明                |
| :------- | :----------- | :------------------ |
| `result` | string(Guid) | 新增成功后的主键 id |

响应示例：

```json
{
  "result": "3f2a8c11-9d4e-4b7a-8f6c-2e1d5a0b7c93",
  "success": true,
  "error": null
}
```

### 失败提示

| 提示文案                 | 触发条件                    |
| :----------------------- | :-------------------------- |
| 输入不能为空             | Body 为空                   |
| 宿主用户不能使用快捷文本 | 当前账号未归属任何租户      |
| 业务类型错误             | `bizType` 不在 0/1/2 之内   |
| 标题长度不能超过32       | `title` 超长                |
| 快捷文本不能为空         | `text` 为空、纯空格或纯换行 |
| 快捷文本长度不能超过4096 | `text` 超长                 |
| 备注长度不能超过4096     | `remark` 超长               |

## 2. 编辑快捷文本

| 项目         | 值                                           |
| :----------- | :------------------------------------------- |
| **接口地址** | `/api/services/app/QuickTextAdmin/EditAsync` |
| **请求方式** | `PUT`                                        |
| **参数位置** | Body (JSON)                                  |
| **权限**     | `Admin.QuickText.Edit`                       |

> **业务类型创建后锁定**，入参中没有 `bizType`，前端编辑弹窗需把该字段置灰或只读。 **设为默认 / 取消默认也走本接口**，没有独立的接口，前端在列表里切换默认时需要回传整条数据。

### 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `id` | string(Guid) | **是** | — | 主键 id，必须是当前用户自己的数据 |
| `default` | bool | **是** | — | 是否默认。传 `true` 时自动把同业务类型下其他记录置为非默认；传 `false` 直接放行，**允许该业务类型变成没有默认项** |
| `title` | string | 否 | `null` | 标题，最长 32 字符 |
| `text` | string | **是** | — | 正文，最长 4096 字符，Trim 后不能为空 |
| `remark` | string | 否 | `null` | 备注，最长 4096 字符 |
| `sortId` | int | **是** | — | 排序值，降序 |

请求示例：

```json
{
  "id": "3f2a8c11-9d4e-4b7a-8f6c-2e1d5a0b7c93",
  "default": false,
  "title": "订舱通知(改)",
  "text": "您好，本票[委托编号]已订舱成功。",
  "remark": null,
  "sortId": 20
}
```

### 输出参数

| 字段     | 类型 | 说明                            |
| :------- | :--- | :------------------------------ |
| `result` | bool | 固定为 `true`，失败会走 `error` |

### 失败提示

| 提示文案 | 触发条件 |
| :-- | :-- |
| 输入不能为空 | Body 为空 |
| 输入快捷文本错误 | id 不存在，**或该数据不属于当前登录用户** |
| 标题长度不能超过32 / 快捷文本不能为空 / 快捷文本长度不能超过4096 / 备注长度不能超过4096 | 同新增接口 |

## 3. 删除快捷文本

| 项目         | 值                                             |
| :----------- | :--------------------------------------------- |
| **接口地址** | `/api/services/app/QuickTextAdmin/DeleteAsync` |
| **请求方式** | `DELETE`                                       |
| **参数位置** | Body (JSON)                                    |
| **权限**     | `Admin.QuickText.Delete`                       |

> **物理删除，不可恢复**，前端必须做二次确认。

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| `id` | string(Guid) | 二选一 | 单条删除时传 |
| `ids` | string(Guid)[] | 二选一 | 批量删除时传。**只要传了非空的 `ids`，就忽略 `id`** |

单条删除示例：

```json
{ "id": "3f2a8c11-9d4e-4b7a-8f6c-2e1d5a0b7c93" }
```

批量删除示例：

```json
{
  "ids": [
    "3f2a8c11-9d4e-4b7a-8f6c-2e1d5a0b7c93",
    "7b91d2e4-5c38-4a16-9e02-8d4f6a3b1c57"
  ]
}
```

### 输出参数

| 字段     | 类型 | 说明                            |
| :------- | :--- | :------------------------------ |
| `result` | bool | 固定为 `true`，失败会走 `error` |

### 失败提示

| 提示文案         | 触发条件                                         |
| :--------------- | :----------------------------------------------- |
| 输入不能为空     | Body 为空                                        |
| 输入快捷文本错误 | 传入的 id 中**只要有一条**不存在或不属于当前用户 |

> **批量删除是全有或全无**：只要集合里混进一条别人的数据或已被删掉的 id，**整批都不会删除**，直接报错。前端不要假设「部分成功」。

## 4. 快捷文本分页列表（管理页）

| 项目         | 值                                                   |
| :----------- | :--------------------------------------------------- |
| **接口地址** | `/api/services/app/QuickTextAdmin/GetPagedListAsync` |
| **请求方式** | `GET`                                                |
| **参数位置** | QueryString                                          |
| **权限**     | 仅需登录（类级鉴权）                                 |

### 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `pageIndex` | int | 否 | `1` | 页码，从 1 开始，最小 1 |
| `pageSize` | int | 否 | `10` | 每页条数，范围 1~100000 |
| `keyword` | string | 否 | `null` | 关键字，模糊匹配 **标题、正文、备注** 三列 |
| `bizType` | int? | 否 | `null` | 业务类型筛选。**不传则返回全部业务类型** |
| `default` | bool? | 否 | `null` | 是否默认筛选。不传则不筛选 |

请求示例：

```
GET /api/services/app/QuickTextAdmin/GetPagedListAsync?pageIndex=1&pageSize=20&bizType=0&keyword=订舱
```

### 输出参数

`result` 为分页包装对象：

| 字段             | 类型           | 说明                   |
| :--------------- | :------------- | :--------------------- |
| `items`          | QuickTextDto[] | 当前页数据，结构见下表 |
| `totalCount`     | int            | 总记录数               |
| `skipCount`      | int            | 已跳过条数             |
| `maxResultCount` | int            | 每页条数               |
| `currentPage`    | int            | 当前页码               |
| `totalPages`     | int            | 总页数                 |

**QuickTextDto 单条结构：**

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | string(Guid) | 主键 id |
| `bizType` | int | 业务类型。0海运出口 1海运进口 2空运出口 |
| `default` | bool | 是否默认 |
| `title` | string | 标题，**可能为 null** |
| `text` | string | 快捷文本正文 |
| `remark` | string | 备注，可能为 null |
| `sortId` | int | 排序值 |
| `creationTime` | string(DateTime) | 创建时间 |
| `creatorUserId` | long? | 创建人 id |
| `creatorUserName` | string | 创建人昵称 |
| `lastModificationTime` | string(DateTime)? | 最后修改时间，从未修改过为 null |
| `lastModifierUserId` | long? | 最后修改人 id |
| `lastModifierUserName` | string | 最后修改人昵称，从未修改过为 null |

响应示例：

```json
{
  "result": {
    "items": [
      {
        "id": "3f2a8c11-9d4e-4b7a-8f6c-2e1d5a0b7c93",
        "bizType": 0,
        "default": true,
        "title": "订舱通知",
        "text": "您好，本票[委托编号]已订舱成功。",
        "remark": "发给客户用",
        "sortId": 10,
        "creationTime": "2026-08-04T13:20:11.123",
        "creatorUserId": 8,
        "creatorUserName": "张三",
        "lastModificationTime": null,
        "lastModifierUserId": null,
        "lastModifierUserName": null
      }
    ],
    "totalCount": 1,
    "skipCount": 0,
    "maxResultCount": 20,
    "currentPage": 1,
    "totalPages": 1
  },
  "success": true,
  "error": null
}
```

### 排序规则

**排序由后端固定，不支持前端指定**，依次为：

1. `default` 降序 —— 默认项永远排在最前
2. `sortId` 降序 —— 值大的在前
3. `creationTime` 降序 —— 新建的在前

> `sortId` 默认值是 0，实际使用中大部分记录都是 0，此时顺序由创建时间决定。前端**按返回顺序直接渲染，不要自己重排**。

| 字段      | 类型         | 说明                                   |

## 7. 前端对接注意事项

1. **业务面板是只读的**。本模块没有为业务面板提供新增、编辑、删除接口，面板里需要维护数据时请引导用户跳转到管理页。
2. **设为默认没有独立接口**，走 `EditAsync`。前端在列表里点星标切换默认时，需要把该行的 `title`、`text`、`remark`、`sortId` 一并回传，否则这些字段会被覆盖成传入值。
3. **业务类型不能改**。`EditAsync` 入参里没有 `bizType`，编辑弹窗必须置灰该字段。
4. **标题可能为 null**。列表渲染要有兜底方案，建议截取 `text` 前若干字符作为展示名。
5. **默认项只是排序置顶**，接口层面不含「自动填入输入框」的语义。是否要在打开输入框时自动填入默认项，由前端根据 `default` 字段自行决定。
6. **越权与不存在返回同一个提示**（「输入快捷文本错误」），前端不需要区分这两种情况。
7. **占位符完全由前端负责**。后端不提供占位符清单接口，也不校验正文里的占位符是否合法，写错了照样能存进去。
