# 港口前端接口文档（PortCode）

**控制器**：`PortCode`（`PortCodeAppService`，非 Admin）

**说明**：登录即可访问，**无需业务权限**。

与 `PortCodeAdmin` 区别：Admin 负责增删改查（带权限、返回国家/航线对象和用户昵称）；本服务只读、无权限点。全量列表仍走 `GetListAsync`；分页检索走 `GetPagedListAsync`，港口列走缓存，国家/航线按本页 id 查表，不带用户名。

---

## 一、获取全部港口列表

### `GET /api/services/app/PortCode/GetListAsync`

**权限**：仅需登录（`[AbpAuthorize]`，无具体权限点）

**入参**：无

**出参**：`List<PortCodeListItemDto>`（JSON 字段为单字母，减小体积）

### `PortCodeListItemDto` 字段

| 字段 | 类型     | 含义                                                |
| ---- | -------- | --------------------------------------------------- |
| `i`  | `long`   | 主键ID                                              |
| `p`  | `string` | 港口英文名称/港口代码（原 portName）                |
| `c`  | `string` | 港口中文名称（原 cnName）                           |
| `e`  | `string` | 关联国家英文名称（原 countryEnName）；无则为 `null` |
| `s`  | `int`    | 排序 id（原 sortId）；降序，值大的排前面            |

**响应示例：**

```json
[
  { "i": 1, "p": "SHANGHAI", "c": "上海", "e": "China", "s": 10 },
  { "i": 2, "p": "LOS ANGELES", "c": "洛杉矶", "e": "United States", "s": 0 }
]
```

### 业务规则

1. **全量返回**：不分页；ABP 软删除过滤后的全部港口（含启用/禁用）。
2. **关联国家**：通过 `PortCode.CountryId` → `CountryCode`，投影 `CountryEnName` → 字段 `e`。
3. **排序**：`SortId` 降序，同值再按 `PortName` 升序、`Id` 升序。存量未维护排序的港口 `s` 为 `0`。
4. 查询使用 `AsNoTracking()`。
5. **传输压缩**：Host 已启用 `ResponseCompression`（gzip/brotli）。浏览器请求带 `Accept-Encoding` 时，响应头会出现 `Content-Encoding`；Chrome 里请看 **Transferred**（传输体积），不要只看 Size（解压后体积）。

## 二、港口分页列表

### `GET /api/services/app/PortCode/GetPagedListAsync`

**权限**：仅需登录（`[AbpAuthorize]`，无具体权限点）

筛选口径与 `PortCodeAdmin/GetPagedListAsync` 相同。港口列来自当前租户的 `PortCodePagedDto` 列缓存；**国家/航线按本页 `countryId`/`laneId` 查表**，结构与管理端列表的简易对象相同。不查用户表、不带用户昵称。

### 入参（`PortCodeQueryDto`）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | `string` | 否 | 模糊匹配港口英文名 `PortName`、中文名 `CnName`、EDI 代码 `EdiCode` |
| `laneId` | `long?` | 否 | 航线 id，精确匹配港口表 `LaneId` |
| `ediCode` | `string` | 否 | EDI 代码，模糊匹配 |
| `countryId` | `long?` | 否 | 国家 id，精确匹配港口表 `CountryId` |
| `status` | `int?` | 否 | 状态：0=启用，1=禁用 |
| `sorting` | `string` | 否 | 排序字段（如 `sortId DESC`）。不传、空、或仍是基类默认 `CreationTime DESC` 时按 `sortId` 降序 + `id` 降序 |
| `pageIndex` | `int` | 否 | 当前页码，默认 1 |
| `pageSize` | `int` | 否 | 每页条数，默认 10 |

### 出参（`PagedList<PortCodePagedDto>`）

#### 分页外壳

| 字段             | 类型                 | 含义                          |
| ---------------- | -------------------- | ----------------------------- |
| `items`          | `PortCodePagedDto[]` | 当前页数据，见下节            |
| `totalCount`     | `int`                | 命中总行数                    |
| `skipCount`      | `int`                | 跳过条数                      |
| `maxResultCount` | `int`                | 本页最大条数（即 `pageSize`） |
| `currentPage`    | `int`                | 当前页                        |
| `totalPages`     | `int`                | 总页数                        |

#### `items[]`（`PortCodePagedDto`）

港口表列 + 嵌套的国家/航线对象。**没有** `creatorUserName` / `lastModifierUserName`。未维护或已软删除时 `country` / `lane` 为 `null`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | `long` | 港口主键 |
| `portName` | `string` | 港口英文名称 |
| `cnName` | `string` | 港口中文名称 |
| `explain` | `string` | 说明 |
| `portType` | `string` | 港口类型 |
| `countryId` | `long` | 国家 id |
| `country` | `CountryCodeSimpleDto \| null` | 国家对象，见下节 |
| `laneId` | `long` | 航线 id |
| `lane` | `LaneCodeSimpleDto \| null` | 航线对象，见下节 |
| `ediCode` | `string` | EDI 代码 |
| `statisticalArea` | `string` | 统计区域 |
| `status` | `int` | 状态 0启用 1禁用 |
| `sortId` | `int` | 排序 id，降序，值大的排前面 |
| `remark` | `string` | 备注 |

#### `items[].country`（`CountryCodeSimpleDto`）

有值条件：本页港口的 `countryId` 在国家表能查到且未软删。

| 字段            | 类型     | 含义         |
| --------------- | -------- | ------------ |
| `id`            | `long`   | 国家主键     |
| `code`          | `string` | 国家唯一代码 |
| `countryName`   | `string` | 国家中文名   |
| `countryEnName` | `string` | 国家英文名   |

#### `items[].lane`（`LaneCodeSimpleDto`）

有值条件：本页港口的 `laneId` 在航线表能查到且未软删。

| 字段         | 类型     | 含义          |
| ------------ | -------- | ------------- |
| `id`         | `long`   | 航线主键      |
| `code`       | `string` | 航线代码      |
| `laneName`   | `string` | 航线中文名    |
| `laneEnName` | `string` | 航线英文名    |
| `ediCode`    | `string` | 航线 EDI 代码 |

**响应示例：**

```json
{
  "totalCount": 2,
  "skipCount": 0,
  "maxResultCount": 20,
  "currentPage": 1,
  "totalPages": 1,
  "items": [
    {
      "id": 1,
      "portName": "SHANGHAI",
      "cnName": "上海",
      "explain": null,
      "portType": "海港",
      "countryId": 9,
      "country": {
        "id": 9,
        "code": "CN",
        "countryName": "中国",
        "countryEnName": "CHINA"
      },
      "laneId": 5,
      "lane": {
        "id": 5,
        "code": "FE",
        "laneName": "远东航线",
        "laneEnName": "FAR EAST",
        "ediCode": "FE"
      },
      "ediCode": "CNSHA",
      "statisticalArea": null,
      "status": 0,
      "sortId": 10,
      "remark": null
    }
  ]
}
```

### 业务规则

1. 港口缓存项只有 `PortCodePagedDto` 的港口表列（不含创建时间等审计字段，也不含国家/航线）。回传前拷贝一份，再按本页 id 查国家表/航线表填对象。
2. 筛选条件与管理端列表一致，可组合。`keyword` / `ediCode` 仍是模糊 `Contains`（忽略大小写）。
3. `country` / `lane` 与管理端列表简易对象字段相同；查不到则为 `null`。本接口不带用户昵称。
4. 管理端增删改港口后港口缓存失效；全量列表 `GetListAsync` 不走这套缓存。
