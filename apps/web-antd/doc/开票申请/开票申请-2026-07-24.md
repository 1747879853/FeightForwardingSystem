# 1. 背景意图

对齐发票开出编辑拆分：原 `EditAsync` 全量替换主表+费用明细+商品明细，前端局部加减费用不便。拆成三个接口并**保留**原 `EditAsync`。

# 2. 核心逻辑

| 接口 | 作用 |
| :-- | :-- |
| `EditMainAsync` | 仅改主表；结算对象变更校验已有费用；驳回→录入 |
| `AddItemsAsync` | 追加费用明细 + 完整商品明细（合并后金额×汇率校验）并全量替换商品 |
| `RemoveItemsAsync` | 按明细 Id 移除 + 剩余商品校验；至少保留一条 |
| `EditAsync` | **保留**全量替换 |

公共：`ValidateInvoiceApplicationBanksAsync`、`GetInvoiceRateValueAsync`、`ValidateGoodsAmountAgainstItems`、`ReplaceGoodsDtlsAsync`、`LockAndValidateOrderFeesForItemsAsync`。

# 3. 避坑

- 移除入参是 `invoiceApplicationItemIds`（明细主键），不是 `orderFeeId`。
- 增删时 `invoiceApplicationGoodsDtls` 不可为 null，是最终完整商品列表。
- 商品金额为人民币，费用申请金额为原币，须按发票汇率折算后比较。
