# 1. 背景意图 (Background)

前端列表需要勾选多条开票申请一次性删除。原 `DeleteAsync` 入参仅为单个 `id`，改为 `ids` 批量删除。

# 2. 核心逻辑变更 (Core Changes)

| 项 | 变更 |
| :-- | :-- |
| `InvoiceApplicationDeleteDto` | `id: Guid` → `ids: List<Guid>` |
| `DeleteAsync` | 按 `ids` 批量校验（已开票不可删）、批量软删子表与主表 |

子表删除改为谓词批量：`DeleteAsync(x => ids.Contains(x.InvoiceApplicationId))`，避免 foreach 单条删。

# 3. 避坑指南 (Pitfalls)

- 请求体字段名是 `ids`（数组），不再接受单个 `id`。
- 只要选中记录中存在已开票（`Invoiced`）状态，整批删除失败。
- ABP 软删不会级联，必须显式删 `InvoiceApplicationItem` / `InvoiceApplicationGoodsDtl`。
