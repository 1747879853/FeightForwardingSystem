# 1. 背景意图 (Background)

开票申请、发票开出的列表与详情接口此前未完整返回**所属公司**信息：开票申请缺少 `companyName` 及 `SetDataPermissionPropsAsync` 解析的组织/公司字段；详情未调用 `SetDataPermissionPropsAsync`；开票申请详情内 `feeGroups.transportOrder` 亦未回填业务所属公司。

# 3. 避坑指南 (Pitfalls)

- **`companyName` 与 `companys` 来源不同**：`companyName` 来自实体 `CompanyId`（开票时选择的公司）；`companys` 来自 `SetDataPermissionPropsAsync` 按 `UserId` 解析的数据权限公司，前端展示开票所属公司优先用 `companyName` 或 `companys[0]` 需按业务场景选择。
- **详情 feeGroups 的 transportOrder**：须先赋值 `UserId` 再调用 `SetDataPermissionPropsAsync`，与 `GetOrderFeeGroupAsync` 一致。
