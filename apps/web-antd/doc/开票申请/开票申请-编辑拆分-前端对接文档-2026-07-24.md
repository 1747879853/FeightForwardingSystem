# 开票申请-编辑拆分-前端对接文档-2026-07-24

路由前缀：`/api/services/app/InvoiceApplicationAdmin`  
权限：`Admin.InvoiceApplication.Edit`

> 原 `PUT EditAsync`（全量替换）**保留不变**，新页面建议改用下列拆分接口。

---

## 校验时机（重要）

| 时机                                 | 费用/商品可否为空 | 商品金额×汇率校验 |
| :----------------------------------- | :---------------- | :---------------- |
| 新增 / 编辑 / AddItems / RemoveItems | **允许为空**      | **不校验**        |
| `SubmitAsync` 提交                   | **均不可为空**    | **必须一致**      |

---

## 1. 仅编辑主表 — `PUT EditMainAsync`

入参：`id`、`settlementId`、`orgId`、`orgBankAccountId`、`clientInvoiceBankId`、`invoiceType`、`require`、`remark`  
不改费用/商品明细。

---

## 2. 新增多条费用明细 — `POST AddItemsAsync`

| 字段 | 必填 | 说明 |
| :-- | :-- | :-- |
| `id` | 是 | 开票申请ID |
| `invoiceApplicationItems` | 否 | 本次新增；可空 |
| `invoiceApplicationGoodsDtls` | 否 | `null`=不改商品；`[]`=清空；有值=全量替换 |

不做商品金额校验。

---

## 3. 移除多条费用明细 — `PUT RemoveItemsAsync`

| 字段                          | 必填 | 说明                             |
| :---------------------------- | :--- | :------------------------------- |
| `id`                          | 是   | 开票申请ID                       |
| `invoiceApplicationItemIds`   | 是   | 明细主键，至少一条；**允许删光** |
| `invoiceApplicationGoodsDtls` | 否   | 同 AddItems                      |

---

## 4. 提交 — `PUT SubmitAsync`

提交时校验：

- 我司银行、客户银行不能为空
- **费用明细不能为空**
- **商品明细不能为空**
- 商品金额合计 = 费用申请金额合计 × 发票汇率（人民币）

---

## 5. 前端适配清单

- [ ] 保存草稿可空费用/商品
- [ ] 提交前确保两边都有数据且金额折算一致
- [ ] Add/Remove 商品字段：不传 `null` 表示不改
