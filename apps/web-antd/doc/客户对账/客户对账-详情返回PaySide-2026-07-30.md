# 客户对账-详情返回PaySide-2026-07-30## 1. 背景意图列表 `GetPagedListAsync` 已按对账单下全部费用汇总返回 `PaySide`（0 全收 / 1 全付 / 2 收付都有），但详情 `DetailAsync` 未赋值，前端详情页拿不到收付类型汇总。本次在详情接口按与列表相同的规则回填。## 2. 核心逻辑变更| 接口 | 方法 | 权限 | 变更 || :--- | :--- | :--- | :--- || `DetailAsync` | `GET` | `Admin.Statement.Get` | 有关联费用时汇总写入 `result.PaySide` |汇总规则（与列表一致）：| 值 | 含义 | 判定 || :--- | :--- | :--- || `0` | 全部为收 | 存在收、不存在付 || `1` | 全部为付 | 存在付、不存在收 || `2` | 收付都有 | 同时存在收与付 |无关联费用时保持默认 `0`。`InvoiceStatus` 详情仍不计算（与既有约定一致）。## 3. 避坑指南- **`PaySide` 是 int 不是枚举**：`2` 表示「收付都有」，勿按费用级收/付枚举解析。- **无费用时为 0**：详情无关联费用时 `paySide` 为默认 `0`，与「全部为收」同值，前端需结合是否有费用明细判断。## 4. 变更日志| 日期 | 变更类型 | 业务功能变动 || :--- | :--- | :--- || 2026-07-30 | `Feature` | 详情 `DetailAsync` 返回收付类型汇总 `PaySide`，规则对齐列表 |
