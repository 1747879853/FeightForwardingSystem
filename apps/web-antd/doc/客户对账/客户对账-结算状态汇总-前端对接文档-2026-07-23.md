# 客户对账-结算状态汇总-前端对接文档-2026-07-23

路由前缀：`/api/services/app/StatementAdmin`  
权限：`Admin.Statement.Get`

---

## 1. 列表 — `GET /api/services/app/StatementAdmin/GetPagedListAsync`

### 入参新增（`StatementQueryDto`）

| 字段 | JSON | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| 结算状态 | `settlementStatus` | SettlementStatus? | 否 | `0`未结算 / `1`部分结算 / `2`结算完毕；不传不筛选 |

### 出参新增（`StatementDto`）

| 字段 | JSON | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| 结算状态 | `settlementStatus` | SettlementStatus | 按对账单下全部费用汇总，规则见下表 |

---

## 2. 详情 — `GET /api/services/app/StatementAdmin/DetailAsync`

### 入参

| 字段     | JSON | 类型 | 必填 | 说明       |
| :------- | :--- | :--- | :--- | :--------- |
| 对账单id | `id` | Guid | 是   | 对账单主键 |

### 出参新增（`StatementDto` 头）

| 字段 | JSON | 类型 | 说明 |
| :-- | :-- | :-- | :-- |
| 结算状态 | `settlementStatus` | SettlementStatus | 与列表相同的汇总规则；无关联费用时为默认 `0` |

> 详情费用行上原有的 `orderFeeGroups[].orderFees[].settlementStatus` 仍是单条费用状态，勿与对账单头汇总字段混用。

---

## 3. 枚举与汇总规则

枚举：`SettlementStatus`

| 值  | 枚举名              | 含义     | 汇总判定                         |
| :-- | :------------------ | :------- | :------------------------------- |
| `0` | `UnSettled`         | 未结算   | 所有费用均为未结算               |
| `1` | `PartialSettlement` | 部分结算 | 既非全部未结算、也非全部结算完毕 |
| `2` | `Settlemented`      | 结算完毕 | 所有费用均为结算完毕             |
