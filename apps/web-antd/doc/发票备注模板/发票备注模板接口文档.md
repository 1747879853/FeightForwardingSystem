# 发票备注模板接口文档

**控制器**：`InvoiceRemarkTemAdmin`

**所有接口均需要登录认证**

---

# 1. 业务背景说明 (Background)

**白话解释：** 发票备注模板（`InvoiceRemarkTem`）用于按"归属公司 + 币别"维护开票时使用的备注文案模板。

- 用户只能查询和管理自己 **DataPermission 数据权限范围内** 的数据。
- **相同归属公司ID + 相同币别ID** 的数据，最多只能有一条"默认"（`Default = true`）。
- 数据无子表。

# 2. 数据结构

- 主表：`InvoiceRemarkTem`（发票备注模板）
- 外键：`OrgId` → 组织机构（**归属公司id，公司层级，只能是公司不能是部门**）；`CurrencyId` → 币别。

## 一、新增发票备注模板

### `POST /api/services/app/InvoiceRemarkTemAdmin/AddAsync`

**权限**：`Admin.InvoiceRemarkTem.Add`

**入参** `InvoiceRemarkTemAddDto`（Body JSON）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | 是 | 名称（最长64） |
| `orgId` | `long?` | 是 | 归属公司id（必填，只能选公司；须为所属人本人所属公司） |
| `currencyId` | `long` | 是 | 币别ID |
| `template` | `string` | 否 | 模板内容（最长8192） |
| `default` | `bool` | 是 | 是否默认（相同公司+相同币别只能有一条默认） |

**出参**：`Guid`（新建ID）

**业务规则（校验）**：

- `name` 不能为空，长度不超过64。
- 归属公司必填，且必须是公司节点（传部门提示"所选组织不是公司，请选择公司。"）。
- 归属公司必须落在数据所属人本人所属公司范围内：本人挂在部门下时，由其直属组织**向上找到最接近的公司**再比对（例如本人在"青岛分公司-业务部"，可录入"青岛分公司"）。
- 币别必须存在。
- 当 `default = true` 时，校验相同 `orgId + currencyId` 下不存在其它默认数据，否则提示"该公司该币别已存在默认发票备注模板"。

## 五、发票备注模板分页列表

### `GET /api/services/app/InvoiceRemarkTemAdmin/GetPagedListAsync`

**权限**：`Admin.InvoiceRemarkTem.Get`

**入参** `InvoiceRemarkTemQueryDto`（Query参数）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | 否 | 名称（模糊） |
| `currencyId` | `long?` | 否 | 币别ID |
| `default` | `bool?` | 否 | 是否默认 |
| `template` | `string` | 否 | 模板内容（模糊） |
| `creatorUserId` | `long?` | 否 | 创建人ID |
| `orgId` | `long?` | 否 | 归属公司ID（**精确匹配，公司层级，不含下属组织**） |
| `pageIndex` | `int` | 是 | 当前页码（从1开始） |
| `pageSize` | `int` | 是 | 每页条数 |
| `sorting` | `string` | 否 | 排序字段（默认 `CreationTime DESC`） |

**出参** `PagedList<InvoiceRemarkTemListDto>`：列表项含名称、币别、模板，以及 `currency` 简易信息和 `creatorUserName`。**2026-10-01 起** `orgs` 每级只留 `name`，并返回 `creationTime`、`lastModificationTime`、`localCurrencyCode`。不再返回 `userId`、`orgId`、`creatorUserId`、`localCurrencyId`。详情仍返回完整组织对象。

**业务规则**：

- 列表通过 `DataPermissionFilterAsync` 过滤，仅返回当前用户数据权限范围内的数据。
- 按 `orgId` 搜索为公司精确相等（`OrgId = @orgId`），不再连带下属组织；`orgId` 为空的数据不会被搜出。
