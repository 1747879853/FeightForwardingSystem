# 微信小程序登录接口 - 前端对接文档

> 更新日期：2026-08-20

## 调用顺序（重要）

```
小程序启动
   ↓ wx.login() 拿 code
调 WxOpenSilentAuthenticate（静默登录，不花钱）
   ↓
shouldBindingUser = false ──→ 拿到 accessToken，直接进首页
   ↓
shouldBindingUser = true
   ↓ 展示「手机号一键登录」按钮，等用户点击
调 WxOpenPhoneAuthenticate（每次成功扣 0.03 元）
   ↓
拿到 accessToken，进首页；此后启动都能静默登录
```

**不要跳过静默登录直接调手机号登录**。手机号快速验证组件按次收费，扣费发生在前端拿到 `bindgetphonenumber` 的 success 回调时刻，哪怕拿到 code 后什么都不做，钱也已经扣了。

## 一、静默登录

### 接口信息

| 项目         | 说明                                           |
| ------------ | ---------------------------------------------- |
| 接口地址     | `POST /api/TokenAuth/WxOpenSilentAuthenticate` |
| 请求方式     | POST                                           |
| Content-Type | application/json                               |
| 是否需要认证 | 否                                             |

### 请求参数（WxOpenSilentLoginModel）

| 参数名    | 类型   | 必填 | 说明                     |
| --------- | ------ | ---- | ------------------------ |
| code      | string | 是   | `wx.login()` 返回的 code |
| returnUrl | string | 否   | 登录后跳转地址，原样回显 |

### 请求示例

```json
{
  "code": "0a1B2c3D4e5F6g7H8i9J0k",
  "returnUrl": null
}
```

### 前端代码示例

```javascript
wx.login({
  success: (res) => {
    wx.request({
      url: 'https://你的域名/api/TokenAuth/WxOpenSilentAuthenticate',
      method: 'POST',
      data: { code: res.code },
      success: (r) => {
        const data = r.data.result;
        if (data.shouldBindingUser) {
          // 没绑过，展示手机号授权按钮
          this.setData({ needPhoneLogin: true });
        } else {
          wx.setStorageSync('token', data.accessToken);
        }
      },
    });
  },
});
```

## 二、手机号登录

### 接口信息

| 项目         | 说明                                          |
| ------------ | --------------------------------------------- |
| 接口地址     | `POST /api/TokenAuth/WxOpenPhoneAuthenticate` |
| 请求方式     | POST                                          |
| Content-Type | application/json                              |
| 是否需要认证 | 否                                            |

### 请求参数（WxOpenPhoneLoginModel）

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| code | string | 是 | 手机号快速验证组件的动态令牌，取自 `bindgetphonenumber` 回调里的 `e.detail.code`。有效期 5 分钟且只能用一次 |
| loginCode | string | 否 | `wx.login()` 返回的 code。传了就把 openid/unionid 绑到账号上，之后可以静默登录；**强烈建议传** |
| returnUrl | string | 否 | 登录后跳转地址，原样回显 |

> `code` 和 `loginCode` 是两套完全独立的令牌，微信不接受交叉使用，不要传混。

### 请求示例

```json
{
  "code": "e8f7d6c5b4a3928170",
  "loginCode": "0a1B2c3D4e5F6g7H8i9J0k",
  "returnUrl": null
}
```

### 前端代码示例

```html
<button open-type="getPhoneNumber" bindgetphonenumber="onGetPhone">
  手机号一键登录
</button>
```

```javascript
onGetPhone(e) {
  if (!e.detail.code) return   // 用户点了拒绝
  wx.login({
    success: (res) => {
      wx.request({
        url: 'https://你的域名/api/TokenAuth/WxOpenPhoneAuthenticate',
        method: 'POST',
        data: { code: e.detail.code, loginCode: res.code },
        success: (r) => {
          wx.setStorageSync('token', r.data.result.accessToken)
        }
      })
    }
  })
}
```

## 三、响应参数（两个接口共用 WeixinAuthenticateResultModel）

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| shouldBindingUser | bool | 是否还需要走手机号登录。静默登录没查到绑定关系时为 `true`，此时下面的 token 字段全为空 |
| accessToken | string | 登录 Token（JWT） |
| refreshToken | string | 刷新 Token |
| encryptedAccessToken | string | 加密后的 AccessToken |
| expireInSeconds | int | Token 过期时间（秒） |
| userId | long | 用户 ID |
| nickName | string | 用户昵称 |
| loginProvider | string | 登录服务商，固定为 `WeappOpenId` |
| weappOpenId | string | 微信 openid。手机号登录时只有传了 `loginCode` 才有值 |
| weChatUnionId | string | 微信 unionid。小程序未绑定开放平台时为 null |
| avatar | string | 头像，当前恒为 null |
| waitingForActivation | bool | 等待激活，当前恒为 false |
| returnUrl | string | 原样回显请求里的 returnUrl |
| inviteUserId | long? | 邀请人 ID，当前恒为 null |

## 四、错误响应

| 场景 | 错误信息 |
| --- | --- |
| 未传 code | 请先授权手机号 / 请重新进入小程序 |
| code 超过 5 分钟或被重复消费 | 手机号授权已失效，请重新点击授权 |
| `wx.login` 的 code 失效 | 微信登录凭证已失效，请重新进入小程序 |
| 手机号在系统中没有对应账号 | 手机号 138\*\*\*\*8000 尚未开通账号，请联系管理员 |
| 账号被停用 | 您的账号已暂停使用，请联系管理员处理 |
| 后端未登记小程序凭据 | 系统未配置小程序的微信应用，请先在微信凭据表中登记 AppId/AppSecret |
| 手机号来源校验不通过 | 手机号来源校验失败，请从正规途径进入小程序 |
| 微信侧其它错误 | 获取手机号失败(错误码): 微信返回的错误描述 |

### 错误响应示例

```json
{
  "result": null,
  "targetUrl": null,
  "success": false,
  "error": {
    "code": 0,
    "message": "手机号 138****8000 尚未开通账号，请联系管理员",
    "details": null,
    "validationErrors": null
  },
  "unAuthorizedRequest": false
}
```

## 五、注意事项

1. **租户固定为 1**，前端不需要也不能传租户 id / 租户编码，服务端写死。
2. **不做自动注册**。手机号必须先由管理员在系统里建好账号，否则登录会被拒绝。
3. **用户换手机号后**，需要重新走一次手机号登录来更新绑定关系；旧的 openid 绑定会被自动清理。
4. 拿到 `accessToken` 后，后续请求在 Header 里带 `Authorization: Bearer {accessToken}`。
