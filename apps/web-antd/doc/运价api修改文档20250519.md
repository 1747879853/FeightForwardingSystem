# 变更一：开船日/开船日周几改为子表 + 新增约号字段

**变更时间**: 2026-05-19 13:25:39

---

## 一、变更概述

本次变更涉及两项核心改动：

1. **开船日和开船日周几从主表标量字段改为子表（一对多）**
   - 原 `SeFreiPrice` 主表上的 `ETD`（DateTime?）、`ETDDayOfWeek`（DayOfWeek?）、`ETDDayTime`（TimeSpan?）三个标量字段已移除
   - 新增两张子表 `SeFreiPriceETD`（开船日）和 `SeFreiPriceETDDay`（开船日周几），与主表为一对多关系（0到多条）
   - 编辑时采用**删除重建**策略

2. **新增约号（ContractNo）字段**
   - 主表新增 `ContractNo`（string，最大128字符）字段
   - 列表查询支持根据约号**模糊搜索**

# 变更二：SeFreiPriceFee 新增 PriceFeeType 和 Price 字段

**变更时间**: 2026-05-19 15:23:03

---

## 一、修改概述

`SeFreiPriceFee`（运价费用）表新增了两个字段：

- **PriceFeeType**（附加费计费方式）：枚举类型，可空。值为 `0=Ctn(按集装箱)`、`1=Order(按票)`。
- **Price**（价格）：`decimal?`，可空。当 PriceFeeType 不等于 Ctn 时存储固定价格。

### 业务逻辑

费用支持两种计费模式：

1. **按集装箱计费模式**（PriceFeeType == Ctn）：Price 必须为空，由 SeFreiPriceCtnFees 提供各箱型对应的价格。
2. **固定计费模式**（PriceFeeType != Ctn，如 Order 按票）：使用 Price 字段记录固定价格，不允许填写箱型费用（SeFreiPriceCtnFees）。

---

## 二、数据库表变动

### App_SeFreiPriceFees 表新增字段

| 字段名 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| PriceFeeType | int | 否 | 附加费计费方式枚举（0=Ctn按集装箱, 1=Order按票） |
| Price | decimal(10,2)? | 是 | 价格，PriceFeeType!=Ctn时有值 |

### PriceFeeType 枚举

| 值  | 名称  | 说明     |
| --- | ----- | -------- |
| 0   | Ctn   | 按集装箱 |
| 1   | Order | 按票     |

---

## 三、DTO 变动

### 3.1 SeFreiPriceFeeAddDto（新建费用输入）

新增字段：

| 字段         | 类型         | 说明                          |
| ------------ | ------------ | ----------------------------- |
| PriceFeeType | PriceFeeType | 附加费计费方式（必填）        |
| Price        | decimal?     | 价格，PriceFeeType!=Ctn时必填 |

### 3.2 SeFreiPriceFeeEditDto（编辑费用输入）

新增字段：

| 字段         | 类型         | 说明                          |
| ------------ | ------------ | ----------------------------- |
| PriceFeeType | PriceFeeType | 附加费计费方式（必填）        |
| Price        | decimal?     | 价格，PriceFeeType!=Ctn时必填 |

### 3.3 SeFreiPriceFeeOutDto（费用输出）

新增字段：

| 字段         | 类型         | 说明                          |
| ------------ | ------------ | ----------------------------- |
| PriceFeeType | PriceFeeType | 附加费计费方式                |
| Price        | decimal?     | 价格，PriceFeeType!=Ctn时有值 |

---

## 四、验证规则

在新增和编辑运价时，对每个费用项执行以下验证：

| PriceFeeType | Price | SeFreiPriceCtnFees | 结果 |
| --- | --- | --- | --- |
| Ctn(0) | 为空 | 有值 | ✅ 通过（按集装箱计费模式） |
| Ctn(0) | 为空 | 为空/null | ✅ 通过（无箱型费用的按集装箱计费） |
| Ctn(0) | 有值 | 任意 | ❌ "按集装箱计费时，价格必须为空" |
| Order(1) | 有值 | 为空/null | ✅ 通过（按票计费模式） |
| Order(1) | 无值 | 任意 | ❌ "非按集装箱计费时，价格不能为空" |
| Order(1) | 有值 | 有值 | ❌ "非按集装箱计费时，不能填写箱型费用" |

---

## 五、受影响的接口

### 5.1 AddAsync（新增运价）

- 费用实体创建时写入 `PriceFeeType` 和 `Price` 字段
- 新增验证：遍历每个费用输入，调用 `ValidatePriceFeeType` 校验

### 5.2 EditAsync（编辑运价）

- 费用实体更新和新增时写入 `PriceFeeType` 和 `Price` 字段
- 新增验证：遍历每个费用输入，调用 `ValidatePriceFeeTypeEdit` 校验

### 5.3 BatchEditAsync（批量编辑运价）

- 新增费用时写入 `PriceFeeType` 和 `Price` 字段
- 新增验证：遍历每个费用输入，调用 `ValidatePriceFeeType` 校验

### 5.4 DetailAsync / GetPagedListAsync（详情/列表）

- 输出的 `SeFreiPriceFeeOutDto` 新增返回 `PriceFeeType` 和 `Price` 字段

### 5.5 BatchAddSimpleAsync / BatchEditSimpleAsync（批量简单新增/编辑）

- 不涉及费用表操作，**无变动**

## 六、前端对接注意事项

1. **费用表单**需新增"计费方式"下拉选择（0=按集装箱(Ctn), 1=按票(Order)）
2. 当 priceFeeType 为 Ctn(0) 时：
   - 隐藏"价格"输入框（传 null）
   - 显示箱型费用列表区域
3. 当 priceFeeType 不为 Ctn（如 Order=1）时：
   - 显示"价格"输入框，必填
   - 隐藏/禁用箱型费用列表区域
4. 输出展示时根据 `priceFeeType` 的值决定显示固定价格还是箱型费用明细

# 变更三：PriceFeeType 改为必填项，逻辑调整

**变更时间**: 2026-05-19 15:41:06

---

## 一、修改概述

将 `SeFreiPriceFee` 的 `PriceFeeType` 字段从**可空**改为**必填**，并调整计费逻辑：

- **PriceFeeType 枚举**：`Ctn=0`（按集装箱计费）、`Order=1`（按票计费）
- **字段类型变更**：`PriceFeeType?` → `PriceFeeType`（非空，必填）
- **验证逻辑调整**：以 `PriceFeeType == Ctn` 作为按集装箱计费的判断条件，替代原来的"PriceFeeType 为空"判断

---

## 二、枚举变更

### PriceFeeType 枚举（调整前 vs 调整后）

| 调整前                             | 调整后                             |
| ---------------------------------- | ---------------------------------- |
| 可空（null=按集装箱, 0=Order按票） | 必填（0=Ctn按集装箱, 1=Order按票） |

---

## 三、实体变更

### SeFreiPriceFee 字段变更

| 字段         | 调整前                  | 调整后                 |
| ------------ | ----------------------- | ---------------------- |
| PriceFeeType | `PriceFeeType?`（可空） | `PriceFeeType`（必填） |

---

### 4.2 SeFreiPriceFeeEditDto

| 字段         | 调整前                  | 调整后                 |

### 4.3 SeFreiPriceFeeOutDto

| 字段         | 调整前                  | 调整后                 |
| ------------ | ----------------------- | ---------------------- |

---

## 五、验证规则变更

### 调整前

| 条件                | Price    | SeFreiPriceCtnFees | 结果         |
| ------------------- | -------- | ------------------ | ------------ |
| PriceFeeType 不为空 | 必须有值 | 不能有值           | 固定计费     |
| PriceFeeType 为空   | 必须为空 | 按需填写           | 按集装箱计费 |

### 调整后

| 条件 | Price | SeFreiPriceCtnFees | 结果 |
| --- | --- | --- | --- |
| PriceFeeType != Ctn（如 Order=1） | 必须有值 | 不能有值 | 固定计费（按票等） |
| PriceFeeType == Ctn（0） | 必须为空 | 按需填写 | 按集装箱计费 |

### 错误信息变更

| 调整前 | 调整后 |
| --- | --- |
| "选择了附加费计费方式时，价格不能为空" | "非按集装箱计费时，价格不能为空" |
| "选择了附加费计费方式时，不能填写箱型费用" | "非按集装箱计费时，不能填写箱型费用" |
| "未选择附加费计费方式时，价格必须为空" | "按集装箱计费时，价格必须为空" |
