# 2026-08-14 付费申请选费抽屉增加业务类型筛选

## 背景意图

`GetOrderFeeGroupAsync` 入参已支持 `BizType`，但添加费用抽屉未暴露该条件，海出/海进/空出费用混在一起不便筛选。

## 核心逻辑变更

- 搜索表单新增「业务类型」下拉：`0` 海运出口 / `1` 海运进口 / `2` 空运出口，可清空。
- 查询时将表单 `BizType` 写入 `GetOrderFeeGroupParams.BizType`；未选则不传，保持全业务混查。

## 避坑指南

- 清空业务类型后请求不应带 `BizType`（传 `undefined`），避免被当成 `0`（海运出口）。
- 港口展示仍按返回行的 `bizType` 读互斥业务简要对象，与筛选条件无关。
