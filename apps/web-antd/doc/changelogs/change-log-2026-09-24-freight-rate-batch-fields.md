# TAPD #1001004：运价批量新增/更新表格字段优化

## 背景

[TAPD #1161580498001001004](https://www.tapd.cn/61580498/bugtrace/bugs/view/1161580498001001004)：批量新增与更新页 Handsontable 字段展示与列配置优化。

## 改动

1. **开船日期**：写入/展示统一为 `YYYY-MM-DD`（不再显示带时区的 ISO 串）。
2. **有效期列**：`有效起始日期` → `有效日期`，`有效截止日期` → `截止日期`；列配置中成对绑定（同显隐、同固定、拖拽保持相邻），渲染前强制相邻。
3. **箱型价列**：去掉千分位；列宽约 78；有上期差额时单元格右上角显示红涨/绿跌徽标（批量更新从列表带入 `_priceChange`）。
4. **是否直达** → **直达**，列宽收窄；单元格「是」绿底绿字、「否」红底红字。
5. **船名航次**：新增文本列 `vesselVoyage`，随简单新增/编辑提交。后端对接见 [TAPD #1000174](./change-log-2026-09-26-freight-rate-vessel-voyage.md)。

## 验收

- 批量更新载入后开船日期为 `YYYY-MM-DD`。
- 列配置拖拽/显隐/固定「有效日期」时「截止日期」始终跟着；保存后不会拆开。
- 箱型成本/指导价无千分位，列更窄；有涨跌时见 ↑/↓ 徽标。
- 表头为「直达」；可录入「船名航次」。
- 直达列单元格「是」绿底绿字、「否」红底红字。
