# 海运出口编辑页服务项目流水线并入顶部操作栏

## 背景意图

编辑页基础信息区原先将服务项目流水线独立放在操作按钮下方，占用纵向空间且与 AI 识别等顶栏操作割裂。需将服务项目标题、配置入口与 Chevron 流水线收拢到同一顶栏行，并缩小节点尺寸以匹配按钮高度。

## 核心逻辑变更

1. **顶栏布局**：`content-section__actions` 改为左右分栏；左侧为「服务项目」标题 + `...` 配置入口 + 内联流水线，右侧保留 AI 识别、打印、取消、保存。
2. **配置入口**：原「配置服务」链接改为 `...` 文字按钮，悬停 Tooltip 提示「配置服务」，点击仍调用 `openServiceTypeModal`。
3. **流水线内联**：移除独立 `biz-block--service` 卡片容器，流水线使用 `service-pipeline--inline` 样式（无边框/阴影），节点高度约 26px，宽度 52–88px，支持横向滚动。
4. **空态紧凑化**：未选起运港、无服务配置等 Empty 在顶栏内仅展示文字描述，隐藏插图。

## 避坑指南

- 流水线与操作按钮共用 `form.vue` 嵌入模式，新建页若需同款布局须单独评估（当前仅编辑顶栏结构变更）。
- `...` 配置按钮受 `showServiceItemContent` 控制，与原先「配置服务」显示条件一致。
- Chevron 紧凑样式挂在 `.service-pipeline--inline` 下，勿直接改全局 `.chevron-step` 以免影响其他潜在复用场景。
