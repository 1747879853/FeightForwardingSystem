# 收费结算列表与按费用明细补金额

## 背景意图

收费结算要同时看清本次到账、按汇率折出的原始金额，以及两者的差额。按发票结算还要在列表上认出是哪张开出；按费用结算要在明细上看到汇率和折算结果。

## 核心逻辑变更

- 收费结算列表增加「发票开出」列。按发票结算展示开出单号，有发票号时写成「开出单号 / 发票号」；按费用结算显示「-」。
- 列表和两种详情里，差值不为 0 时用橙色标出。空值和 0 不标。
- 按费用详情的汇率行旁边显示该币别原币净额（应收为正、应付为负）。
- 按费用明细增加汇率、原始结算金额。本单行按当前录入的汇率现场计算；同一流水下其他核销单的行用接口已经算好的值。

## 避坑指南

- 原始结算金额与本次结算金额同号，应付在汇总成整单时才取负。不要把明细行直接按收付取负后再展示。
- 列表的 `invoiceIssues` 只在按发票结算时有值。不要用它判断按费用结算有没有明细。
- 费用上的币别对象可能没有 id，只有代码。同币别要能按代码认成汇率 1，明细行还要回退到接口已经算好的汇率和原始结算金额，否则详情会把有值的格子显示成「-」。
