# 船期查询按周班只显示一个星期，同日按最近离港排

## 背景意图

操作扫方案时，「按周班」应对齐「周几开的产品」。卡片却把组内全部 `routeEtd` 列成「周一、周二…周日」，看起来不像按星期排；同一天里又按共舱名字母序，找不到谁先开。

## 核心逻辑变更

- 卡片星期只写组内计划班期众数（与排序键 `departureDay` 相同），不再列出全部星期。改期班次仍在展开后的班次表里看。
- 「按周班」仍是星期一 → 星期日；同一天改为按最近离港升序，字母序只作最后平票。
- 分组键未改。

## 避坑指南

- 不要再把 `formatGroupWeekdays` 做成去重后的星期清单。那会让「按周班」看起来没在按周几排。
- 众数仍来自计划班期 `routeEtd`，可能和最近一班的实际星期不一致；订舱看右侧最近离港/截关，不要把卡片星期当成下一班开航日。
