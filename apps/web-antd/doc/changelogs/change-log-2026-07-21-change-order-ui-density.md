# 更改单页面信息密度与状态反馈优化

- 日期：2026-07-21
- 类型：Feature / UX 优化
- 影响页面：海运出口 → 编辑器 → 更改单页签（`sea-export-admin/changeOrder`）

## 背景意图

上一轮工作流重构后，页面结构已清晰（选择 → 编辑基本信息 → 编辑应收/应付 → 保存），但仍存在“固定表格高度造成大面积空白、利润结果不即时可见、行编辑辨识度低、保存状态缺少完成反馈”等体验问题。本轮聚焦空间利用率、表格编辑体验与状态反馈。

## 核心逻辑变更

1. **表格自适应高度**
   - 费用表（`orderFee/modules/order-fee-table.vue`）在 `mode==='changeOrder'` 时 `height:'auto'`、`minHeight:180`、`maxHeight:420`，按行数撑开、超出内部滚动。
   - 更改单列表（`changeOrder/table.vue`）改为 `height:'auto'`、`minHeight:100`、`maxHeight:220`，1 条记录不再占半屏。

2. **利润汇总栏常驻可见**
   - `.profit-summary` 保持 sticky 底部；新增“原币”分币种展示（仅非本位币），本位币合计始终展示应收/应付/利润/利润率。
   - 汇率缺失时给出明确文案提示，不再静默显示 0.00。

3. **保存状态闭环**
   - 详情标题状态链：`草稿` / `未锁定|已锁定` / `正在保存…` / `有未保存修改` / `已保存 · HH:mm`。
   - 新增 `canSaveChangeOrder`（新建草稿或有未保存修改且未锁定才可保存）；无修改时按钮禁用并 Tooltip 提示“当前没有需要保存的修改”。
   - 校验失败保留用户输入并聚焦“更改原因”字段（`showReasonError` + Form.Item 校验态）。

4. **压缩重复标题**
   - 更改单模式下去除费用表内“应收/应付费用”标题，工具栏直接置于页签内容顶部。
   - 页签费用条数改用中性色 `Badge`（`show-zero`）。

5. **更改单列表精简列**
   - 仅保留会计期间、更改原因、备注、状态（已锁定/未锁定 Tag）、最后修改时间；移除锁定人/锁定时间/解锁人/创建时间等低频列。
   - 选中行改为左侧 3px 蓝色标记 + 浅蓝底，替代整行铺蓝；未选中记录隐藏删除按钮。

6. **基本信息响应式栅格 + 常用原因补全**
   - 三列栅格（会计期间 180px / 更改原因 minmax(320px,1.4fr) / 备注 minmax(280px,1fr)），窄屏降为两列、备注独占整行。
   - 更改原因标签加粗突出；常用原因补充“供应商补费”“其他”。

7. **行编辑可读性**
   - 更改单费用表可编辑单元格增加浅底色，占位符加深，与只读结果区分。

## 避坑指南

- VXE Grid 自适应需同时设置 `height:'auto'` 与 `minHeight/maxHeight`，仅设 `maxHeight` 在少行时仍会塌陷或留白。
- 费用表为主单/更改单共用组件，所有本轮样式与标题调整均以 `props.mode === 'changeOrder'` 收敛，避免污染主单费用表。
- `Badge` 默认红色告警色，费用计数需用中性 `number-style` 覆盖，避免误读为异常提醒。
