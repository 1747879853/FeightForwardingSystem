# 费用录入订单信息卡分区样式

## 背景意图

费用录入左侧「订单信息」原先是扁平 label:value 列表，字段多时密、乱、无主次。需要分区层次与重点字段强调，且三模块（海出/海进/空出）共用同一页。

## 核心逻辑变更

- 新增 `display-field-groups.ts`：按单号 / 船期 / 航线 / 客商 / 节点 / 货量分组，并标记 emphasis。
- `OrderFeePage`：按组渲染；标签上、值下；主提单/主运单等重点字段放大加品牌色；空值弱化；卡片头与分组分隔线整理。
- 字段可见性与用户配置顺序不变，仅展示结构变化。

## 避坑指南

- 新增展示字段时记得在 `DISPLAY_FIELD_META` 登记分组，否则会落入「其它」。
- 勿把分组写进 localStorage 配置；分组是展示元数据，与用户勾选解耦。
