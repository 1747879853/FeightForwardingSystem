# 空运出口空港选中回显三字码、备注回填英文名

## 背景意图

- 航段起运地 / 中转地 / 目的地原先选中后按「三字码/中文名」整段回显。
- 录入习惯是选择框只看 IATA 三字码，英文全称落到下方备注，方便单证使用且仍可手改。

## 核心逻辑变更

- `AirPortSelect` 的 `labelKey` 改为 `iataCode`，选中后输入框只显示三字码。
- 新增 `formatAirPortRemark`，选中后把备注回填为机场英文名称；清空空港时备注一并清空。
- 列表列改用 `formatAirPortLabel` 展示「三字码/英文名」，不跟表单回显绑死。

## 避坑指南

- 已保存的旧备注不会自动改写，只有重新选择空港才会按英文名回填。
- 详情回显必须带上 `iataCode` 与 `enName`；缺三字码时选择框不要回退中文名。
