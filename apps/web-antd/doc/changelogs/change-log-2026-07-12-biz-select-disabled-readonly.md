# biz-select 禁用态统一改为只读文本外观

## 背景意图

业务表单进入不可编辑状态后，`biz-select` 原先仍显示灰色边框、下拉箭头和低对比度文字，容易让用户误认为控件仍可操作，也不利于阅读已选内容。

## 核心逻辑变更

- 为 `biz-select` 下的 Select、分页 Select 和地区 Cascader 根节点统一增加 `biz-select` 标识。
- 新增全局只读样式：整体 `disabled` 时移除边框、背景、阴影、下拉箭头、清除按钮和搜索输入。
- 恢复禁用态已选值的正常前景色并在容器内垂直居中，多选值去除标签背景与边框。
- 保留原控件和异步选项加载流程，使客户、港口、船公司、地区等组件继续按业务名称回显，避免直接显示 ID。

## 避坑指南

- `disabled` 仍表示不可交互，本次只改变视觉呈现，不应使用该样式代替权限或表单状态控制。
- 新增 `biz-select` 组件时，底层 `Select`、`ApiComponent` 或 `Cascader` 根节点必须带上 `biz-select` 类名。
- 不要在禁用态直接用 `modelValue` 渲染文本；分页组件的值通常是 ID，应继续依赖现有 options、selectedItems 或详情接口解析名称。
