# 海运进口按海运出口版式重建表单与列表

## 背景意图

海运进口原先是过时的出口拷贝，字段与布局均未按进口接口落地。需要按海运出口的表单骨架重建进口列表、新建/编辑工作台，并保留进口特有字段与日期推算逻辑。

## 核心逻辑变更

- 重写 `sea-import-admin` API/DTO，路由权限改为 `Admin.SeaImport`；新建组件指向 `basic-info-form/form.vue`。
- 表单版式对齐出口：`content-section` + 右侧干系人面板 + `form.css` 流程条栅格；船期为到港→换单→提货→报关→转站→箱使。
- 转站日期、箱使日期只读文本（`readonly` 输入框），由到港日期 / 免箱期自动推算；免箱期挂在船期标题旁。
- 原产国挪到基础信息「运输条款」之后；净重合计跟随箱型净重求和，可二次手改。
- 唛头/货描高度通过 `ResizeObserver` 与右侧件重尺（含体积 CBM）底对齐。

## 避坑指南

- 转站/箱使在表单里存 `YYYY-MM-DD` 字符串，不要用 `DatePicker`/`dayjs` 对象回填，否则只读文本会显示异常。
- 详情回填期间需挂起净重自动求和，避免覆盖后端已存的 `totalNetWeight`。
- `favicon.png` 若工作区有无关改动，勿与本功能混提。
