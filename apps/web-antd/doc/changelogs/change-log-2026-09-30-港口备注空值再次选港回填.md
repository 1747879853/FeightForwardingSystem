# 港口备注为空时再次选中同一港口会回填

## 背景意图

交货地（以及收货地、起运港等）已经选中，但 `deliverPortRemark` 等备注是空的。用户再搜索并点同一个港口，备注仍然不会出现。选港回填只挂在下拉的 `change` 上，而 Ant Design Select 在值没有变化时不会触发 `change`。

## 核心逻辑变更

`PortSelect` 额外监听 `select`。本次点击如果已经走过 `change`（港口换了）就不再补发；值没变时补发一次 `change`，并带上 `sameValueReselect`。选项上没有 `raw` 时，从当前下拉缓存里按 id 再取一次。

海运出口新建/编辑、列表批量修改、业务联系单、海运进口收到这个标记后：备注为空才按 `PORTNAME, COUNTRYENNAME` 回填；备注已有内容则保留。换成另一个港口时仍覆盖备注。再次点选同一起运港不会重跑服务项目联动。

## 避坑指南

不能靠「表单里的港口 id 是否等于刚选的 id」判断是不是同港重选。`change` 触发时 v-model 已经写成新值，两边总是相等。同港重选必须走 `select`，并用标记和 `change` 去重，避免一次点击把备注写两遍。
