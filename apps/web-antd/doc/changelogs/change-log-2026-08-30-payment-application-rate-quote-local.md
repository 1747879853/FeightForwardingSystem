# 背景意图

指定结算币别为 RMB、费用为 USD 时，汇率表已有「USD 兑 RMB」就够了，不需要再维护或推算「RMB 兑 RMB」。预填应完全按汇率资料：维护了就填入，没维护就留空。付费申请按**当天**有效期匹配，不跟业务联系单一样用开船日。

# 核心逻辑变更

- `peekQuotedExchangeRate(费用币别, 应付, 结算币别)`：只匹配 `currencyId` + `localCurrencyId`（结算币）+ **今天**在有效期内，取 `crValue`。
- 不再交叉相除，不再把结算币/公司本位币兜底为 1，**不按开船日**。
- 业务联系单费用行仍按 ETD 匹配，互不影响。

# 避坑指南

- 结算 EUR 时不会拿 USD 兑 RMB 的 8 来填；必须有 USD 兑 EUR 的资料。
- 今天不在有效期内视为未维护，留空；不要用费用开船日去对有效期。
