# 全局字体统一配置（Web AntD）

## 背景意图

- 当前系统页面与 Ant Design 组件字体来源不一致，可能导致不同区域字形观感不统一。
- 需要提供统一的全局字体栈，保证中文优先展示与跨平台可回退。

## 核心逻辑变更

- 新增 `src/global-font.css`，在 `:root`、`body`、`#app` 层面统一 `font-family`。
- 在 `src/bootstrap.ts` 引入全局字体样式，确保应用初始化时即生效。
- 在 `src/app.vue` 的 `ConfigProvider` 主题 token 中注入 `fontFamily`，覆盖 AntD 组件默认字体来源，保证组件与业务文本一致。

## 避坑指南

- 仅设置页面根节点字体不一定能覆盖第三方组件，组件库场景建议同步设置主题 token。
- 字体栈应按“中文优先 -> 英文回退 -> 通用 sans-serif”排序，避免中文环境下回退到不理想字体。
- 若后续接入自定义 WebFont，建议保留当前系统字体回退链，避免首屏字体闪动影响可读性。
