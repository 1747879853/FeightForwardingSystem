# 2026-08-24 分单 Tab 按 Figma 改为页内工作台

## 背景意图

按 [Figma 分单稿](https://www.figma.com/design/6Fp1XCtTc0rfw2hLtZCOCn/Untitled?node-id=24-654) 把海出编辑「分单」从列表+弹窗改成页内多提单工作台，版式对齐稿面三块白卡：主信息（收发通 + 提单条款 + 装箱明细）、船期与港口、货物明细。

## 核心逻辑变更

- 顶栏用分提单号胶囊切换已保存分单；激活态蓝底 `#3389eb` 15% 透明，未激活灰底 `#eff1f5`。蓝色「+」开新草稿（稿面 plus SVG）。右侧「删除 / 打印 / 保存」。
- 主卡左列：Shipper / Consignee 为标签+下拉+多行地址，标签靠左对齐；Notify Party 与第二通知人点选切换（激活标签蓝色），第二通知人名称与内容仍只读主单。
- 主卡右列两列栅格：主提单号只读、分提单号可编、签单方式、提单份数（主单 `noBillEnum/copyNoBillEnum` 显示为 `3/3`）、运输条款（稿面文案「运输状态」）、付费方式（稿面文案「付款方式」）、代理下拉及代理地址；上述 label 靠左对齐。装箱明细表列：序号、箱型、箱号、封号、件数、包装、重量、尺码、箱皮重、备注。
- 船期与港口卡：标题用稿面 `◉`（同心圆，非实心点）；ETD / 预抵日期 / 船名 / 船次，以及收货地、起运港、目的港、交货地（短框代码 + 长框名称），全部只读自主单，不提交。
- 货物明细卡：唛头、货描大文本，右侧件数 / 包装 / 毛重KGS / 体积CBM。
- **新增默认**仍只带主单条款与装箱；装箱标题栏「读入主单」整包覆盖收发通/代理/货描。切换分单胶囊若有未保存修改会确认丢弃。
- 打印复用海出详情 `PrintJsonType=0` + `bizType=0`，与基础信息顶栏同一套模板弹窗。

## 避坑指南

- 分单 DTO 没有第二通知人、提单份数、船期港口字段，这些只能展示主单，保存时不要写进 `AddAsync`/`EditAsync`。
- 稿面装箱表混入了费用行图层，以可见列名为准，不要按费用列实现。
- 加号图标来自 Figma `download_assets`，不要改成手绘 SVG。
- 稿面输入高 20px、字号 9px，管理端用 Ant `size="small"`（约 24px）和 12px 标签，避免无法点选。
