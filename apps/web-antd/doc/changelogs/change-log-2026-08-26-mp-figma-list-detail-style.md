# 小程序列表/详情按 Figma 还原视觉

## 背景意图

监装师傅端第一期页面结构已通，但色值、字号、圆角与插图仍是近似稿。按 Figma「检索条件」列表与「检索条件-详情」把内部首页和工单详情对齐到 750rpx 设计稿。

## 核心逻辑变更

- 设计 token 改为稿面色：主色 `#327aff`、页面底 `#eceef6`、标题 `#1d1a27`、辅助字 `#6e7b83`。
- 列表：顶部蓝渐变、口号渐变字、3D 插图压在分段 Tab 右侧、白底卡片 28rpx 圆角、待接单橙徽标、页脚日期加粗；检索改为右侧「检索条件」抽屉。
- 详情：同套渐变顶栏、蓝条标题、胶囊标签；箱列表合并为「监装处理」入口（状态 + 张数），面板内切换完成并分拍照/相册传图。认领/拒接/保存操作条保留（稿未画底栏按钮）。
- 图标与插图改用 Figma 导出 PNG；底栏已分选中/未选中图。微信原生 tabBar 无法做成稿里的悬浮胶囊，仅对齐颜色与图标。

## 避坑指南

- 稿宽 750，尺寸按 1:1 写 rpx；不要把 Figma 的 38px 当成 76rpx。
- 插图必须用带透明通道的原图，不要用带浅底的整节点导出，否则会盖住渐变。
- 高分辨率原图各 1.5MB+，会撑爆小程序主包，列表只用约 300px 宽的 2x PNG。
- 微信 `tabBar` 只要 PNG；选中/未选中稿只给了「内部首页」蓝态，其余 Tab 仍共用一张。
