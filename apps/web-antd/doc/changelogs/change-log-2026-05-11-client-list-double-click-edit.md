# 变更记录：客户列表支持双击行进入编辑页

## 背景意图

- 客户列表已改为“顶部统一操作 + 勾选行”后，编辑入口只剩顶部按钮，单条快速进入编辑的效率下降。
- 需要补充与项目列表规范一致的双击交互，提升高频编辑效率。

## 核心技术决策 / 逻辑变更

- 在 `apps/web-antd/src/views/client/list.vue` 新增 `cellDblclick` 事件处理器。
- 双击普通数据单元格时，直接调用现有 `handleEdit(row)` 跳转客户编辑页。
- 对 checkbox 列做过滤，双击选择列不会触发跳转，避免误跳。

## 避坑指南（Gotchas & Constraints）

- 双击事件应复用既有编辑跳转方法，避免出现两套路由规则。
- 若后续新增可编辑单元格，需评估双击进入编辑与单元格交互是否冲突。
- 勾选列必须排除在双击跳转之外，否则会影响多选操作稳定性。
