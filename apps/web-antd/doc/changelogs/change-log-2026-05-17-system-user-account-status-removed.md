# 变更记录：人员管理移除账号状态展示

## 背景意图

- 人员管理当前同时展示了「账号状态」与「账号启用」，业务判断是否可使用系统只依赖「账号启用」。
- 双状态并存容易增加理解成本，也会让列表筛选与维护口径不一致。

## 核心技术决策/逻辑变更

- 调整 `src/views/system/user/data.ts`：
  - 移除人员管理列表搜索中的 `Status`（账号状态）筛选项。
  - 移除人员管理列表中的 `status`（账号状态）展示列，仅保留 `enable`（账号启用）列。
  - 表单中的 `status` 字段改为隐藏默认值 `UserStatus.Passed`，避免影响后端 DTO 提交兼容性。

## 避坑指南（Gotchas & Constraints）

- 本次仅移除前端展示与筛选，不涉及后端状态枚举与接口字段删除，避免影响旧接口兼容。
- 若后续后端收敛为单状态模型，可再评估移除 `status` 入参并同步调整 DTO 与数据库映射。
