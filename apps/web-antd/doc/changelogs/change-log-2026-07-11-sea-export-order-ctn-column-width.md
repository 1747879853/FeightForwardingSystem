# 海运出口箱型箱量表格列宽优化

## 背景意图

新建/编辑页「箱型箱量」表格在横向空间紧张时，序号与箱型列偏宽、箱号与封号列偏窄，影响整体列分配与长箱号录入展示；需按业务字段长度重新分配列宽。

## 核心逻辑变更

- `order-ctn-table.vue` 列宽调整：序号 60→40px、箱型 120→76px；箱号 100→130px、封号 90→120px。
- 为序号、箱型、箱号、封号列补充 `order-ctn-table__*-col` 固定列宽样式，避免 `table-layout: fixed` 下被挤压。
- 箱型下拉 `min-w-[100px]` 改为 `min-w-0`，防止撑开箱型列；表格横向滚动宽度同步为 1108。

## 避坑指南

- 列宽同时维护 `tableColumns.width` 与 scoped CSS 的 `min/max-width`，否则 Ant Design Table 固定布局下可能出现表头与单元格不一致。
- 箱号标准格式约 11 位，封号亦可能较长，不宜再收窄箱号/封号列。
