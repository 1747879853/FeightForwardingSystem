# 编号规则配置卡片交互与实时预览

## 背景意图

编号规则子表原先使用固定列表格，固定字符串、长度、重置序号等字段与生成类型不匹配，易误配。需对齐后端 `generateEnum` 语义，并让用户在保存前直观看到编号拼接效果。

## 核心逻辑变更

1. **按类型显隐字段**：`text` 仅 Text(1)；`length` 仅 AutoNum(0)；`reset` 仅非 AutoNum，AutoNum 强制 `false`。
2. **卡片式规则行**：参考港口服务项配置，一行展示有效字段；标题为 `规则 #N · 类型名`。
3. **排序**：隐藏 `sortId` 输入，支持上移/下移，保存时按列表顺序写入 `0, 1, 2...`；预览按当前 card 顺序拼接。
4. **实时预览**：顶部展示编号样例（自增段以 1 示例）；缺少 AutoNum 时警告仍可保存但生成会失败。
5. **删除交互**：卡片悬浮显示删除图标；自增规则全局最多一条，其他行禁用 AutoNum 选项。

## 避坑指南

- 预览顺序以 UI 列表为准，不再读取行内 `sortId` 字段。
- 编辑加载时需先按后端 `sortId` 排序再渲染，避免与保存顺序不一致。
- 提交 payload 中仅向对应类型传递有效字段，避免无意义字段干扰后端存储。
