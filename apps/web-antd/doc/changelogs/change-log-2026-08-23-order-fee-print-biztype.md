# 背景意图

打印格式新增 `BizType` 后，应收/应付费用共用同一套 `PrintJsonType`（1000/1500）。拉模板列表若不传 `bizType`，会把三种业务的专用模板和通用模板混在一起。费用打印必须按当前票业务类型筛选。

# 核心逻辑变更

- 海运出口费用打印传 `bizType=0`，海运进口 `1`，空运出口 `2`。
- 更改单费用打印同样带上对应业务类型。
- 海运出口单据打印也补传 `bizType=0`（空运出口单据打印此前已传 `2`）。
- 列表接口按「相等或为空」匹配，结果里仍会包含不限业务类型的通用模板。
- `0` 是海运出口有效值，判空只用 `== null`。

# 避坑指南

- **不要漏传 `bizType`**：费用模板跨业务共用数据源，不传就无法按业务切开。
- 管理端与业务端对 `bizType` 都是「相等或为空」，不要期望「只看专用、不含通用」。
- 海出/海进/空出各有一份 `order-fee-table.vue` 与 `useOrderFeePrint.ts`，改打印入参要三处一起改。
