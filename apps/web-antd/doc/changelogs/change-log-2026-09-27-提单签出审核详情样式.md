# 提单签出审核详情样式

## 背景意图

签出审核详情原先用带边框的描述列表、默认页签和细边栏时间轴堆在一起，宽表和审批信息挤在同一视线里，阅读成本高。

## 核心逻辑变更

- 抽屉标题带出结算对象和批次状态；申请人、申请时间、提单数量和未收金额改成摘要条。未完成数量大于 0 时用金色，未收金额大于 0 时用红色。
- 六块依据留在左侧页签，页签显示条数。申请放单的通过、驳回放在浅底工具条里，已选张数靠右。
- 表格表头改浅灰，提单状态、审核状态、是否压单用浅色标签；日期只显示到日，金额右对齐并带人民币符号。
- 客户信息改为两列字段，空值显示「未维护」。审批流程改到右侧时间轴，按通过、驳回、待审核区分节点颜色。
- 审核接口、勾选范围和通过后驳回规则没有改。

## 避坑指南

抽屉内容在传送层里，背景色要写在 Drawer 的 `body-style` 上。表格用了自定义单元格后，日期和金额也要在同一个插槽里格式化，否则格子会空。

## 验证

本地打开真实审核批次：摘要四格对齐，未完成数量为金色、未收金额为红色；压单表状态标签和右侧审批时间轴并排。勾选两张后「已选 2 张」，通过和驳回按钮可用。客户信息空值显示「未维护」，最近交易只显示日期。
