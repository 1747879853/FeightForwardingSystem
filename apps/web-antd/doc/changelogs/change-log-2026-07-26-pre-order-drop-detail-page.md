# 业务联系单取消独立详情页，按状态显隐保存按钮

## 背景意图

独立纯展示详情页与编辑页双轨维护成本高，且禁用态表单体验差。改为统一走编辑页：控件不再按状态禁用，仅「录入/驳回」显示保存与提交审核。

## 核心逻辑变更

1. 删除 `detail.vue`；`/pre-order/:id/detail` 重定向到 `/edit`（兼容旧书签）。
2. 列表 / 审核中心 / 工作台一律进编辑页。
3. 编辑页去掉表单 `disabled` 同步与标题栏 Select 禁用；用 `canSave`（录入/驳回/新建）控制「保存」「提交审核」显隐。
4. 子表与服务面板不再传 `readonly`；不可保存时不做未保存拦截。

## 避坑指南

1. **待审核/通过仍可改界面值，但落不了库**：保存按钮隐藏，后端也不会接受业务态编辑；勿误以为前端禁用即权限。
2. **审核动作仍在编辑页**：撤回 / 通过 / 驳回按钮按状态显隐，与保存无关。
