# 集装箱信息新增柜型字段

## 背景意图

后端为箱型主数据新增 `cabinetType`，用于区分普柜与特种柜。前端需要在维护入口强制选择柜型，并让列表、查询及各业务接口类型能够读取该字段。

## 核心逻辑变更

- 箱型新增、编辑请求体补传必填 `cabinetType`，取值限定为 `0`（普柜）或 `1`（特种柜）。
- 箱型维护表单新增“柜型”下拉，默认普柜且不可清空；列表新增柜型标签列，查询区新增可清空的柜型筛选。
- 箱型详情、列表、运价完整对象及海运出口、海运进口、业务联系单、分单、派车、付费申请等简易对象类型补齐 `cabinetType`。
- 中英文文案同步增加柜型及枚举选项。

## 避坑指南

- `cabinetType` 是数值枚举，不能提交字符串 `"0"` / `"1"` 或其他值。
- 存量数据由后端默认按普柜返回；冻柜、开顶柜、框架柜、罐柜等特种柜仍需业务侧人工维护。
- 查询参数沿用当前接口封装的 PascalCase 口径，筛选字段为 `CabinetType`；请求体和响应对象字段为 camelCase 的 `cabinetType`。
