# 业务联系单收发通支持展开折叠（默认折叠）

## 背景意图

编辑页「收发通」占位较高，多数单据录入时未必先填；改为可折叠区块并默认折叠，优先露出基础信息与港口信息。

## 核心逻辑变更

- `editor.vue` 增加 `partyExpanded`（默认 `false`）
- 收发通改为带标题栏的 `content-section`：点击标题栏切换展开/收起；右侧提示「展开 / 收起」
- 表单区域用 `v-show` 控制，折叠时仍保留表单实例与已填值
- 去掉基础信息与收发通之间的 `flush-bottom` / `flush-top` 贴合样式（收发通已独立成带标题分区）

## 避坑指南

- 校验/保存仍走 `partyFormApi`，与折叠状态无关；折叠态下字段值仍会参与提交
- 勿用 `v-if` 替代 `v-show`，否则折叠再展开会丢未落库的本地输入
