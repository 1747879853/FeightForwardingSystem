# 小程序登录失效循环跳转修复

## 背景意图

进入体验版后持续报“当前用户没有登录到系统”。本地回归测试复现：401 只清理缓存 token，内存 authState.token 保留旧值，登录页 onShow 又跳回列表，触发下一轮未授权请求。

## 核心逻辑变更

- 抽出共享 auth-state，统一请求清理 token 时同步清除内存 token、个人信息与绑定标志。
- 已在登录页时不重复 reLaunch。
- 个人信息鉴权失败向登录调用方抛出，避免当作登录成功；普通资料加载错误仍可降级。
- 测试配置补充小程序 @ 路径解析，新增四项回归验证。

## 避坑指南

- 不能只移除本地存储，页面路由判断使用的是响应式内存状态。
- 首次 token 被服务器拒绝的原因尚未通过体验版实际响应确认，本次修复的是前端循环。
- 包需重新上传并设置体验版，源码修改不会自动更新微信中的已上传版本。

## 验证

小程序 22 项测试通过，失效 token 测试修复前失败、修复后通过。微信小程序构建通过。类型检查存在未改动的 paged-select-sheet 与 skew-tabs 组件错误，登录相关文件无报错。
