# 背景意图

TAPD #0145：海运出口 / 海运进口 / 空运出口编辑工作台要按**当时列表的筛选和排序**翻票。后端详情已返回 `previousId` / `nextId`，但必须带上与 `GetPagedListAsync` 同一套 Query；只传 `id` 时按可见全量 + 创建时间倒序算。

# 核心逻辑变更

- 三端列表每次查询把筛选和排序（去掉分页）写入品牌隔离的 `sessionStorage`。
- `DetailAsync` 自动带上这份 Query；`Keys` 等数组走 `repeat` 序列化。
- 工作台顶栏右侧增加「上一票 / 下一票」：Id 为空则禁用；点击 `push` 相邻票编辑页，未保存离开走现有脏检查。
- 基础信息 `loadEditData` 成功后 `emit('saved')`，把详情里的相邻 Id 回写到顶栏，避免切票时标题请求被取消后按钮一直灰着。

# 避坑指南

- 翻票只换当前票 `Id`，不要改记忆里的筛选和排序。
- 当前票已不在该检索结果里时，两条都是 `null`，两个按钮都禁用。
- `IsPrint=true` 不计算相邻 Id。
- 邻票定位走全量顺序、与当前页无关；后端算邻票可能要数秒，顶栏会等详情回来再亮。
- 业务联系单内嵌海出工作台不展示翻票按钮。
