# 背景意图

业务联系单新建/编辑页的「归属组织」「干系人」需与海运出口行为对齐：归属组织按销售所属组织选；选择委托单位后自动带出客户维护的干系人。

# 核心逻辑变更

1. **归属组织**：标题栏 `UserOrgSelect` 传入干系人「销售」的 `userId`；编辑回显用详情 `orgs` 路径作 `selectedItems` 兜底。
2. **委托单位 → 干系人**：`clientId` `onChange` 拉客户详情，按销售/客服/操作/单证的默认干系人回填；操作/单证/客服未绑定时兜底当前登录账号；商务等未维护角色保持原值。可编辑态用户主动切换时生效。

# 避坑指南

- 归属组织选项依赖已选销售；未选销售时下拉为空，保存仍会拦「请选择归属组织」。
- 干系人回填挂在 `ClientSelect` 的 `onChange` 上，详情 `setValues` 不会误触发；只读态直接 return。
- 客户干系人取「默认」优先，无默认取列表第一个；与海运出口 `applyClientDefaultOrderUsers` 同构。
