# TAPD #1000166：客户附件支持拖拽上传

## 背景

[TAPD #1161580498001000166](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000166)：客户管理附件按类型分卡片，原先只能点「上传」。需求说明若是公共组件则统一改成可拖拽；客户附件页是独立实现，海运出口同类卡片已支持拖到卡片上上传。

## 改动

客户详情「附件」页（`views/client/attachments/list.vue`）：可编辑时把文件拖到对应类型卡片上即上传，悬停时卡片用主题色虚线高亮。空卡片文案改为「点击或拖拽上传」。账期附件卡片只读，不接收拖拽。

## 验收

- 客户详情 → 附件，把文件拖到「合同 / 营业执照」等卡片上，松手后出现在该类型下。
- 一次拖入多个文件会依次上传。
- 拖拽经过卡片时边框变为虚线；只读或无编辑权限时不能拖入。
