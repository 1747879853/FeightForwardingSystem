# TAPD #1000174：运价船名航次字段对接

## 背景

[TAPD 需求 #1161580498001000174](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000174)：后端已支持 `SeFreiPrice.VesselVoyage` 持久化，前端对接并回显。与航程 `voyage` 不是同一列。

字段：`vesselVoyage`（string，可空，最长 100）。

## 改动

1. **列表**：增加「船名航次」列（默认可见），排序字段 `VesselVoyage`。
2. **单条新增/编辑**：表单航程后增加船名航次；详情回显；提交空值传 `null`（编辑可清空）。
3. **批量新增/更新 Tab**：沿用既有列；简单提交空值传 `null`。
4. **批量更改弹窗**：增加船名航次；空白不覆盖，有内容才更新（对齐 BatchEdit 契约）。
5. API 注释去掉「待后端落库」表述。

## 验收

- 简单新增/编辑提交后，列表与详情可见同一 `vesselVoyage`。
- 完整编辑、批量简单编辑、批量更改同样提交并回显。
- 不把船名航次写入航程 `voyage`。
