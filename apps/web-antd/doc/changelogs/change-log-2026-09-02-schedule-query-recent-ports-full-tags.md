# 船期查询最近记录不缓存日期，筛选标签完整展示

## 背景意图

最近查询只需要记住航线两端港口，离港日每次现选。船公司、码头多选后被收成 `+2`，看不清选了谁。

## 核心逻辑变更

- `ffs.schedule-query.recent` 只存起运港、目的港（中英文名和五字码）。点胶囊沿用查询条上当前日期，不再写回缓存里的 ETD。
- 读旧缓存时丢掉 `etd` 字段。
- 船公司、起运码头、目的码头去掉 `max-tag-count="responsive"`，选中项全部展示，允许换行。

## 避坑指南

- 不要再给这些筛选下拉加 `max-tag-count="responsive"`，那就是 `+N` 折叠的来源。
- 不要把 `ghost-select` 的 `max-width` 锁死在 160px，标签会被挤掉。
