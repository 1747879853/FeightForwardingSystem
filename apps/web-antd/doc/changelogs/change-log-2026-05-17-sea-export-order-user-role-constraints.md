# 海运出口干系人角色约束修复（固定角色不可删不可重）

## 背景意图

海运出口新建页在默认渲染销售/商务/操作/客服/单证后，仍可通过悬浮看到删除按钮，且继续“添加角色”会产生重复角色，不符合干系人固定分工约束。需要将角色约束落到页面实际入口 `sea-exports/create` 对应组件。

## 核心逻辑变更

1. 在 `src/views/sea-export-admin/form.vue` 增加固定角色集合与必填角色集合：
   - 固定角色：销售、商务、操作、客服、单证。
   - 必填角色：销售、操作。
2. 删除按钮改为按固定角色条件渲染：
   - 固定角色行不再渲染删除按钮，悬浮也不会出现删除入口。
   - 删除函数仍保留逻辑拦截，防止绕过 UI 直接调用。
3. 角色唯一性由“仅销售唯一”升级为“所有角色唯一”：
   - 角色下拉禁用已被其他行占用的角色。
   - 手工切换到重复角色会拦截并提示。
4. 新增角色逻辑改为“新增待选行 + 仅允许选择剩余角色”：
   - 点击“添加角色”后新增空白角色行，用户可在下拉中选择尚未占用的角色。
   - 当五个固定角色已齐全时，禁止继续新增并提示不可重复添加。
   - 仅禁用重复角色选项，不禁用角色下拉本身，避免编辑页缺角色情况下无法补录。
5. 提交前新增角色人员必填校验：
   - 在保留“销售必须且只能一个”的基础上，新增“销售、操作必须选择人员”。

## 避坑指南

- 固定角色约束必须同时覆盖 UI（按钮渲染/下拉状态）与函数层（删除/角色更新/新增），否则容易被边界交互绕过。
- 后续如果扩展角色类型，需同步维护固定角色集合和必填角色集合，避免出现“可编辑但不可提交”的校验割裂。
