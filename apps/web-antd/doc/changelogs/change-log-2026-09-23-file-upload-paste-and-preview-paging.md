# TAPD #1000170：文件上传支持粘贴，预览可翻页

## 背景

[TAPD #1161580498001000170](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000170)：上传区截图后 Ctrl+V 贴不上去；多个附件预览时不能翻到下一张。

## 改动

1. 公共上传（`FileUploadInput`）：鼠标停在上传区时，Ctrl+V 可粘贴截图或剪贴板文件，多个文件依次上传。拖拽区提示改为「支持多文件上传，可 Ctrl+V 粘贴截图」。
2. 公共预览（附件查看器）：打开时带上同一批附件，左右按钮和方向键可切换上一张 / 下一张，工具栏显示页码。付费结算「付费申请附件」和上传组件里的已传列表都会带上整批文件。

## 验收

- 付费结算附件区截图后，鼠标停在上传区按 Ctrl+V，文件出现在已上传列表。一次粘贴多张会依次上传。
- 已上传不少于 2 个文件时点开预览，左侧上一张、右侧下一张可切换，到头后对应按钮不可点。
