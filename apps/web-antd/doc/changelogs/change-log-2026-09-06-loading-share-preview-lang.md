# 2026-09-06 监装分享先预览再切中英文复制链接

## 背景意图

点「分享」原先直接复制中文链接。发给海外客户前没法确认页面长什么样，也不能出英文版。轨迹地图已经是「弹窗预览 + 中英切换 + 再复制」，监装分享对齐这套。

## 核心逻辑变更

- 监装 Tab「分享」改为打开预览弹窗，内嵌客户公开页（同一套组件，走公开详情接口）。
- 弹窗可切中文 / English。切换只改界面文案和即将复制的链接，不重新拉详情。
- 中文链接仍是 `mblNum` + `loadingOrderNum`。英文额外带 `lang=en`。客户打开后按 URL 语言展示，不跟后台账号语言。
- 公开页标签、状态、空态写在 `share-text.ts`。师傅英文名优先用 `enName`。

## 避坑指南

- **不要用 `$t` 做客户页文案。** 分享页免登录，系统语言可能是操作员的中文，海外客户打开仍会变成中文。
- **预览不要 iframe 整站。** 同一套 Vue 应用再 boot 一遍又慢又抢路由。弹窗直接挂 `page.vue`，`embedded` 时只认 props，不读当前编辑页的 query。
- **英文链接必须带 `lang=en`。** 中文不要写 `lang=zh`，缺省就是中文，和轨迹分享一致。
- **业务数据不会被翻译。** 品名、堆场、附件类型名、后端错误信息仍是接口原值。
