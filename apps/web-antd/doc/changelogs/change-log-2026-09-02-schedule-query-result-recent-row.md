# 船期查询方案统计与最近查询同一行

## 背景意图

有结果时「找到 N 个共舱方案，共 M 个班次」单独占一行，最近查询胶囊又占一行，把方案卡往下挤。对照稿是同一行：左统计、右最近航线。

## 核心逻辑变更

- 结果统计从方案列表里抽出来，和「最近查询」合成 `.result-toolbar`。
- 有方案时左侧写统计、右侧贴胶囊；未查询或只有历史时仍只显示胶囊。
- 统计出现后重新计算胶囊溢出，宽度不够仍直接藏掉，不出滚动条。

## 避坑指南

- 不要把统计再塞回 `scheme-board`，否则会重新变成两行。
- 胶囊容器用 `flex: 0 1 auto` 才能在右侧收紧；`flex: 1` 会把空白留在胶囊右边，看起来仍像两段。
