# 2026-07-25 业务联系单费用单位仅保留四项固定枚举

## 背景意图

费用单位若把「箱型名」（如 20GP）塞进下拉，详情回显时只有字符串、没有箱型字典注入，Select 无法稳定显示已选项。业务上联系单预估费用也只需按票/重量/体积/TEU 计价。

## 核心逻辑变更

- 单位下拉固定为 `票 / 重量 / 体积 / TEU`，不再拼接已选箱型名。
- 新增 `coercePreOrderFeeUnit`：别名归一后若不在四项白名单（含历史箱型名），一律落到「票」。
- 新增行默认单位「票」；费用代码默认「箱型/CTN」或非法单位时提示并改「票」。
- 去掉「应收 + 单位=箱型 → 带出卖价/箱量锁单价」逻辑，含税单价全程手填；箱型表仍仅供 TEU 累加。
- 详情回显与提交 payload 均对 `unit` 做 coerce，保证落库与回显一致。

## 避坑指南

1. 后端仍可按箱型名重算，但前端故意不开放该选项；不要为了「对齐后端全集」再把箱型名加回下拉。
2. 历史单据单位若是 20GP 等，打开编辑页会静默变成「票」并重算数量为 1，保存后覆盖原值。
