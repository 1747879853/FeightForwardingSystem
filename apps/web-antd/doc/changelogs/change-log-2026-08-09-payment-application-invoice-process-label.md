# 1. 背景意图 (Background)

TAPD #0734：添加费用抽屉「发票制作方式」文案需改为「发票方式」；未选时要有必填提示；费用明细「+ 添加费用」按钮不够醒目。

# 2. 核心逻辑变更 (Core Logic)

1. 申请单表单与添加费用抽屉文案统一为「发票方式」，标签旁增加红色 `*`。
2. 未选发票方式时：弹出 `message.warning('请选择发票方式')`；下拉/选项卡标红（不在控件旁插入行内错误文案，避免挤乱原布局）。
3. 费用明细「+ 添加费用」改为 `type="primary"`，并略加大字号与阴影，便于识别。

# 3. 避坑指南 (Pitfalls)

- 必填提示以顶部 toast 为主；勿在费用明细标题行旁再加一行错误文案，否则会改变原一行布局。
- 选中发票方式后需清掉 `invoiceProcessError`，否则控件会一直保持错误态。
