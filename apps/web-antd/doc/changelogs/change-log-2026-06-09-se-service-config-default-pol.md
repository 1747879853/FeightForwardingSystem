# 港口服务项配置支持默认港口配置

## 背景意图

港口数量多达数千个，无法为每个港口单独配置服务项。后端 `SeServiceConfigAdmin/EditAsync`（及 AddAsync）接口的 `polId` 字段允许为空，表示**默认港口配置**，供所有未单独配置的起运港复用。

## 核心逻辑变更

1. **表单校验**：移除起运港必填校验；清空起运港下拉后提交时 `polId` 传 `null`。
2. **列表展示**：`polId` 为空时显示「默认港口配置」，删除/提示文案同步使用该口径。
3. **类型定义**：`SeServiceConfigAddDto` / `EditDto` / `ListDto` / `DetailDto` 的 `polId` 改为可选。
4. **交互提示**：弹窗起运港字段增加占位符与说明文案，引导用户理解「不选 = 默认」。

## 避坑指南

- 编辑默认配置时详情 `polId` 可能为 `null`，前端不应再强制回显港口下拉选中项。
- 列表筛选仍通过 `PortSelect` 按具体港口过滤；查默认配置需依赖后端对空 `polId` 的筛选支持（或不传 `polId`）。
