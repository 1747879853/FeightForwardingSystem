# 提单数量卡图标样式

## 背景意图

提单列表顶部四个数量入口原先是纯文字按钮，标签和数字挤在一行，筛选选中态也只是整钮变蓝，待签出、超期未收和待我审核不好一眼区分。

## 核心逻辑变更

- 改为图标指标卡：全部提单、待签出、超期未收、待我审核各自带色块图标。
- 前三张仍切换列表筛选。选中时用该卡自己的颜色描边，待签出为青、超期未收为红，与列表状态色一致。
- 超期未收、待我审核数量大于 0 时，数字使用对应告警色。
- 待我审核仍跳转签出审核页，右侧增加跳转箭头，不参与列表筛选。

## 避坑指南

数量卡继续放在 `shrink-0` 行里，不要让卡片高度参与表格自动测高。筛选逻辑仍只认 `all` / `pending` / `overdue`，待我审核不写入 `cardFilter`。

## 验证

样式与点击筛选在提单列表页核对。
