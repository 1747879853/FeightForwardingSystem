# 付费申请费用明细按费用名称筛选应只显示命中费用

## 一、背景意图

编辑页底部费用明细筛选「费用名称」后，用户期望内层只看到该费用；实际仍展示同组其他费用行，筛选语义不完整。

## 二、核心逻辑变更

### 根因

`filteredOrderGroups` 对费用名/币别使用 `children.some(...)`，只决定**订单组是否保留**，未裁剪组内 `children`，故命中组仍展开显示全部费用。

### 修复

- 抽出纯函数 `filterOrderGroups`（`form-data.ts`）：费用名、币别条件会 `filter` 组内费用行；无命中行则丢弃该组；并按可见行重算「{币别}申请合计」。
- `form.vue` 改调该函数；组勾选状态改为基于 `filteredOrderGroups`，与当前可见行一致。
- 单测覆盖「同组多费用仅保留命中行 / 币别裁剪 / 无匹配返回空」。

## 三、避坑指南

- 嵌套表「外层筛组 + 内层筛行」不能只用 `.some()`；需要同时过滤 `children`。
- 裁剪 `children` 后务必同步外层动态金额列，否则合计与可见明细不一致。
