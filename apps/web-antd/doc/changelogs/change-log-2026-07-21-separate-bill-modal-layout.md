# 分单弹窗表单布局对齐截图（收发通 + 装箱 + 货物三栏）

## 背景意图

分单新增/编辑弹窗原先为四列平铺字段，收发通内容与下拉分离、装箱表沉底，录入动线与旧「分单系统」截图差异大。按截图密度重组弹窗，不改接口字段与保存语义。

## 核心逻辑变更

1. **上区左右分栏**：左侧发货人/收货人/通知人（下拉 + 大文本）；右侧分提单号/签单方式/运输条款/付费方式、目的港代理（下拉 + 文本）、装箱明细表。
2. **中区签单信息**：蓝条分区，签单日期 / 签单地点 / 付费地点三列。
3. **下区货物明细**：唛头 | 货物描述 | 件数/包装/毛重/体积 三栏。
4. **装箱操作**：增加/删除文案按钮；「更新合计」按箱行汇总回填件数、毛重、体积（包装取首个有值箱行）。
5. 弹窗加宽至 1280，正文区可滚动；文案键补充 `updateTotal` / `signingSection` / `cargoSection` 等。

## 避坑指南

- 截图中的主提单号、船期港口、第二通知人、读入主单等属主单或未接字段，本次未新增 DTO/接口能力，仅用现有 `SeaExportSeparate` 字段排布。
- 「更新合计」只汇总本地箱行，不请求后端；包装 ID 取第一条有 `codePackageId` 的箱行。
