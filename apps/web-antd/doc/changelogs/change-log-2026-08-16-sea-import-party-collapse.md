# 海运进口收发通支持展开折叠（默认展开）

## 背景意图

海运进口基础信息里的收发通（发货人 / 收货人 / 通知人 + 内外部备注）占位较高。对齐业务联系单的折叠条交互，让操作员可以收起该区，同时进口场景默认展开，避免进编辑页还要先点一次才能看到已填内容。

## 核心逻辑变更

- `basic-info-form/form.vue` 增加 `partyExpanded`（默认 `true`）
- 基础信息与收发通之间增加灰色折叠条（文案「收发通」+ chevron），点击或键盘 Enter/Space 切换
- 收发通表单与备注用 `v-show` 控制，折叠时仍保留表单实例与已填值
- 样式对齐业务联系单：24px 高、`#f5f5f5` 底、chevron 收起时旋转 180°

## 避坑指南

- 校验/保存仍走 `partyInfoFormApi` / `cargoRemarkFormApi`，与折叠状态无关
- 勿用 `v-if` 替代 `v-show`，否则折叠再展开会丢未落库的本地输入
- 新建与编辑共用同一 `form.vue`，两处都会默认展开
