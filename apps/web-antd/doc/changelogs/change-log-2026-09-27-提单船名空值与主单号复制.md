# 提单船名空值与主单号复制

## 背景意图

提单详情里船名、航次都空时写成「未排载」。系统没有排载状态，和其他空字段不是一类。列表主提单号旁的复制图标也占位置，单击号码本身已经能复制。

## 核心逻辑变更

- 船名 / 航次为空时改为「未维护」，与港口、委托单位等空字段一致。超期天数为 0 时仍显示「未超期」。
- 提单列表主提单号去掉复制图标。单击号码仍复制这一条，双击仍打开详情。分提单号、详情标题和操作弹窗仍保留复制图标。

## 避坑指南

主提单号没有图标后，只能走单击延迟复制。不要把图标的立即复制也删掉分提单号上的按钮，两列不是同一处。

## 验证

本地提单列表主提单号 4 个号码旁都没有复制图标，分提单号仍有图标。单击主提单号会进入复制；自动化浏览器没有剪贴板权限，提示「复制失败，请手动复制」。打开船名为空的详情，船名 / 航次为「未维护」，页面上没有「未排载」。
