# 变更记录：客户列表改为顶部统一操作并强化选择安全

## 背景意图

- 客户列表原先采用“行内操作列（编辑/删除）”，与当前项目列表规范不一致，也不利于后续批量操作扩展。
- 行内删除在翻页或刷新后的选择状态不明确，存在误操作风险。
- 需要统一为“顶部操作 + 勾选行”的交互模型，提升一致性与可控性。

## 核心技术决策 / 逻辑变更

- 移除 `apps/web-antd/src/views/client/base/data.ts` 中 `CellOperation` 操作列。
- 在列定义第一列新增 `type: 'checkbox'`，并固定在左侧，作为列表统一选择入口。
- 在 `apps/web-antd/src/views/client/list.vue` 顶部工具栏新增“修改”“删除”按钮：
  - “修改”仅在**单选**时可用，点击后跳转对应编辑页。
  - “删除”在有选中项时可用，点击后弹出二次确认，再调用删除接口。
- 删除接口改为传递 `GuidIdDto` 的 `ids`，支持一次删除多条勾选记录。
- 增加选择状态同步与清理机制：
  - 监听 `checkboxChange` / `checkboxAll`，实时同步当前选中行。
  - 刷新、重新查询、翻页时主动清空勾选与缓存，避免跨页残留导致误删。

## 避坑指南（Gotchas & Constraints）

- `deleteClient` 入参是对象结构（`{ id }` 或 `{ ids }`），不要直接传字符串 id。
- 勾选状态清理建议同时调用 `clearCheckboxRow` 与 `clearCheckboxReserve`，否则部分场景可能出现“视觉已清空但缓存仍保留”。
- 顶部按钮禁用态必须与当前勾选数强绑定：编辑=1 条、删除>=1 条，避免用户预期与行为不一致。
