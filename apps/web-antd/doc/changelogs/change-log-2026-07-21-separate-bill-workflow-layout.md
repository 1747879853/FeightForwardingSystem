# 分单弹窗按业务动线重组 + 新增默认仅带条款与箱

## 背景意图

原布局偏「提单面单仿样」，箱表挤右上、货描沉底、船期只读区过重；新增默认整单读入主单收发通/货描，分票场景易误存。按货代分单录入动线调整。

## 核心逻辑变更

1. **布局**：身份+运费条款（含付费地点）→ 船期港口可折叠摘要 → 左收发通/国外代理 | 右货物 → 装箱通栏 → 签单（方式/日期/地点）。
2. **新增默认带出（defaults）**：仅运输条款、付费方式、付费地点、签单方式/日期/地点 + 主单装箱；**不带**收发通、国外代理、唛头货描件毛体。
3. **读入主单（full）**：仍整包覆盖收发通/代理/条款/货物/装箱。

## 避坑指南

- 分票件毛体勿盲目点「更新合计」后不核对；默认带入的箱需按本票删改。
- 需要主单收发通/货描时再点「读入主单」。
