# 更改单布局与操作栏精简（订单信息顶部通铺 / 隐藏新建 / 去更多 / 费用 Tab 入表头）

## 背景意图

更改单页左侧订单摘要占宽、操作栏按钮偏多，费用应收/应付切换又与表格操作栏分离，录入时视线来回跳。本次将订单信息改为顶部通铺折叠、精简标题栏操作，并把收付方向切换挪到费用表工具栏左侧，贴近表格本身。

## 核心逻辑变更

1. **订单信息顶部通铺**
   - 去掉左侧 `280px` 固定栏，改为页面顶部全宽卡片。
   - 默认折叠：仅展示关键字段（提单号/订舱号/客户/船司/船名航次/起运港/目的港/ETD 等有值项）。
   - 点击标题区或「展开」后展示全部有值字段栅格；仍可「查看更多订单信息」展开空字段；配置按钮保留。

2. **新建态隐藏「新建」**
   - `isNewDraft`（当前更改单尚无服务端 id）时，标题栏「新建」与选择器底部「新建更改单」一并隐藏，避免重复进入草稿。

3. **删除「更多」按钮**
   - 移除「更多」下拉及复制为新更改单 / 查看锁定记录 / 删除更改单等菜单入口与对应脚本。
   - 标题栏操作收敛为：条件「新建」+「保存更改单」。

4. **应收/应付切换进表格工具栏左侧**
   - 去掉外层 `Tabs`，两张 `OrderFeeTable` 用 `v-show` 按 `activeFeeTab` 切换并保持挂载。
   - `order-fee-table` 透传 `#toolbar-actions` 插槽；更改单在该插槽放分段切换（含条数 Badge），与右侧新增/打印/删除同一行。

## 避坑指南

- 折叠态关键字段清单在 `KEY_ORDER_INFO_KEYS`；若业务要改默认摘要字段，改该常量即可，勿再写死在模板。
- 费用 Tab 在两张表的 `toolbar-actions` 各渲染一份（因 `v-show` 只显示当前表）；改样式时改 `.fee-tab-switch` 即可两边同步。
- 删除「更多」后，复制/删除/锁定记录暂无 UI 入口；若后续需要，应单独设计显式按钮，勿再塞回「更多」。
- 海进更改单页（`sea-import-admin/changeOrder`）未同步本次布局，若要对齐需单独改。
