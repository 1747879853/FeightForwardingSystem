# 银行流水编辑页基础信息与核销进度左右分栏

## 背景意图

编辑页原先「核销进度」汇总卡与「流水基础信息」表单上下堆叠，首屏纵向占用偏高，希望同一行左右对照查看。

## 核心逻辑变更

- 编辑态顶部改为 `top-panels--split`：左侧「流水基础信息」，右侧「核销进度」，两卡等高拉伸。
- 流水基础信息统一为 4 列「到账信息」网格；银行字段与原补充信息（摘要/留言/备注）并入同一区块，去掉独立「补充信息」折叠。
- 锁定态字段改为纯文本，不再渲染禁用输入框；新建态仍整行只展示流水基础信息。
- 窄屏（≤1180px）分栏回落为上下堆叠。

## 避坑指南

- 分栏等高依赖 `align-items: stretch` + 卡片 `height: 100%`；窄屏需改回 `height: auto` 避免空白过高。
- 锁定态银行/组织文案取自详情 `orgs` / `orgBankAccount` / `clientInvoiceBank`，勿再挂载 Select 指望禁用回显。
- 关联核销单表格高度由 `Page auto-content-height` + `ResizeObserver` 计算 `scroll.y`，勿再写死表格高度。
- 关联核销单列表仍在下方全宽区域，未并入右侧进度卡。
