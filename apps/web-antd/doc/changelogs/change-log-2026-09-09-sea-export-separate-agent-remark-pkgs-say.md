# 2026-09-09 海运出口分单代理旁备注与件数大写

## 背景意图

TAPD #0934：分单页要把备注放到代理地址旁边，货物区底部要按提单套话展示件数大写。复制分单（分提单号与装箱清空）此前已经落地，本条不再改复制接口。

## 核心逻辑变更

- **代理 + 备注并排：** 代理地址文本框缩小为 3 行；分单头 `remark` 从主卡底部挪到代理地址右侧，仍提交 `SeaExportSeparate.Remark`，与装箱行备注分离。
- **件数大写：** 货物明细底部只读展示 `SAY:{英文件数} {包装名} ONLY.`。件数转英式英文（hundred 后带 `AND`，21–99 连字符），包装名转大写；件数和包装都空时为 `SAY: ONLY.`。不读主单 `transportOrder.upperPKGS`。
- **装箱联动：** 改装箱行件数（或删行）会把件数合计写回货物件数，SAY 行跟着变；改货物件数/包装也会即时重算。

## 避坑指南

- **不要套主单 `upperPKGS`。** 主单是 `ToWords + 包装名` 中间无空格、无 `SAY:`/`ONLY.`；分单按 TAPD 样例前端自拼。
- **件数大写只在页面上。** 分单 Tab 已去掉打印；不要再把 SAY 当成能打进模板的字段。
- **包装英文取决于字典 `name`。** 前端只把当前包装名转大写；字典若是中文，SAY 里也会是中文。
