# 提单数量卡收紧并弱化告警底

## 背景意图

提单列表顶部四张汇总卡里，超期未收在选中时整卡铺浅红，标签和数字字号接近，第四张单独挂右上角箭头。卡片偏高，也让人分不清前三张能不能点。

## 核心逻辑变更

- 四张卡统一白底、浅灰边框，高度 72px，内边距 12px 16px。
- 图标为 40px 圆角方徽章：全部提单蓝、待签出青绿、超期未收红、待我审核橙，浅底深色图标。
- 标签 12px 中性灰，数字 26px、字重 600。超期未收只在数量大于 0 时数字为红，为 0 时与普通数字同色。待我审核大于 0 时数字为橙。
- 前三张仍筛选列表。选中只用主色描边，不再给整卡铺底色。
- 待我审核仍跳转签出审核页。去掉右上角独立箭头，改为卡片右侧「进入」。四张卡悬浮都轻微上浮。

## 避坑指南

待我审核的数量是审核子任务，不能改成提单列表筛选。选中态不要再给卡片加背景色，否则超期未收会重新变成整卡浅红。

## 验证

本地提单列表测量四张卡高度均为 72px，背景为白色。选中超期未收后底色仍是白，描边为主色蓝，数字为红色。点击待签出、超期未收、全部提单会切换列表条数。点击「进入」打开签出审核页。
