# 背景意图

新建编号规则时，日期/固定文本等非自增段的「重置序号」默认未勾选，测试每次都要手点。勾选后该段内容变化时自增序号从 1 重新开始，是常见用法。

# 核心逻辑变更

- `GenerateNumAdmin/modules/form.vue` 的 `addRule()` 将 `reset` 默认改为 `true`。
- 生成类型从自增序号切到日期/文本等时，补回默认勾选；自增段仍强制 `reset=false`（该选项无效）。
- 编辑已有规则仍按详情回填，不覆盖已保存的勾选状态。

# 避坑指南

- 自增序号段不展示「重置序号」，提交时仍写 `false`。
- 不要在编辑回填路径给 `reset` 再套默认值，否则会把历史未勾选的规则改掉。
