# 2026-07-25 业务联系单费用新增默认 USD 与箱型卖价/箱量带出

## 背景意图

新建页 `/pre-order/add` 费用区点「添加」后，币别未默认 USD，且「应收 + 单位=箱型」时含税单价/数量未可靠带出箱型卖价与箱量（切换单位后表格不重渲，看起来像没生效）。

## 核心逻辑变更

- 挂载时按 `Keyword=USD` 拉取币别，缓存 USD `id`；新增费用行默认写入该币别；若列表稍晚返回，回填尚未选币别的行。
- 已有带名称的箱型时，新增费用行单位默认取**首个**箱型名，并经 `applyCtnPriceAndQty` 写入卖价、箱量并重算金额。
- **无论是否有箱型**，新增行都会调用 `recalcAmount`（无单价时金额为 `0`），避免金额列空白。
- 单位/收付切换、手改数量单价税率后，对 `dataSource` 换新数组引用（`touchDataSource`），避免 `a-table` 浅比较导致只读态与金额列不刷新。

## 避坑指南

1. **先录箱型再加费用**：箱型行须已选箱型（有 `ctnCodeName`）且填了卖价/箱量，新增费用才能自动带出；仅点了箱型「添加」但未选箱型时，费用仍默认单位「票」。
2. **多箱型时单位默认首个**：用户可再改单位到其他箱型，改后会重新带出对应卖价/箱量。
3. **a-table 行内原地改值要换数组引用**，否则 `isCtnDrivenRow` 只读态与金额列可能不更新。
