# 销售提成新建弹窗对齐设计稿

## 背景意图

新建销售提成弹窗筛选条是外置 Label 白卡片，未结清提示塞在票表内部，参与计算票列过多，和设计稿的浅灰底、内嵌标签、分卡表格不一致。

## 核心逻辑变更

- `create-modal.vue`：弹窗加宽浅灰底；提成人/组织/提成月标签内嵌到白色圆角控件；不可新建原因与未结清提示改为独立红/黄条；未结清票与参与计算票分卡。
- `data.ts`：`useSalesTicketColumns({ compact })` 精简为委托编号、业务信息、应收/应付/利润/提成金额、状态；`showUnsettled` 只保留催款列，不再带金额列。
- `calc-panels.vue`：达标票数显示「N票」，步骤文案改为达标利润 / 阶梯提成 / 底薪比较。

操作提成新建仍用原操作票列，不走 compact。

## 避坑指南

- 跨部门详情仍用完整销售票列，不要给 `detail-modal` 传 `compact`。
- 未结清表不要复用 compact 列，设计稿要委托编号到欠款明细的催款字段。
