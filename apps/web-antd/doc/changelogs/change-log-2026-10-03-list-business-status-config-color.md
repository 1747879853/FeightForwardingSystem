# 列表业务状态融合服务项目配置色

## 背景意图

海运出口、业务联系单列表的「业务状态」原先按未开始 / 进行中 / 已完成三套固定色。TAPD [#1000136](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000136) 要求带上枚举管理里该服务项配的颜色，同时保留三态底色扫进度。

## 核心逻辑变更

1. `ServiceType` 子项 `remark`（页面叫「颜色」）解析成十六进制，建成 `serviceType → color` 映射。
2. 色块底始终用原来的灰 / 黄 / 绿三态色，用来看进度。
3. 当前服务项有配置色时，「待」和服务名用配置色；没配则字色仍走三态。
4. 再进列表会重拉 ServiceType，避免 keep-alive 还拿着改色前的映射。
5. 海运出口列表与业务联系单列表共用同一套解析。

## 避坑指南

- 接口字段仍是 `remark`，不要改成 `color` 再提交。
- 并行未完成多项时，取当前组里第一个未完成项的颜色。
- 旧版枚举缓存若没有 `remark`，列表会回退三态色，改完颜色后需刷新枚举或重进页面。
