# 数据权限指定用户显示默认公司与部门

## 背景意图

权限配置里新增数据权限、数据范围选「多用户」时，「指定用户」下拉只显示用户名和昵称，分不清人在哪家公司、哪个部门。TAPD #1008。

## 核心逻辑变更

- 仅这个下拉打开 `showDefaultOrg`。下拉第二行显示该用户默认组织的公司 / 部门。
- 公司取默认组织路径上第一个公司节点，部门取路径末端。人直接挂在公司上时只显示公司。
- 名称优先简称。组织数据走已有的全部用户组织缓存，打开下拉时加载；缓存未到之前第二行仍显示英文名。
- 其他页面的选人下拉仍显示英文名。

## 避坑指南

- 用 `default=true` 的那条组织，不要拿用户任意一条组织来拼。
- 选中后的标签仍是昵称，公司和部门只出现在下拉列表里。
