# 2026-07-26 业务联系单装运方式/箱量/业务类型必填

## 背景意图

保存时装运方式、业务类型、箱量此前缺少明确必填卡点（装运方式还默认 0，易漏选感知）。需在录入阶段强制补齐。

## 核心逻辑变更

1. 标题 meta「业务类型」「装运方式」加必填星标；`validateForms` 空值拦截。
2. 装运方式新建默认改为空（不再默认整柜 0），详情/复制仍按源单回填。
3. 箱量表头「箱量」加星标，输入 `min=1`；`validateCtns` 要求至少一行，且每行已选箱型、箱量 > 0。

## 避坑指南

- 业务类型本期仅一项且默认海运出口，星标主要用于契约一致；勿因此去掉默认值导致多余点击。
- 无箱型行直接保存会提示「请至少添加一条箱型箱量」，不只校验已有行的箱量字段。
