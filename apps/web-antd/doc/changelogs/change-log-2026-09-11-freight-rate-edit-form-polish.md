# 运价新增/编辑弹窗视觉分区优化

## 背景意图

`edit-form.vue` 有效期区使用紫渐变、分区扁平灰底，与系统结算/费用页的卡片分区风格不一致，层次与间距偏弱。

## 核心逻辑变更

- 有效期横幅改为主色浅底 + 主题 token，去掉紫渐变
- 基础信息 / 日期时间 / 箱型费率 / 附加费改为统一分区卡片：渐变标题栏、图标徽标、规范间距
- 日期/星期模式改为分段 chip 切换；日期组卡片增加悬停反馈
- 底部操作栏 sticky，按钮有轻微位移与主色阴影反馈
- 费率表头/行悬停与边框对齐系统浅蓝灰体系；业务逻辑未改

## 避坑指南

- 弹窗仍 `:footer="false"`，底部按钮在内容区 sticky，滚动长表单时仍可见
- 暗色主题下依赖 `hsl(var(--*))` 的区域会跟主题走；部分卡片边框仍用结算页同款硬编码浅灰以保持一致
