# 背景意图

师傅端需要在用户每次打开小程序、或从后台回到前台时检查是否有新版本。有更新时弹出确认框，由用户决定是否立刻重启；个人中心不再放「检测更新」入口。

# 核心逻辑变更

- `App.onLaunch` 尽早绑定 `uni.getUpdateManager`，赶上微信冷启动时的异步版本检查。
- `App.onShow` 再次走同一套逻辑：监听器只绑一次；若新包已下载完成，再次弹出「立即重启 / 稍后」。
- 新版本下载失败才 Toast；无更新不提示。
- 个人中心去掉「关于 / 检测更新」区块。

# 避坑指南

- 微信没有主动 `checkForUpdate`。短时间热启动不一定会再向服务器查版本；能保证的是：冷启动会查，已下好的包在回到前台时会再问一次要不要重启。
- `onUpdateReady` / `onUpdateFailed` 只能注册一次，重复绑定会叠弹窗。
- 开发版、体验版检测不到线上正式版。
- 用户点「稍后」后，下次从后台进入仍会再问；不要自动 `applyUpdate`。
