# 付费审核页主从布局与费用明细只读展示

## 背景意图

付费审核页原先仅为任务列表，审核人无法在页内查看付款申请的费用合计、附件与费用明细，需跳转或依赖其他页面。业务期望在同一屏完成「选任务 → 看明细 → 批量审核」，并控制页面高度不出现整页纵向滚动。

## 核心逻辑变更

1. **页面布局重构**（`payment-review/index.vue` + 新增 `detail-panel.vue`）：
   - 上方两栏：左侧为审核任务列表（`Grid` 插槽注入），右侧上下排列「费用合计」「附件信息」。
   - 下方一栏：费用明细整行通铺，表格内部滚动。
   - 整页 `Page auto-content-height` + flex 分区，避免页面级垂直滚动条。
2. **选中联动详情**：
   - 列表 `cellClick` 高亮当前行，取 `row.paymentApplicationId` 调用 `getPaymentApplicationDetail`。
   - 详情展示复用 `payment-application/form-data.ts` 的币别汇总、分组与列定义，均为只读。
3. **工具栏简化**：
   - 仅保留「审核全部」「批量驳回」两个普通按钮，移除下拉菜单及「选中通过/选中驳回」入口。
   - 批量操作范围仍为当前列表页全部任务行。

## 避坑指南

- 详情数据入口是 `paymentApplicationId`，不是任务行 `id`；审核接口仍使用任务 `id`。
- `detail-panel.vue` 通过 `#list` 插槽接收列表，布局与数据加载集中在同一组件，避免左右分文件时高度计算不一致。
- 右侧费用合计卡片需 `flex: 1` 占满附件上方剩余高度，附件区 `flex-shrink: 0` 固定在右栏底部。
