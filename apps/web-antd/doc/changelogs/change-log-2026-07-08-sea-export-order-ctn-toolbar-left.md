# 海运出口箱型箱量工具栏按钮靠左

## 背景意图

新建/编辑页「箱型箱量」标题栏上的新增、删除（及堆场实装箱量查询）按钮原先因标题 `flex: 1` 被顶到右侧，操作路径偏长；调整为紧跟标题靠左排列，便于就近操作。

## 核心逻辑变更

- `order-ctn-table.vue` 标题文本去掉 `flex: 1`，标题栏仍为 `display: flex` + `gap`，按钮自然排在标题右侧、整体靠左。
- 新建页与编辑工作台共用该组件，布局一并生效。

## 避坑指南

- 不要用 `margin-left: auto` 把按钮组顶回右侧；若需恢复右对齐，再给标题加回 `flex: 1`。
