# 付费申请添加费用抽屉必选发票制作方式

## 背景意图

新建付费申请时，用户可能在未选定「发票制作方式」前就确认费用并触发 `AddAsync`，导致申请单缺少 `invoiceProcess`。业务要求在添加费用抽屉内选定发票制作方式后，才允许创建申请或提交。

## 核心逻辑变更

1. **添加费用抽屉**（`enableInvoiceProcess`）：付费申请打开抽屉时启用；标题栏旁展示「发票制作方式」下拉（先票后付 / 先付后票 / 不开票）；未选时确认拦截并提示。
2. **抽屉回写**：确认时 `emit('update:invoiceProcess')`，外层 `form.vue` 同步 `invoiceProcess`。
3. **表单校验**：新建确认费用、保存、提交、提交并新建、提交申请前均调用 `ensureInvoiceProcessSelected()`；未选则不创建申请。
4. **单测**：覆盖「未选不创建」与「抽屉选定后带 `invoiceProcess` 创建并跳转编辑」。

## 避坑指南

- 仅付费申请场景传 `enableInvoiceProcess: true`；付款结算等其它复用抽屉默认不展示该字段。
- 先付后票仍可在结算后补录票号/日期；本卡点只强制「制作方式」必选，不强制发票号。
