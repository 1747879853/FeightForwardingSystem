# 运价批量新增弹窗视觉分区优化

## 背景意图

批量新增（含列表「更新」编辑模式）工具栏扁平散落，与已优化的单条新增/编辑弹窗风格不一致。

## 核心逻辑变更

- `batch-add-modal-handsontable.vue`：主色摘要顶栏（行数 / 已选 chip + 帮助说明）+「运价明细」分区卡片（渐变标题栏、统一操作区）。
- Handsontable 表头浅蓝、行悬停反馈；列配置按钮悬停旋转；自定义行数子弹点遮罩关闭关闭。
- 业务提交与表格逻辑未改。

## 避坑指南

- 线上入口为 `batch-add-modal-handsontable.vue`，勿改未接线的 `batch-add-modal.vue` 误以为已生效。
- 分区头同时承载新增行操作与添加箱型，编辑模式仅隐藏行操作区。
