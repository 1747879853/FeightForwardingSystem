# 2026-05-21 海运出口港口服务项详情港口名称回显补齐

## 背景意图

在“海运出口港口服务项配置”编辑场景中，详情接口虽然返回了 `pol.portName`，但当对应港口不在下拉首屏数据里时，`polId` 仅有值而缺少选中项对象，导致起运港下拉不稳定回显。  
本次改动将详情返回的港口信息手动注入下拉选中项，确保编辑态打开即显示正确港口名称。

## 核心逻辑变更

1. 在表单状态中新增 `selectedPortItems`，专门承载 `PortSelect` 的编辑态已选项。
2. 详情加载成功后，基于 `detail.polId + detail.pol.portName/cnName` 手动拼装选中项对象并写入 `selectedPortItems`。
3. `PortSelect` 增加 `selected-items` 绑定，让分页下拉组件在未加载到目标港口分页数据时也能直接回显。
4. 表单重置时同步清空 `selectedPortItems`，避免新增/编辑切换时残留历史港口。
5. 将编辑态 `polId` 与 `selected-items.id` 统一按字符串处理，规避超大整型 ID 在下拉匹配时出现的类型或精度差异。
6. 编辑打开时从列表行额外透传港口名称作为兜底，详情缺失 `pol` 时仍可稳定回显。

## 避坑指南

- 对于分页下拉类组件，编辑回显不要只依赖 `v-model` 的 id，必须同时提供“已选项对象”以避免首屏未命中导致空白。
- 回显对象至少应包含 `id` 与名称字段（本场景使用 `portName/cnName`），否则组件无法生成稳定展示文案。
- 表单 `reset` 阶段要清理回显缓存，防止弹窗复用带来的串值问题。
