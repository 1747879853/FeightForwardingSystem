# 监装小程序箱列表易读易点

## 背景意图

原五列表格字号过小；初版四行展示又占用过多空间，进一步压缩为两行布局。

## 核心逻辑变更

- 左侧序号；中部箱号 34rpx 加粗、下方封号 28rpx；右侧箱型、状态和进入箭头，有照片时补充数量。
- 整行作为箱级面板入口，最小高度 76px，提供按下背景反馈；列表顶部提示点击用途。
- 长编号换行完整展示，保留原保存及权限逻辑。

## 避坑指南

- 使用原生 button 和 tap，整行只打开面板，不直接修改状态；需真机验证滑动与点击体验。
- 不使用固定高度或截断编号；照片数存在时允许行高自然增加。
- 微信小程序构建通过；上一轮类型检查发现其他组件既有错误，本次未修改相关组件。
- 基于独立临时 Git 暂存区核对差异，未改变用户暂存区。
