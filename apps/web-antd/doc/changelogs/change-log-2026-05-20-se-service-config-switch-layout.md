# 2026-05-20 海运出口港口服务项配置开关布局优化

## 背景意图

- 现有“自动完成 / 允许手动完成 / 完成提醒”使用 Checkbox 且分散在两行，单条服务项占用纵向空间较大。
- 在同一弹窗维护多条服务项时，用户需要频繁滚动，配置密度偏低，操作路径不够紧凑。

## 核心逻辑变更

- 将 `SeServiceConfigAdmin` 弹窗明细中的三个布尔字段统一从 `Checkbox` 切换为 `Switch`。
- 调整明细区域栅格布局，将“自动完成 / 允许手动完成 / 完成提醒”放到同一行显示。
- 原本与“完成提醒”同排的“责任角色”改为单列独占一行，保证开关项横向对齐更直观。

## 避坑指南

- `Switch` 仍通过 `v-model:checked` 绑定布尔值，提交 DTO 无需额外改造，避免误改接口字段类型。
- 若后续需要兼容更窄视口，建议将 `grid-cols-4` 增加响应式断点（如 `md:grid-cols-2`），避免小屏下表单拥挤。
