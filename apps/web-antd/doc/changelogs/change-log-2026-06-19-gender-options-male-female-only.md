# 性别选项统一为男/女两项

## 背景意图

个人中心曾提供「未知」(0)、「男」(1)、「女」(2) 三档，用户管理仅男/女。用户在个人中心选「未知」后，用户管理回显为数字 `0`。产品口径为性别仅保留男、女两项。

## 核心逻辑变更

- 个人中心 `base-setting.vue` 移除「未知」选项，仅保留男(1)、女(2)，可清空为 `null`。
- 用户管理 `getGenderOptions()` 维持男/女两项（撤销此前补齐未知的改动）。
- 回显时若后端值为 `0` 或其它非法值，前端归一化为空，避免 Select 显示原始数字。

## 避坑指南

- 性别有效取值：`1` 男、`2` 女、`null` 未设置；`0` 视为历史脏数据，加载时按空处理，保存时用户需重新选择或留空。
