# 自动费用模板编辑页整体布局样式

## 背景意图

编辑页原先标题裸放、基础信息用默认 Card、明细区另套一套样式，页面碎、背景不统一、主操作不醒目。

## 核心逻辑变更

`OrderFeeTemplateAdmin/edit.vue`：

- 浅色渐变页底 + `oft-editor__hero` 标题区（图标徽标、主副标题、返回/保存）。
- 基础信息与费用明细统一为 `oft-panel`（蓝条 + 图标标题 + 提示文案）。
- 费用明细头展示行数；表单栅格响应式、控件圆角与字色统一。

## 避坑指南

- 勿再给 `Page` 与 `oft-editor` 叠两层厚 padding；保留 `oft-editor` 内边距即可让背景露出来。
- 返回走已有 `handleBack`，与未保存守卫兼容。
