# TAPD #1000170：各附件区支持悬停粘贴上传

## 背景

[TAPD #1161580498001000170](https://www.tapd.cn/61580498/prong/stories/view/1161580498001000170)：公共上传已支持鼠标停在上传区后 Ctrl+V 粘贴。客户附件、海运/空运附件、业务联系单、付费申请、账期合同和监装照片仍只有点击或拖拽。

## 改动

1. 抽出 `useAttachmentZonePaste`：鼠标停在某一上传卡片时，Ctrl+V 把剪贴板文件交给该卡片；光标在输入框里时不拦截文字粘贴。截图没有文件名时补成 `screenshot-*.png`。
2. 接到客户附件、海运出口/进口、空运出口、业务联系单、付费申请附件分组、付费申请发票行、客户账期合同附件、海运出口监装照片。公共 `FileUploadInput` 的主提示改为「点击、拖拽或 Ctrl+V 粘贴上传」。
3. 空状态文案同步带上 Ctrl+V。账期附件卡片仍只读，不接收粘贴。

## 验收

- 上述任一可编辑附件卡片上截图后，鼠标停在该卡片按 Ctrl+V，文件进入这一类，不会进到旁边的类型。
- 光标在备注等输入框里 Ctrl+V，仍然粘贴文字。
- 付费结算、公告、对账单等使用公共上传组件的地方，拖拽区主文案同样提示可粘贴。
