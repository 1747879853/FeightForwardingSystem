# 业务联系单编辑页「基础信息」文案更名

## 背景意图

编辑页顶部 Tab 与主分区标题仍显示「基础信息」，与业务模块正式名称「业务联系单」不一致，需统一文案。

## 核心逻辑变更

- `editor.vue` 顶部 content-tab 文案：`基础信息` → `业务联系单`。
- 主栏分区标题条（`basic-info-header`）卡片标题：`基础信息` → `业务联系单`。
- 仅展示文案变更，路由、`activeTab === 'basic'` 等内部标识不变。

## 避坑指南

1. **新建态无顶部 Tab**：仅编辑态展示 content-tabs；分区标题在新建/编辑均可见。
2. **勿改内部 key**：`activeTab` 仍为 `'basic'`，避免牵动 Tab 切换与脏检查逻辑。
