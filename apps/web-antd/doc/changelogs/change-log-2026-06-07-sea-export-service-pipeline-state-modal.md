# 变更日志：海运出口服务流水线三态 + 配置弹窗

> 日期：2026-06-07  
> 范围：`form.vue`、`se-service-task-admin.ts`

---

## 背景意图

服务项目流水线需按业务进度展示三态（已完成 / 处理中 / 还未到），节点增删改到独立弹窗维护；已完成节点取消勾选前须调用 `CancelCompleteAsync`。

## 核心逻辑变更

### 流水线三态（按 sortId 顺序）

在已勾选节点中：

1. 找到第一个 `taskStatus !== 已处理` 的节点 → **处理中**（蓝）
2. 其之前的节点 → **已完成**（绿）
3. 其之后的节点 → **还未到**（灰）
4. 全部已完成时，所有节点均为已完成

流水线仅展示已勾选节点，只读；「完成服务」仍在 Tooltip 中操作。

### 配置弹窗

- 入口：「配置服务」按钮
- 列表：当前起运港 `getServiceTypesByPOL` 返回的全部节点，Checkbox 勾选
- 待处理且已生成任务的节点：禁止取消勾选
- 已完成节点：允许取消勾选，确认时先批量调用 `cancelCompleteSeServiceTask`，再 `loadEditData` 刷新，最后应用弹窗草稿

## 避坑指南

- `loadEditData` 会覆盖本地 `serviceTypeNodes`，须在重载**之后**再应用弹窗草稿。
- 新建页取消已完成节点不涉及 API，仅编辑态需要取消完成接口。
