# 海运出口干系人角色图标货代语义化

## 背景意图

右侧干系人卡片左上角角色图标原先使用通用办公类 MDI 图标（领带、公文包、耳机等），与货代业务角色语义关联弱，用户难以一眼区分岗位职能。

## 核心逻辑变更

`getOrderUserRoleIcon` 按 `UserAttribute` 映射为货代岗位职责语义图标：

| 角色       | 图标                        | 对应职责                 |
| :--------- | :-------------------------- | :----------------------- |
| 销售       | `mdi:handshake-outline`     | 开拓客户、报价促成交易   |
| 商务(航线) | `mdi:tag-multiple-outline`  | 运价表管理、合约价定价   |
| 操作       | `mdi:truck-cargo-container` | 订舱、拖车装柜、物流执行 |
| 客服       | `mdi:forum-outline`         | 订单期间沟通与节点反馈   |
| 单证       | `mdi:file-sign`             | 提单/舱单签发与核对      |
| 海外客服   | `mdi:earth-arrow-right`     | 海外代理跨国协同对接     |

## 避坑指南

- 图标仅影响展示，不参与校验或提交逻辑。
- 若后续海运进口等页面复用同一映射，建议抽到共享常量避免漂移。
