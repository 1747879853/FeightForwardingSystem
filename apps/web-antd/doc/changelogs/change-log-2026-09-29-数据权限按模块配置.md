# 数据权限按模块配置

## 背景意图

数据权限可以按业务模块单独配置，没单独配的模块继续用通用规则，并新增「排除人员」。各页面的所属公司下拉要按当前页面所属模块，向「当前登录人有数据权限的公司」接口要公司范围。对应 TAPD 需求 #1000193。

## 核心逻辑变更

- 权限配置的数据权限列表增加模块列和模块筛选。不选模块保存为通用规则；筛「通用」只看模块为空的规则。同一用户或角色可以同时保留多条规则。
- 数据范围增加「排除人员」，必须选择用户。配给某个用户的规则不能选他自己。子项仍随规则的 `entityIds` 一起提交。
- 删除确认展示「模块 / 操作 / 数据范围」，例如「通用 / 查询 / 排除人员」，不再用规则编号。
- 所属公司下拉改为按数据权限取公司，并带上页面模块：海运出口、海运进口、空运出口列表，监装工单（跟随海运出口），付费申请选费用，客户及客户审核，进项发票。对账单选费用不在模块表里，只按通用规则取公司。

## 避坑指南

- 模块值 0 是海运出口，不能当成没传。不传模块时接口只看通用规则。
- 数据权限模块和表级权限的模块枚举不是同一套。件杂货在数据权限里是 12。
- 提单、分单、业务联系单、收费结算、付款结算、发票开出、开票申请、提成单、客户联系人、银行流水目前页面上没有「所属公司」下拉，这次没有新加筛选项。银行流水列表筛的是「组织」，仍可选部门。
