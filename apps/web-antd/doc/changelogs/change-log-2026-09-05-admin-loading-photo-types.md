# 2026-09-05 管理端监装照片按附件类型分组

## 背景意图

小程序监装处理已经按维护的附件类型分槽上传。管理端海出编辑页「照片采集」仍只展示工单里已有分组，没有类型时落到一个「监装照片」，和师傅端不一致。

## 核心逻辑变更

- 监装 Tab 进入与打开照片弹窗时调 `AttachmentDtlType/GetListByModuleTypesAsync`（`moduleTypes: [160100]`）。
- 弹窗先铺维护类型空槽，再填该箱已有照片；历史未分类组追加在后。标题读 `name`。
- 未配置类型时提示「未配置监装附件类型」，仍保留未分类槽。
- 保存口径不变：`EditOrderCtnAttachmentGroupsAsync` 按箱全量替换，空组不提交。

## 避坑指南

- **和师傅端同一模块码。** `ORDER_CTN_LOADING_MODULE_TYPE = 160100`。枚举管理 `ModuleType` 要有这项，附件类型还要勾上「监装箱型附件」，否则两边都是空槽 + 提示。
- **打开弹窗会再拉一次类型。** 刚在附件类型页勾上模块后，不必整页刷新也能看到新槽位。
- **ID 比较用 `String(id)`。** 不要把附件类型 id 转 `Number()`。
