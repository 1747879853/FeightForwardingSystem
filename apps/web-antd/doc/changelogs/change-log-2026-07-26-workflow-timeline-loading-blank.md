# 审批流程弹窗加载中空白修复

## 背景意图

业务联系单等页面点「审核流程」时，弹窗在请求返回前几乎看不到内容。根因是 `workflow-timeline-modal` 在 `loading=true` 且尚无数据时三个 `v-if` 都不成立，`Spin` 没有子节点，弹窗体高度塌缩，表现为“点了没显示”。后端代理超时较慢时更明显。

## 核心逻辑变更

- 加载中增加占位文案与 `min-height`，保证弹窗打开即可见。
- `open` 失败时优先取 ABP `error.message`，避免只显示 axios 通用错误句。
- 业务联系单「审核流程」在无单据 id 时先提示保存。

## 避坑指南

- 全局单例弹窗里，`Spin` 包裹的内容在 loading 态也必须有占位节点，不能依赖“三个互斥分支都 miss”的空壳。
- 工作流实例不存在时后端 `FirstAsync` 会抛错；前端应展示明确错误，而不是空白 Modal。
