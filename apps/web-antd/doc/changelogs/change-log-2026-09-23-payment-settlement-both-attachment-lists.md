# 付费结算：结算单附件不再顶掉付费申请附件

## 背景

编辑结算单右侧附件卡片高度固定。先显示付费申请附件时能看见；再上传结算单附件后，上传区变高，付费申请附件被顶出卡片。

## 改动

`settlement-management/payment-settlement/form.vue`：结算单附件占用卡片剩余高度，文件多了在该区域内滚动。付费申请附件固定留在卡片底部，超出部分在自己的列表里滚动。

## 验收

- 选中带附件的付费申请后，右侧能看到「付费申请附件」。
- 再上传结算单附件，付费申请附件仍留在卡片底部，可预览、下载。
- 两类附件各自超出时，在对应区域内滚动，卡片总高度不变。
