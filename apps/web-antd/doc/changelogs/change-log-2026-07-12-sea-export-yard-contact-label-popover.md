# 背景意图

海运出口编辑页原先在右侧单独展示「场站信息」卡片，占用干系人侧栏空间，且场站联系方式与基础信息中的场站选择字段距离较远。现将联系人及联系方式收敛到场站字段附近，减少视线跳转。

# 核心逻辑变更

- 编辑态「场站」字段标签行最右侧展示详情返回的场站联系人，与字段右边界对齐。
- 鼠标悬浮联系人时，通过浮层展示场站邮箱、场站手机、场站电话；空值统一显示 `-`。
- 删除右侧独立的「场站信息」卡片及对应样式。
- 联系方式仍来自详情只读字段 `yardContact`、`yardEmail`、`yardMobile`、`yardTel`，不参与保存提交。

# 避坑指南

- 联系人标签仅在编辑态增强；新建态仍保持普通「场站」标签，避免展示尚不存在的详情联系方式。
- 当前联系方式来自已加载的委托详情，用户在表单内切换场站后不会即时改写联系方式，需以后端详情刷新结果为准。
- 不要通过 DOM 定位和 `Teleport` 向动态表单标签注入内容：目标节点会受子表单渲染时序和后续 patch 影响。当前使用正式的 `defineComponent` 标签组件，并在初始 schema 与详情 `updateSchema` 两处显式绑定；组件直接订阅 `entrustReadonlyInfo`，确保详情回填后联系人和浮层内容响应式更新。
