# 2026-07-16 船期查询筛选：港口下拉与表单布局优化

## 背景意图

船期查询原先要求手填起始港/目的港五字码，易输错且不便检索。筛选区字段较多，默认展开占位大。需改为系统港口下拉，并压缩默认筛选行布局。

## 核心逻辑变更

- **起始港 / 目的港**：`Input` 改为 `PortSelect`，`valueKey`/`labelKey` 取 `ediCode`，表单值仍为五字码，查询入参 `polCode`/`podCode` 无需改动。
- **筛选布局**：一行 6 列（`lg:grid-cols-6`），默认收起；收起首行顺序为起始港 → 目的港 → 预计离港日期 → 范围(周) → 中转标识 → 预计到港日期。
- **标签宽度**：`labelWidth` 调整为 `92`。

## 避坑指南

- 查询接口仍要五字码字符串，切勿把 `valueKey` 改回默认 `id`，否则传参会变成港口主键。
- `PortSelect` 按 EDI 作 value 时，无预置回显场景可直接用；若后续要带默认选中，需按 `ediCode` 补 `selectedItems`。
