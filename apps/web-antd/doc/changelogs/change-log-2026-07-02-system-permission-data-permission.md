# 权限管理 - 数据权限对接

## 背景意图

按后端 `UserDataPermissionAdmin` / `UserDataPermissionItemAdmin` 契约，在 `/system/permission` 数据权限 Tab 完成主规则与子项的前端配置能力。

## 核心逻辑变更

- 主规则 CRUD：操作类型（查询/编辑）+ 数据范围（排除系统默认「自己」）。
- 数据范围为「多用户」或「多部门/多公司」时，弹窗内多选维护 `entityId` 子项；保存时 diff 增删子项。
- 列表支持「查看明细」抽屉，按用户/组织接口回显名称。
- 分页参数统一为 `pageIndex` / `pageSize`。

## 避坑指南

- 后端无子项批量保存接口，编辑须自行 diff。
- 修改数据范围类型离开 3/4 时会提示并清理子项。
- 删除主规则会级联删除子项，无需单独清理。
