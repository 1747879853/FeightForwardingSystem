# 付款申请费用明细卡片固定高度 650px

## 背景意图

费用明细整块卡片需要固定可视高度，避免随视口剩余空间拉伸；卡片内表格继续占满筛选栏与底栏之外的空间并内部滚动。

## 核心逻辑变更

1. **`fee-detail-card`**：固定 `height: 650px`，内部 head/body 纵向 flex。
2. **`fee-group-table` + `NestedDataTable.fillHeight`**：在卡片内吃掉筛选栏、底栏之外的剩余高度，超出表格内滚动。
3. **页面**：恢复 `content-class="!h-auto !p-0"`，整页随内容滚动，不再依赖视口剩余高度链。

## 避坑指南

- 改高度只调 `.fee-detail-card { height: 650px }` 即可；勿再给表格写死像素高，否则筛选栏/底栏变化会挤乱布局。
- 若卡片总高小于筛选+底栏+表头，需同步加大卡片高度，否则表格区会被压扁。
