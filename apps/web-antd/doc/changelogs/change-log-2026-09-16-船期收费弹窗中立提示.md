title: 船期收费弹窗替换为中立提示
date: 2026-09-16
module: schedule-query
---

# 背景意图

船期 SDK 查询不可用时展示供应商套餐。用户界面统一改为「船期查询暂不可用，请联系管理员。」。

# 核心逻辑变更

- CSS 预隐藏实际套餐弹窗标识 `.ft-upgrade-transparent-dialog` 及遮罩，避免闪现。
- 监听整个 body 的节点、文本和样式变化，覆盖外层挂载弹窗；通过专用标识及收费、额度耗尽、到期文案识别。关闭状态不触发，普通详情不匹配。
- 进入不可用状态后显示本地提示及重新加载，挂载回调和超时不会覆盖该提示。离开时断开监听，返回时恢复。
- 不更改供应商权限、额度或接口返回。

# 验证

实际点击青岛至宿务最近航线，触发套餐弹窗后仅显示中立提示及重新加载；重新加载恢复查询入口，首次进入未误判。静态 HTML 验证脚本通过。

# 避坑指南

识别依赖供应商 DOM 和中文文案，供应商重构或新增提示形式需更新规则。套餐弹窗不等于已确认额度耗尽，故统一提示暂不可用。不删除 SDK 管理的节点。
