# 更改单顶部改为「当前更改单选择器 + 历史抽屉」

- 日期：2026-07-21
- 类型：Feature / 交互重构
- 影响页面：海运出口 → 编辑器 → 更改单页签（`sea-export-admin/changeOrder`）

## 背景意图

高频场景是「录入当前更改单费用」，单票通常只有 1～5 张更改单。常驻顶部列表长期占用约 100px 首屏且信息噪声大。改为「标题选择器负责快速切换 + 右侧抽屉承载完整历史与审计信息」，直接进入编辑区。

## 核心逻辑变更

1. **移除顶部常驻列表**
   - 删除 `changeOrder/table.vue`、`changeOrder/data.ts`（VXE 列表），列表数据上提到 `index.vue` 的 `changeOrderList`（`GetPagedList`）。

2. **当前更改单选择器**
   - 标题区改为「更改单」导航层级 + 可点击选择器：`会计期间 · 更改原因 ▾`，原因过长截断并悬停显示完整内容。
   - 下拉展示最近更改单，每条 4 项：会计期间、更改原因、状态、是否当前/未保存；底部「＋新建更改单」「查看全部」。选择器基于 `a-menu`，支持键盘上下键 + Enter。

3. **历史抽屉（查看全部）**
   - 右侧 `a-drawer`：关键字搜索（原因/会计期间）+ 状态筛选（全部/未锁定/已锁定），列表展示原因、状态、创建时间、锁定人/锁定时间等审计字段；点击某条切换当前更改单。

4. **切换未保存守卫升级为三选一**
   - 自定义弹窗「保存并切换 / 放弃修改 / 取消」；`saveRow` 返回布尔，保存失败时停留当前更改单，不静默切换。

5. **操作收敛到标题栏**
   - `[＋新建] [保存更改单] [更多]`。更多菜单：复制为新更改单（复制会计期间/原因/备注，费用需重录）、查看锁定记录（Modal 展示锁定/解锁信息）、查看操作记录（待接入，禁用占位）、删除更改单。
   - 删除为当前更改单级操作，删除前提示「及其 N 条费用一并移除」；已锁定时禁用删除。

6. **标题与空态**
   - 标题格式 `会计期间 · 更改原因`（新建为「新建更改单」）；无选中时空态引导「点击新建或从选择器选择」。

## 避坑指南

- `a-menu` 的 `@click` 事件 `key` 类型为 `string | number`，处理函数需按此签名声明，否则 `MenuClickEventHandler` 类型不匹配。
- 列表数据单一来源（`changeOrderList`）同时驱动选择器与抽屉，保存/删除后统一 `loadChangeOrderList()` 刷新即可，无需再维护 VXE 表格选中态。
- 「复制为新更改单」受限于费用子表按 `id` 从服务端加载，暂只复制基本信息，费用需重新录入（后续如需连费用复制需子表支持本地灌数）。
- 更改单 DTO 目前仅有 `feeLocked` 一个状态维度，暂无「已审核/已结算」字段，状态标签只区分已锁定/未锁定/草稿。
