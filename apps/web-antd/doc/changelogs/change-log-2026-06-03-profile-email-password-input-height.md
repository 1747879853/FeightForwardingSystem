# 个人中心个人邮箱密码输入框高度对齐

## 背景意图

个人中心「个人信息」表单中，`个人邮箱密码` 输入框高度与其它输入框不一致，视觉上出现错位，影响录入体验与页面整齐度。

## 核心逻辑变更

- `apps/web-antd/src/views/_core/profile/base-setting.vue`：将 `emailPwd` 字段组件由 `VbenInputPassword` 调整为 `InputPassword`。
- 统一该字段与页面其它输入组件的尺寸体系，消除高度差异，保证同一行表单控件对齐。

## 避坑指南

- 个人中心基本信息表单需优先保持组件尺寸一致性，避免混用默认尺寸不同的输入组件导致视觉偏移。
- 如后续需要恢复强度提示或自定义密码交互，建议显式配置 `size` 并验证与 `Input` 组件对齐后再上线。
