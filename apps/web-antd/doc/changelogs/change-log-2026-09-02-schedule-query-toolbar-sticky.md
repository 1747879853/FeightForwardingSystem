# 船期查询顶部查询条真正吸顶

## 背景意图

查询条已经写了 `position: sticky`，但后台布局外层是 `overflow: hidden`，真正滚动的不是工具栏所在这一层，滚动方案列表时查询条仍会被带走。对照场景需要一直能改港口、改筛选。

## 核心逻辑变更

- `Page` 打开 `auto-content-height`，内容区锁成布局剩余高度。
- 查询条（标题、港口、日期、查询，以及查询后的直达/中转与二次筛选）`flex-shrink: 0` 钉在内容区顶部。
- 方案列表所在 `.schedule-main` 自己滚动。分组键、接口、字段含义未改。

## 避坑指南

- 不要只给工具栏加 `sticky` 而不改滚动容器：Vben 内容列 `overflow: hidden` 会让 sticky 失效。
- 下拉（港口、船公司、日期）仍走 Ant Design 默认挂到 `body`，不会被列表滚动层裁切。
