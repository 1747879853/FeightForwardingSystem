# 海运出口港口服务项配置明细支持手动调整顺序

## 背景意图

服务项配置弹窗中的明细列表此前只能按新增顺序排列，用户在维护过程中无法直接调整先后顺序，导致需要删除重建或反复编辑才能达到目标展示与执行顺位。

## 核心逻辑变更

1. 在 `SeServiceConfigAdmin` 明细卡片头部新增“上移 / 下移”操作，支持在当前弹窗内手动调整服务项顺序。
2. 新增和编辑提交时统一按当前列表顺序写入 `sortId`（从 0 开始），确保前后端排序口径一致。
3. 编辑回显时按后端返回的 `sortId` 排序后再渲染，避免历史数据顺序漂移。
4. 补充中英文 i18n 文案与排序提示，明确“手动调整 + 自动写入 sortId”的行为。

## 避坑指南

- `seServiceConfigItems` 的顺序与 `sortId` 必须保持一致提交，不要只改数组顺序而遗漏 `sortId`。
- 旧数据可能存在 `sortId` 为空，前端回显时应将空值放到末尾，避免打乱已有显式排序。
- 若后端后续改为仅信任 `sortId`，前端仍应继续保证数组顺序与 `sortId` 双一致，降低兼容风险。
