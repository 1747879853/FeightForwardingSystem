# 提单管理改为一级菜单

## 背景意图

提单管理原挂在侧边栏「操作管理」分组下。业务上它是独立的签入、换签、扣单和签出入口，需提升为与「业务联系单」同级的一级菜单，便于直接进入。

## 核心逻辑变更

- 从 `operation-management.ts` 抽出提单路由，新建 `router/routes/modules/bill-of-lading.ts`。
- 顶层路由 `order: 195`、`hideChildrenInMenu: true`。侧边栏展示为一级「提单管理」，位于「业务联系单」(194) 之后；「操作管理」顺延为 196。
- 页面路径不变：`/bill-of-lading`。路由名仍为 `BillOfLadingList`，列表缓存与分组配置键不受影响。
- 「操作管理」分组权限收回 `Admin.SeaExport`。提单查看权限只控制一级菜单本身。

## 避坑指南

- 模块文件会被 `import.meta.glob('./modules/**/*.ts')` 自动合并，无需改 `routes/index.ts`。
- 只有提单查看权限、没有海运出口权限的账号，调整后不再看到「操作管理」。海运进口、空运出口、监装仍跟调整前一样，要能看到「操作管理」分组，账号上仍需有海运出口权限。
