# 业务联系单干系人下拉按用户属性过滤

## 背景意图

编辑页右侧干系人、审核通过弹窗「指派操作」打开用户下拉时列出全部账号。海运出口/进口已把行上的 `userAttribute` 传给 `UserSelect`，业务联系单漏传，选销售能看到操作、财务等无关人员。

## 核心逻辑变更

- 干系人面板每行 `UserSelect` 传入该角色的 `userAttribute`，只展示带对应位标志的用户。
- 审核通过弹窗指派操作人同样只筛「操作」属性。

## 避坑指南

- 列表筛选里的销售/操作下拉本来就带了 `userAttribute`，不要误改。
- 不传或传 `0` 时 `UserSelect` 不过滤属性，等于全员。
