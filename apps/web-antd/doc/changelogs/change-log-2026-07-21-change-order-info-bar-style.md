# 更改单订单信息条样式精简（去配置入口）

## 背景意图

顶部订单信息区仍偏「卡片 + 操作按钮」形态，配置齿轮对更改单录入无必要，且标题/摘要分行占高。改为更轻的通栏摘要条，去掉本页配置入口。

## 核心逻辑变更

1. **去掉配置**：移除右上角齿轮与 `DisplayFieldsConfigModal`；仍只读共用 `order_fee_display_config`（可在应收应付页改字段显隐）。
2. **样式**：由 Card 改为浅底通栏；折叠时「标题 + 关键字段 + 展开」同一行，字段间竖线分隔、超长省略；展开为紧凑栅格，空字段链接触发。

## 避坑指南

- 更改单页不再能改显示字段；若需调整可见字段，请到应收应付页配置，或改 `KEY_ORDER_INFO_KEYS` / `allDisplayFields`。
- `font-weight: 500` 用于摘要值，避免非标准字重。
