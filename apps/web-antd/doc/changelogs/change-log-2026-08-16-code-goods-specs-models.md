# 1. 背景意图 (Background)

品名（`CodeGoods`）后端新增规格/型号子表，且海运进口箱表规格/型号改为引用子表 id。基础资料维护页此前只能编辑主表字段，无法配置下拉候选项；同时接口要求提交 `cargoId`。

# 2. 核心逻辑变更 (Core Logic)

1. `CodeGoodsAdmin` API：`Add/Edit/Dto` 补齐 `cargoId`、`codeGoodsSpecs`、`codeGoodsModels`；规格/型号 Edit 明细支持 `id` 有则改、无则增；列表查询支持 `CargoId`。
2. 品名弹窗表单增加「规格明细」「型号明细」可增删表格（名称/排序/备注）；编辑回填保留明细 `id`，提交全量数组。
3. 提交前做名称必填、长度、同名（去空格大小写不敏感）校验；主表补货物类型必选，列表与筛选同步展示/过滤。
4. 字段长度按接口文档对齐（如名称 128、描述 256、备注 1024）。

# 3. 避坑指南 (Pitfalls)

- 编辑子表必须全量提交：未带回的旧行会被后端删除；不要用删除标记字段。
- 已被海运进口箱表引用的规格/型号删不掉，需先在业务单上改选。
- `cargoId` 与业务单一致，传数字 `0/1/2/3`（普通货/冻柜/危险品/超限箱），不是字母 `S/R/D/O`。
- 海运进口箱表侧此前已改为 `codeGoodsSpecId` / `codeGoodsModelId`，切换品名须清空这两列。
