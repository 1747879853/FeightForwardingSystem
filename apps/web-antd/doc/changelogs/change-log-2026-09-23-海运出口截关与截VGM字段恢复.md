# 海运出口截关与截VGM字段恢复

## 背景意图

按本次业务要求，截关日期使用后端 `closingTime`，恢复 `closeVgmTime` 的截VGM含义。此前 closingTime 隐藏、VGM 显示为截港、舱单显示为截关，导致字段含义混淆。

## 核心逻辑变更

- 新建和编辑展示截关日期，船期区扩为八列：货好、开船、实际开船、预抵、截单、截VGM、截关、截舱单。
- 截关加入开船日期校验和批量修改；详情回填与单条提交原本已支持该字段。
- 中英文标签、费用信息、列表标签与简报统一字段含义。
- 码头查询 customsCloseDate 回填 closingTime；cyClosing 不再覆盖截VGM。

## 避坑指南

- 用户明确指定的字段含义优先于历史日志及后端旧注释；closeManifestTime 仍是独立的截舱单字段。
- 历史数据不自动搬移；GetDates 未返回 closingTime，不猜测历史日期。
- 基于临时 Git 暂存区审阅本次字段差异，未改变用户真实暂存区。
- 已通过格式检查、映射断言、JSON 解析与差异空白检查；未运行浏览器验收。
