# 客户编辑「是否共享」挪到所属公司标题右侧

## 背景意图

客户新建/编辑页「是否共享」原先在客户信息分区底部，不易发现；产品要求放到基础信息「所属公司」标题右侧，并提示共享后全集团可见。

## 核心逻辑变更

- `base/data.ts`：从客户信息 schema 移除 `isShared`；基础信息增加隐藏 `isShared` 字段（参与取值/脏检查）；`orgId` 标签行 `labelClass: w-full`。
- `org-shared-label.vue` + `form.vue`：所属公司标题右侧渲染「是否共享」开关与问号提示「共享后全集团可见」。
- 详情回填与新增/编辑提交补传 `isShared`（此前 UI 有开关但未进 DTO）。

## 避坑指南

- 标题区开关只是 UI，真实表单字段仍是隐藏的 `isShared`，切换时须 `setFieldValue`，否则脏检查与提交拿不到值。
- 勿再把 `isShared` 放回客户信息分区，避免双份控件。
