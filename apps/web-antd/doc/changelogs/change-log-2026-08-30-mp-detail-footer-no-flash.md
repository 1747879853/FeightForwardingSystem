# 进详情时底栏按钮不再跟着系统 Tab 闪一下

## 背景意图

从监装列表（底栏页）进详情时，微信会收起原生 tabBar，详情里 `position: fixed; bottom: 0` 的按钮会跟着跳。接口回来后底栏才插入，也会再闪一次。

## 核心逻辑变更

- 回列表时 `onShow` 里补一次 `showTabBar`，不再进详情时 `hideTabBar`（藏了回来经常显示不出来）。
- 详情底栏等切页约 180ms 后再出现，避开和系统 tabBar 抢 `bottom`。
- 详情用 URL 上的 `status` 先决定按钮，不再等详情接口。

## 避坑指南

- 从 tabBar 页进二级页，要先把系统底栏藏掉，自定义底栏才不会和它抢 `bottom: 0`。
- 保存仍等详情拉回后再点，避免空箱提交。
