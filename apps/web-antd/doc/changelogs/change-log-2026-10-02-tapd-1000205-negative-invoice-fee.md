# 开票申请支持负数费用抵减

TAPD：1000205

## 背景意图

折扣、返利会录成负数费用。这类费用要能和正数费用开进同一张开票申请，明细金额带符号相加，整张申请折成开票申请币别后的合计以及商品明细每行金额仍必须大于 0。

## 核心逻辑变更

- 选费用时，本次申请金额按费用方向限制区间：正数费用可冲红到已占用额度，负数费用默认带出剩余负数，不能填成正数，也不能超过剩余额度。
- 金额、未开票金额、勾选合计为负时用红色显示。列表申请金额合计、费用明细里的负数同样按原值显示。
- 提交时，申请合计小于等于 0 提示「费用明细申请金额合计(折成开票申请币别…)必须大于0」；商品明细有一行小于等于 0 提示「商品明细金额必须大于0」。商品金额输入不能小于 0.01。
- 已按发票收费结算的下限仍由后端校验，前端不拦截接口返回的报错。
