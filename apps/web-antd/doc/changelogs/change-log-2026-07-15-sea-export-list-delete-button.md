# 海运出口列表补充删除按钮

## 背景意图

海运出口列表已有删除接口和多选能力，但顶部工具栏缺少删除入口，业务人员无法从列表直接删除误建委托。

## 核心逻辑变更

- 顶部工具栏新增危险样式的「删除」按钮，并通过 `Admin.SeaExport.Delete` 权限控制显示。
- 删除前要求恰好勾选一条记录，并展示包含委托编号、主提单号或记录 ID 的二次确认弹窗。
- 删除成功后清理表格勾选状态、刷新当前列表并展示成功提示。
- 删除接口参数兼容 `number | string`，与列表 DTO 可能返回 GUID 的 ID 类型保持一致。

## 避坑指南

- 列表采用 checkbox 多选，删除仍限定单条；不要改为行内操作列。
- 删除按钮必须保留权限指令，避免仅依赖后端鉴权导致无权限用户看到入口。
- GUID 不可转换为数字，调用删除接口时应原样透传 ID。
