# 海运出口箱型箱量支持批量新增

## 背景意图

TAPD `#0694`：海运出口「箱型箱量」此前只能点「+」逐条加空行，多柜（如 20FR×11）录入成本高。需提供「批量新增」：按箱型填数量后一次生成多行集装箱信息。

## 核心逻辑变更

- `order-ctn-table.vue` 标题栏新增「批量新增」Popover。
- 打开时分页拉取全部启用箱型（`status=0`），不按 `isDefault` 裁剪；顶部支持按箱型名本地搜索。
- 确认后按各箱型数量展开为「一行一柜」，预填 `ctnCodeId`/`ctnCodeName`，并复用订单级总包装默认值。
- 单箱型上限 99、单次合计上限 200；原单条「+」添加保留。
- 补齐 `zh-CN` / `en-US` 文案。

## 避坑指南

- 箱型主键为雪花 ID，生成行时原样透传，禁止 `Number(id)`。
- 搜索过滤只影响列表展示，确认时仍按全部已填数量汇总生成，避免搜完丢数量。
- 弹层箱型列表依赖 `CtnCodeAdmin/GetPagedListAsync`，禁用箱型（`status=1`）不展示。
