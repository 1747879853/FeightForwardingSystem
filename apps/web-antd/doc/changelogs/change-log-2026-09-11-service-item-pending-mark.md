# 背景意图

工作台与海运出口的服务项目节点原先只靠颜色/图标区分待处理，扫一眼不够直观。待处理项需要直接露出文字「待」。

# 核心逻辑变更

1. **工作台**：`待处理` 页签下，服务项 chevron 左侧显示橙色「待」徽标；已处理页签不显示。
2. **海运出口详情**：流水线 `active`（当前待处理）节点用「待」替换时钟图标；已完成仍用对勾，未到节点不变。
3. **海运出口列表**：业务状态为进行中时，文案前加同一「待」徽标（如「待 放舱」）。

# 避坑指南

- 海运进口目前没有服务项目流水线，本次未改进口页。
- 工作台「待」只跟处理状态页签走，与当前选中的服务项节点无关。
- 徽标在 chevron 内部，避免被 `clip-path` 裁掉。
