# 2026-09-05 新建成功 replace 进编辑并关闭新建页签

## 背景意图

新建页与编辑页是不同 Tab key。仅 `push` 会在顶栏留下新建、编辑两个页签；仅 `replace` 仍会留下新建页签。应对齐海运出口：先 `await router.replace` 进编辑页，再 `closeTabByKey` 关掉跳转前缓存的新建 `fullPath`。

## 核心逻辑变更

下列页面新建保存成功后统一为「replace 进编辑 + 关闭新建页签」：

- 系统用户：`push` 改为 `replace`，原已有关页签
- 付费申请：抽屉自动建单与顶栏保存两处补关页签
- 银行水单、收费核销（按费用 / 按发票）、业务联系单、自动费用模板：原已 `replace`，补 `closeTabByKey`

收费核销抽屉内嵌新建仍只 `emit('close')`，不改顶栏页签。

## 避坑指南

- 必须先 `await` 导航再关新建页签；否则当前激活页仍是新建页，关的是当前页，会跳到相邻页签
- 关页签的 key 必须是跳转前的 `route.fullPath`，不能关完再读当前路由
- 提交后回列表、保存后继续新建（重置表单）不要套这套跳转
