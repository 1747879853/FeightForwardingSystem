# 背景意图

海运出口编辑页「运踪信息」在按箱轨迹落地后，Tab 外包了一层白卡，航段日期用两端拉开的横排，箱行又是一排可换行的碎片，宽屏会显得松、窄屏会对不齐。本次只收版式，不改订阅、快照和节点口径。

# 核心逻辑变更

1. **去掉套卡：** `editor.vue` 运踪 Tab 不再用 `m-3 rounded-xl bg-white` 再包一层，改成内容区直接铺开；摘要卡和箱行自己带边框。
2. **航段时间条：** 仍是左路径、右「离开 / 到达」两列，预计在上、实际在下；每格改为上标签下数值，不再 `space-between` 把日期拉到最右侧。
3. **箱行对齐：** 折叠头改成四列网格（箱号+标记 / 当前状态与地点 / 节点数 / 箭头），默认仍折叠；状态不再靠 `margin-left: auto` 挤到行尾后乱换行。
4. **sjtd 旧运踪：** `yundang-tracking-panel.vue` 的 Descriptions 与航段表加上圆角浅底，去掉整页白底铺满，和编辑页其它 Tab 的密度接近。

# 避坑指南

- 海进列表弹窗也复用 `container-tracking-panel.vue`，箱行网格会一起变；不要只在海出编辑页再写一份样式。
- 箱行默认折叠是 2026-09-17 按箱轨迹的产品口径，这次没有改成默认展开。
- sjtd 海运出口仍走云当面板；新服务商品牌才看得到航段卡和箱行网格。
