# 海运出口基础信息字段顺序对齐业务稿

## 背景意图

- 海运出口新建/编辑「基础信息」6 列栅格原先第二行是报关行、仓库、保险公司、订舱编号、主提单号、场站，合同号也未纳入显式排序，落到末尾。
- 业务稿要求按「订舱编号 → 主提单号 → 保险公司 → 报关行 → 仓库 → 场站」排第二行，第三行末尾放合同号；稿中没有的字段保持原样、不新增。

## 核心逻辑变更

- `form.vue` 的 `BASIC_INFO_FIELD_ORDER` 调整为：
  1. 委托单位、船公司、船名/航次、船代、订舱代理、车队
  2. 订舱编号、主提单号、保险公司、报关行、仓库、场站
  3. 签单方式、提单/副本份数、付费方式/付款地点、运输条款/贸易条款、合同号
- 头部只读/下拉（委托编号、会计期间、应结日期、归属组织、业务来源、装运方式、订单类型）仍在标题栏，不占栅格。
- 签单地点/日期、贸易条款隐藏载体等仍 `hidden`，仅保留在排序表里避免落到可见末尾。

## 避坑指南

- 基础信息可见顺序以 `BASIC_INFO_FIELD_ORDER` 为准，不要只改 `useBasicInfoFormSchema` 数组顺序；表单组装后会按该 Map 再排一次。
- 合同号必须写进排序表，否则 `sort` 会把它丢到所有已登记字段之后。
