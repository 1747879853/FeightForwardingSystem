# 业务联系单费用工具栏合并添加并改用海出 icon

## 背景意图

新建/编辑页费用区原先有「添加应收」「添加应付」两个文案按钮，以及独立的「删除」文案按钮。收付类型已在行内可切换，双添加入口冗余；视觉上希望与海运出口「箱型箱量」工具栏的 `mdi:add-box` / `mdi:close-box` icon 按钮一致。

## 核心逻辑变更

- `fee-table.vue`：合并为一个「添加费用」入口，默认 `paySide = 0`（应收），行内「收付」列可改应付。
- 添加 / 删除改为海出 `order-ctn-table` 同款 text icon 按钮（蓝底加号 / 红底关闭，未选中删除置灰）。
- 勾选行后删除、箱型驱动应收联动等业务逻辑不变。

## 避坑指南

- 不要再拆「添加应收 / 添加应付」两个入口；需要应付时在新行改「收付」列即可。
- icon 样式类与海出箱型表保持一致，后续若统一抽组件应两边一起改。
