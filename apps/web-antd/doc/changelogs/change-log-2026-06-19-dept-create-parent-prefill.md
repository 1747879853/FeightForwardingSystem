# 组织管理：新增组织自动带出上级组织

## 背景意图

用户在左侧组织架构树选中某节点后，点击顶部「+」新增组织时，期望「上级组织」字段自动填充为当前选中节点，与右键「新增下级」行为一致。

## 核心逻辑变更

- `list.vue` 中 `onCreateOrg`：若 `selectedKeys` 有值，向表单弹窗传入 `{ parentId }`；未选中时仍传 `null`（上级组织留空）。

## 避坑指南

- 右键「新增下级」已通过 `onAppendOrg` 传入 `parentId`，本次仅补齐顶部新增按钮路径，勿重复修改 `form.vue` 的 `onOpenChange` 逻辑。
