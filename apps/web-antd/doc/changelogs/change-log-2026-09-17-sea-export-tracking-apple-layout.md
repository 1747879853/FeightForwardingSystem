# 背景意图

运踪 Tab 上一版箱轨迹是纵向时间轴，顶部摘要又占了两块卡，「01」航段序号没有业务含义。按操作习惯改回横向时间轴，并把顶部收成一行统计 + 一行航段，视觉靠苹果系统设置那种浅底、细线和短标签。

# 核心逻辑变更

1. **时间轴横向：** `container-tracking-panel.vue` 箱轨迹改回默认横向 `TrackingTimeline`；首个箱默认展开，方便一进 Tab 就看到轴。节点数据、排序、状态口径不变。
2. **去掉 01：** 航段不再显示序号徽章。港口名本身就能区分航段。
3. **顶部空间：** 订阅号 / 船公司 / 订舱 / 箱量同一行四列；航段一行是「起运港 → 目的港 + 船名」，右侧 ETD/ATD/ETA/ATA 四个短标签横排。
4. **苹果风：** 运踪 Tab 底 `#f2f2f7`，卡片白底 12px 圆角、0.5px 分割线，字重 590、略收字距；横向轴连线改细。
5. **顶部航次卡：** 不再用四列表格。上半是登机牌式票根（大号订阅号 + 船公司/订舱/箱量），虚线打孔分隔；下半三列：左起运港、中间航线小船、右目的港；ETD/ATD 挂起运、ETA/ATA 挂目的，船名航次落在航线正下方。航线不要再单独占一整行，否则顶卡被撑高。

# 避坑指南

- 时间标签改成 ETD/ATD/ETA/ATA，只在本面板 `tracking.overview.*` 使用；不要把长文案加回去，否则顶卡又会被撑高。
- `:open="index === 0"` 只给首箱默认展开，用户仍可收起；不要改成所有箱都展开。
- 海进列表弹窗共用这块面板，顶卡四列和横向轴会一起变。
