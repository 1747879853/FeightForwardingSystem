# 关联核销单金额列对齐与差值高亮

## 背景意图

关联核销单里的本次结算、原始结算金额、差值需要按财务表习惯右对齐，方便上下对小数点。差值为 0 的单据应退到背景里，非 0 的差额要能一眼扫到。

## 核心逻辑变更

- 三列继续使用列 `align: 'right'`，表头和单元格都右对齐；单元格改为块级等宽数字，避免字宽不同导致小数点错位。
- 差值来自列表 `diffAmount`。绝对值小于 0.005 视为 0，显示灰色；其余非 0 用橙色加粗。空值仍显示 `-`，不上色。

## 避坑指南

- 不要用核销状态给差值上色。差值是本次结算减原始结算金额，和录入中、已锁定无关。
- 展开区的费用明细金额不是这三列，不要套用同一套橙色规则。
