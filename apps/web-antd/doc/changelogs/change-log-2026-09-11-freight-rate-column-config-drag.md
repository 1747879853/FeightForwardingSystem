# 运价批量新增列配置改为拖拽排序

## 背景意图

列配置原先用「上移 / 下移」按钮调整顺序，操作繁琐，与常见表格列设置交互不一致。

## 核心逻辑变更

- `column-config-modal.vue`：分区内（左固定 / 普通 / 右固定）使用 `sortablejs` 手柄拖拽排序，去掉 ↑↓ 按钮。
- 拖拽结束后按「左固定 → 普通 → 右固定」重写 `order`；固定状态变更时将该列移入目标分区末尾。
- 弹窗标题增加「拖拽调整顺序」提示。

## 避坑指南

- 仅同分区内可拖拽，跨分区请用固定按钮；分区长度变化后会重建 Sortable 实例。
- 依赖 `apps/web-antd` 已有的 `sortablejs`，勿再引入 vuedraggable。
