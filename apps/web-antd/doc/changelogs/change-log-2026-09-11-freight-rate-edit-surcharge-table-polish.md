# 运价新增/编辑弹窗附加费表格样式优化

## 背景意图

`edit-form.vue` 附加费区域虽已有分区卡片外壳，表内仍是扁平灰边表格，费用基础信息与箱型价格区混在一起，空态与行操作反馈偏弱。

## 核心逻辑变更

- 表头增加条数徽标与操作说明；空态改为图标 + 标题 + 引导文案
- 表格分区：序号 / 费用基础（名称·币别·计费）/ 箱型价格（chip 表头）/ 操作
- 按票、条件模式单元格用底色与标签区分；条件按钮启用态高亮
- 行悬停、删除/添加按钮、算符切换、输入聚焦补交互反馈
- 顺带修正「按票」价只在首个箱型列录入（原先首行附加费会在所有箱型列重复显示输入框）
- 业务提交字段与条件计费逻辑未改

## 避坑指南

- 附加费区仅横向滚动（`.surcharge-table-wrap`），纵向仍交给弹窗内容区，避免再套 `vh` 内层滚动
- 通用 `.section-body :deep(table)` 边框规则需在附加费表上覆盖，否则与外层 wrap 双边框重叠
