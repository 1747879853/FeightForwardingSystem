# 1. 背景意图 (Background)

供应商开给我们的票会定时落入进项发票。付费申请录发票时不必手抄，可从当前公司、结算对象近一个月内未占用的进项票里勾选，回填票号、日期、抬头、金额和 PDF。

# 2. 核心逻辑变更 (Core Logic)

- 发票明细增加「从进项发票选择」，调 `PaymentApplicationAdmin/GetInputInvoiceListAsync`。
- `orgId` 必须传公司节点：优先组织串 `isCompany`，否则用当前归属组织换算公司。
- 已填（含未保存）的发票号放进 `excludeInvoiceNos`，避免重复挑到。
- 结算币别已选银行账户时传 `clientInvoiceInfoId`（该银行所属开票信息），只用这一条税号匹配；没选银行则不传，用结算对象名下全部开票信息。多币别只能传一个：优先人民币（`RMB`/`CNY`）银行，没有再取第一条。
- 勾选结果先填空发票号行，再追加；不覆盖已有票号。不自动保存。

# 3. 避坑指南 (Pitfalls)

- 传部门 `orgId` 会得到空列表且不报错。
- 结算对象没维护纳税人识别号、或指定的开票信息对不上，同样空列表不报错。
- 进项发票 `id` 只用于勾选，不要提交给付费申请发票子表。
