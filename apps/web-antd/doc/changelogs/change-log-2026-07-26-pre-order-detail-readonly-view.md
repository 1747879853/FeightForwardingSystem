# 业务联系单详情页改为纯文本展示

## 背景意图

详情路由虽已独立，但仍复用编辑页表单组件（禁用态 Select/Input），审核查看时控件感重、也不符合「详情只读展示」预期。改为独立纯展示页。

## 核心逻辑变更

1. 新增 `views/pre-order/detail.vue`：布局对齐编辑页（主栏分区、港口流转卡片、货物左右分栏、右栏干系人），字段用纯文本，不挂载 vben/antd 表单控件；服务流水线用只读 `ServicePanel`。
2. 路由 `PreOrderDetail` 改为加载 `detail.vue`（不再复用 `editor.vue`）。
3. 审核相关动作（流程 / 撤回 / 通过 / 驳回 / 审核后驳回）与弹窗仍保留在详情页；通过后「关联海运出口」Tab 仍内嵌海出编辑器。
4. 状态与路由对齐逻辑保留：录入/驳回会 `replace` 回 `/edit`。

## 避坑指南

1. **展示取值优先详情嵌套对象**：委托单位/港口/费用代码等用 `name/cnName`，列表兜底字段作 fallback。
2. **费用行业类别存的是 options.key（数字）**，展示时按 `key` 匹配，不要按字母 `value` 匹配。
3. **审核弹窗仍可用表单控件**：仅详情主体展示禁表单；`AuditModal` 填写意见/指派操作不受影响。
