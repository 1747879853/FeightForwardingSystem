# 银行流水新建/编辑页布局改版

## 背景意图

在银行流水编辑页内完成关联收费结算查看与快捷建单，减少跳转收费结算新建页的操作路径；操作人配置移至标题行以释放主表单区域。

## 核心逻辑变更

1. **标题行操作人**：Tag 摘要 + Popover 多行编辑（`operator-title-bar.vue`），新建/编辑页共用。
2. **编辑页主布局**：左 40% 流水信息（含核销状态 Tag），右 60% 关联收费结算列表（全列、分页、搜索、行展开调 `DetailAsync` 只读明细、双击跳转编辑）。
3. **底部选费建单**：内嵌收费结算选费能力（`create-settlement-fee-panel.vue`），独立「创建结算单」按钮；顶部「保存」仅维护银行流水。
4. **状态展示**：收费结算 `status` 数字归一化后映射中文；流水 `writeOffStatus` 在编辑页流水号旁展示。
5. **新建页**：仅标题行操作人 + 左流水信息；保存后跳转编辑页再展示右侧与底部区块。

## 避坑指南

- 创建结算单后需刷新流水详情、关联列表与选费列表，以更新 `settledAmount` 与剩余可结算校验。
- 右侧关联列表展开明细按结算单 ID 缓存，避免重复请求 `DetailAsync`。
- 底部建单需 `Admin.ReceiveSettlement.Add` 权限，与原先「新建收费结算」按钮权限一致。
