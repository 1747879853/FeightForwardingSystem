# 付费结算选择列表仍显示本单已部分核销的申请

## 背景意图

同一张付费结算里，已经核销过一部分的付费申请还有剩余。再打开选择抽屉按申请单号搜索，列表里没有它。业务上要能看到剩余未结费用，只是不能再勾一次。

## 核心逻辑变更

- 选择付费申请列表不再把当前结算单 id 传给 `GetPagedListByCurrencyForSettlementAsync`。
- 接口因此不再排除本单已关联的付费申请。仍有未结算余额的申请会回到列表。
- 已经在本单里的行继续用 `existingRowKeys` 把勾选框置灰，并在单号旁显示「已选」。全选会跳过这些行。

## 避坑指南

- 不要再把结算单 id 传回去，否则接口会把整张已关联申请排除，剩余费用又会从列表消失。
- 勾选框是否置灰取决于行 `rowKey` 是否已在本单明细里。对不上时会变成可勾，等于又能加一次。
