# TAPD #1000985：应收应付审核检索栏收起时按钮回到第一行

## 背景

[TAPD #1161580498001000985](https://www.tapd.cn/61580498/bugtrace/bugs/view/1161580498001000985)：应收应付审核检索栏在收起状态下，重置、搜索、展开单独占一行，挤掉列表高度。展开后按钮位置保持不变。

## 改动

1. 查询表单收起时，操作按钮钉在第一行最后一列（`form-actions` 的 `rowEnd` + `row-start-1`）。展开后仍靠最后一行右侧。
2. 折叠掉的字段使用 `!hidden`，避免被表单项上的 `flex` 盖掉后继续占格子。
3. 折叠保留行数按表单项的实际纵向位置计算。按钮占住第一行末列后，开航日期、销售、操作等第二行条件在收起时隐藏。

## 验收

- 应收应付审核进入页面（检索栏收起）：只占一行。第一行为审核状态、业务类型、编号、委托单位，右侧是重置、搜索、展开。
- 点击展开后出现开航日期、销售、操作，按钮回到条件区最后一行右侧；再收起恢复为一行。
