# 2026-09-06 监装明细包装占位区分未填包装与无明细

## 背景意图

主单已经填了包装时，明细包装下拉仍显示「该海运出口未填写包装，不能选择明细包装」。真实原因往往是该包装类型没有明细子表，占位把两种空态写死成一句。

## 核心逻辑变更

- 空态对齐堆场：记下已保存 `savedPackageId`，再按有没有 `codePackageItems` 分支占位。
- 未填包装仍用 `packageMissing`。
- 已填包装但子表为空改为 `packageItemEmpty`：「包装「x」未维护明细包装，请到基础数据-包装代码里添加」。
- 包装 id 同时认 `transportOrder.codePackageId` 与 `codePackage.id`。

## 避坑指南

- **主单包装和明细包装不是同一个东西。** 基础信息选的是包装类型；监装下拉来自该类型的 `codePackageItems`。老包装类型经常没有子表。
- **只认已保存海出。** 基础信息改了包装但没点保存，监装仍按库值判断，占位不会跟着未保存值变。
