# 提单详情基础信息三列

## 背景意图

提单详情弹窗已经够宽，基础信息仍按两列排布，同一组字段要多换一行才能看完。

## 核心逻辑变更

- 基础信息各组字段改为三列。港口流向仍单独占满一行。
- 销售 / 操作与委托编号、委托单位并排，不再占满整行。
- 窗口窄于 960px 时退回两列，窄于 768px 时退回一列。

## 避坑指南

港口流向是整段流向，不要拆进单列。窄屏规则要写在三列规则之后，否则会被桌面三列盖住。

## 验证

本地打开提单详情，四组字段栅格均为三列。港口流向单独占满一行；船公司、船名 / 航次、开船日期同一行；委托编号、委托单位、销售 / 操作同一行；结算对象、未收金额、应结日期同一行，超期天数与承诺付款在下一行；签单方式、签入日期、签出日期同一行。字段没有横向溢出。
