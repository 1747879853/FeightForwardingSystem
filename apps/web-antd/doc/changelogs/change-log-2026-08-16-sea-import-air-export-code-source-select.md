# 海运进口 / 空运出口业务来源改为可下拉二次修改

## 背景意图

- 海运出口头部业务来源已可下拉再改；海运进口、空运出口仍是禁用下拉，编辑态空值还显示「-」，保存后无法改。

## 核心逻辑变更

- 两处共用表单（新建/编辑同一组件）去掉 `disabled` 与空值短横线，改回可清空的 `CodeSourceSelect`。
- 头部选择通过 `handleHeaderCodeSourceChange` 写回隐藏字段 `codeSourceId`，保存口径不变。

## 避坑指南

- 这两条业务线目前**不会**随委托单位自动带出业务来源（与海运出口不同）；换客户不会覆盖已选手选值。
