# 背景意图

箱轨迹卡用原生 `details` 展开会瞬间撑开，没有过渡。横向时间轴仍偏 Ant 大圆点+胶囊，和顶部登机牌的苹果风不齐。

# 核心逻辑变更

1. 箱卡改为按钮手风琴：`grid-template-rows: 0fr / 1fr` 做高度过渡，内容淡入，箭头同步旋转。首箱仍默认展开；用户收起后刷新同一票会尽量保留已打开的箱。
2. 横向时间轴改细线小圆点：已完成实心绿、当前蓝点轻脉冲、预计空心橙。状态改成彩色字不再用胶囊底。已完成段连线偏绿，当前之后改虚线。
3. 节点数据、排序、订阅逻辑未改。空运共用 `tracking-timeline.vue` 的横向样式一起变；纵向布局仍保留图标圆点。

# 避坑指南

- 不要再给箱卡绑 `:open`，原生 `details` 无法做高度动画。
- `prefers-reduced-motion` 下取消高度过渡和当前点脉冲。
- 海进列表弹窗与海出/海进编辑 Tab 共用这块面板。
