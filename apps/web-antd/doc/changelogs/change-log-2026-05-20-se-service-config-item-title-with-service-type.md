# 2026-05-20 海运出口港口服务项标题显示服务项名称

## 背景意图

- 弹窗内明细标题仅显示“服务项 #序号”，当存在多条配置时识别成本较高。
- 用户在滚动编辑时无法快速判断当前块对应的服务项类型，影响操作效率。

## 核心逻辑变更

- 新增标题计算逻辑：在“服务项 #序号”后追加当前已选 `serviceType` 的枚举文案。
- 标题展示格式调整为：`服务项 #1 · {服务项名称}`。
- 未选择服务项类型时保持原有编号标题，避免展示空文案。

## 避坑指南

- 标题文案依赖 `serviceTypeOptions`，请确保弹窗打开时先完成枚举加载再渲染标题。
- 若后续引入多语言枚举源，标题无需额外改造，沿用下拉选项中的 `label` 即可自动适配。
