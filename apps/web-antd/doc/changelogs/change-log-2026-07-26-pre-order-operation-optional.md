# 2026-07-26 业务联系单干系人操作改为非必填

## 背景意图

录入/保存阶段「操作」与销售同为必填，销售常未定操作人时无法保存。操作应延后到审核通过时再强制指派（后端生成海运出口仍需要）。

## 核心逻辑变更

1. 干系人面板 `REQUIRED_ROLES` 仅保留销售：操作不再显示星标，允许删除。
2. `validateUsers` 只校验销售必填且唯一，去掉「所有干系人行必须已选人」拦截。
3. 提交 `preOrderUsers` 时用 `hasValidUserId` 剔除未选人的行，避免把空操作行打到后端。
4. 审核通过弹窗仍在缺失操作人时强制指派（后端卡点不变）。

## 避坑指南

- 勿把海运出口干系人必填规则同步改掉；本次仅业务联系单。
- 新建态仍默认展示操作行，只是可不填、可删；空行不会进 payload。
