# 银行流水关联核销按发票展开，并补按发票新建本次结算

## 背景意图

银行流水核销已按各收费结算「本次结算」汇总。关联列表要能展开看按发票单的「发票开出 → 费用」；按发票新建也要录入本次结算，否则后端拒收、流水已结算金额也不会更新。TAPD #1000180。

## 核心逻辑变更

- 编辑页把详情 `receiveSettlements` 传给关联核销单面板。只有按发票（`type=1`）且有 `invoiceIssues` 的行可展开。
- 展开组头：开出单号、发票号、本组原始结算金额；`id` 为空显示「无发票开出（已冲红解绑）」。组内只读费用名称、收付、币别、结算金额、原始结算金额；金额缺省显示 `-`。
- 按发票新建底部增加「本次结算」必填，提交带 `actualSettled`；用它对比流水剩余可核销。明细净额只作参考，不拿来和本次结算比对。
- 选票可参考汇率自动填本次结算；用户改过之后不再覆盖。选票行结构若已切到「发票开出 + 费用」则一并提交，否则留给 #1000177。

## 避坑指南

- 列表分页接口的 `invoiceIssues` 没有费用行，展开必须用详情里的 `receiveSettlements`。
- 不要用核销状态判断能不能改币别和付款方；有没有收费结算看 `receiveSettlements` 是否为空。
- 按发票新建不填本次结算会被拦；明细删光时的本次结算仍由收费结算抽屉处理，本页列表不做勾选取消核销。
