# 业务联系单编辑页增加复制新建

## 背景意图

列表已有「复制」，编辑页没有入口。测试要求编辑界面也能复制新建，形式对齐海出：有「保存」时放进保存下拉；待审核/通过没有保存时单独出一个按钮。绑定新建权限。

## 核心逻辑变更

- 录入/驳回（有保存）：「保存」改为拆分按钮，下拉「复制新建」跳 `/pre-order/add?copyFrom=<当前单 id>`。
- 待审核/通过（无保存）：顶栏单独渲染「复制新建」，同样走 `copyFrom`。
- 空白新建页没有源单，不显示复制。
- 「复制新建」绑 `Admin.PreOrder.Add`；没有该权限时保存仍是普通按钮，避免空下拉。
- 复制仍走新建页已有预填（清单号与子表主键）。有未保存内容时走现有离开拦截。

## 避坑指南

- 不要再单独做「新建」拆分按钮；列表本身已有新建入口。
- 页签 key 含 `fullPath`，`copyFrom` 会开独立新建页签，不会冲掉正在填的空白新建。
