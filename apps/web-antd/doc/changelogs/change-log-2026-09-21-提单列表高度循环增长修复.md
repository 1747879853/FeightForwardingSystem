# 提单列表高度循环增长修复

## 背景意图

提单列表在停留期间持续增高。列表使用 VXE 自动高度，但 Page 内容区默认是普通块布局，嵌套的 `flex-1` 没有获得受约束的剩余高度，表格测量父容器后又撑高父容器。

## 核心逻辑变更

- Page 内容区显式设为纵向 flex。
- 数量卡片禁止压缩；列表区域用 `flex-1 min-h-0` 取得剩余空间。
- 表格父容器使用 `h-full min-h-0` 和溢出约束，分组栏在自身区域滚动。

## 避坑指南

VXE `height: auto` 的父容器必须具有明确高度来源。额外包裹卡片、侧栏时，要保持从 Page 到表格的高度约束链，不能依赖内容撑高后反推表格高度。

## 验证

本地浏览器加载真实列表后，两次间隔测量表格高度均为约 757.6px、父容器均为 750px；展开检索后自动重算回相同高度，没有继续向下增长。展开和收起筛选均可正常操作。
