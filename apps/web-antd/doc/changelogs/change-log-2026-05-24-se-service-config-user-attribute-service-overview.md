# 海运出口港口服务项配置 — 弹窗用户属性服务概览

**日期：** 2026-05-24  
**变更类型：** Feature  
**影响模块：** 基础资料 / 海运出口港口服务项配置

---

## 背景意图

配置弹窗中，服务项明细按条展开编辑，缺少「按用户属性汇总已配置服务」的全局视图，不便于快速核对各角色（销售、商务、操作等）负责哪些服务项。

---

## 核心逻辑变更

### 1. 弹窗（`modules/form.vue`）

| 变更项 | 内容 |
| --- | --- |
| 新增 `userAttributeServiceSummary` | 基于 `itemRows` 实时聚合：用户属性 → 已勾选的服务项类型 |
| 概览区块位置 | 置于「服务项配置明细」标题上方 |
| 展示规则 | 5 项海运出口用户角色均展示；无服务时显示「未配置」 |
| 文案来源 | 服务项类型优先枚举 label，兜底 `DEFAULT_SERVICE_TYPE_OPTIONS` |

### 2. i18n

新增 `userAttributeServiceOverview`、`noServiceConfigured` 中英文键。

---

## 影响范围

- 新增/编辑弹窗：编辑服务项类型或用户属性勾选时，概览区同步更新
- 不影响保存 payload 与后端接口

---

## 避坑指南

1. **概览为前端派生视图**：数据来自当前 `itemRows`，未选服务项类型或未勾选用户属性的行不会计入汇总。
2. **同一服务项可绑定多个用户属性**：概览按属性维度展开，同一服务类型可能出现在多行角色下。
