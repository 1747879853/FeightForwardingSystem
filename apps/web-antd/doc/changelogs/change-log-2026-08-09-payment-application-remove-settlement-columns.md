# 付费申请指定币别表移除实付金额与结算方式列

## 背景意图

指定结算币别模式下，结算币别卡片表格中的「实付金额」「结算方式」为前端占位展示，业务上不再需要，避免干扰银行账户选择与付款金额阅读。

## 核心逻辑变更

- `form.vue` 指定币别 `settlement-table` 删除「实付金额」「结算方式」列及相关 `col` / 样式。
- 保留「支付币别 / 付款金额 / 银行账户 / 银行账号」。
- `summarizeByCurrencyWithConversion` 的 `convertedTotal` 计算仍保留（审批等其它入口可能复用），仅表单不再展示。

## 避坑指南

- 勿与原币模式的币别卡片混淆；本次仅改指定币别表格。
- 删除展示列不等于删除折算逻辑，提交明细仍带 `rate` / `appliedAmount`。
