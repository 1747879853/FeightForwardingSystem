# 提单详情弹窗按业务分组并左右分栏

## 背景意图

首版弹窗信息平铺、单号重复、空值横杠多、历史区大块留白，B 端阅读成本高。按业务分组和左右分栏重排，补当前可做的快捷操作。

## 核心逻辑变更

- 标题行保留单号与复制，去掉卡片内重复大号；标签按主分单 / 签单方式 / 状态分级。
- 左侧按航程、业务负责人、结算风控、签单节点分组，左右结构展示字段；港口做成流向，金额带人民币符号，超期天数大于 0 告警。
- 空值改为「未维护 / 未排载 / 未超期」，不再铺满 `-`。
- 右侧时间轴展示操作历史，去掉套卡片；底部按状态与权限提供去签入、去签出、提交审核、扣单等，关闭只留右上角叉号。
- 未做打印/导出：提单模块没有对应接口。

## 避坑指南

底部快捷操作会关掉详情再打开原有动作弹窗，权限仍走 `actionPermission`，状态仍走 `canAct`。

## 验证

双击待签入票：标题可复制、空值为未维护/未排载、底部「去签入」能打开签入弹窗。双击有扣单历史且超期的电放票：右侧时间轴、超期天数告警、底部「提交签出审核 / 扣单」。
