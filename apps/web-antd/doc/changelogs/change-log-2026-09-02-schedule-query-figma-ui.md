# 船期查询按 Figma 还原方案列表样式

## 背景意图

专业 UI 已出桌面稿。页面仍是工程搭的方案工作台，层级和卡片节奏对不上稿。本次只换视觉与信息排布，分组算法、查询接口、字段含义不动。

## 核心逻辑变更

- 查询条做成吸顶工具栏：标题、港口对（交换图标）、日期、周数、「查询」黑按钮；查询后第二行是胶囊 Tab、幽灵下拉筛选和关键词。
- 结果区先写「找到 N 个共舱方案，共 M 个班次」，右侧本地记住最近航线，点胶囊可再查。
- 方案卡对齐稿：直达/中转 Tag + 共舱名主标题，下面星期/班次/码头；右侧航程大数字、最近离港 `MM-DD`、最早截关。展开后班次表把船名航次合成一列，日期和时间拆行，延误只用小红标「延误」。
- 卡片星期展示组内全部班期短写，仍不按星期拆组。点击共舱名复制。
- 港口选中回显为 `QINGDAO (CNTAO)`。图标来自设计稿导出 SVG。

## 避坑指南

- 不要改 `getScheduleGroupKey` / `getGroupName`。稿上的「周二、周四、周六」只是展示。
- 用户可见文案不要写第三方数据供应商名。
- 延误标签必须比日期行的灰色文字更具体，否则会被 `.moment-cell span` 盖成灰色。
