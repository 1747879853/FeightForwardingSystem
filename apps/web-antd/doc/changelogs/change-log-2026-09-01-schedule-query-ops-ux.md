# 船期查询按操作对照场景优化方案卡与班次表

## 背景意图

方案工作台已经能按共舱服务归组，但操作对照时仍要反复点进详情才看得到截关，卡片上码头空白占位、每行都打「准点」、一次只能展开一组，查询条还带英文装饰。这次按「先扫方案、再对照班次」改交互，分组算法不动。

## 核心逻辑变更

- 方案卡展示航程区间（组内最短–最长）、最近离港、最早截关；两端标准码头合成一条路径，缺一侧就只显示有值的那头。
- 班次表增加截关列；零点时刻只显示日期；延误才打 Tag，「准点」不再刷屏；组内第一班标「最近」。
- 可同时展开多个方案对照；查询后不再自动打开第一组，也不清空二次筛选（无效选项会剔除）。
- 筛选 Tab 数量跟当前船公司/码头/关键词走；筛选条吸顶；方案名可复制；交换港口时带着选中港口对象，避免只换五字码丢回显。
- 「航程最短」排序改按组内最短航程，不再按最大值把慢班顶到前面。

## 避坑指南

- 分组键、`groupName`、清洗去重仍以 [方案分组规则](../modules/schedule-query/grouping.md) 为准，本改动只动展示与交互。
- 截关列取班次 `cyCutoff`；卡片上的截关是组内最早一条，和某一班自己的截关可能不同。
- 点船名仍打开船舶定位，悬浮提示「查看船舶定位」，避免误当成普通链接。
