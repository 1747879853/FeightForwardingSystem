# 用户管理操作列收纳至「更多」

## 背景意图

用户列表操作列平铺 6 个按钮时列宽难兼顾：偏窄会裁切「修改」，偏宽又挤压其他列。需要外露高频操作，次要操作收入下拉。

## 核心逻辑变更

1. **`CellOperation`**：支持 `children` 配置，渲染为「更多」`Dropdown` + `Menu`；菜单内删除走 `Modal.confirm`。
2. **用户列表操作列**：外露「修改 / 权限配置 / 分配角色」，「银行账户 / 修改密码 / 删除」放入「更多」；列宽改为 `280`。
3. **i18n**：`common.more`（更多 / More）。

## 避坑指南

- 其他列表若要用「更多」，在 `options` 中增加 `{ code: 'more', children: [...] }` 即可，无需再复制下拉逻辑。
- 若账号保存过操作列宽，持久化配置可能仍偏宽/偏窄，需在列设置中恢复默认。
