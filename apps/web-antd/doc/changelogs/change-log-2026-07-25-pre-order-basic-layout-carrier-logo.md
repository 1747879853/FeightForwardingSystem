# 背景意图

业务联系单详情中的船公司需要与海运出口一致展示 Logo；新建页顶部只有一个「基础信息」Tab，没有切换意义；贸易条款与付费方式需要移到备注之前，优化录入顺序。

# 核心逻辑变更

1. 船公司详情回显优先使用业务联系单返回的 `carrierLogo`，没有 Logo 时补拉船公司详情，并将完整船公司对象写入 `CarrierSelect.selectedItems`。
2. `/pre-order/add` 新建态隐藏顶部 Tab 条；编辑态仍保留「基础信息」，存在海运出口时继续显示「关联海运出口」。
3. 基础信息字段顺序调整为：委托单位 → 主提单号 → 货好时间 → 开船日期 → 船公司 → 运输条款 → 贸易条款 → 付费方式 → 备注。
4. 付费方式未选择时明确显示「请选择」。

# 避坑指南

- 不要只向 `CarrierSelect.selectedItems` 传船公司 id 和名称，否则组件会认为已完成回显加载，无法获得 Logo。
- 异步补拉船公司详情后需核对当前单据的 `carrierId`，避免快速切换单据时旧请求覆盖新单据。
