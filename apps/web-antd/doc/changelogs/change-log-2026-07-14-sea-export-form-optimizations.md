# 海运出口表单校验与联动优化

## 背景意图

修复 TAPD 缺陷 `1161580498001000467` 中海运出口录单体验问题，使必填岗位、船期时间、付费地点和箱包装的交互规则与业务口径一致，并修正列表新增按钮图标对齐。

## 核心逻辑变更

- 干系人面板为销售、操作增加必填标识，保存仍复用既有必选人员校验。
- 保存时校验截 VGM、截单、截舱单日期不得晚于开船日期或实际开船日期。
- 付费方式为到付时，付费地点自动带出目的港；为预付时自动带出起运港。编辑详情回填同样执行联动并覆盖原付费地点。
- 新增箱型箱量行时，从订单级总包装同步包装 ID 与显示文本；箱行可继续独立修改，且无需额外请求包装详情。
- 包装选择组件补充 `change(value, option)` 事件，使业务表单能获得所选包装文本。
- 海运出口列表新增、复制按钮改用 Ant Design Vue `icon` 插槽，图标与文字垂直居中。

## 避坑指南

- 总包装和箱行包装共用包装基础资料数据源，但分别保存于 `transportOrder.codePackageId` 和 `orderCtns[].codePackageId`，只能在新增箱行时复制默认值，不能持续双向同步。
- 仅复制包装 ID 会导致远程下拉短暂显示数字；应同时传递 `codePackageName` 作为 `selectedItems` 回显来源。
- 付费方式识别兼容中文名“预付/到付”和 EDI 代码 `PP/CC`；基础资料命名变更时需同步维护识别规则。
- 船期校验按日期粒度比较，同日截关时间不会被拦截。
