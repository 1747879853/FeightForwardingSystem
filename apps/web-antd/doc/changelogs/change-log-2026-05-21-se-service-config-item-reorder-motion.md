# 海运出口港口服务项顺序调整动画反馈优化

## 背景意图

“上移/下移”功能已支持手动调整顺序，但列表瞬间重排时空间关系不够直观，用户不容易快速感知“哪一项从哪里移动到了哪里”。

## 核心逻辑变更

1. 将服务项明细列表容器升级为 `TransitionGroup`，为重排提供 FLIP 位移动画能力。
2. 为明细项新增稳定 `rowKey`，避免新建项在排序时因索引 key 变化导致错误复用或动画失效。
3. 补充进入/离开/移动过渡，仅使用 `transform + opacity`，在保留性能的前提下增强位置感知。
4. 增加 `prefers-reduced-motion` 兜底，减少动画敏感用户的运动负担。

## 避坑指南

- 可重排列表务必使用稳定 key，不能继续用 `new-${index}` 这类随位置变化的 key。
- 位移动画优先使用 `*-move` + `transform`，避免使用 `top/left/height` 等布局属性引发卡顿。
- 需要保留 reduced motion 分支，避免无障碍回归风险。
