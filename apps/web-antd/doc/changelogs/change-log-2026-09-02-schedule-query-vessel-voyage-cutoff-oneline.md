# 船期查询班次表船名航次分列，截关改为一行

## 背景意图

展开共舱方案后，船名和航次叠在同一列，截关时间又拆成日期、时刻两行；卡片右侧「最早截关」同样上下两行。对照班次时要竖着扫，截关也不如离港那样一眼看完。

## 核心逻辑变更

- 班次表把「船名航次」拆成 **船名**、**航次** 两列。船名仍可点进详情，旁边 i 悬浮船舶标识保留。
- 表内 **截关时间** 改为一行：`YYYY-MM-DD HH:mm`（零点仍只写日期）。
- 卡片 **最早截关** 改为一行：`MM-DD` 与时刻并排，不再把时刻挤到下一行。计划离到港仍是日期+时间两行。

## 避坑指南

- 不要把计划离港/到港也改成一行；这次只动截关。
- 零点截关继续走 `formatScheduleMoment` / `splitScheduleMoment` 的约定，不要补 `00:00`。
- 最早截关列宽已略加宽；窄屏（≤900px）卡片上的航程/离港/截关本来就会藏掉，不要为了一行显示把那套响应式改回去。
