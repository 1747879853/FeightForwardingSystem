# 船期查询班次表船名旁悬浮船舶标识

## 背景意图

展开方案对照班次时，点船名才进详情才能看到 MMSI / IMO。对照港到港页是船名旁一个 i，悬停就能扫船舶关键标识。操作对照时需要同样的轻量入口。

## 核心逻辑变更

- 班次表船名右侧加信息图标，悬停弹出两列卡片：船名、MMSI、IMO、呼号、航次、运营方（`carrierCd`）。
- 字段只取当前班次行，不再打接口。空值和 `0` 显示 `-`。
- 点船名仍打开船期详情；点图标不打开详情。
- 船期接口没有船旗、建造日、箱量，卡片不编造这三项。

## 避坑指南

- 不要为了对齐对照页去调船舶档案接口：本页只有 `QueryScheduleAsync` 班次字段。
- 悬浮卡挂到 `body`，样式写在页面非 scoped 块；`overlay-class-name` 才能打到 Popover。
- 用户可见文案不要写第三方数据供应商名。
