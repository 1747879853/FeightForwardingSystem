# 提单列表复用通用分组

## 背景意图

提单列表分组与海运出口既有实现保持一致，避免独立维护侧栏和分组查询状态。

## 核心逻辑变更

- 复用 GroupingSettings、GroupingTabs、useListGrouping，提供委托单位、船公司、签单方式三种维度。
- 使用用户表格配置存储分组偏好，恢复后统一触发首查。
- 在分页查询 mapParams 中装饰筛选条件，点击分组项只查询列表；搜索变化重置选中组并更新统计。
- 操作成功和重新进入页面刷新分组统计，保留原有纵向 flex 高度约束。
- 删除自定义 groupFilter，改为通过通用 hook 验证空分组、字符串 ID 及搜索重置。

## 避坑指南

分组基础参数不得包含分页和排序参数，否则翻页会被当作搜索变化而重置选中项。toolbar-actions 插槽常驻，避免切换分组时重建表格标题结构。

## 验证

提单接口、流转规则及通用分组接入测试共 8 项通过。
