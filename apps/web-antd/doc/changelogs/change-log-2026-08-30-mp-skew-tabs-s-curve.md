# 斜切 Tab 按 Figma 路径还原 S 形圆弧

## 背景意图

去掉 canvas 后，两侧只用四分之一圆，对不上稿。Figma `Rectangle 30` 的右缘是上凸、斜切、下凹两段三次贝塞尔。

## 核心逻辑变更

- 从稿面路径抽出 S 线（水平约 58、高 68），做成左右两张 PNG，贴在选中滑块两侧。
- Tab 行仍是 88rpx：上面 68rpx 走 S 线，底下 20rpx 铺选中色，接到列表渐变。
- 首个 Tab 只出右缘，末个只出左缘，中间两个都出。

## 避坑指南

- 路径来自节点 `11:4539`，不要再用 `border-radius` 四分之一圆去近似这段 S。
- 用 PNG 不用 SVG，避免微信 `image` 对 SVG 支持不稳。
