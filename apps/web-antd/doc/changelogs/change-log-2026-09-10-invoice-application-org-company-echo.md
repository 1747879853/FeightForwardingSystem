# 开票申请编辑页跨部门回显所属公司与销售方

## 背景意图

开票申请 `orgId` 按后端要求存部门 id，下拉展示的是所属公司名。不同部门的人打开同一张单时，本人组织选项对不上该部门 id：归属组织裸显 id，销售方（名称/税号/地址/银行）因只在当前用户组织树里找公司而为空。销售方应按该部门所属公司拉取。

## 核心逻辑变更

- `resolveOrganizationCompany`：全量组织列表沿父级找到最近 `isCompany` 节点（与本位币解析同口径）。
- `resolveMyOrgCompanyNode`：先按本人组织缓存；未命中则部门→公司，再取本人同公司缓存或 `GetOrganizationUnitAsync`（含税号与银行）。
- `MyOrgSelect`：已选部门 id 不在本人选项时，关闭态用公司名回显；该项不进入本人下拉候选，提交值仍是原部门 id。
- 开票申请 / 发票开出编辑：加载详情后按所属公司填充销售方；已保存的销售方银行在列表就绪前不清空。

## 避坑指南

- 提交仍传部门 id，不要改成公司 id。
- 列表接口没有 `orgBankAccounts`；跨公司时必须走单个组织接口才能拿到银行。
- `getMyOrgCompanyNode(deptId)` 在「同公司不同部门」时也会落空，必须先换算公司 id 再查。
