# 2026-07-11 海运出口编辑页 Tab 与服务组间距微调

## 背景意图

编辑工作台顶部 Tab 与下方内容区之间原先同时存在外层 `gap-2` 与内容区自身 padding，间距来源不唯一、不好调。服务流水线同 `sortId` 组之间的间距也偏大，分组感过重。

## 核心逻辑变更

1. `editor.vue`：去掉 Tab 与内容区外层容器的 `gap-2`，Tab 与表单间距只由内容区 padding（如 `.main-layout { padding: 12px }`）控制。
2. `form.vue`：服务流水线组间间距缩小——普通态 `10px → 6px`，顶栏内联 `8px → 4px`；组内无缝咬合逻辑不变。

## 避坑指南

- 调 Tab 与表单间距时改内容区 padding，不要再往外层加 gap，避免双重间距。
- 组间间距过小会看不出分组，过大则打断箭头链观感；顶栏内联与普通态两套值需同步调整。
