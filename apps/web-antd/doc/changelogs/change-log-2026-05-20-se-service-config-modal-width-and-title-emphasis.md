# 2026-05-20 海运出口港口服务项弹窗宽度与标题强调优化

## 背景意图

- 服务项配置弹窗在常见办公分辨率下横向占用偏大，内容阅读焦点不够集中。
- 明细标题虽已展示“序号 + 服务项名称”，但视觉层级仍不够突出，快速定位效率一般。

## 核心逻辑变更

- 将 `SeServiceConfigAdmin` 弹窗宽度由 `w-[1280px]` 调整为 `w-[1080px]`，收敛整体横向占用。
- 服务项明细标题增加强调样式：圆角浅底色、加粗、放大字号与深色文本。
- 标题文本仍沿用“服务项 #序号 · 服务项名称”格式，仅提升视觉可识别性。

## 避坑指南

- 若后续字段继续扩展导致横向拥挤，建议优先通过响应式栅格断点适配，而非盲目放大弹窗宽度。
- 标题样式应保持中性色，避免与表单校验色（红/橙）冲突，减少误判风险。
