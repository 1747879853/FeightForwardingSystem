# 海运进口干系人角色约束收敛（销售/商务/操作/客服/单证）

## 背景意图

海运进口表单的“干系人”区域此前仅限制“销售角色唯一”，其余角色仍可重复添加，且默认角色可删除，容易导致运输单缺失关键角色或出现重复角色。业务侧要求固定展示角色（销售、商务、操作、客服、单证）不可删除、不可重复，且销售与操作必须落到具体人员。

## 核心逻辑变更

1. 在 `src/views/sea-import-admin/form.vue` 新增固定角色集合与必填角色集合：
   - 固定角色：销售、商务、操作、客服、单证（不可删除）。
   - 必填角色：销售、操作（提交前必须已选人员）。
2. 角色选择逻辑由“仅限制销售唯一”升级为“所有角色唯一”：
   - 角色下拉项会禁用当前已被其他行占用的角色。
   - 手工切换到已占用角色会被拦截并提示“角色不可重复添加”。
3. “添加角色”按钮改为“新增待选行 + 剩余角色可选”：
   - 点击“添加角色”后新增空白角色行，由用户在下拉中选择尚未占用的角色。
   - 当五个固定角色已齐全时，禁止继续新增并给出提示。
   - 仅禁用重复角色选项，不禁用角色下拉本身。
4. 删除逻辑增加固定角色保护：
   - 固定角色行删除按钮禁用，点击删除时也会二次拦截。
5. 提交校验新增“销售/操作必须选择人员”：
   - 在原有“销售必须且只能一人”基础上，新增对销售、操作 `userId` 必填校验。

## 避坑指南

- 不要只在 UI 层做按钮禁用，删除与角色切换函数也必须做逻辑拦截，避免通过状态回放或脚本调用绕过限制。
- 后续若扩展干系人角色，需同步维护固定角色集合和必填角色集合，否则会出现“可选但不可保存”或“可保存但不符合业务规则”的不一致。
