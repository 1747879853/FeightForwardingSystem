# 2026-08-22 监装工单页面对齐 Figma 稿

## 背景意图

按 [Figma 监装详情稿](https://www.figma.com/design/6Fp1XCtTc0rfw2hLtZCOCn/Untitled?node-id=13-5858) **按节点几何 1:1** 还原海出编辑工作台「监装」Tab：基础信息紧凑栅格、监装要求分组勾选、集装箱信息表。接口与状态机不变，只改管理端展示。稿面顶部「详情 / 订舱…」属于海出工作台壳，不在本 Tab 内重复做。

## 核心逻辑变更

- 工作台 Tab 文案为「监装」。未提交工单顶栏直接「保存 / 提交 / 删除」；工号只出现在基础信息第一格（带复制），不再在顶栏重复。
- 基础信息白卡片：五列、列宽随容器均分、列间距 13px、行间距 12px、内边距 12px；标签 12/16、控件用 Ant Design 默认 middle（约 32px），不再用 `size="small"` / 强制 24px。第三行预计到货 / 堆场 / 师傅各占一列。堆场标签旁橙色「推荐」角标对齐稿面。
- 监装师傅：`UserSelect` 多选（最多 2 人），走 `modelValue` 绑定；单行展示，超出用 `max-tag-count="responsive"`，避免选人后把整行撑高。
- 监装要求：标题与「已选择 N 项」在白底；已选标签区**始终占一行 24px**，从 0 项勾到 1 项不再把下方勾选井顶下去。标签 24px 高、间距 5px；浅蓝井里放分类 Tab + 白底勾选行；「详细说明」只读文本框高 62px，拼当前组已勾明细 `remark`，不另传字段。
- 新建尚未落库时，用 `LoadingRequirementAdmin/GetPagedListAsync` 拉目录做勾选树；无该权限则等第一次保存后走工单详情里的 `loadingRequirements`。
- 集装箱信息：32px 浅蓝标题条 + 灰色说明「集装箱信息由主单自动带入，如有修改请至主单修改」。表头 36 / 行 50；列宽按稿面 93/204/188/183/332/187。照片采集按钮 123×30，图标用稿面导出 SVG。
- `GetYardUsersAsync` 已排师傅提示仍不做；「推荐」仅是稿面角标。
- 无工单且有 `.Add` 时，`DetailBySeaExportIdAsync` 返回 `null` 后直接进入新建表单，不再先展示「该海运出口还没有监装工单」再点新建。无 `.Add` 仍空态。删除工单后同样自动回到新建。新建草稿顶栏只留「保存」，去掉「取消」（取消会回到空态）。
- 堆场候选项只认**已保存**的船公司。切回监装 Tab 会重拉船公司堆场。无数据时**不禁用**下拉，打开后为空列表（无船公司 / 无堆场用不同空态文案）。

## 避坑指南

- 「详细说明」不是工单字段，不要写进 Add/Edit 入参。
- 管理端「照片采集」是预览入口，不是上传。
- 主单只读值优先工单详情 `seaExport`，没有工单时用已保存海出 `DetailAsync`；箱型名海出侧是 `ctnCode.ctnName`，工单侧还有 `name`。
- 相机 / 标签关闭图标来自 Figma `download_assets`，不要改成手绘 SVG。
