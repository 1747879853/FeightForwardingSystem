# 背景意图

客户打开监装分享链接后的全屏监控页，云台方向盘旁原先有放大、缩小（变倍）按钮。现场暂不向客户提供变倍，先把这两项操作从画面上拿掉，方向控制保留。

# 核心逻辑变更

- `loading-order-share/live-video.vue` 增加 `showZoom = false`，`+` / `−` 按钮不渲染。
- 变倍按键与云台 `command` 9/10 的处理仍留在组件里，把开关改回 `true` 即可恢复。
- 圆形方向盘（上下左右及斜向）不受影响。

# 避坑指南

- 这是界面隐藏，不是后端关掉变倍接口。客户侧目前没有入口发出变倍指令。
- 管理端或其它页面的云台不受本次改动影响；只改分享公开页的全屏监控 HUD。
