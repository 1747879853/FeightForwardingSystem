# 海运出口费用录入表格接入字段权限

日期：2026-09-15

## 背景意图

海运出口列表和基础信息已按 PropMask 显示，但应收应付 Handsontable 仍把被屏蔽字段画成空单元格，非条件屏蔽也不会藏列。费用行走 `OrderFee` 模块，需要和列表同一套口径。

## 核心逻辑变更

- 条件屏蔽：单元格显示 `***`，只读，不能打开下拉或把占位值写回。
- 非条件屏蔽：费用表直接去掉该列。
- 行上挂 `_maskedFields`（用原始 DTO 的 key 判定），避免 normalize 补 `industryCategory` 等字段后误判成有权限。
- 保存走 `omitMaskedOrderFeeValues`，剔除已打码 / 无条件屏蔽字段；后端 InputGuard 回填原值。
- 实现落在共享费用表 `_shared/order-fee`，海进 / 空出 / 更改单同一张表一并生效。

## 避坑指南

- 被屏蔽字段是 JSON 里消失，不是 `null`。用 `'prop' in obj`。
- 条件屏蔽绝不能整列隐藏。
- 不要把 `***` 写进行数据，数字列和下拉会坏；只在 `afterRenderer` 里覆盖显示。
- 规则未加载 fail-open，不误藏列。

## 验证

纯函数单测覆盖：未加载、非条件藏列、条件打码、费用代码 key、normalize 后仍打码、提交剔除。未在浏览器用真实权限账号联调。
