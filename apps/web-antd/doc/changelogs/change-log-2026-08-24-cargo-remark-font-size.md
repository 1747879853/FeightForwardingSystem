# 货物区内外部备注字号与其他输入框对齐

## 背景意图

TAPD #0872 截图圈的是货物区「内部备注 / 外部备注」，字号写死 10px，比旁边件数、毛重、体积小。要求改成和其他文本框一致。海进、空出同一套备注卡片一并改。

## 核心逻辑变更

- 海出 / 海进 / 空出 `form.css` 中 `.cargo-remark-field textarea` 的 `font-size`：`10px` → `14px`（与 Ant Design 输入框默认字号一致）。
- 业务联系单审核通过后内嵌海出工作台会跟着变。

## 避坑指南

- 三套 `form.css` 各有两处 textarea 规则（本页 scoped 与子组件 `:deep`），都要改，只改一处会被另一处盖住。
- Tab 标签「内部备注 / 外部备注」仍是 10px，只改文本框。
