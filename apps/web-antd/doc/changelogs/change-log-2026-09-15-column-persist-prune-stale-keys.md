title: 列表列设置以当前列为全集并清掉脏键
date: 2026-09-15

---

# 背景意图

列勾选只记显隐，但持久化 key 就是列的 `field`。改路径或删列后，旧 key 不应再当一列留下来，也不该继续写回用户配置。

# 核心逻辑变更

1. **加载：** 配置里有、当前 `useColumns` 没有的 key 视为脏数据；先按现列应用（对得上的保留勾选，新列走代码默认），再按当前列全集回写远端。
2. **保存：** `getColumns()` 里对不上当前列定义的运行时列不再写入 `visibleColumnKeys`。

# 避坑指南

- 不会根据旧 `field` 长出一列空格子；脏键只存在 JSON 里，进页会被清掉。
- 用户以前藏过的旧列，改名后的新列按代码默认显隐，不会把「隐藏」迁移到新 key 上。
