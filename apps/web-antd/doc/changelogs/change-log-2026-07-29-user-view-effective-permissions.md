# 用户管理支持查看最终生效权限

## 背景意图

管理员在用户列表需要快速核对某用户「角色权限 + 用户级授权/禁止」合并后的最终生效能力，而不必跳到权限配置页猜测结果。对接 `UserAdmin/GetUserPermissions`。

## 核心逻辑变更

1. 用户列表操作列新增「最终权限」按钮，打开只读弹窗。
2. 弹窗并行拉取全量权限树与 `GetUserPermissionsAsync?id=`，默认仅展示已拥有分支，支持搜索与数量统计。
3. 统一三处 API 封装的入参为小驼峰 `id`，并注明返回值为最终生效权限名列表。

## 避坑指南

- 本接口用于查**指定用户**最终权限；查当前登录人自己请用 `AbpUserConfiguration/GetAll` → `auth.grantedPermissions`。
- 「权限配置」仍跳转 `/system/permission` 做用户级授权编辑；「最终权限」只读诊断，二者不要混用。
- 用户 Id 可能为雪花值，传参保持原类型，勿 `Number()`。
