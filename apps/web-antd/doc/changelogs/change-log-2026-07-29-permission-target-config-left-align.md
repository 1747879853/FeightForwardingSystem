# 2026-07-29 权限页顶部配置对象内容靠左

## 背景意图

权限管理页（`/system/permission`）顶部「配置对象」卡片使用 24 栅格把控件拉满整行，视觉过空；期望卡片仍占满宽度，但内部表单项靠左紧凑排列。

## 核心逻辑变更

- 文件：`src/views/system/permission/list.vue`
- 移除顶部 `Row`/`Col` 栅格布局，改为横向 `flex` + `gap`。
- 角色/用户 `Select` 固定为 `w-56`，不再 `width: 100%`。
- 卡片本身保持块级占满，仅内容靠左。

## 避坑指南

- 顶部筛选区若只需靠左内容、卡片仍通栏，用 `flex` 即可，勿再用满宽栅格把控件撑开。
