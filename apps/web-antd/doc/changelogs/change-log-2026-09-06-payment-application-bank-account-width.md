# 1. 背景意图 (Background)

费用合计区「银行账户」下拉与「银行账号」列偏窄，长户名、长账号被省略号截断，核对收款账户时看不全。

# 2. 核心逻辑变更 (Core Logic)

- **原币结算：** 银行下拉不再固定 260px，改为占满「银行账户」列（最小 320px）；开户行 / 账号 / SWIFT 换行展示且不再截断。
- **指定币别：** 「银行账户」列 193px → 320px，「银行账号」列 118px → 220px，表格最小宽度 837px → 960px。
- **下拉：** `popupMatchSelectWidth=false`，选项可比控件更宽，完整显示「开户行 / 账户名」。

# 3. 避坑指南 (Pitfalls)

- 只改展示宽度，不改银行必填、默认账户和提交字段。
- 窄屏时原币表格允许横向滚动，不要再把账号做成省略号。
