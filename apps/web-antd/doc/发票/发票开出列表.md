# 2. 功能与操作说明 (Features & Operations)

- **列表查询：** 按开出单号、发票号、开票方式、结算对象、币别、发票类型、开票时间范围、创建人等条件查询发票开出记录。
- **新建发票开出：** 选择多个开票申请（需满足结算对象、发票类型、币别、我司银行一致），填写商品明细，生成发票开出。
- **编辑发票开出：** 修改已有发票开出的基本信息、关联的开票申请和商品明细。
- **删除发票开出：** 批量删除选中的发票开出记录，删除后关联的开票申请回退为"待审核"状态。
- **双击编辑：** 双击列表行可直接进入编辑页面。

# 5. 核心业务卡点 (Business Blockers)

> [!IMPORTANT] **[卡点 1：开票申请一致性校验]** 合并的开票申请必须满足：结算对象（SettlementId）、发票类型（InvoiceType）、币别（CurrencyId）、我司银行（OrgBankAccountId）完全一致，否则不允许合并。

> [!IMPORTANT] **[卡点 2：金额一致性校验]** 开票申请的商品明细与发票开出商品明细的金额（Amount）、不含税金额（NoTaxAmount）、税额（TaxAmount）三项合计必须分别相等，否则提示"开票申请与发票开出不一致"。

> [!IMPORTANT] **[卡点 3：开票申请状态校验]** 只有状态为"待审核（已提交）"（Auditing）的开票申请才能被关联到发票开出，且不能被其他发票开出重复关联。
