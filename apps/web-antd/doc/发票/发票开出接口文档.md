# 发票开出接口文档

**控制器**：`InvoiceIssueAdmin`

**所有接口均需要登录认证**

---

# 1. 业务背景说明 (Background)

**白话解释：** 开票申请（`InvoiceApplication`）经提交审核后，可由开票人合并成一张实际开出的发票，即"发票开出"（`InvoiceIssue`）。

- 多个开票申请可以合并成一个发票开出，但这些开票申请的 `SettlementId`（结算对象）、`InvoiceType`（发票类型）、`CurrencyId`（币别）、`OrgBankAccountId`（我司银行）必须完全相同，否则不允许合并。
- 开票申请的商品明细与发票开出商品明细的 `Amount`（金额）、`NoTaxAmount`（不含税金额）、`TaxAmount`（税额）三个字段，其合计必须分别相等，否则提示"开票申请与发票开出不一致"。
- 发票开出新建成功后，关联的开票申请状态会被改为"已开票"（`Invoiced`）。

# 2. 数据结构

- 主表：`InvoiceIssue`（发票开出）
- 子表1：`InvoiceIssueItem`（发票开出明细，关联开票申请）
- 子表2：`InvoiceIssueGoodsDtl`（发票开出商品明细）

## 一、新增发票开出

### `POST /api/services/app/InvoiceIssueAdmin/AddAsync`

**权限**：`Admin.InvoiceIssue.Add`

**入参** `InvoiceIssueAddDto`（Body JSON）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `invoiceIssueType` | `InvoiceIssueType` | 是 | 发票开出方式：0=诺诺接口开票，1=手动记录 |
| `invoiceNo` | `string` | 否 | 发票号 |
| `invoiceIssueTime` | `DateTime` | 是 | 开票时间 |
| `require` | `string` | 否 | 开票要求 |
| `remark` | `string` | 否 | 备注 |
| `invoiceIssueItems` | `List<InvoiceIssueItemInputDto>` | 是 | 合并的开票申请（至少一条） |
| `invoiceIssueGoodsDtls` | `List<InvoiceIssueGoodsDtlInputDto>` | 是 | 发票开出商品明细（至少一条） |

`InvoiceIssueItemInputDto`：

| 字段                   | 类型     | 必填 | 说明       |
| ---------------------- | -------- | ---- | ---------- |
| `invoiceApplicationId` | `Guid`   | 是   | 开票申请ID |
| `remark`               | `string` | 否   | 备注       |

`InvoiceIssueGoodsDtlInputDto`：

| 字段            | 类型      | 必填 | 说明           |
| --------------- | --------- | ---- | -------------- |
| `codeInvoiceId` | `long`    | 是   | 发票商品编码ID |
| `specification` | `string`  | 否   | 规格型号       |
| `unit`          | `string`  | 否   | 发票单位       |
| `quantity`      | `decimal` | 是   | 数量           |
| `unitPrice`     | `decimal` | 是   | 含税单价       |
| `amount`        | `decimal` | 是   | 金额           |
| `noTaxAmount`   | `decimal` | 是   | 不含税金额     |
| `taxRate`       | `decimal` | 是   | 税率(%)        |
| `taxAmount`     | `decimal` | 是   | 税额           |
| `remark`        | `string`  | 否   | 备注           |

**出参**：`Guid`（新建的发票开出ID）

**业务规则（校验）**：

- `invoiceIssueItems`、`invoiceIssueGoodsDtls` 均不能为空，开票申请不能重复。
- 所有开票申请必须存在，且未被其他发票开出关联。
- 开票申请状态必须为"待审核（已提交）"（`Auditing`）。
- 所有开票申请的 `SettlementId`、`InvoiceType`、`CurrencyId`、`OrgBankAccountId` 必须一致，否则报错。
- 开票申请商品明细与发票开出商品明细的 `Amount`、`NoTaxAmount`、`TaxAmount` 三项合计需分别相等，否则提示"开票申请与发票开出不一致"。
- 主表的 `SettlementId`、`InvoiceType`、`CurrencyId`、`OrgBankAccountId`、`ClientInvoiceBankId`、`CompanyId` 取自开票申请（已校验一致）。
- 开出单号 `ApplicationNo` 由编号生成规则（`InvoiceIssue.ApplicationNo`）自动生成。
- 新建成功后，关联的开票申请状态改为"已开票"（`Invoiced`）。

## 二、修改发票开出

### `PUT /api/services/app/InvoiceIssueAdmin/EditAsync`

**权限**：`Admin.InvoiceIssue.Edit`

**入参** `InvoiceIssueEditDto`（Body JSON）：在 `InvoiceIssueAddDto` 基础上增加：

| 字段 | 类型   | 必填 | 说明       |
| ---- | ------ | ---- | ---------- |
| `id` | `Guid` | 是   | 发票开出ID |

**出参**：`bool`

**业务规则**：

- 子表（开票申请明细、商品明细）全量替换。
- 校验逻辑同新增（排除自身的关联校验）。
- 新关联的开票申请改为"已开票"；被移除的开票申请回退为"待审核"（`Auditing`）。

## 四、发票开出详情

### `GET /api/services/app/InvoiceIssueAdmin/DetailAsync`

**权限**：`Admin.InvoiceIssue.Get`

**入参**：`id`（`Guid`，Query参数）

**出参** `InvoiceIssueDetailDto`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `Guid` | 主键ID |
| `companyId` | `long` | 所属公司ID |
| `invoiceIssueType` | `InvoiceIssueType` | 发票开出方式 |
| `applicationNo` | `string` | 开出单号 |
| `invoiceNo` | `string` | 发票号 |
| `invoiceIssueTime` | `DateTime` | 开票时间 |
| `settlementId` | `Guid` | 结算对象ID |
| `invoiceType` | `string` | 发票类型 |
| `currencyId` | `long` | 币别ID |
| `clientInvoiceBankId` | `Guid` | 客户银行ID |
| `orgBankAccountId` | `Guid` | 我司银行ID |
| `applyUserId` | `long` | 申请人ID |
| `applyTime` | `DateTime` | 申请时间 |
| `require` | `string` | 开票要求 |
| `remark` | `string` | 备注 |
| `creatorUserName` | `string` | 创建人名称 |
| `applyUserName` | `string` | 申请人名称 |
| `companyName` | `string` | 所属公司名称 |
| `settlement` | `ClientSimpleDto` | 结算对象简易信息 |
| `currency` | `CurrencySimpleDto` | 币别简易信息 |
| `clientInvoiceBank` | `ClientInvoiceBankSimpleDto` | 客户银行简易信息 |
| `orgBankAccount` | `OrgBankAccountSimpleDto` | 我司银行简易信息 |
| `invoiceExchangeRate` | `decimal?` | 发票汇率（见下方说明） |
| `invoiceIssueItems` | `List<InvoiceIssueItemDto>` | 关联开票申请明细 |
| `invoiceIssueGoodsDtls` | `List<InvoiceIssueGoodsDtlDto>` | 发票开出商品明细 |

`InvoiceIssueItemDto`：包含 `id`、`invoiceIssueId`、`invoiceApplicationId`、`remark` 及 `invoiceApplication`（`InvoiceApplicationSimpleDto`，含 `applicationNo`、`invoiceNo`、`settlementId`、`status`、`invoiceType`、`currencyId`、`orgBankAccountId`、`applyTime`）。

`InvoiceIssueGoodsDtlDto`：包含 `id`、`invoiceIssueId`、`codeInvoiceId`、`specification`、`unit`、`quantity`、`unitPrice`、`amount`、`noTaxAmount`、`taxRate`、`taxAmount`、`remark` 及 `codeInvoice`（`CodeInvoiceSimpleDto`，含 `code`、`name`、`taxRate`、`specification`、`unit`、`taxClassificationCode`、`taxClassificationName`）。

**发票汇率说明**：根据当前时间从 `ExchangeRate` 表拉取，条件为 `CurrencyId` 匹配、`LocalCurrency = "RMB"`、`Enable = true`、`StartDate <= 当前时间 <= EndDate`、`InvoiceValue` 有值，取 `InvoiceValue` 字段值。
