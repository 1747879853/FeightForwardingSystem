# 发票备注模板接口文档

**控制器**：`InvoiceRemarkTemAdmin`

**所有接口均需要登录认证**

---

# 1. 业务背景说明 (Background)

**白话解释：** 发票备注模板（`InvoiceRemarkTem`）用于按"所属公司 + 币别"维护开票时使用的备注文案模板。

- 用户只能查询和管理自己 **DataPermission 数据权限范围内** 的数据。
- **相同所属公司ID + 相同币别ID** 的数据，最多只能有一条"默认"（`Default = true`）。
- 数据无子表。

# 2. 数据结构

- 主表：`InvoiceRemarkTem`（发票备注模板）
- 外键：`CompanyId` → 组织机构（公司，需 `IsCompany = true`）；`CurrencyId` → 币别。

---

## 一、新增发票备注模板

### `POST /api/services/app/InvoiceRemarkTemAdmin/AddAsync`

**权限**：`Admin.InvoiceRemarkTem.Add`

**入参** `InvoiceRemarkTemAddDto`（Body JSON）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `companyId` | `long` | 是 | 所属公司ID（OrganizationUnit的Id，需验证 IsCompany=true） |
| `currencyId` | `long` | 是 | 币别ID |
| `template` | `string` | 否 | 模板内容（最长8192） |
| `default` | `bool` | 是 | 是否默认（相同公司+相同币别只能有一条默认） |

**出参**：`Guid`（新建ID）

**业务规则（校验）**：

- 所属公司必须存在，且 `IsCompany = true`。
- 币别必须存在。
- 当 `default = true` 时，校验相同 `companyId + currencyId` 下不存在其它默认数据，否则提示"该公司该币别已存在默认发票备注模板"。

## 四、发票备注模板详情

### `GET /api/services/app/InvoiceRemarkTemAdmin/DetailAsync`

**权限**：`Admin.InvoiceRemarkTem.Get`

**入参**：`id`（`Guid`，Query参数）

**出参** `InvoiceRemarkTemDetailDto`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `Guid` | 主键ID |

| `currencyId` | `long` | 币别ID |
| `template` | `string` | 模板内容 |

| `currency` | `CurrencySimpleDto` | 币别简易信息（code、cnName、enName、defaultRate） |

## 五、发票备注模板分页列表

### `GET /api/services/app/InvoiceRemarkTemAdmin/GetPagedListAsync`

**权限**：`Admin.InvoiceRemarkTem.Get`

**入参** `InvoiceRemarkTemQueryDto`（Query参数）：

| 字段            | 类型     | 必填 | 说明                                 |
| --------------- | -------- | ---- | ------------------------------------ |
| `companyId`     | `long?`  | 否   | 所属公司ID                           |
| `currencyId`    | `long?`  | 否   | 币别ID                               |
| `default`       | `bool?`  | 否   | 是否默认                             |
| `template`      | `string` | 否   | 模板内容（模糊）                     |
| `creatorUserId` | `long?`  | 否   | 创建人ID                             |
| `orgId`         | `long?`  | 否   | 组织ID（通过UserId查询）             |
| `pageIndex`     | `int`    | 是   | 当前页码（从1开始）                  |
| `pageSize`      | `int`    | 是   | 每页条数                             |
| `sorting`       | `string` | 否   | 排序字段（默认 `CreationTime DESC`） |

**出参** `PagedList<InvoiceRemarkTemListDto>`：列表项字段同详情，额外返回 `company`、`currency` 简易信息及 `creatorUserName`。

**业务规则**：列表通过 `DataPermissionFilterAsync` 过滤，仅返回当前用户数据权限范围内的数据。
