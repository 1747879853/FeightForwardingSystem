# 1. 背景意图 (Background)

`AttachmentItem`（附件与业务对象的关联表）原本只有 `ModuleTypeId`（附件所属模块，如海运出口、费用等大类）。

本次新增能力分三部分：

- **AttachmentDtlTypeId（附件详细类型）**：表示附件的"业务类型"，注意它不是附件所属模块。例如海运出口下有一堆附件，附件1、2 是提单，附件3 是托书，"提单""托书"就是这里说的详细类型。对应实体 `AttachmentDtlType`（表 `App_AttachmentDtlTypes`），其 `Name` 字段为类型名称。
- **ClientVisible（客户是否可见）**：标记该附件是否对客户端可见。
- **附件类型管理（CRUD + 权限）**：对 `AttachmentDtlType` 及其子表 `AttachmentDefaultModule`（表 `App_AttachmentDefaultModules`，配置该附件类型默认在哪些模块展示）提供后台增删改查接口与权限。

# 2. 核心逻辑变更 (Core Changes)

## 2.1 实体

- `AttachmentItem` 新增 `long? AttachmentDtlTypeId`、`bool ClientVisible`。
- `AttachmentDtlType`（CreationAuditedEntity，IMustHaveTenant）：`Name` + 子表 `List<AttachmentDefaultModule> AttachmentDefaultModules`。
- `AttachmentDefaultModule`：`AttachmentDtlTypeId` + `ModuleType`（前端定义，后端无逻辑）。

> 本次不生成迁移文件，迁移由后端自行生成。

## 2.2 DTO 变更

| DTO | 变更内容 |
| :-- | :-- |
| `AttachmentItemInputDto` / `AttachmentItemForItemInputDto` | 新增入参 `AttachmentDtlTypeId`、`ClientVisible` |
| `AttachmentItemDto`（返回） | 新增 `AttachmentDtlTypeId`、`ClientVisible`，并额外返回 `AttachmentDtlType`（`AttachmentDtlTypeSimpleDto`，含 `Id`、`Name`） |
| `AttachmentDtlTypeSimpleDto` | 仅含 `Id`、`Name`，用于附件返回时携带其详细类型信息 |
| `AttachmentDtlTypeDto.cs`（新增，含多类） | `AttachmentDtlTypeAddDto`、`AttachmentDtlTypeEditDto`、`AttachmentDtlTypeQueryDto`、`AttachmentDtlTypeDto`、`AttachmentDefaultModuleInputDto`、`AttachmentDefaultModuleDto` |

## 2.3 附件增删改查接口

- **CreateAttachmentItemsAsync**：入参新增 `AttachmentDtlTypeId`、`ClientVisible`，按名称自动映射写入实体。
- **GetAttachmentItemsAsync**：返回新增 `AttachmentDtlTypeId`、`ClientVisible`；当 `AttachmentDtlTypeId` 有值时，根据其 id 批量查询 `AttachmentDtlType` 并填充 `AttachmentDtlTypeSimpleDto` 一并返回。

### 2.3.1 各业务模块保存附件时的字段透传（重要）

各业务模块在保存附件时，是把 `AttachmentItemForItemInputDto` 手动 `new` 成 `AttachmentItemInputDto` 再调用 `CreateAttachmentItemsAsync` 的，必须显式把这两个字段透传过去，否则前端传了也不会入库。已统一补充 `AttachmentDtlTypeId`、`ClientVisible` 的赋值，涉及：`AgreementAdminAppService`、`PaymentApplicationAdminAppService`、`PaymentSettlementAdminAppService`、`StatementAdminAppService`、`ClientAdminAppService`、`TransportOrderQuestionAdminAppService`、`OuterWarehouseAdminAppService`、`EnterWarehouseAdminAppService`、`InventoryAdminAppService`、`AnnouncementAdminAppService`、`CategoryAdminAppService`、`CarrierAdminAppService`、`OrganizationUnitAppService`、`TenantSettingsAppService`、`HostSettingsAppService`。

> `UserAdminAppService` 中相关代码为注释状态，未启用，未改动。

## 2.4 附件类型管理接口（新增）

新增 `AttachmentDtlTypeAdminAppService`（接口 `IAttachmentDtlTypeAdminAppService`），所有读写都带子表 `AttachmentDefaultModules`：

| 接口 | 权限 | 说明 |
| :-- | :-- | :-- |
| `AddAsync` | `Admin.AttachmentDtlType.Add` | 新增附件类型，同时插入子表（默认展示模块） |
| `EditAsync` | `Admin.AttachmentDtlType.Edit` | 编辑名称，子表全量替换（先删后插） |
| `DeleteAsync` | `Admin.AttachmentDtlType.Delete` | 删除前校验是否被 `AttachmentItem` 引用，被引用则禁止删除；删除时一并删除子表 |
| `GetPagedListAsync` | `Admin.AttachmentDtlType.Get` | 分页（PageIndex/PageSize），返回 `PagedList`，带子表及创建人昵称 |
| `DetailAsync` | `Admin.AttachmentDtlType.Get` | 详情，带子表及创建人昵称 |

子表含义：配置该附件类型默认在哪些模块展示。例如某附件类型子表有 `ModuleType=1` 和 `2`，则 `ModuleType=1` 的模块在新建时，前端会默认给一个该类型附件的上传/新建口。

### 2.4.1 按模块查询附件类型（无需权限）

新增通用 AppService `AttachmentDtlTypeAppService`（接口 `IAttachmentDtlTypeAppService`，**需登录，无需权限校验**）：

- `GetListAsync()`：无入参，返回全部附件类型列表（`AttachmentDtlTypeSimpleDto`，仅 Id+Name，不带子表）。
- `GetListByModuleTypesAsync(AttachmentDtlTypeByModuleQueryDto input)`：入参 `ModuleTypes`（`List<int>`，可不填）。
- 行为：对每个 `ModuleType` 返回其默认展示的附件类型集合（`AttachmentDtlTypeSimpleDto` 列表，含 Id+Name）。
- 传了 `ModuleTypes`：对传入的每个值都返回一项（即使该模块下没有配置附件类型，也返回空集合）；不传：返回所有已在子表中配置过的模块。

## 2.5 权限与本地化

- `FreightPermissions`：新增 `Admin.AttachmentDtlType` 及 `.Add/.Get/.Edit/.Delete`。
- `FreightAuthorizationProvider`：在 `admin` 下注册附件类型权限组（挂在船公司权限之后）。
- 本地化 `CsprojBuilder-zh-Hans.xml`：附件类型=`附件类型`，查看/编辑/添加/删除已汉化。

# 3. 避坑指南 (Pitfalls)

- **不生成迁移文件**：迁移由后端自行生成。需确保 `App_AttachmentDtlTypes`、`App_AttachmentDefaultModules` 表已存在。
- **删除引用校验**：附件类型被任意 `AttachmentItem` 引用即禁止删除，提示"该附件类型已被【附件】模块引用,禁止删除"。
- **创建人昵称**：`AttachmentDtlType` 为 `CreationAuditedEntity`，只有创建人，无修改人，故仅返回 `CreatorUserName`（昵称），不返回修改人昵称。
- **多租户**：`AttachmentDtlType` 为 `IMustHaveTenant`，查询时 ABP 自动按当前租户过滤。
- `AttachmentDtlType`（简单 DTO）属于附件返回时的计算字段，由 `GetAttachmentItemsAsync` 手动填充。
