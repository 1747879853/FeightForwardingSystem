# 02 船公司加堆场子表

## 需求是什么

基础资料「船公司」维护页，新建/编辑时在主表下方加一张 **堆场子表**（可增删行），交互对齐商品信息规格/型号。

后续监装工单的「监装堆场」必须属于该海运出口所选船公司下的堆场。本条只改船公司基础资料。

| 接口 | HTTP   | 地址                                             |
| :--- | :----- | :----------------------------------------------- |
| 新建 | POST   | `/CarrierAdmin/AddAsync`                         |
| 编辑 | PUT    | `/CarrierAdmin/EditAsync`                        |

| 分页 | GET    | `/CarrierAdmin/GetPagedListAsync`（已带堆场）    |
| 详情 | GET    | `/CarrierAdmin/DetailAsync`                      |

### 子表字段

| JSON      | 必填             | 说明                       |
| :-------- | :--------------- | :------------------------- |
| `id`      | 编辑时保留行必填 | Guid；新增 `null`          |
| `name`    | 是               | 最长 128，同船公司下不重名 |
| `address` | 否               | 最长 512                   |
| `remark`  | 否               | 最长 1024                  |

**不要传 `sortId`。** 返回按 `sortId` 升序。

## 现状

- 页面：`/basic-data/carrier`，弹窗 CRUD，权限 `Admin.Carrier.*`
- API：`src/api/system/base-data/carrier-admin.ts` **还没有** `carrierYards`
- 表单已有 Logo 上传，提交时必须继续带 `logo`，否则可能被清空
- 运价等处内嵌的 `carrier.carrierYards` **恒为 `null`**，取值要判空；需要堆场时调船公司详情

## 验收

1. 新建船公司可录多个堆场（名称+地址），再打开顺序正确。
2. 编辑增删改堆场一次保存；未改进 `id` 不变。
3. 同船公司堆场重名前端拦住。
4. 不填堆场仍能保存；Logo 不会因本次改动被清空。
5. 海出船公司下拉仍只显示 Logo + 简称，不崩。

## 避坑

- 编辑漏传 `logo` 或漏传已有堆场都会丢数据。
- 海运运价里的 `carrier.carrierYards` 是 `null` 不是 `[]`。
- 船公司主表 `id` 是 long，堆场 `id` 是 Guid。
