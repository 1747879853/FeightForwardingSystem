# 01 包装加明细包装子表

## 需求是什么

基础资料「包装类型」维护页，新建/编辑时在主表下方加一张 **明细包装子表**（可增删行），交互对齐商品信息的规格/型号。

后续监装工单会从「海运出口主单包装」下拉选明细包装。本条只改包装基础资料，不改海出表单。

| :--- | :----- | :------------------------------------------------ |

| 详情 | GET    | `/CodePackageAdmin/DetailAsync`                   |

### 子表字段

| JSON     | 必填             | 说明                                           |
| :------- | :--------------- | :--------------------------------------------- |
| `id`     | 编辑时保留行必填 | Guid；新增 `null`                              |
| `name`   | 是               | 最长 128，同包装下不重名（去空格、忽略大小写） |
| `remark` | 否               | 最长 1024                                      |

**不要传 `sortId`。** 返回按 `sortId` 升序，直接按数组渲染。

## 验收

1. 新建包装可录入多条明细，保存后再打开顺序与名称正确。
2. 编辑：改名、加一行、删一行，一次保存；未改的行 `id` 不变。
3. 同包装两条同名（大小写不同）前端拦住。
4. 不填明细仍能保存（空数组）。
5. 海出/海进包装下拉不受影响。

## 避坑

- 商品信息规格表有 `sortId` 列且会提交，包装明细 **禁止** 这样做。
- 编辑漏传已有明细 = 后端删除。必须全量回填。
- 包装主表 `id` 是 long（雪花），子表 `id` 是 Guid，不要混类型。
