# 监装工单-公开详情-2026-09-04

# 1. 背景意图

需要一个不登录也能看监装工单详情的入口（主提单号 + 监装工单号当口令）。出参必须和师傅端 `DetailAsync` 一样，包括箱型分组附件和只返回已勾选的监装要求。

# 2. 核心逻辑变更

| 项 | 说明 |
| :-- | :-- |
| 新接口 | `GET /api/services/app/LoadingOrder/DetailByMblAndLoadingOrderNumAsync` |
| 鉴权 | `[AbpAllowAnonymous]`，不校验监装属性 |
| 入参 | `mblNum` 主提单号、`loadingOrderNum` 监装工单号，都必填、**精确匹配** |
| 出参 | `LoadingOrderDetailDto`，映射与 `DetailAsync` 相同（`onlyCheckedRequirements: true`） |
| 对不上 | 统一报 `主提单号或监装工单号错误` |
| 租户 | 定位时关闭多租户过滤；找到工单后再切到该工单 `TenantId` 映射详情 |
| 类级鉴权 | `LoadingOrderAppService` 类上不再标 `[AbpAuthorize]`；其余 6 个方法各自标 `[AbpAuthorize]` |

完整入参见《监装工单模块接口文档》第 12 节。

# 3. 避坑指南

> [!IMPORTANT] **`[AbpAuthorize]` 不能再挂在类上。** 挂在类上时，方法上的 `[AbpAllowAnonymous]` 才能覆盖；当前做法是类上不标、方法上分别标。以后加需要登录的接口，记得自己补 `[AbpAuthorize]`，漏了就是匿名接口。

> [!IMPORTANT] **免登录没有租户，定位必须关过滤。** 先 `DisableFilter(MustHaveTenant, MayHaveTenant)` 按主提单号+监装工单号跨租户找到工单，再 `SetTenantId` 切到该工单所属租户去映射详情。全程关着过滤会把各租户的监装要求混在一起。
