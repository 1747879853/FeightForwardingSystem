# 1. 业务背景说明 (Background)

维护开票用的商品编码（税目、税率、税收分类、默认币别等），供开票申请、发票开出引用。

# 2. 核心业务规则

| 规则 | 说明 |
| :-- | :-- |
| 编码必填 | 新建/编辑 `Code` 不能为空 |
| 默认币别外键 | `CurrencyId` 可空弱外键；有值必须在 `App_Currencys` 存在，否则提示「币别不存在，请重新选择」 |
| 删除引用校验 | 被开票申请商品明细或发票开出商品明细引用时禁止删除 |
| 列表/详情 | 返回 `currency`（CurrencySimpleDto）及创建人/修改人昵称 |

# 3. 字段说明

| 字段名          | 含义           | 数据来源         | 校验       |
| :-------------- | :------------- | :--------------- | :--------- |
| Code            | 商品编码       | 录入             | 必填       |
| Name            | 名称           | 录入             |            |
| TaxRate         | 税率           | 录入             |            |
| CurrencyId      | 币别Id(弱外键) | 币别下拉         | 有值须存在 |
| DefaultCurrency | 默认币别代码   | 历史冗余，不使用 |            |
| Enable          | 是否启用       | 录入             |            |
