# 1. 说明

发票商品编码（`CodeInvoiceAdminAppService`）前端对接文档。

# 2. 接口清单

| 接口     | 方法   | 地址                                                   |
| :------- | :----- | :----------------------------------------------------- |
| 新建     | POST   | `/api/services/app/CodeInvoiceAdmin/AddAsync`          |
| 编辑     | PUT    | `/api/services/app/CodeInvoiceAdmin/EditAsync`         |
| 删除     | DELETE | `/api/services/app/CodeInvoiceAdmin/DeleteAsync`       |
| 分页列表 | GET    | `/api/services/app/CodeInvoiceAdmin/GetPagedListAsync` |
| 详情     | GET    | `/api/services/app/CodeInvoiceAdmin/DetailAsync`       |

# 3. 新建 AddAsync

## 3.1 入参 (CodeInvoiceAddDto)

| 字段 | 类型 | 必填 | 说明 |
| :-- | :-- | :-- | :-- |
| code | string | 是 | 发票商品编码 |
| name | string | 否 | 名称 |
| taxCategory | string | 否 | 税目 |
| taxRate | decimal | 否 | 税率 |
| zeroTaxRateEnum | enum | 否 | 零税率标识 |
| taxClassificationCode | string | 否 | 税收分类编码 |
| taxClassificationName | string | 否 | 税收分类名称 |
| isIncludingTax | bool | 否 | 是否含税 |
| hasPreferentialPolicy | bool | 否 | 是否享受优惠政策 |
| preferentialPolicyDescription | string | 否 | 优惠政策说明 |
| isDefault | bool | 否 | 是否默认商品名 |
| defaultCurrency | string | 否 | 历史冗余币别代码，可不传 |
| currencyId | long? | 否 | 币别Id（弱外键）；有值须存在于 Currency 表，否则报「币别不存在，请重新选择」 |
| specification | string | 否 | 规格型号 |
| unit | string | 否 | 单位 |
| enable | bool | 否 | 是否启用 |
| sortId | int | 否 | 排序 |
| remark | string | 否 | 备注 |

## 3.2 出参

`long` 新建主键 Id。

# 4. 编辑 EditAsync

## 4.1 入参 (CodeInvoiceEditDto)

在新建字段基础上增加：

| 字段       | 类型  | 必填 | 说明                             |
| :--------- | :---- | :--- | :------------------------------- |
| id         | long  | 是   | 主键                             |
| currencyId | long? | 否   | 同新建；有值校验 Currency 弱外键 |

## 4.2 出参

`bool`。

# 5. 删除 DeleteAsync

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| id   | long | 是   | 主键 |

被【开票申请】或【发票开出】引用时禁止删除。

# 6. 分页列表 GetPagedListAsync

## 6.1 入参 (CodeInvoiceQueryDto)

| 字段      | 类型   | 必填 | 说明                      |
| :-------- | :----- | :--- | :------------------------ |
| pageIndex | int    | 是   | 页码                      |
| pageSize  | int    | 是   | 每页条数                  |
| keyword   | string | 否   | 模糊匹配 code/name/remark |
| sorting   | string | 否   | 排序                      |

## 6.2 出参 (PagedList&lt;CodeInvoiceDto&gt;)

见「8」。

# 7. 详情 DetailAsync

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| id   | long | 是   | 主键 |

出参见「8」。

# 8. 列表/详情输出 CodeInvoiceDto

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| id | long | 主键 |
| code | string | 编码 |
| name | string | 名称 |
| taxCategory | string | 税目 |
| taxRate | decimal | 税率 |
| zeroTaxRateEnum | enum | 零税率标识 |
| taxClassificationCode | string | 税收分类编码 |
| taxClassificationName | string | 税收分类名称 |
| isIncludingTax | bool | 是否含税 |
| hasPreferentialPolicy | bool | 是否享受优惠政策 |
| preferentialPolicyDescription | string | 优惠政策说明 |
| isDefault | bool | 是否默认商品名 |
| defaultCurrency | string | 默认币别代码(历史冗余) |
| currencyId | long? | 币别Id(弱外键) |
| specification | string | 规格型号 |
| unit | string | 单位 |
| enable | bool | 是否启用 |
| sortId | int | 排序 |
| remark | string | 备注 |
| currency | CurrencySimpleDto | 币别简易对象；无 Id 时为 null |
| creatorUserName | string | 创建人昵称 |
| lastModifierUserName | string | 修改人昵称 |
| creationTime / lastModificationTime 等 |  | 审计字段 |

### CurrencySimpleDto

| 字段        | 类型    | 说明             |
| :---------- | :------ | :--------------- |
| code        | string  | 币别代码         |
| cnName      | string  | 中文名           |
| enName      | string  | 英文名           |
| defaultRate | decimal | 默认对人民币汇率 |
