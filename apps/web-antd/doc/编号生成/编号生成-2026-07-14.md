# 编号生成 - 变更记录 (2026-07-14)

## 背景意图

编号规则需要支持按「年月」维度生成前缀，用于按月重置自增序号的场景（如 `SO2026070001`）。

## 核心逻辑变更

- `GenerateEnum` 新增：
  - `yyyyMM = 5`：四位年 + 两位月（如 `202607`）
  - `yyMM = 6`：两位年 + 两位月（如 `2607`）
- `CsprojBuilderAppServiceBase` 编号生成逻辑已同步支持上述两种格式，行为与 `yyyyMMdd` / `yyMMdd` 一致。

## 避坑指南

- 若规则设置 `reset=true`，月份变化时自增序号会重置为 0；若需跨月连续递增，请将 `reset` 设为 `false`。
- 无需数据库迁移，枚举值存储在 `GenerateNumRules.GenerateEnum` 整型字段中。
