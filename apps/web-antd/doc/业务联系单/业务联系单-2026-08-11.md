# 背景意图

业务联系单列表需要展示船公司 Logo，且列表里的 `carrier` 对象此前只填了 `id`/`cnName`，前端拿不到简称、英文名、EDI 等字段。对齐海运出口列表写法。

# 核心逻辑变更

1. `PreOrderDto` 新增 `CarrierLogo`（`AttachmentItemDto`）。
2. `FillNamesAsync`（列表/`PreOrderTaskListAsync` 共用）：
   - `CarrierSimpleDto` 补齐 `Code`/`CnShortName`/`EnName`/`EdiCode`；
   - 批量拉取 `ModuleTypeIds.Bussiness.CarrierLogo`，按 `ItemId=CarrierId` 回填 `CarrierLogo`。
3. `FillDetailSimpleDtosAsync`（详情）同步回填 `CarrierLogo`。

# 避坑指南

- **Logo 在 `carrierLogo` 上，不在 `carrier` 对象内。** 与海运出口 `SeaExportDto.CarrierLogo` 一致，不要去 `carrier.logo` 取值。
- **无船公司或无附件时 `carrierLogo` 为 null。** 前端展示需判空。
