# 付费申请银行可空-2026-07-07

## 背景意图

- 业务要求将 `PaymentApplicationBank.ClientInvoiceBankId` 从必填改为可空，支持付费申请在未选银行时也可保存/编辑。

## 核心逻辑变更

- 实体可空化：
  - `PaymentApplicationBank.ClientInvoiceBankId` 从 `Guid` 改为 `Guid?`。
- DTO 可空化：
  - `PaymentApplicationBankAddDto.ClientInvoiceBankId` 改为 `Guid?`。
  - `PaymentApplicationBankEditDto.ClientInvoiceBankId` 改为 `Guid?`。
  - `PaymentApplicationBankDto.ClientInvoiceBankId` 改为 `Guid?`。
- 服务层校验调整：
  - 新增/编辑中提取银行ID时，仅取 `HasValue` 的记录参与校验。
  - `ValidatePaymentApplicationBanksAsync` 在无银行ID输入时直接返回，不再强制“每种币别必须选择银行”。
- 详情映射容错：
  - 币别分组映射银行时，仅处理 `ClientInvoiceBankId` 有值且导航实体存在的数据，避免空引用。

## 避坑指南

- 当前改造为“银行可空即允许不选”，因此不会再阻止无银行的付费申请提交；若后续需要在特定状态（如提交审核）强制选银行，需单独补状态化校验。
- 本次未生成 migration，数据库结构变更请按项目规范由维护人统一生成并执行。
