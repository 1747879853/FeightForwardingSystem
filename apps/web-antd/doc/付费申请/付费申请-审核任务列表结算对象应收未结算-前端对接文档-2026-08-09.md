# 付费申请 — 审核任务列表结算对象应收未结算（前端对接）

**变更日期**：2026-08-09  
**关联后端文档**：《付费申请-审核任务列表结算对象应收未结算-2026-08-09》  
**破坏性**：否（仅新增字段）

## 接口

| 项     | 内容                                                                |
| ------ | ------------------------------------------------------------------- |
| 方法名 | `PayAppTaskListAsync`                                               |
| 路由   | `GET /api/services/app/PaymentApplicationAdmin/PayAppTaskListAsync` |
| 权限   | `Admin.PaymentApplication.Audit`                                    |
| 返回   | `PagedList<PayAppTaskItemDto>`                                      |

## 字段变更

| 操作 | 字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| 新增 | `settlementReceivableGroup` | `PayAppSettlementReceivableGroupDto[]` | 该行付费申请结算对象的应收未结算金额，按币别分组合计；无欠款为 `[]` |

其余入参/出参不变。

### `settlementReceivableGroup[]`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `currencyId` | `number` | 币别id |
| `currencyCode` | `string` | 币别代码，如 `USD` / `CNY` |
| `unSettledAmount` | `number` | 该币别应收未结算合计（原币，2位小数，不乘汇率） |

## 业务口径（展示用）

1. 取当前行付费申请的结算对象。
2. 在业务费用表找：同一结算对象 + 收付类型=收 + 费用已审核通过 + 仍有未结算。
3. 未结算金额 = `费用金额 - 已结算金额`。
4. 按币别分组求和后返回。

与本行 `currencyGroup`（本申请申请金额分组）无关，不要拼到同一列展示逻辑里。

## 出参示例（节选）

```json
{
  "id": "...",

      "currencyCode": "CNY",

    }
  ]

```

## 前端注意

1. 空数组兜底：`item.settlementReceivableGroup ?? []`。
2. 建议展示为「币别 + 金额」多行/标签，例如 `USD 25,800.50`、`CNY 120,000.00`。
3. 不要把本字段当成「本申请可结算余额」；它是结算对象维度的应收欠款总览。
4. 已结清的币别不会出现在数组中。
