# 付费申请 — Client 对象化（前端对接）

**变更日期**：2026-07-24  
**关联文档**：《海运出口-往来单位与船公司对象化-前端对接文档-2026-07-24》（完整字段与迁移表）

## 接口

`GET /api/services/app/PaymentApplicationAdmin/GetOrderFeeGroupAsync`

返回项类型：`PayAppFeeGroupDto`（继承 `TransportOrderDto`）

## 字段变更

| 操作 | 字段 | 说明 |
| --- | --- | --- |
| 删除 | `clientName` | 原委托单位名字符串 |
| 新增 | `client` | `ClientSimpleDtoForOrder`：`id` / `name`(简称) / `fullName`(全称) / `address`(地址) / `enAddress`(英文地址) |

其它往来单位字段（`team`/`custBroker`/`warehouse`/`insurance`/`consignee`/`shipper`/`notifier`）随 `TransportOrderDto` 一并对象化，详见关联文档。

## 前端改造

```text
旧：item.clientName
新：item.client?.name   // 全称：item.client?.fullName
```
