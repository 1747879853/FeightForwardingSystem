## 1. 产品概述

### 1.1 业务背景

提单随海运出口主单、分单自动生成。操作在提单管理里做签入、换签、扣单、提交签出审核和签出。审核人在签出审核里按批次看申请放单、压单、后续新单、客户、欠费和历史异常，可以只通过或驳回其中几张。

### 1.2 核心价值

| 维度     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 操作粒度 | 提单行；提交审核和签出审核按同一结算对象的一批         |
| 使用场景 | 单证签入/签出；审核人放单前先看压单和客户欠款          |
| 下游影响 | 提单状态回到海出侧；通过后变为可签出，驳回后变为已驳回 |

### 1.3 不在本功能范围内

- 页面上不能新建、编辑、删除提单。存量海出不会补建提单。
- 没有打印、导出接口。
- 海运出口列表上的「提单状态」对接不在本次范围（另有需求，未随这次发布验收）。
- 没有启用的「提单签出」工作流时，提交审核会失败，这是环境前提，不是页面缺陷。

## 2. 目标用户与权限

| 角色               | 典型操作                                             |
| ------------------ | ---------------------------------------------------- |
| 操作 / 单证        | 检索、签入、换签、扣单、提交审核、签出               |

| 无海出查看权限的人 | 仍可看提单；详情里不出现「业务附件」                 |

| `Admin.BillOfLading.Swap` | 换签、取消换签 |

## 4. 页面结构

### 4.1 提单管理

- 顶部四张白底数量卡，高度约 72px。全部提单、待签出、超期未收切换列表；选中只描主色边，不铺底。超期未收大于 0 时只有数字变红。待我审核不筛选列表，右侧「进入」打开签出审核；数量大于 0 时数字为橙色。待我审核数字是审核子任务数，不是提单行数。
- 分组：委托单位、船公司、签单方式。空分组显示「未填写」。
- 无操作列。勾选后从顶部操作。双击行打开详情。单击提单号复制，双击仍进详情。
- 详情默认「基础信息」，另有「操作记录」「业务附件」。底部操作三个页签都在。内容区高度固定，页签内部滚动。

### 4.2 签出审核

- 默认筛选「待我审核」。双击批次行打开详情。没有「打开详情」按钮，也没有批次勾选列。
- 列表只留「批次状态」。悬浮看「我的审核状态」和本批审批流程。
- 详情摘要五格：申请人、申请时间、提单数量 / 未完成、本批未收、客户欠款。页签：申请放单、压单、后续新单、客户信息、应收欠费、客户历史异常。数量是浅底圆角胶囊。
- 申请放单的通过、驳回固定在表下。抽屉滚动时表头和合计不动，只滚数据行。

### 4.3 提单状态

| 状态值 | 名称       | 颜色 |
| ------ | ---------- | ---- |
| 0      | 待签入     | 橙   |
| 1      | 已签入     | 蓝   |
| 2      | 已驳回     | 红   |
| 3      | 签出审核中 | 金   |
| 4      | 可签出     | 青   |
| 5      | 已签出     | 绿   |
| 6      | 已扣单     | 品红 |

## 5. 业务规则（测试重点）

| 规则 ID | 规则描述 |
| --- | --- |
| R-01 | 只有待签入且正本可以签入。签入必须上传 1 个扫描件，日期默认当天 |
| R-02 | 非正本不能签入、不能换签。已换签不能取消签入 |
| R-03 | 换签、取消换签只在已签入或已驳回。换签是正本换电放，或恢复换签前方式。状态不变 |
| R-04 | 签出审核中、已扣单不能扣单。已扣单只能取消扣单，回到扣单前状态 |
| R-05 | 提交签出审核：每张都必须是已签入或已驳回，且结算对象 Id 相同、非空。可以一次多张。待签入不能进这批 |
| R-06 | 分单比的是分单结算对象，不是主单委托单位。未收和是否超期仍按主单 |
| R-07 | 提交时 `isOverdue=true` 的提单必须填承诺付款日期、超期备注、超期证明。承诺日期必须晚于主单应结日期。列表「超期未收」卡片不是这个字段 |
| R-08 | 撤销提交只针对整批，且这批还没有任何已审结果。传 `taskBaseId` |
| R-09 | 可签出才能签出。批量共用签出方式（快递/自提/外派/邮件/电子提单）和重新选择的签单方式。已签出取消签出回到可签出，不回退签单方式 |
| R-10 | 签入、取消签入、取消换签、取消扣单、取消签出、撤销提交一次只能选一张。换签、扣单、提交、签出可以多张（提交另受 R-05） |
| R-11 | 操作成功后列表重查，原勾选还在，按钮按新状态重算 |
| R-12 | 已驳回才显示驳回原因。来源是列表/详情的 `auditRemark`、`auditUserName`、`auditTime`。没填意见显示「未填写」。重新提交后不再显示上一轮意见 |
| R-13 | 提单号单击复制当前这一条，提示「已复制提单号」。同一格多个号码各自复制，不把顿号拼在一起的整段写入剪贴板。「未填提单号」不能复制。号码旁没有复制图标 |
| R-14 | 船名、航次、港口、委托单位等空值显示「未维护」。超期天数 0 显示「未超期」 |
| R-15 | 审核通过：提单仍是签出审核中，本人待审，任务未审。驳回未勾选的提单不受影响 |
| R-16 | 通过后驳回：提单已是可签出，本人和该张任务都已通过，只能驳回，不能再点通过 |
| R-17 | 已签出不能再从审核页驳回 |
| R-18 | 全选只勾当前可审核的提单。全部通过只勾「可以通过」的，再弹出原来的确认框。确认前不提交。只能驳回的行不会被全部通过勾上 |
| R-19 | 申请放单有压单时，该行淡橙底，行首红色「压单」。整批都没有压单时不占这一列。压单、后续新单的状态标签没有本人审核浮层 |
| R-20 | 申请放单、压单、后续新单：结算对象都一样时不重复结算对象列。分提单号、超期备注、审核人、审核意见整列为空才隐藏；有一张有内容就保留整列 |
| R-21 | 应收欠费表始终保留结算对象。藏掉会让合计行错位 |
| R-22 | 客户欠款 = 本页应收欠费按本位币分别加总未收，人民币和美元不要合成一个数。超期只统计超期天数大于 0；当天到期和未到期不写进红色「超期」 |
| R-23 | 欠费超期天数：负数绿色（未到期），0 黄色（当天到期），正数红色。客户历史异常里的「当前超期天数」未超期为 0，不套这套颜色 |
| R-24 | 表上金额是折算后本位币，带币种符号。本位币列显示代码（如 RMB），不要显示成符号。悬浮应收/已收/未收看折算前原币。没有原币明细时不画虚线、不出现浮层 |
| R-25 | 原币浮层挂在页面上，不要被表格或抽屉裁掉。列表未收金额悬浮时会现查本批原币，读取中和失败都要有一句说明 |
| R-26 | 工作流任务类型「提单签出」只允许用户或角色审核，不能配用户属性。条件：委托单位（属于/不属于，客户）、提交人组织（属于/不属于）、是否超期（是/不是） |

## 6. 接口清单

## 8. 验收标准（Must Have）

1. 正本可以从待签入走到已签入、提交审核、部分通过/驳回、可签出、已签出。
2. 已驳回在列表悬浮和详情顶部直接看到最近一次审核意见，不要求审核权限。
3. 审核人不用翻到表尾就能看到压单，摘要能看到本批未收和按币种分开的客户欠款。
4. 通过、驳回在申请放单表格下方；未确认不提交；未勾选的提单不变。
5. 原币悬浮不被表格裁切；本位币列是币种代码。
6. 无对应权限时按钮或页签按第 2 节隐藏，不出现 403 打断整页。

## 9. 已知风险与测试关注点

| 风险点 | 说明 | 测试建议 |
| --- | --- | --- |
| 环境没有提单签出工作流 | 提交审核失败 | 先在系统管理确认已启用任务类型「提单签出」。基础资料要有「正本」「电放」 |
| 超期两套口径 | 列表超期未收 ≠ 提交时的 `isOverdue` | 两处分开造数，不要互相代替 |
| 待我审核数字 | 子任务数，不是列表行数 | 不要把它当成提单筛选结果条数 |
| 分单结算对象为空 | 提交会被拦住 | 老分单要先补结算对象 |
| 客户欠款只统计当前详情里的应收欠费 | 不是全公司另一套报表 | 用详情欠费表手工按币种加总核对 |
| 审核浮层的本人状态 | 列表是整批，申请放单是单张提单 | 同一批里两处文案可以不同 |
| 文档旧行 | 活文档变更日志里还有一条「驳回原因另请求审核任务」 | 以现在的列表/详情字段为准，那条已过期 |

| 不同结算对象           | 2 张，确认不能同批提交                             |
| 已驳回                 | 1 张有审核意见，1 张意见为空                       |
| 可签出且原审核人仍登录 | 1 张，测通过后驳回                                 |
| 压单批次               | 申请放单里至少 1 张 `isHeldUp`                     |
| 多币种欠费             | 同一客户同时有人民币、美元未收，并含未到期负数天数 |
| 分单                   | 1 张有分提单号和结算对象，1 张结算对象为空         |
