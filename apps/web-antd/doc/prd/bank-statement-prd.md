## 1. 产品概述

### 1.1 业务背景

银行流水用于登记客户实际到账的收款记录（金额、币别、付款方、我司/对方银行等）。一条流水可关联多张**收费结算单**，财务据此把到账金额分摊到具体应收费用上。

### 1.2 核心价值

| 维度     | 说明                                                    |
| -------- | ------------------------------------------------------- |
| 操作粒度 | 一条银行流水 = 一笔到账记录                             |
| 使用场景 | 财务录入/维护到账流水，并从流水页快捷创建或查看收费结算 |
| 下游影响 | 收费结算必须绑定银行流水；流水总金额约束各结算单合计    |

### 1.3 不在本功能范围内

- 不直接结算费用（结算动作在收费结算模块）
- 不提供审核/锁定流水的前端操作
- 列表「结算对象」筛选项对应接口字段 `settlementId`，表单中同字段展示为「付款方」

## 2. 目标用户与权限

### 2.1 角色

| 角色       | 典型操作                                          |
| ---------- | ------------------------------------------------- |
| 财务       | 新建/编辑流水、查看关联收费结算、快捷新建收费结算 |
| 无权限用户 | 不可见菜单                                        |

### 2.2 权限点（ABP）

| 权限                         | 说明                         |
| ---------------------------- | ---------------------------- |
| `Admin.BankStatement`        | 页面访问（列表、编辑页查看） |
| `Admin.BankStatement.Add`    | 新建按钮、新建页保存         |
| `Admin.BankStatement.Edit`   | 编辑页保存、操作人增删       |
| `Admin.BankStatement.Delete` | 列表删除                     |

**关联权限：** 银行流水编辑页「新建收费结算」按钮依赖 `Admin.ReceiveSettlement.Add`（与收费结算模块独立）。

**测试前置：** 准备具备完整银行流水权限的账号；另备仅有查看权限（无 Edit）账号验证只读编辑页。

## 4. 页面结构

### 4.1 列表页

- **布局：** 查询区（默认折叠）+ 表格 + 分页；查询区一行六列，`labelWidth=64`。
- **交互：** 勾选行 + 顶部工具栏操作；**双击行**进入编辑页；无操作列。
- **默认排序：** `statementTime desc`。

**查询字段：**

| 字段 | 接口参数 | 说明 |
| --- | --- | --- |
| 流水号 | `bankStatementNo` | 模糊 |
| 结算对象 | `settlementId` | 客户下拉 |
| 币别 | `currencyId` |  |
| 交易时间 | `statementTimeStart` / `statementTimeEnd` | 范围，占两列；按日拆分为当天 00:00–23:59 |
| 创建人 | `creatorUserId` |  |
| 组织 | `orgId` |  |

**列表列：**

| 列                | 说明                    |
| ----------------- | ----------------------- |
| 流水号            |                         |
| 交易时间          | 格式 `YYYY-MM-DD HH:mm` |
| 付款方            | `settlementName`        |
| 总金额            | 右对齐，两位小数        |
| 币别              |                         |
| 我司银行          |                         |
| 手续费            | 无值显示 `-`            |
| 操作人            | 多人以 `/` 拼接         |
| 所属公司          | 取第一个公司名          |
| 创建人 / 创建时间 |                         |
| 交易备注          | 溢出省略                |

### 4.2 新建/编辑页

**布局：**

- **新建页：** 标题行「操作人」（Tag + Popover）+ 左「流水信息」；保存后跳转编辑页。
- **编辑页：** 标题行操作人；左 40%「流水信息」（含核销状态 Tag）；右 60%「关联收费结算」（全列、搜索、分页、行展开只读明细、双击跳转）；底部全宽「选择费用并创建结算单」（需 `Admin.ReceiveSettlement.Add`）。

**流水信息字段：**

| 字段 | 新建 | 编辑 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| 流水号 | 无 | 只读文本 | — | 后端生成 |
| 交易时间 | 可编辑 | 可编辑\* | 是 | 日期选择，无时分 |
| 币别 | 可编辑 | 可编辑\* | 是 |  |
| 付款方 | 可编辑 | 可编辑\* | 是 | `ClientSelect` |
| 总金额 | 可编辑 | 可编辑\* | 是 | ≥0，精度 2 |
| 手续费 | 可编辑 | 可编辑\* | 否 | ≥0，精度 2 |
| 我司银行 | 可编辑 | 可编辑\* | 否 |  |
| 对方银行 | 可编辑 | 可编辑\* | 否 | 须先选付款方；换付款方清空 |
| 交易备注 / 留言 / 备注 | 可编辑 | 可编辑\* | 否 |  |

\* 无 `Edit` 权限时编辑页字段只读，保存按钮隐藏。

**操作人（标题行）：**

- Tag 展示已选操作人，Popover 内增删行；每行：操作人（UserSelect）+ 备注。
- 空状态提示：「未配置时，所有人均可在非 Admin 端查看」。
- 保存时仅提交已选 `operationId` 的行。

**保存行为：**

- 新建成功 → 提示「创建成功」→ **跳转编辑页**（`replace` 到 `/bank-statement/edit/:id`）。
- 编辑成功 → 提示「保存成功」，停留当前页。

**关联收费结算（仅编辑页，右侧 Card）：**

- 按 `bankStatementId` 分页加载；可按结算单号模糊搜索。
- 列：结算单号、结算状态（Tag 中文）、结算时间、明细总金额、明细条数、锁定状态、锁定时间、创建人、创建时间、备注。
- **行展开** → 调 `ReceiveSettlementAdmin/DetailAsync` 展示只读费用明细。
- **双击行** → 跳转收费结算编辑页。
- 无「新建收费结算」按钮；建单走底部选费区。

**底部选费建单（仅编辑页，需 Add 权限）：**

- 复用收费结算 `GetOrderFeeGroupAsync` 分组选费；勾选费用后点击「创建结算单」直接建单（结算时间取当前时间）。
- 「创建结算单」调用 `ReceiveSettlementAdmin/AddAsync`；成功后停留本页并刷新关联列表。

## 5. 业务规则（测试重点）

| 规则 ID | 规则描述 |
| --- | --- |
| R-01 | 列表删除**每次只能选一条**；未选或多选均提示 |
| R-02 | 前端必填：总金额、币别、交易时间、付款方；缺任一项保存前 `message.warning` |
| R-03 | 切换付款方时，对方银行自动清空 |
| R-04 | 新建成功后必须进入编辑页，不应回到列表 |
| R-05 | 从表单页返回列表时，列表应刷新（`markListShouldRefresh`） |
| R-06 | 关联收费结算子表仅在编辑态展示；新建页不可见 |
| R-07 | 流水与收费结算为 1:N；同一流水可有多张收费结算单 |
| R-08 | 删除流水若后端有关联结算单等业务约束，应验证后端报错提示（待确认具体规则） |

## 7. 测试用例（建议）

### 7.1 入口与权限

| 用例 ID | 步骤 | 期望结果 |
| --- | --- | --- |
| TC-001 | 无 `Admin.BankStatement` 账号访问 `/bank-statement` | 无菜单或 403 |
| TC-002 | 有 Get 无 Add 权限 | 列表可见，「新建」隐藏 |
| TC-003 | 有 Get 无 Edit 权限，双击进入编辑页 | 字段只读，无保存按钮 |
| TC-004 | 有 Get 无 Delete 权限 | 「删除」按钮隐藏 |

### 7.2 主流程

| 用例 ID | 步骤                          | 期望结果                           |
| ------- | ----------------------------- | ---------------------------------- |
| TC-101  | 新建：填必填项 → 保存         | 成功跳转编辑页，流水号有值         |
| TC-102  | 编辑：修改总金额、备注 → 保存 | 保存成功，列表数据更新             |
| TC-103  | 编辑页添加操作人并保存        | 列表「操作人」列展示对应姓名       |
| TC-104  | 编辑页「新建收费结算」        | 进入收费结算新建页，银行流水已预填 |

| 用例 ID | 步骤                             | 期望结果                     |

## 9. 已知风险与测试关注点

| 风险点 | 说明 | 测试建议 |
| --- | --- | --- |
| 删除约束 | 前端未校验是否有关联收费结算，依赖后端 | 有关联结算单时尝试删流水，记录后端提示 |
| 列表 vs 表单字段名 | 列表筛「结算对象」，表单填「付款方」，同一 `settlementId` | 勿报字段不一致缺陷 |
| 操作人权限语义 | 空操作人 = 非 Admin 端全员可见 | 与产品/后端确认 Admin 端是否也受限制 |
| 交易时间精度 | 表单仅选日期，列表展示到分钟 | 核对后端存储与时区 |
| 模块活文档缺失 | 无 `doc/modules/bank-statement.md` | 以本 PRD 与代码为准 |
