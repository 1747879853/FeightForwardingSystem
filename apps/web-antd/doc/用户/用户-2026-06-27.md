# 1. 背景意图 (Background)

两个用户相关接口需补充返回字段：

1. `UserAdminAppService.GetUserForEditAsync`（后台编辑单个用户）需**额外返回**该用户所属的**部门id、部门名字、公司id、公司名字**；无对应值时返回 `null`。
2. `UserAdminAppService.GetMyAsync`（获取自己的信息）需**额外返回当前公司的 `OrgBankAccounts`** 对应 DTO 列表，供前端展示本公司银行账户。

公司/部门的口径沿用系统既有约定：在用户所属组织架构层级（从根到叶）中，**公司 = 最底层 `IsCompany=true` 节点**，**部门 = 最底层 `IsCompany=false` 节点**。

# 2. 核心逻辑变更 (Core Logic)

涉及文件：

- `src/CsprojBuilder.Application/Authorization/Users/UserAdminAppService.cs`（`GetUserForEditAsync`、`GetMyAsync`、构造函数）
- `src/CsprojBuilder.Application/Authorization/Users/Dto/UserInputDto.cs`（`UserInAdminDataPermissionDto`、`MyDto`）

## 2.1 GetUserForEditAsync 返回结构变更（`UserInAdminDataPermissionDto`）

新增 4 个字段（均可空，无值返回 `null`）：

| DTO 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `DepartmentId` | `long?` | 部门Id（组织层级最底层 `IsCompany=false` 节点） |
| `DepartmentName` | `string` | 部门名字 |
| `CompanyId` | `long?` | 公司Id（组织层级最底层 `IsCompany=true` 节点） |
| `CompanyName` | `string` | 公司名字 |

填充逻辑复用基类 `GetUserOrganizationHierarchy(userId)`：

```
var orgs = GetUserOrganizationHierarchy(input.Id);
var company = orgs.LastOrDefault(o => o.IsCompany);
var department = orgs.LastOrDefault(o => !o.IsCompany);
```

> 既有 `OrganizationId`/`OrganizationName`（来自 `UserManager.GetOrganization`，用户直接所属组织）**保持不变**，未与新字段混用。

## 2.2 GetMyAsync 返回结构变更（`MyDto`）

`MyDto` 新增 `Company`（`OrganizationUnitDto`）：取**当前公司**（已解析出的 `company` 节点，`OrganizationUnitEx`）映射为公司 DTO，无公司时为 `null`。`CompanyId`/`CompanyName` 保留为原平铺字段。

公司银行账户 **`OrgBankAccounts` 放在 `Company` DTO 内**（`OrganizationUnitDto.OrgBankAccounts`）：取该公司下的银行账户，按 `SortId` 排序，逐条 `Map<OrgBankAccountDto>` 并回填 `CurrencyCode`，无账户时为空列表。公司本位币 `LocalCurrencyCode` 按 `LocalCurrencyId` 回填。

> 复用既有 `OrganizationUnitDto`（`[AutoMapFrom(typeof(OrganizationUnitEx))]` 且自带 `OrgBankAccounts`），未污染共享的 `CompanySimpleDto`（其被发票备注模板等模块外键引用）。

## 2.3 依赖注入变更

`UserAdminAppService` 构造函数新增注入 `IRepository<OrgBankAccount, Guid> _orgBankAccountRepository`；新增 `using Abp.Organizations;` 与 `using CsprojBuilder.Organizations.Dto;`。

# 3. 避坑指南 (Pitfalls)

- **公司/部门来自组织层级链，不是直接所属组织**：取的是层级链中“最底层”的公司/部门节点，与 `UserManager.GetOrganization`（直接所属组织）是两套口径，前端不要混淆。
- **GetUserForEditAsync 无值返回 `null`**：用户未分配组织、或链中缺公司/部门节点时，对应 4 个字段为 `null`。
- **GetMyAsync 的 `OrgBankAccounts` 现位于 `Company` DTO 内**：不再平铺在 `MyDto` 上；无公司时 `Company` 为 `null`，有公司无账户时 `Company.OrgBankAccounts` 为空列表。
- **银行账户取“当前公司”维度**：按 `OrgBankAccount.OrganizationUnitId == company.Id` 过滤，未按部门；排序沿用 `SortId`，与组织模块 `GetOrgBankAccountListAsync` 一致。
- **`CurrencyCode` 非实体字段**：`OrgBankAccountDto.CurrencyCode` 需按 `CurrencyId` 关联币别回填，AutoMapper 不会自动赋值。
