# 自动费用模板管理

## 功能概述

自动费用模板管理模块用于配置海运出口业务中的自动费用生成规则。通过预设模板，系统可以根据订单条件自动匹配并生成相应的费用项。

## 文件结构

```
OrderFeeTemplateAdmin/
├── list.vue              # 列表管理页面
├── data.ts               # 表格列定义和表单配置
└── modules/
    └── form.vue          # 新建/编辑表单（含handsontable费用录入）
```

## 主要功能

### 1. 列表页面 (list.vue)

**布局特点：**

- 左侧：起运港分组统计面板
- 右侧：模板列表表格

**功能特性：**

- ✅ 按起运港分组展示模板数量
- ✅ 点击分组可筛选对应港口的模板
- ✅ 支持多条件查询（模板名称、业务类型、收付类型等）
- ✅ 双击行直接进入编辑模式
- ✅ 支持批量删除
- ✅ 支持新建模板

**查询条件：**

- 模板名称（模糊查询）
- 业务类型
- 收付类型
- 是否长期有效
- 委托单位
- 起运港
- 目的港
- 服务项

### 2. 表单页面 (modules/form.vue)

**页面布局：**

- 上半部分：基础信息填写区
- 下半部分：费用明细录入区（使用Handsontable组件）

**基础信息字段：**

- 模板名称（必填，最长64字符）
- 业务类型（必填，默认：海运出口）
- 收付类型（必填，0=收，1=付）
- 是否长期有效（开关）
- 生效时间范围（非长期有效时显示）
- 委托单位（可选，为空表示适用所有）
- 贸易条款（可选）
- 货物类型（可选）
- 付费方式（可选）
- 业务来源（可选）
- 船公司（可选）
- 订舱代理（可选）
- 起运港（可选）
- 目的港（可选）
- 装运方式（可选）
- 服务项（可选）
- 排序号
- 备注（最长4096字符）

**费用明细字段（Handsontable）：**

- 服务项（数字，可选）
- 费用代码（下拉选择，必填）
- 行业类别（下拉选择：客户/承运人，必填）
- 结算对象（文本，必填）
- 币别（下拉选择，必填）
- 含税单价（数字，必填）
- 不含税单价（数字，必填）
- 单位（文本，如：票、重量、体积、TEU等）
- 税率（百分比，必填）
- 排序号（数字）
- 备注（文本）

**Handsontable功能：**

- ✅ 右键菜单：添加行、删除行
- ✅ 自动换行
- ✅ 最小空行数：1（保证至少有一行可编辑）
- ✅ 数据类型验证（数字、下拉等）

## API接口

使用的API接口定义在 `apps/web-antd/src/api/sea-export/order-fee-template-admin.ts`：

- `addOrderFeeTemplate` - 新增模板
- `editOrderFeeTemplate` - 编辑模板
- `copyOrderFeeTemplate` - 复制模板
- `deleteOrderFeeTemplate` - 删除模板
- `getOrderFeeTemplateDetail` - 获取模板详情
- `getOrderFeeTemplatePagedList` - 获取分页列表
- `getPolGroupList` - 获取起运港分组统计

## 权限控制

需要以下权限：

- `Admin.OrderFeeTemplate.Add` - 新建权限
- `Admin.OrderFeeTemplate.Edit` - 编辑权限
- `Admin.OrderFeeTemplate.Delete` - 删除权限

## 使用示例

### 新建模板流程

1. 点击"新建"按钮
2. 填写基础信息（模板名称、业务类型、收付类型为必填）
3. 在费用明细区域添加费用项：
   - 右键点击表格 → "row_below" 添加新行
   - 选择费用代码、行业类别、币别等
   - 输入单价、税率等信息
4. 点击"确定"保存

### 编辑模板流程

1. 双击列表中的某一行
2. 修改基础信息或费用明细
3. 点击"确定"保存

### 批量删除流程

1. 勾选要删除的模板（复选框）
2. 点击"批量删除"按钮
3. 确认删除操作

## 注意事项

1. **费用明细至少一条**：保存时必须至少有一条费用明细
2. **下拉数据源**：当前版本中费用代码、币别等下拉数据需要从API加载，实际使用时需要补充对应的API调用
3. **Handsontable许可证**：当前使用评估版许可证（non-commercial-and-evaluation），生产环境需要购买商业许可证
4. **港口分组统计**：左侧分组面板会实时根据查询条件更新统计数据
