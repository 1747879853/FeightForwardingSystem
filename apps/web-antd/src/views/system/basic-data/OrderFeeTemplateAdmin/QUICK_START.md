## 2. 快速上手

### 2.1 新建第一个模板

**步骤：**

1. **点击"新建"按钮**
   - 位置：列表页面右上角工具栏

2. **填写基础信息**

   ```
   模板名称：上海-洛杉矶标准费用模板
   业务类型：海运出口（默认）
   收付类型：应收
   长期有效：开启
   起运港：上海
   目的港：洛杉矶
   ```

3. **添加费用明细**
   - 在费用明细表格中右键 → 选择"row_below"添加行
   - 填写第一行：
     ```
     费用代码：海运费
     行业类别：承运人
     结算对象：COSCO
     币别：USD
     含税单价：2000
     不含税单价：1886.79
     单位：TEU
     税率：6
     ```
   - 继续添加其他费用项（文件费、THC等）

4. **保存**
   - 点击弹窗底部的"确定"按钮
   - 看到成功提示后返回列表

### 2.2 编辑已有模板

**方法一：双击行**

- 在列表中直接双击要编辑的模板行

**方法二：操作按钮**

- 点击右侧"操作"列的编辑按钮

### 2.3 批量删除

1. 勾选要删除的模板（左侧复选框）
2. 点击"批量删除"按钮
3. 确认删除操作

| 业务类型 | ✅   | 目前只有海运出口   | 海运出口                |
| 收付类型 | ✅   | 0=应收，1=应付     | 应收                    |
| 长期有效 | ❌   | 开关，默认开启     | 是                      |
| 生效时间 | 条件 | 非长期有效时必填   | 2026-01-01 ~ 2026-12-31 |
| 委托单位 | ❌   | 留空表示所有客户   | ABC公司                 |
| 贸易条款 | ❌   | 留空表示所有条款   | FOB                     |
| 货物类型 | ❌   | 留空表示所有类型   | 普通货物                |
| 船公司   | ❌   | 留空表示所有船公司 | COSCO                   |
| 订舱代理 | ❌   | 留空表示所有代理   | XYZ代理                 |
| 起运港   | ❌   | 留空表示所有港口   | 上海                    |
| 目的港   | ❌   | 留空表示所有港口   | 洛杉矶                  |
| 装运方式 | ❌   | MBL主单/HBL分单    | MBL                     |
| 服务项   | ❌   | 数字，留空表示所有 | 1                       |
| 排序     | ❌   | 数字，越小越靠前   | 0                       |
| 备注     | ❌   | 最长4096字符       | 适用于美西航线          |

| 字段       | 必填 | 说明               | 示例          |

## 5. Handsontable操作技巧

### 5.1 添加行

**方法一：右键菜单**

- 右键点击任意单元格
- 选择"Insert row above"（在上方插入）
- 或"Insert row below"（在下方插入）

**方法二：滚动到底部**

- 表格会自动保留一个空行
- 直接在空行中输入即可

### 5.2 删除行

1. 右键点击要删除的行
2. 选择"Remove row"

### 5.3 复制粘贴

- 支持Excel格式的复制粘贴
- 选中单元格区域 → Ctrl+C → 在其他位置Ctrl+V

### 5.4 快捷键

| 快捷键    | 功能               |
| --------- | ------------------ |
| Tab       | 移动到下一个单元格 |
| Shift+Tab | 移动到上一个单元格 |
| Enter     | 移动到下一行       |
| Ctrl+C    | 复制               |
| Ctrl+V    | 粘贴               |
| Delete    | 清空单元格         |

## 6. 常见问题FAQ

### Q1: 为什么看不到"新建"按钮？

**A**: 检查是否有`Admin.OrderFeeTemplate.Add`权限。联系管理员分配权限。

### Q2: 费用代码下拉选项为空？

**A**: 当前版本需要从API加载费用代码列表。需要在`form.vue`的`loadDropdownData()`函数中添加：

```typescript
const feeCodes = await getFeeCodeList();
feeCodeList.value = feeCodes.map((item) => ({
  label: item.cnName,
  value: item.id,
  currencyId: item.currencyId,
}));
```

### Q3: 保存时提示"至少需要一条费用明细"？

**A**: 确保Handsontable表格中至少有一行数据，且必填字段都已填写。

### Q4: 如何快速复制一个模板？

**A**:

1. 双击打开要复制的模板
2. 修改模板名称（如添加"副本"）
3. 点击"确定"保存为新模板

或者使用API的复制功能（需要前端实现UI）。

### Q5: 起运港分组统计不准确？

**A**:

1. 点击查询表单的"重置"按钮
2. 重新执行查询
3. 分组统计会自动更新

### Q6: Handsontable有水印？

**A**: 当前使用的是评估版许可证。生产环境需要购买商业许可证： https://handsontable.com/pricing

### Q7: 如何设置模板只对特定组织可见？

**A**: 在基础信息中填写"适用组织ID"字段。留空表示对所有组织可见。

### Q8: 能否导入Excel模板？

**A**: 当前版本不支持。后续可以添加Excel导入功能。

## 7. 最佳实践

### 7.1 命名规范

**推荐格式：**

```
{起运港}-{目的港}-{收付类型}-{用途}模板

示例：
- 上海-洛杉矶-应收-标准模板
- 深圳-应付-COSCO专用模板
- 宁波-应收-ABC客户模板
```

### 7.2 模板分类建议

**按维度分类：**

1. **按港口**：每个主要港口创建独立模板
2. **按船公司**：为每个船公司创建专用模板
3. **按客户**：为大客户创建专属模板
4. **按航线**：美西线、欧地线、东南亚线等

### 7.3 费用明细组织

**排序建议：**

1. 主要费用（海运费、空运费）
2. 港口费用（THC、港建费）
3. 操作费用（文件费、报关费）
4. 其他费用（保险、杂费）

### 7.4 定期维护

**建议每月检查：**

- 过期的模板（非长期有效）
- 价格变动的费用项
- 新增的费用类型
- 不再使用的模板（可删除）
