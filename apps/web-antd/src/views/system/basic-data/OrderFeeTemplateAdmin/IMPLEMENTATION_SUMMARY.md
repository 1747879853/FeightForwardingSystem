### 2. 核心功能

#### 2.1 列表页面 (list.vue)

**布局特点：**

- 左侧起运港分组统计面板（240px宽）
- 右侧查询表单 + 数据表格（自适应宽度）

**功能特性：** ✅ 按起运港分组展示模板数量  
✅ 点击分组筛选对应港口的模板  
✅ 多条件查询（8个查询字段）  
✅ 双击行进入编辑模式  
✅ 批量删除功能  
✅ 新建功能  
✅ 远程排序支持  
✅ 权限控制（新建、编辑、删除）

**表格列（共22列）：**

- 复选框、模板名称、业务类型、收付类型、长期有效
- 生效时间范围、委托单位、起运港、目的港
- 船公司、订舱代理、贸易条款、货物类型、装运方式
- 服务项、费用明细数、创建人、创建时间
- 修改人、修改时间、备注、操作

#### 2.2 表单页面 (modules/form.vue)

**页面布局：**

- 上半部分：基础信息卡片（19个字段）
- 下半部分：费用明细卡片（Handsontable表格）

**基础信息字段：**

1. 模板名称（必填）
2. 业务类型（必填，默认：海运出口）
3. 收付类型（必填，0=收，1=付）
4. 是否长期有效（开关）
5. 生效开始时间（条件显示）
6. 生效结束时间（条件显示）
7. 委托单位（ClientSelect组件）
8. 贸易条款（枚举选择）
9. 货物类型（枚举选择）
10. 付费方式（文本输入）
11. 业务来源（文本输入）
12. 船公司（CarrierSelect组件）
13. 订舱代理（ClientSelect组件，行业类别=o）
14. 起运港（PortSelect组件）
15. 目的港（PortSelect组件）
16. 装运方式（枚举选择）
17. 服务项（数字输入）
18. 排序号（数字输入）
19. 备注（多行文本）

**费用明细字段（Handsontable）：**

1. 服务项（数字）
2. 费用代码（下拉选择，必填）
3. 行业类别（下拉选择，必填）
4. 结算对象（文本，必填）
5. 币别（下拉选择，必填）
6. 含税单价（数字，必填）
7. 不含税单价（数字，必填）
8. 单位（文本，必填）
9. 税率%（数字，必填）
10. 排序（数字）
11. 备注（文本）

**Handsontable功能：** ✅ 右键菜单（添加行、删除行）  
✅ 自动换行  
✅ 最小空行数：1  
✅ 数据类型验证  
✅ 数值格式化（保留2位小数）

## 注意事项

### 1. Handsontable许可证

当前使用的是评估版许可证：

```typescript
licenseKey: 'non-commercial-and-evaluation';
```

**生产环境必须购买商业许可证**，否则会有水印和功能限制。

购买链接：https://handsontable.com/pricing

### 2. 权限配置

需要在ABP系统中配置以下权限：

| 权限标识                      | 说明     |
| ----------------------------- | -------- |
| Admin.OrderFeeTemplate.Add    | 新建权限 |
| Admin.OrderFeeTemplate.Edit   | 编辑权限 |
| Admin.OrderFeeTemplate.Delete | 删除权限 |

### 3. 枚举值加载

所有枚举值都通过 `getEnumItems()` 从缓存加载，确保：

- 枚举名称正确（BizType、PaySide等）
- 缓存已初始化（在应用启动时）

### 4. SimpleDto对象访问

接口返回的数据使用了SimpleDto对象化设计，访问时需要：

```typescript
// 正确
record.client?.clientName;
record.pol?.portName || record.pol?.cnName;

// 错误（旧字段已删除）
record.clientName; // ❌ 不存在
record.polName; // ❌ 不存在
```
