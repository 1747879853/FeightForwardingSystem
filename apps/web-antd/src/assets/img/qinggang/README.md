# 青港品牌素材

素材提取自公司提供的《青港logo总.pdf》第 1 页，保留原稿图形、配色及中英文字样，未重新绘制。PDF 内原稿为位图，因此这些文件不是矢量图。

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| logo.png | 432 × 432 | 方形图标，侧栏、偏好设置及站点图标来源 |
| logo-text.png | 235 × 54 | 彩色横版，首屏及路由加载 |
| logo-login.png | 2170 × 725 | 登录页专用：左侧蓝色图标，右侧中文、分隔线、The 及英文均为白色，透明背景 |
| logo-stacked.png | 380 × 576 | 图形与青港国际文字的竖版组合 |
| logo-dark.png | 560 × 160 | 黑底亮蓝横版，备用深色背景版本 |

logo-text.png 与 logo-login.png 已使用 imagegen 去除白底，包含真实 Alpha 透明通道（图标内部白色镂空也透明）；logo.png 和 logo-stacked.png 保留原稿白底，logo-dark.png 保留黑底。系统现有品牌配置已引用前三个文件；后两个是备用素材。

横版 logo-text.png、logo-login.png、logo-dark.png 左侧保留原稿图形，右侧使用「青港国际」+ 分隔线与花体 The +「QING GANG INTERNATIONAL」组合，不含公司全称。

加载图片 logo-text.png 与 hhyy 同为 235 × 54px；裁去原图外围透明留白后等比例缩放并居中，保留透明背景。
