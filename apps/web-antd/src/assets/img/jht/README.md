# 津海通（jht）品牌资源

`pnpm build:jht` / `pnpm dev:jht`（根目录 `pnpm dev:antd:jht`）会使用本目录下的图片，请替换为津海通正式素材。

浩瀚远洋请使用 `pnpm dev:antd:hhyy` / `pnpm build:antd:hhyy`（素材见 `../hhyy/`）。

| 文件 | 用途 |
| --- | --- |
| `logo.png` | 侧栏 / 系统偏好 Logo |
| `logo-text.png` | 首屏 Loading、路由切换 Loading（建议透明底 PNG；深蓝/彩色 Logo 与默认黑底渐变素材滤镜表现不同） |
| `logo-login.png` | 登录页 `auth-title-logo`（可由设计稿 `jht-logo-login.png` 导出替换） |
| `login-back.mp4` | 登录页背景视频 |
| `favicon.png` | 浏览器标签页图标（可选，缺省则回退默认 `public/favicon.png`） |
