# 世纪通达（sjtd）品牌资源

`pnpm build:sjtd` / `pnpm dev:sjtd`（根目录 `pnpm build:antd:sjtd` / `pnpm dev:antd:sjtd`）使用本目录图片。

| 文件             | 用途                                            |
| ---------------- | ----------------------------------------------- |
| `logo.png`       | 侧栏 / 系统偏好 Logo                            |
| `logo-text.png`  | 首屏 Loading、路由切换 Loading                  |
| `logo-login.png` | 登录页 `auth-title-logo`                        |
| `favicon.png`    | 浏览器标签页图标（可选，缺省则回退 `logo.png`） |

登录页背景视频暂复用浩瀚远洋 OSS 地址，可按需单独上传 `sjtd-login-back.mp4` 后改 `brand-assets.ts`。

其他品牌素材见 `../hhyy/README.md`、`../jht/README.md`。
